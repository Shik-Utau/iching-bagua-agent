# 归妹卦（震上兑下）

**卦画**：䷵

## 总论：婚媾之道的哲学

**核心短词**：“永终知敝”

**卦象**：上震（☳）为雷、为动、为长男，下兑（☴）为泽、为悦、为少女。雷泽归妹。泽上有雷，少女欣悦而动，长男以动娶之。

**核心卦辞**：“征凶，无攸利。”

**总纲**：归妹卦象征 “婚嫁”。前行有凶险，无所利益。

+ “征凶，无攸利”：卦辞 开门见山，直言凶险。这并非否定婚嫁本身，而是针对 “归妹”这一特定婚嫁形式 发出的 严厉警告。“归妹”特指 “少女出嫁”，但卦象中 少女（兑）在下位欣悦（悦），长男（震）在上位躁动（动），形成 “悦以动” 的组合。这暗示婚嫁的动机可能 过于侧重情感上的欣悦与冲动，而 缺乏礼制的规范、长远的考虑和正当的名分，故 前行凶险，无利可图。

**本质**：归妹卦描述 “泽上有雷” 的状态。雷（震）动于上，泽（兑）悦于下，象征一种 以情感悦动为基础，但可能失之轻率、不正 的 结合关系。其**核心精神**是：以 “婚嫁” 为喻，探讨人际结合（特别是婚姻）中，若 不遵循正道、不顾及长远、不确立名分，将 导致的弊端与凶险。它强调 “永终知敝”——在结合之初，就要 预见到可能的弊病，并思考如何保持长久。

## 卦辞



### 经

**原文**：征凶，无攸利。

**白话**：前进有凶险，无所利益。

### 彖传

**原文**：归妹，天地之大义也。天地不交而万物不兴，归妹，人之终始也。说以动，所归妹也。“征凶”，位不当也。“无攸利”，柔乘刚也。

**白话**：归妹卦，体现的是天地间重要的道理。如果天地阴阳不交合，万物就不能繁衍兴旺，归妹所代表的婚嫁，是人类延续和发展的开端。喜悦而行动，所以嫁出少女。“出征有凶险”，是因为所处的位置不恰当。“无所利益”，是因为阴柔凌驾于阳刚之上。

### 大象传

**原文**：泽上有雷，归妹；君子以永终知敝。

**白话**：水泽之上响动着雷声，象征婚嫁；君子因此要长久保持至终，并知晓其中的弊害。


## 爻辞

### 初九：归妹以娣，跛能履，征吉。


**原文**：归妹以娣，跛能履，征吉。

**白话**：出嫁时以娣（妹妹）的身份陪嫁，像跛脚者努力行走，前进吉祥。

**小象传**
**原文**：“归妹以娣”，以恒也。“跛能履吉”，相承也。

**白话**：嫁出少女以妹妹陪嫁，是为了维持长久婚姻关系。跛脚却能行走吉祥，是因为有人扶持辅助。


**说明**

这是 归妹的初始——地位虽卑，安分守正。

+ “归妹以娣”：出嫁作为侧室（娣）。
+ “跛能履”：犹如跛足者（跛）努力行走（能履）。
+ “征吉”：前行可获吉祥（征吉）。
+ 爻传“归妹以娣，以恒也；跛能履，吉相承也”：出嫁作为侧室，是为了维持恒常之道；跛足者能行走，吉祥在于能承助正室。

**相关性**：初九阳刚处下，地位卑微，如 随嫁的“娣”（侧室、妹妹）。“归妹以娣”点明其 非正配的身份。“跛能履”是 生动的比喻：跛足 象征其 地位不正，有所缺陷；但 “能履” 表示其 安于本分，尽力履行辅助的职责。因其 不僭越，能守恒道，辅助正室（相承），故 前行可得吉祥。此爻阐明：在不完美的结合关系中， 认清自身位置，恪守本分，尽己所能，是 趋吉避凶的基础。


### 九二：眇能视，利幽人之贞。


**原文**：眇能视，利幽人之贞。

**白话**：一只眼盲而勉强能看，利于幽居之人守持正固。

**小象传**
**原文**：“利幽人之贞”，未变常也。

**白话**：利于隐士坚守正道，是因为没有改变恒常的准则。


**说明**

这是 归妹的守持——才德被掩，静处守贞。

+ “眇能视”：眼盲（眇）而勉强能看（能视）。
+ “利幽人之贞”：利于幽居之人（幽人）守持正固（利贞）。
+ 爻传“利幽人之贞，未变常也”：利于幽居之人守持正固，说明（九二）未曾改变恒常之道。

**相关性**：九二阳刚居中，有贤德，但与六五阴柔之君 并非正应（五爻为阴，二爻为阳，虽相应但非阴阳正配），象征才德之士 未遇明主，或身处不当的婚姻关系。“眇能视”比喻其 贤明（视） 受到 遮蔽或限制（眇），才能 无法充分发挥。“幽人”指 隐居、不显山露水之人。爻辞劝告：在此境遇下，最有利的做法是 如同“幽人”一般， 深居简出，守持内心的贞正与常道（未变常），静待时机，而非 强求表现或结合。此爻强调：当 所处关系不正或环境不利 时，内在的贞固与等待，比 外在的躁进 更为重要。


### 六三：归妹以须，反归以娣。


**原文**：归妹以须，反归以娣。

**白话**：出嫁时期盼成为正室，反而只能以娣的身份陪嫁而归。

**小象传**
**原文**：“归妹以须”，未当也。

**白话**：嫁妹时陪嫁的妾室，这种做法是不妥当的。


**说明**

这是 归妹的妄求——自视过高，反遭贬抑。

+ “归妹以须”：出嫁时以姐姐（须）的身份期待正室之位。
+ “反归以娣”：反而被当作侧室（娣）嫁回（反归）。
+ 爻传“归妹以须，未当也”：出嫁时以姐姐的身份期待正室之位，说明（六三）行为不当。

**相关性**：六三阴柔不中不正，处下卦之极，是 有非分之想者。“须”通“媭”，指 姐姐。六三 本为少女（兑卦），却自比姐姐，企图 获得正室（嫡妻）的地位。这种 僭越本分、不正当的奢求，导致 事与愿违，不仅 未得正位，反而 被降格，以 更低的“娣”的身份 被 遣回（反归）。爻传直言“未当也”，指出其 想法和行为完全错误。此爻是对 贪求名分、不安本位 者的 严厉告诫：**在不正的关系中 强求高位，只会 自取其辱。


### 九四：归妹愆期，迟归有时。


**原文**：归妹愆期，迟归有时。

**白话**：出嫁延误了佳期，延迟待嫁是为了等待合适的时机。

**小象传**
**原文**：“愆期”之志，有待而行也。

**白话**：错过了约定的时间，是因为心中有所期待，要等待合适的时机才行动。


**说明**

这是 归妹的明智——主动延期，以待良缘。

+ “归妹愆期”：出嫁延误了佳期（愆期）。
+ “迟归有时”：延迟出嫁（迟归）是为了等待正当的时机（有时）。
+ 爻传“愆期之志，有待而行也”：延误佳期的心志，是为了有所等待然后再出嫁。

**相关性**：九四阳刚失正，与初九无应，是 有主见、不轻易苟合者。“愆期”表面看是 错过了通常的婚嫁年龄，似乎是 不利。但爻辞和爻传揭示了其 积极的内涵：这是 主动的、有意识的延迟。因为找不到 合适的、正当的配偶，故 宁可等待（有待）。其 心志（志） 在于 “有时”——等待那个 恰当的、属于自己的时机 到来。此爻赞扬了在婚媾（及一切结合）中 不随波逐流、不将就苟且 的 清醒与定力，强调 “时” 的重要性。


### 六五：帝乙归妹，其君之袂，不如其娣之袂良。月几望，吉。


**原文**：帝乙归妹，其君之袂，不如其娣之袂良。月几望，吉。

**白话**：帝乙嫁女，作为正室的衣饰，反不如陪嫁的娣的衣饰华美。月亮接近圆满，吉祥。

**小象传**
**原文**：“帝乙归妹”，“不如其娣之袂良”也。其位在中，以贵行也。

**白话**：帝乙嫁出妹妹，她的衣饰不如陪嫁的侧室华美。因为她地位尊贵居中，以高贵的身份行事，所以崇尚俭朴。


**说明**

这是 归妹的尊贵——位高而谦，德盛不盈。

+ “帝乙归妹”：帝乙（商王）嫁女（归妹）。
+ “其君之袂，不如其娣之袂良”：作为正室（其君）的衣饰（袂），反不如侧室（其娣）的华美（良）。
+ “月几望，吉”：月亮接近圆满（几望）而不盈，吉祥（吉）。
+ 爻传“帝乙归妹，不如其娣之袂良也；其位在中，以贵行也”：帝乙嫁女，其衣饰不如侧室的华美；说明（六五）居位中正，以尊贵的身份施行谦俭。

**相关性**：六五阴柔居中，居尊位，是 高贵而贤明的出嫁者（以帝王之女喻之）。“其君之袂，不如其娣之袂良”是 极具象征意义的细节：身份尊贵的正室（君），其 服饰（袂，外在装饰） 却 不如侧室华丽。这体现了一种 内在的谦逊、俭德与不尚虚荣。“月几望”是 另一个关键比喻：月亮 将圆未圆（几望），象征德行、福分盛大而 不达到盈满骄溢 的 最佳状态。因其 居尊位而能行中道，贵而不骄，盛而不盈，故得 吉祥。此爻描绘了婚媾（及一切结合）中 最理想的尊贵者形象：以 谦逊、俭朴、中庸 的 内在美德 为 真正的装饰。


### 上六：女承筐无实，士刲羊无血，无攸利。


**原文**：女承筐无实，士刲羊无血，无攸利。

**白话**：女子手捧竹筐，里面空无一物；男子宰羊，不见流血，无所利益。

**小象传**
**原文**：上六“无实”，“承”虚“筐”也。

**白话**：上六爻辞说“没有果实”，是因为捧着空筐子。


**说明**

这是 归妹的终局——结合虚妄，有名无实。

+ “女承筐，无实”：女子手捧（承）竹筐（筐），里面空空无物（无实）。
+ “士刲羊，无血”：男子（士）刀刺（刲）其羊，不见血流（无血）。
+ “无攸利”：无所利益（无攸利）。
+ 爻传“上六无实，承虚筐也”：上六空虚无实，正如手捧空筐。

**相关性**：上六阴柔处卦之极，是归妹之道的 失败终结。“女承筐”、“士刲羊”是古代婚礼中 祭祀祖先的仪式（女子捧筐献祭，男子杀羊取血），象征婚姻的 神圣性与实质性。但爻辞说 “无实”、“无血”，意味着仪式 徒具形式，内容空虚。这比喻 整场婚姻（或结合）缺乏 实质的情感、责任、成果，是一场 完全失败、毫无益处 的结合。爻传“承虚筐也”的断语，冰冷而彻底。此爻作为 卦的终结，以 最鲜明的意象 回应了卦辞 “征凶，无攸利” 的警告，揭示了若 不遵循正道、不顾及“永终”，婚媾（及一切结合）可能堕入的 彻底虚无与无益 的结局。


## 总结

**总结**：归妹卦的现代启示

归妹卦的 “永终知敝” 是关于 “结合、婚媾、合作”的深刻警示与智慧。它聚焦于结合过程中 可能出现的各种“不正”与“弊端，并教导如何 防患于未然。

婚媾（结合）之道的六种情境与警示：

+ 卑而守正（初九）：归妹以娣，跛能履，征吉。
+ 内怀明德（九二）：眇能视，利幽人之贞。
+ 不正求贵（六三）：归妹以须，反归以娣。
+ 待时择配（九四）：归妹愆期，迟归有时。
+ 尊而俭德（六五）：帝乙归妹，其君之袂，不如其娣之袂良；月几望，吉。
+ 虚而无实（上六）：女承筐，无实；士刲羊，无血。无攸利。

核心心法：大象传总纲——“泽上有雷，归妹；君子以永终知敝。” 这意味着：

+ “泽上有雷，归妹”：是 归妹卦之象（泽悦而雷动，象征欣悦而动之合）。
+ “君子以永终知敝”：君子效法此象，在结合之初，就思虑如何保持长久，并预知可能的弊病。

这是 归妹卦精神的灵魂，也是其 最核心的教诲。君子从 “悦以动” 的卦象中，看到结合 易因情感冲动而始，却难因理性持守而终 的 潜在风险。因此，在 开始一段关系（婚姻、合作、盟约）时，就必须 超越眼前的欣悦，深入思考：如何 使之长久（永终）？其中 可能存在哪些弊端（知敝）？如何 预防和克服？“永终知敝” 是一种 深谋远虑、居安思危 的 结合智慧。

根本精神：彖传 “归妹，天地之大义也。天地不交而万物不兴，归妹，人之终始也。说以动，所归妹也。征凶，位不当也。无攸利，柔乘刚也。” 揭示了归妹之道的深刻矛盾：

+ “归妹，天地之大义也。天地不交而万物不兴，归妹，人之终始也”：首先 肯定：婚嫁（归妹） 是 符合天地阴阳交合之大义的，是 人伦的起始与归宿。没有结合，就没有繁衍与发展。
+ “说以动，所归妹也”：接着 描述：（本卦）欣悦（兑）而动（震），正是“归妹”的卦象特征。
+ “征凶，位不当也。无攸利，柔乘刚也”：然后 诊断：**之所以“前行凶险”，是因为 卦中诸爻位置大多不当；之所以“无所利益”，是因为 阴柔者凌乘于阳刚者之上（柔乘刚）。

彖传的 逻辑 非常清晰：肯定结合的意义（大义） → 指出本卦结合的特质（悦以动） →警告此特质导致的 结构性风险（位不当、柔乘刚） →最终得出 “征凶，无攸利” 的 总体判断。

归妹卦告诉我们：“归妹”是 一个关于 “有缺陷的结合” 的 完整案例研究。它提醒我们：任何结合（无论爱情、婚姻、合伙、联盟），若 仅建立在 一时的情感悦动（悦以动） 之上，而 缺乏 正当的名分（位不当）、合理的秩序（柔乘刚） 和 长远的谋虑（永终知敝），那么 无论其初衷多么美好（天地大义），最终都可能 走向 “无攸利” 甚至 “征凶” 的结局。其 最高智慧 在于 六五爻的“帝乙归妹”——以 尊贵而行谦俭，以盛德而守不盈，这或许是 在“悦以动”的世界中，实现 “永终” 的 唯一正道。
