# 坎卦（坎上坎下）

**卦画**：䷜

## 总论：坎险的哲学

**核心短词**：“常德行，习教事”

**卦象**：上坎（☵）为水、为险，下坎（☵）为水、为险。坎为水。水洊至，险而又险；水流不盈，行险不失其信。

**核心卦辞**：“习坎，有孚，维心亨，行有尚。”

**总纲**：坎卦直面 “重重险陷” 的困境。面对险境，唯有心怀诚信，内心通达，行动才能获得嘉尚。

+ “习坎”：重叠的险难（习，重也）。
+ “有孚”：心怀诚信（孚）。
+ “维心亨”：唯有内心（维心）保持亨通、豁达。
+ “行有尚”：行动（行）才能获得崇尚、嘉奖（有尚）。

**本质**：坎卦的核心是 “重险也” 与 “水流而不盈，行险而不失其信”。卦象上下皆水，象征 险难接连不断，如水流般无孔不入。但水有 “流而不盈” 的特性——永远流动，永不盈满自溢。这比喻：身处险境，只要像水一样保持流动（行动）、保持谦卑（不盈），并且始终心怀诚信（不失其信），就能 在险中寻得出路。关键在于 “维心亨”：内心的信念与通达，是战胜一切外险的根本。

## 卦辞



### 经

**原文**：习坎，有孚，维心亨，行有尚。

**白话**：重重险陷，但心怀诚信，维系于心则亨通，行动必获嘉尚。

### 彖传

**原文**：习坎，重险也。水流而不盈，行险而不失其信。维心亨，乃以刚中也。行有尚，往有功也。天险不可升也，地险山川丘陵也，王公设险以守其国，坎之时用大矣哉！

**白话**：习坎卦，象征着重重险阻。水流动却不会满溢，历经险境却从不失去诚信。内心保持通达，是因为刚健中正。行动会有嘉许，向前能建立功业。天险高远不可攀登，地险在于山川丘陵，王公设置险阻来守卫国家，坎卦的时势作用真是伟大啊！

### 大象传

**原文**：水洊至，习坎；君子以常德行，习教事。

**白话**：水接连不断地涌来，象征重重险阻；君子因此要保持恒久的德行，反复熟习政教事务。


## 爻辞

### 初六：习坎，入于坎窞，凶。


**原文**：习坎，入于坎窞，凶。

**白话**：重重险陷，落入陷坑深处，凶险。

**小象传**
**原文**：“习坎入坎”，失道凶也。

**白话**：反复陷入重重险境，是因为迷失正道而招致凶险。


**说明**

这是 坎险的初陷——失道深陷。

+ “习坎”：陷入重叠的险难。
+ “入于坎窞”：坠入（入于）深坑（坎窞）之中。
+ “凶”：凶险。
+ 爻传“失道凶也”：因为 失去了正道（失道）而致凶。

**相关性**：初六阴柔处下，是 陷入险难的最初阶段。“坎窞”是 坑中之坑，喻险中之险。爻传点明其凶的根源：“失道”。这并非指客观环境险恶，而是指 主观上行为不当、迷失方向、或缺乏准备，从而 在险境中越陷越深。此爻警示：面对险境，首先要确保自己走在正道上（有孚），否则将万劫不复。


### 九二：坎有险，求小得。


**原文**：坎有险，求小得。

**白话**：坎陷中有险难，谋求小的收获。

**小象传**
**原文**：“求小得”，未出中也。

**白话**：追求小的收获，是因为还没有偏离中道。


**说明**

这是 坎险的挣扎——险中求进。

+ “坎有险”：坑穴（坎）中存在危险。
+ “求小得”：谋求（求）小的收获（小得）。
+ 爻传“未出中也”：因为 尚未脱离（出）险境之中。

**相关性**：九二阳刚居中，象征 在险境中仍保有刚健与中道之德。但因其陷于二阴之中（坎卦中爻），仍未脱离险境的核心区域（未出中也）。此时，不宜奢求大的突破或脱险，而应 务实、低调地谋求小的进展与收获（求小得），比如 保全自身、积累资源、等待时机。这是 在重压下生存与积累的智慧。


### 六三：来之坎坎，险且枕，入于坎窞，勿用。


**原文**：来之坎坎，险且枕，入于坎窞，勿用。

**白话**：来去都是险陷，危险且深陷，落入陷坑深处，不可施展才用。

**小象传**
**原文**：“来之坎坎”，终无功也。

**白话**：来去都处在险陷之中，终究是徒劳无功。


**说明**

这是 坎险的胶着——动辄得咎。

+ “来之坎坎”：前来（来）与退去（之）都是险难（坎坎）。
+ “险且枕”：危险（险）而且深陷（枕）。
+ “入于坎窞”：坠入深坑。
+ “勿用”：不可有所作为（用）。
+ 爻传“终无功也”：因为 终究不会成功。

**相关性**：六三阴柔不中不正，且处上下坎卦之交，正是 险难汇集、进退维谷之地。“来之坎坎”形容 无论前进还是后退，都面临险阻；“枕”有 沉溺、依靠之意，喻 深陷其中，无法自拔。在此绝境，任何轻举妄动（用）都只会 加剧危险，徒劳无功（终无功）。爻辞给出的唯一指示是 “勿用”——静守、忍耐，等待形势变化。此爻描述了 险境中最绝望的状态。


### 六四：樽酒簋贰，用缶，纳约自牖，终无咎。


**原文**：樽酒簋贰，用缶，纳约自牖，终无咎。

**白话**：一樽酒，两簋食，用瓦缶盛着，通过窗户递送简约的祭品，终无咎害。

**小象传**
**原文**：“樽酒簋贰”，刚柔际也。

**白话**：一樽酒两盘饭，象征刚健与柔顺相互交接。


**说明**

这是 坎险的沟通——简朴至诚。

+ “樽酒簋贰，用缶”：一樽酒（樽酒），两簋食物（簋贰），用朴素的瓦器（缶）盛着。
+ “纳约自牖”：通过窗户（牖）递送（纳）简约（约）的祭品。
+ “终无咎”：最终没有过错。
+ 爻传“刚柔际也”：因为 （处于）刚柔交接的际会。

**相关性**：六四已进入上卦坎，但柔顺得正，且与九五君位相比。爻辞描绘了一幅 在险难、困顿（如被囚禁）中，以极其简朴（樽酒簋贰用缶）而真诚的方式，通过非正式渠道（自牖）与尊者（九五）沟通（纳约） 的场景。这象征：**在险境中，外在的华丽与排场已不重要，关键在于 内心的至诚（有孚）与沟通的诚意。六四以柔顺之姿，真诚地亲比于九五刚中之君（刚柔际），终能 获得理解与帮助，渡过险关（无咎）。此爻强调 “诚”是化险为夷的桥梁。


### 九五：坎不盈，祗既平，无咎。


**原文**：坎不盈，祗既平，无咎。

**白话**：险陷尚未满盈，（九五阳刚中正）则险已平，没有咎害。

**小象传**
**原文**：“坎不盈”，中未大也。

**白话**：水坑还没有满溢，是因为居中之道尚未光大。


**说明**

这是 坎险的中和——水流不盈。

+ “坎不盈”：坑穴（坎）尚未盈满。
+ “祗既平”：（水流）刚好（祗）已经齐平（既平）。
+ “无咎”：没有过错。
+ 爻传“中未大也”：因为 （九五）虽得中道，但险难尚未完全平息（未大）。

**相关性**：九五阳刚中正居尊，是 “坎”卦之主，也是处险之道的典范。“坎不盈”呼应卦辞“水流而不盈”，象征 身处险境（君位之险）而不自满、不傲慢，保持谦卑与流动。“祗既平”意为 水流恰到好处，不溢不枯，保持平衡。这比喻：**作为领导者，在危机中能 持守中道，平衡各方，使险难得到控制，不至于恶化。但爻传“中未大也”提醒：险境只是得到控制（平），并未完全解除（未大），仍需谨慎。此爻是 领导者在危机中应有的姿态。


### 上六：系用徽纆，寘于丛棘，三岁不得，凶。


**原文**：系用徽纆，寘于丛棘，三岁不得，凶。

**白话**：被绳索捆绑，囚禁在荆棘丛中，三年不得解脱，凶险。

**小象传**
**原文**：上六失道，凶三岁也。

**白话**：上六爻偏离正道，所以会有连续三年的凶险。


**说明**

这是 坎险的终极——桎梏难脱。

+ “系用徽纆”：用绳索（徽纆）捆绑（系）。
+ “寘于丛棘”：囚禁（寘）在荆棘丛（丛棘）中。
+ “三岁不得”：三年（喻长期）不得解脱。
+ “凶”：凶险。
+ 爻传“失道凶也”：因为 失去了正道而致凶。

**相关性**：上六阴柔处卦之极，是 险难的终极形态。“徽纆”是 粗重的绳索，“丛棘”象征 监狱或绝境。这描绘了 身陷囹圄、失去自由、长期困顿的极端险境。爻传再次归因为 “失道凶也”，与初六呼应，形成闭环。这表明：若从一开始就“失道”，或在整个处险过程中未能把握“有孚”“心亨”的原则，最终将陷入万劫不复的绝境。此爻是对 违背“坎”道者的最终审判。


## 总结

**总结**：坎卦的现代启示

坎卦的 “常德行，习教事” 是关于 面对困境、危机与内心恐惧 的修心与实践哲学。

坎险的层次：

+ 初陷（初六）：失道深陷，凶。
+ 挣扎（九二）：险中求存，求小得。
+ 胶着（六三）：进退皆险，勿用。
+ 沟通（六四）：险中守诚，简朴至诚可无咎。
+ 中和（九五）：险中得中，水流不盈则平。
+ 终极（上六）：桎梏难脱，失道终凶。

核心心法：大象传总纲——“水洊至，习坎；君子以常德行，习教事。” 这意味着：

+ “水洊至”：是 坎险之象（水流接连而至）。
+ “君子以常德行，习教事”：君子效法此象，做到：

+ “常德行”：恒常（常）地修养、保持（行）自己的德行。在险境中，德行是 内心的定海神针。
+ “习教事”：反复练习（习）教化、管理（教）的事务。在险境中，能力是 突围的武器。

这是 应对险难的根本方法：对内，要不断砥砺德行，使内心强大（维心亨）；对外，要反复练习技能，使行动有效（行有尚）。如同水永远流动（习），君子也需 永恒地修炼与实践，才能 处险不惊，履险如夷。

根本精神：卦辞 “有孚，维心亨，行有尚” 是坎卦的总诀。“有孚”（诚信）是态度，“维心亨”（内心通达）是境界，“行有尚”（行动嘉尚）是结果。三者一体：心怀至诚，则内心豁达；内心豁达，则行动果敢有力；行动有力且正，则能克服险难，赢得尊崇。彖传 “王公设险以守其国，坎之时用大矣哉！” 更将“坎”的功用提升到战略高度：险难（坎）不仅可以被动经历，更可以主动设置、利用（设险），用以守卫国家。这揭示了 “坎”的双重性：它既是危险，也是屏障；既是考验，也是工具。

坎卦与大过卦的承续：大过卦（䷛）讲 “阳刚过甚”（独立不惧），是 因内部力量失衡而导致的“非常”危机；坎卦（䷜）则讲 “重险环生”（常德行习教事），是 因外部环境险恶而陷入的“常态”困境。《序卦传》言：“物不可以终过，故受之以坎；坎者，陷也。” 意思是：事物不可能始终过度（大过），（过极必反）所以会陷入险境（坎）；坎，就是陷落。“大过”是主动的、内部的“过”，“坎”是被动的、外部的“陷”。从大过到坎，揭示了 事物发展在经历极端（大过）之后，往往容易陷入低谷或困境（坎） 的规律。这提醒我们：在取得巨大成功或经历剧烈变动后，要格外警惕随之而来的风险与挑战。
