# 咸卦（兑上艮下）

**卦画**：䷞

## 总论：感应的哲学

**核心短词**：“以虚受人”

**卦象**：上兑（☱）为泽、为悦，下艮（☶）为山、为止。泽山咸。山上有泽，山感泽润，泽感山止；二气感应以相与。

**核心卦辞**：“咸，亨，利贞，取女吉。”

**总纲**：咸卦阐述 “感应、沟通、情感” 之道。亨通，利于守持正道，娶妻吉祥。

+ “咸”：感，感应、感通（无心之感，非刻意而为）。
+ “亨”：亨通（感应则通）。
+ “利贞”：利于守持正道（感应须以正为基）。
+ “取女吉”：娶妻（取女）吉祥（以男女婚媾喻最根本的阴阳感应）。

**本质**：咸卦的核心是 “咸，感也” 与 “止而说”。卦象上兑悦、下艮止，象征 内心宁静（止）而对外喜悦（悦） 的感应状态。咸是 “无心之感”，即 不存机心、自然而然的感通，如同少男（艮）少女（兑）的纯真爱慕。卦辞以“取女吉”点明其 始于人伦，通于天下 的普遍意义：男女相感而成夫妇，是所有人伦关系与社会和谐的起点。

## 卦辞

### 经

**原文**：亨，利贞，取女吉。

**白话**：亨通，利于守持正固，娶妻吉祥。

### 彖传

**原文**：咸，感也。柔上而刚下，二气感应以相与，止而说，男下女，是以亨，利贞，取女吉也。天地感而万物化生，圣人感人心而天下和平。观其所感，而天地万物之情可见矣！

**白话**：咸卦，讲的是感应。阴柔在上而阳刚在下，阴阳二气相互感应而结合，静止而喜悦，如同男子谦卑求娶女子，所以亨通，利于持守正道，娶妻吉祥。天地相互感应而万物化育生长，圣人感化人心而天下和平。观察这种感应，天地万物的情状就可以明白了！

### 大象传

**原文**：山上有泽，咸；君子以虚受人。

**白话**：山上有湖泊，象征感通；君子因此虚怀若谷，接纳众人。


## 爻辞

### 初六：咸其拇。


**原文**：咸其拇。

**白话**：感应于脚拇指。

**小象传**
**原文**：“咸其拇”，志在外也。

**白话**：感应发生在脚拇指，说明心思已经向外追求了。


**说明**

这是 感应的初萌——微动未深。

+ “咸其拇”：感应（咸）到脚拇指（拇）。
+ 爻传“志在外也”：因为 心意（志）指向外方（九四）。

**相关性**：初六处卦之始，如同 感应的第一缕涟漪。“拇”是 身体最末梢、最不敏感的部位，感应于此，表示 感应刚刚发生，非常轻微、浅表，尚未深入。爻传“志在外也”说明，这种微动源于 内心对外界（相应之爻九四）的向往。此爻描绘了 情感或意念初动时那种朦胧、隐约的状态。


### 六二：咸其腓，凶，居吉。


**原文**：咸其腓，凶，居吉。

**白话**：感应于小腿肚，有凶险，安居守静则吉祥。

**小象传**
**原文**：虽凶居吉，顺不害也。

**白话**：虽然处境凶险，但只要安守本分，顺应时势，就能避免祸患。


**说明**

这是 感应的躁进——妄动招凶。

+ “咸其腓”：感应（咸）到小腿肚（腓）。
+ “凶”：凶险。
+ “居吉”：安居不动（居）则吉。
+ 爻传“顺不害也”：因为 顺从（九三）就不会受害。

**相关性**：六二柔顺中正，但感应已至“腓”（小腿肚），比“拇”更接近行动中枢。小腿主 行走，感应于此，易产生 盲动、躁进的冲动。若急于行动（如急于追求九三），则凶。爻辞给出的转机是 “居吉”——安居静守，不妄动。爻传“顺不害也”进一步阐释：只要柔顺地安居其位，等待时机，或顺从正理（九三），便可免害获吉。此爻强调 感应过程中“止”（艮）的重要性：不可因感而乱，应静观其变。


### 九三：咸其股，执其随，往吝。


**原文**：咸其股，执其随，往吝。

**白话**：感应于大腿，执意盲从他人，前往必有憾惜。

**小象传**
**原文**：“咸其股”，亦不处也。志在随人，所执下也。

**白话**：大腿感应而躁动，也是不能安处。心意在于追随他人，所持的志向是卑下的。


**说明**

这是 感应的盲从——失其自主。

+ “咸其股”：感应（咸）到大腿（股）。
+ “执其随”：执意（执）盲从（随）他人。
+ “往吝”：前往（往）必有憾惜（吝）。
+ 爻传“志在随人，所执下也”：因为 心志（志）在于追随（随）他人，所执持的（所执）是卑下的原则。

**相关性**：九三阳刚处艮卦之顶，本应 有主见、能静止（艮），但它却感应于“股”。大腿 自己不能动，完全跟随小腿（腓）而动。这象征 失去了独立判断和主导权，盲目追随他人（初六、六二）或外界影响。“执其随”的“执”字，更凸显其 固执于盲从。以此状态行动（往），必然 迷失自我，招致憾惜。此爻警示：在感应中，不可丧失主体性与原则性。


### 九四：贞吉，悔亡。憧憧往来，朋从尔思。


**原文**：贞吉，悔亡。憧憧往来，朋从尔思。

**白话**：守持正固吉祥，悔恨消亡。心意不定地来来往往，朋友们会顺从你的心思。

**小象传**
**原文**：“贞吉悔亡”，未感害也。“憧憧往来”，未光大也。

**白话**：坚守正道可获吉祥，悔恨就会消失，这是因为没有感受到伤害。心思不定地频繁往来，这说明德行还没有发扬光大。


**说明**

这是 感应的核心——心感纷纭。

+ “贞吉，悔亡”：守持正道（贞）则吉，悔恨消亡。
+ “憧憧往来”：心意不定（憧憧）地来来往往（往来）。
+ “朋从尔思”：朋友们（朋）会顺从（从）你的心思（尔思）。
+ 爻传“未光大也”：因为 （这种私心相感）未能光明正大。

**相关性**：九四已入上卦兑（悦），且处三、四爻 人心之位，是 全卦感应的枢纽与核心。“憧憧往来”生动描绘了 内心因感应而产生的思绪纷扰、权衡计较、患得患失的状态。此时，若能 持守正道（贞），则可获吉，悔恨消亡。但爻辞也指出，这种基于个人心思（尔思）的感应，即使能吸引同类（朋从），也终究 局限于私心私情的范畴，境界不够光明正大（未光大也）。此爻深刻揭示了 人心感应的复杂性与局限性。


### 九五：咸其脢，无悔。


**原文**：咸其脢，无悔。

**白话**：感应于背脊肉，没有悔恨。

**小象传**
**原文**：“咸其脢”，志末也。

**白话**：感应到了后背，是因为心思在远处。


**说明**

这是 感应的淡漠——无心无应。

+ “咸其脢”：感应（咸）到背脊肉（脢）。
+ “无悔”：没有悔恨。
+ 爻传“志末也”：因为 心志（志）在于末梢（无关紧要之处）。

**相关性**：九五阳刚中正居尊，但感应于“脢”（背脊肉），这是 身体最不敏感、几乎无知觉的部位，且 背对他人。这象征 高高在上，对下情淡漠，缺乏感应的意愿与能力，或 感应仅流于形式、未及真心。因其 居尊守中，故可“无悔”（没有大的过错或悔恨），但爻传“志末也”批评其 心志浅薄，未能感通天下。此爻描述了 领导者脱离群众、情感淡漠的状态。


### 上六：咸其辅颊舌。


**原文**：咸其辅颊舌。

**白话**：感应于口辅、面颊、舌头。

**小象传**
**原文**：“咸其辅颊舌”，滕口说也。

**白话**：感应表现在面颊和舌头上，是张口说话的样子。


**说明**

这是 感应的末路——空言无实。

+ “咸其辅、颊、舌”：感应（咸）到牙床（辅）、面颊（颊）、舌头（舌）。
+ 爻传“滕口说也”：只是 张口（滕）空谈（口说）而已。

**相关性**：上六处卦之终，感应集中于 口舌部位（辅、颊、舌）。这象征 感应完全停留在言语表面，沦为花言巧语、空谈虚论，缺乏 内心的真诚（艮止）与行动的实质。爻传“滕口说也”一针见血，指出其 徒逞口舌之快，感通之道已穷。此爻是对 一切虚伪、浮夸、言不由衷的“伪感应”的最终刻画。


## 总结

**总结**：咸卦的现代启示

咸卦的 “以虚受人” 是关于 情感交流、人际沟通、乃至万物共鸣 的深刻哲学。

感应的层次（自下而上，由浅入深，亦由正入偏）：

+ 初萌（初六）：心意微动，志在外。
+ 躁进（六二）：易生妄动，居则吉。
+ 盲从（九三）：失其主见，往则吝。
+ 心枢（九四）：思绪纷纭，贞则吉但未光。
+ 淡漠（九五）：高高在上，感而无心。
+ 空言（上六）：徒逞口舌，感道已穷。

核心心法：大象传总纲——“山上有泽，咸；君子以虚受人。” 这意味着：

+ “山上有泽”：是 咸卦之象（山体坚实，却能容纳泽水；泽水流动，却能润泽山体）。
+ “君子以虚受人”：君子效法此象，以虚空、谦卑的胸怀（虚）来容纳、接受（受）他人。

这是 实现真正感应的前提：山（自我）必须“虚”其心，才能容纳泽水（他人、外物）；泽水（他人）也必须流动（悦），才能润泽山体。君子要 摒弃成见与自我中心（虚），才能真切地感知、理解并接纳他人，从而实现 心心相印的感通。

根本精神：彖传 “天地感而万物化生，圣人感人心而天下和平” 将“咸”道提升到宇宙与社会的最高境界。天地阴阳二气相互感应，化生万物；圣人以至诚之心感化人心，带来天下和平。咸卦始于 男女婚媾（取女吉），通于 人际交往（朋从尔思），终于 天下和平，构成了一个 由近及远、由微至著 的完整感应体系。它告诉我们：一切和谐关系，都始于真诚无私的感应。

咸卦与离卦的承续：离卦（䷝）讲 “附丽与光明”（继明照于四方），强调 有形的依附与文明的传承；咸卦（䷞）则讲 “感应与沟通”（以虚受人），强调 无形的交流与情感的共鸣。《序卦传》言：“有天地然后有万物，有万物然后有男女，有男女然后有夫妇，有夫妇然后有父子，有父子然后有君臣，有君臣然后有上下，有上下然后礼义有所错。” 而咸卦，正是 下经之首，始于夫妇人伦。从离（文明）到咸（情感），标志着 《周易》从侧重自然天道（上经）转向侧重社会人伦（下经）。咸卦作为下经开端，确立了 “感”作为一切人伦关系与社会建构的情感基石 的地位。
