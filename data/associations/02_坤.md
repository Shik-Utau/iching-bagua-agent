# 坤卦（坤上坤下）

**卦画**：䷁

## 总论：承载的哲学

**核心短词**：“厚德载物”

**卦象**：上坤（☷）为地、为顺，下坤（☷）为地、为顺。坤为地。纯阴至顺，地势坤，君子以厚德载物。

**核心卦辞**：“元，亨，利牝马之贞。君子有攸往，先迷后得主，利西南得朋，东北丧朋。安贞，吉。”

**总纲**：坤卦象征 “地”的创始、亨通，利于像母马一样守持正固。君子有所前往，抢先会迷失，随后会找到主人。利于往西南得到朋友，往东北丧失朋友。安于守正，吉祥。

+ “元亨利”：与乾卦同，但坤的创始是 顺承乾天 的创始。
+ “牝马之贞”：母马（牝马）的贞正。母马既柔顺（追随公马），又能行远负重，象征 坤德：柔顺而能持久，承载而能致远。
+ “先迷后得主”：抢先（先）会迷失（迷），随后（后）会得到主人（得主）。强调 坤道在于追随与配合（乾为主），不宜争先。
+ “西南得朋，东北丧朋”：在 后天八卦方位 中，西南为坤方（同类），东北为艮方（异类）。意为 追随同类（得朋）则利，背离同类（丧朋）则不利。深层含义是：应顺应大势（乾的方向），与同道者（阴）协力。
+ “安贞吉”：安于（安）守持正固（贞），则吉祥（吉）。这是坤道的总原则。

**本质**：坤卦是 纯阴之卦，代表 地道、阴柔、承载、顺从、包容。其**核心精神**是 “顺”，即 柔顺地承载万物，配合乾天而化生。坤德是 辅助性的、执行性的、滋养性的伟大力量。

## 卦辞



### 经

**原文**：元，亨，利牝马之贞。君子有攸往，先迷后得主，利西南得朋，东北丧朋。安贞，吉。

**白话**：创始、通达，适宜像母马那样守持正固。君子有所前往，起初会迷失方向，随后会找到主人。利于往西南方得到朋友，往东北方会丧失朋友。安于守持正固，吉祥。

### 彖传

**原文**：至哉坤元，万物资生，乃顺承天。坤厚载物，德合无疆。含弘光大，品物咸亨。牝马地类，行地无疆，柔顺利贞。君子攸行，先迷失道，后顺得常。西南得朋，乃与类行；东北丧朋，乃终有庆。安贞之吉，应地无疆。

**白话**：坤元的功德真是达到了极致啊，万物都依靠它生长，它柔顺地承接天的意志。大地深厚而承载万物，它的德行广阔无边。它包容、广阔、光明、宏大，使各类事物都得以顺利通达。母马属于地上的生物，能在大地上无限驰骋，它性情柔顺，利于坚守正道。君子有所行动时，起初可能会迷失方向，但随后顺应柔顺之道就能回归常理。往西南方向会得到朋友，是与同类相伴而行；往东北方向会失去朋友，但最终会有吉庆。安于坚守正道所带来的吉祥，正如大地一样广阔无疆。

### 大象传

**原文**：地势坤，君子以厚德载物。

**白话**：大地气势宽厚和顺，君子应当效法大地，以深厚的德行来承载万物。


## 爻辞

### 初六：履霜，坚冰至。


**原文**：履霜，坚冰至。

**白话**：踩到薄霜，坚冰即将到来。

**小象传**
**原文**：“履霜坚冰”，阴始凝也；驯致其道，至坚冰也。

**白话**：脚下踩到薄霜，意味着阴寒之气开始凝结；顺着这个趋势发展下去，就会迎来坚冰封冻的时节。


**说明**

这是 承载的永恒法则——永守柔顺。

+ “利永贞”：利于（利）永久（永）守持正固（贞）。
+ 爻传“以大终也”：因为 （坤道）以（成就）宏大（大）为归宿（终）。

**相关性**：“用六”是 坤卦六爻皆阴（皆变）时的总断。它概括了坤道的根本精神：永远利于守持柔顺、安静、承载的正道（利永贞）。爻传“以大终也”揭示了这样做的结果：**正因为坤能永守其贞，顺承乾天，才能 成就化育万物、承载一切的宏大功业（以大终）。此爻是 对坤德“厚德载物”的最终定论：其伟大，正源于其永恒的守正与柔顺。


### 六二：直方大，不习无不利。


**原文**：直方大，不习无不利。

**白话**：正直、端方、宏大，不熟悉（环境）也没有不利。

**小象传**
**原文**：六二之动，“直”以“方”也；“不习无不利”，地道光也。

**白话**：六二的变动，是正直而端方的表现；不刻意学习也没有不利，是因为大地之道的光明广大。


**说明**

这是 承载的德性——内德自成。

+ “直，方，大”：正直（直）、端方（方）、宏大（大）。
+ “不习无不利”：不熟悉（不习）也无不顺利（无不利）。
+ 爻传“六二之动，直以方也；不习无不利，地道光也”：六二的行动（动），因正直而端方；不熟悉也无不利，是因为地道（地道）广大光明（光）。

**相关性**：六二柔顺中正，是 坤卦之主爻，代表最纯粹的坤德。“直”是 内在的真诚无私（坤德之质）；“方”是 外在的规矩法则（坤德之形）；“大”是 效法地的博大包容（坤德之量）。具备这三种品德，则 无需刻意学习钻营，一切行为自然合乎正道，无所不利。爻传指出，这是因为 地道（坤道）本身广大光明，顺之而行则吉。此爻揭示了 **坤道的最高境界：以 内在的至诚与方正，自然契合天道，无为而无不为。


### 六三：含章可贞，或从王事，无成有终。


**原文**：含章可贞，或从王事，无成有终。

**白话**：蕴含文采而可守持正固，或许跟随君王做事，不居功而能有好结局。

**小象传**
**原文**：“含章可贞”，以时发也；“或从王事”，知光大也。

**白话**：蕴含文采而可以守持正固，是要等待时机来施展；或许辅助君王的事业，是因为智慧光明远大。


**说明**

这是 承载的智慧——功成不居。

+ “含章可贞”：蕴含（含）文采才华（章），可以（可）守持正固（贞）。
+ “或从王事”：或者（或）辅助（从）君王的事业（王事）。
+ “无成有终”：不居功（无成）而能有好的结局（有终）。
+ 爻传“以时发也”：等待时机（以时）而发挥（发）。

**相关性**：六三阴居阳位，不中不正，处于 多忧多惧的人位。象征 有才华但处境微妙。爻辞给出了完美的处世之道：**首先要 内含光华，不张扬炫耀（含章），坚守正道（可贞）。当有机会辅佐上级（从王事）时，要 **恪尽辅佐之责，但将功劳归于主上（无成），如此才能 善始善终（有终）。爻传“以时发也”强调：才华的施展要 顺应时机，不可躁进。此爻是 坤道“柔顺”与“智慧”的完美结合，是辅佐者的黄金法则。


### 六四：括囊，无咎无誉。


**原文**：括囊，无咎无誉。

**白话**：扎紧口袋，既无灾祸也无赞誉。

**小象传**
**原文**：“括囊无咎”，慎不害也。

**白话**：扎紧口袋没有过错，是因为谨慎小心不会招致祸害。


**说明**

这是 承载的退守——明哲保身。

+ “括囊”：扎紧（括）口袋（囊）。
+ “无咎无誉”：没有咎害（无咎），也没有赞誉（无誉）。
+ 爻传“慎不害也”：因为 谨慎（慎）可以避免祸害（不害）。

**相关性**：六四阴居阴位，得正，但已逼近君位（六五），处于 高危、多疑的近臣位置。“括囊”是比喻：像扎紧口袋一样，收敛锋芒，闭藏智慧，谨言慎行。在这种环境下，不求有功（无誉），但求无过（无咎），是 最稳妥的选择。爻传“慎不害也”直接点明：**谨慎是为了 避免伤害。此爻适用于 环境复杂、是非纷扰或自身无力改变大局时，强调 坤道的另一面：静默与忍耐。


### 六五：黄裳，元吉。


**原文**：黄裳，元吉。

**白话**：黄色的下衣，至为吉祥。

**小象传**
**原文**：“黄裳元吉”，文在中也。

**白话**：黄色下裳最为吉祥，是因为文采美德蕴藏在内心之中。


**说明**

这是 承载的尊位——以柔制刚。

+ “黄裳”：黄色（黄）的下衣（裳）。
+ “元吉”：至为吉祥（元吉）。
+ 爻传“文在中也”：因为 文采美德（文）蕴藏于内心（在中）。

**相关性**：六五阴居尊位，是 坤卦的君位。“黄”是 土地之色，居中之色，象征 中和、尊贵；“裳”是 下衣，象征 谦下、柔顺。“黄裳”比喻：身居高位（黄色），却保持柔顺谦下的美德（裳）。如此，则能 调和四方，大吉大利（元吉）。爻传“文在中也”指出：吉祥的根源在于 内在的中和美德，而非外在的权位。此爻是 领导者（尤其是女性或柔和型领导）的最高境界：以 谦卑、包容、中和的品德施行领导，而非以刚强权势压人。


### 上六：龙战于野，其血玄黄。


**原文**：龙战于野，其血玄黄。

**白话**：龙在郊野交战，流出青黄混杂的血。

**小象传**
**原文**：“龙战于野”，其道穷也。

**白话**：龙在荒野上交战，说明它的发展道路已经走到了尽头。

### 用六：利永贞。

**原文**：利永贞。

**白话**：利于永久守持正固。

**小象传**
**原文**：“用六永贞”，以大终也。

**白话**：用六这一爻之所以能永久保持正道，是因为它最终能成就宏大的事业。


**说明**

这是 承载的极端——阴阳冲突。

+ “龙战于野”：龙（龙，象征阳）在田野（野）交战（战）。
+ “其血玄黄”：流出的血（其血）是青黄混杂的（玄黄）。
+ 爻传“其道穷也”：因为 （阴的）道（其道）已走到穷尽（穷）。

**相关性**：上六阴爻处卦之极，是 阴气发展到极盛的状态。物极必反，盛极而衰。极盛的阴气 不再安于顺承，反而疑忌阳刚，企图与之争衡，这就导致了 阴阳冲突（龙战）。“其血玄黄”（天玄地黄）象征 天地混杂、阴阳两伤。爻传“其道穷也”宣告：阴柔之道走到极端，就会陷入穷途末路。此爻是 严厉的警告：坤道贵在“顺”与“安贞”，若失去柔顺的本性，妄图与乾阳争主，必将导致混乱与伤害。


## 总结

**总结**：坤卦的现代启示

坤卦的 “厚德载物” 是关于 包容、配合、执行、滋养与内在修养 的完整哲学。

处世的六种境遇与智慧：

+ 履霜（初六）：见微知著，慎始慎微。
+ 直方大（六二）：内德自成，正直端方。
+ 含章（六三）：功成不居，待时而发。
+ 括囊（六四）：谨言慎行，明哲保身。
+ 黄裳（六五）：居中谦和，以柔克刚。
+ 龙战（上六）：阴盛疑阳，道穷则乱。

核心心法：大象传总纲——“地势坤，君子以厚德载物。” 这意味着：

+ “地势坤”：是 坤卦之象（大地气势厚实和顺，承载万物）。
+ “君子以厚德载物”：君子效法此象，增厚美德，容载万物。

这是 坤卦精神的灵魂：将大地“承载”的物理属性，升华为人“厚德”的道德属性。它教导我们：真正的强大，不是征服，而是包容；不是张扬，而是涵养；不是争先，而是配合。要以 宽广的胸怀、深厚的德行、柔韧的智慧，去承担、去滋养、去成就。

根本精神：彖传 “至哉坤元，万物资生，乃顺承天” 与 “坤厚载物，德合无疆” 将“坤”道置于化生万物的高度。至极的坤元（滋养力），是万物赖以生长的根源，它柔顺地承奉着天道。坤地深厚而承载万物，其德性与天相合而广大无疆。坤卦告诉我们：**“厚德载物”不仅是个人修养，更是一种 与天地共生的宏大力量。我们学习坤卦，是学习如何 在配合与承载中实现自身价值，如何 以柔顺的姿态完成刚健的事业，最终达到 “安贞吉”的和谐境界。

乾坤两卦的关系：乾卦（䷀）是 “自强不息” 的 创始、进取、领导 之力；坤卦（䷁）是 “厚德载物” 的 承载、配合、执行 之力。二者 一主一从，一创一承，一刚一柔，缺一不可。《周易》以乾坤开篇，确立了 阴阳和合、刚柔并济 的宇宙观与人生观。乾道教我们如何“开创”，坤道教我们如何“成就”；乾道是“发动机”，坤道是“承载器”。真正完整的人格与成功的事业，必然是 乾坤并用的结果。
