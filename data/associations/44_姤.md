# 姤卦（乾上巽下）

**卦画**：䷫

## 总论：相遇之道的哲学

**核心短词**：“施命诰四方”

**卦象**：上乾（☰）为天、为健，下巽（☴）为风、为入。天风姤。天下有风，不期而遇。

**核心卦辞**：“女壮，勿用取女。”

**总纲**：姤卦象征 “相遇、邂逅”，（如果遇到的）女子过分强壮，不宜娶作妻室。

+ “女壮”：女子（女）过分强壮（壮）。这是 比喻，指 所遇之对象（或势力） 虽然 初始微小（一阴始生），但其 性质（阴柔） 决定了它有 潜在的、巨大的生长与渗透能力（壮），可能在未来改变格局。
+ “勿用取女”：不宜（勿用）娶作（取）妻室（女）。这是 告诫，对于这种 性质特殊、可能带来长远隐患的相遇，应当 保持警惕，避免建立长久、稳固的亲密关系（如婚姻），以防其坐大。

**本质**：姤卦是夬卦的覆卦，描述 “柔遇刚” 的状态。五阳在上，一阴始生于下（初六），象征 小人（或新事物、新势力）初现，与君子（或旧格局）不期而遇。其**核心精神**是：**在 新生事物（无论善恶）刚刚出现、力量尚微时，如何识别、应对这种“相遇”。是接纳、防范、利用还是清除？卦辞以“女壮”为喻，给出了 总体谨慎、防范未然的基调。

## 卦辞

### 经

**原文**：女壮，勿用取女。

**白话**：女子过于强盛，不宜娶这样的女子。

### 彖传

**原文**：姤，遇也，柔遇刚也。“勿用取女”，不可与长也。天地相遇，品物咸章也。刚遇中正，天下大行也。姤之时义大矣哉！

**白话**：姤，就是相遇的意思，是柔弱者遇到刚强者。“不要娶这个女子”，是因为不能与她长久相处。天地阴阳相遇，各类事物都得以彰显繁盛。刚强者遇到居中守正的时位，正道就能在天下广泛推行。姤卦所蕴含的时势意义真是重大啊！

### 大象传

**原文**：天下有风，姤；后以施命诰四方。

**白话**：天下吹拂着和风，象征着相遇；君王因此发布政令，昭告四方。


## 爻辞

### 初六：系于金柅，贞吉。有攸往，见凶，羸豕孚蹢躅。


**原文**：系于金柅，贞吉。有攸往，见凶，羸豕孚蹢躅。

**白话**：系缚在坚固的金属刹车器上，守持正固吉祥。若有所前往，会出现凶险，像瘦弱的母猪一样浮躁徘徊。

**小象传**
**原文**：“系于金柅”，柔道牵也。

**白话**：系在金属刹车器上，是阴柔之道受到牵制。


**说明**

这是 相遇的起点——阴始生，当控其本。

+ “系于金柅，贞吉”：系缚（系）在金属刹车器（于金柅）上，守持正固（贞）可获吉祥（吉）。
+ “有攸往，见凶”：有所前往（有攸往），则出现凶险（见凶）。
+ “羸豕孚蹢躅”：像瘦弱的母猪（羸豕）一样，轻浮躁动（孚）徘徊不定（蹢躅）。
+ 爻传“系于金柅，柔道牵也”：系缚在金属刹车器上，是（为了）牵制阴柔之道。

**相关性**：初六是 姤卦唯一的阴爻，也是“相遇”的肇始者。“金柅”是 坚固的制动装置，比喻 强大的阳刚力量（九二）或严格的规范。“系于金柅”意味着 从一开始就用强力手段将其控制、约束住，使其 安分守己（贞），则 可保吉祥。反之，若 任其发展、有所动作（有攸往），则 凶险立现。“羸豕孚蹢躅”是 绝妙比喻：母猪虽瘦弱（羸），但其 本性（孚，通“浮”，轻浮） 就是 躁动徘徊、伺机而动（蹢躅）。这揭示了 **阴柔势力的本质：**即便初始微弱，也 内蕴着不可抑制的扩张冲动。此爻强调：**应对初生的潜在对手或隐患，**最佳策略是 在其根源处施加最强力的控制（金柅），防微杜渐。


### 九二：包有鱼，无咎，不利宾。


**原文**：包有鱼，无咎，不利宾。

**白话**：厨房里有鱼，没有咎害，但不利于用来招待宾客。

**小象传**
**原文**：“包有鱼”，义不及宾也。

**白话**：厨房里有鱼，从道理上讲不应该用来招待宾客。


**说明**

这是 相遇的应对——就近管控，不使外溢。

+ “包有鱼”：厨房（包，通“庖”）里有鱼（有鱼）。
+ “无咎”：没有咎害（无咎）。
+ “不利宾”：但不宜（不利）用来招待宾客（宾）。
+ 爻传“包有鱼，义不及宾也”：厨房里有鱼，从道义上讲（不宜）涉及宾客。

**相关性**：九二阳刚居中，与初六最近，是 首先“遭遇”阴爻并负有管控责任的阳爻。“鱼”是 阴柔之物（初六）的比喻。“包有鱼”意为 九二将初六控制在自己的范围（厨房）内，使其 无法为害外界，故 无咎。但爻辞强调：**这种控制是 “内部消化”，不宜公开化、扩大化（不利宾）。因为 一旦将“鱼”展示或分享给“宾客”（其他阳爻或外部势力），就可能 引发不必要的关注、争夺或效仿，反而使问题复杂化。爻传“义不及宾”点明：**从道理上讲，处理这种隐微之事，应局限在最小范围内。此爻讲的是 “内部问题内部处理”的智慧。


### 九三：臀无肤，其行次且，厉，无大咎。


**原文**：臀无肤，其行次且，厉，无大咎。

**白话**：臀部没有皮肤，行动趑趄不前，有危险，但没有大的咎害。

**小象传**
**原文**：“其行次且”，行未牵也。

**白话**：走路踉踉跄跄，是因为行动没有受到外力的牵制。


**说明**

这是 相遇的旁观——欲动无应，危而无害。

+ “臀无肤，其行次且”：臀部（臀）没有皮肤（无肤），行动（其行）趑趄不前（次且）。
+ “厉”：有危险（厉）。
+ “无大咎”：但没有大的咎害（无大咎）。
+ 爻传“其行次且，行未牵也”：行动趑趄不前，是因为行动没有受到牵制（指与初六无应）。

**相关性**：九三阳刚过甚，处下卦之极，与初六无应，是 “相遇”事件的旁观者或边缘者。爻辞与夬卦九四相似，都用“臀无肤，其行次且”形容 进退两难的尴尬。但在姤卦中，原因不同：**九三想有所行动（可能与初六有关），但 上与上九无应，下与初六无涉（行未牵），找不到发力的支点和理由，故 犹豫不决。这种 孤立无援、想动不能动的状态 本身就有 危险（厉）。但正因为 其没有真正卷入与阴爻的纠葛，所以 最终不会招致大的祸患（无大咎）。此爻描绘了 **在重大事件（相遇）中，缺乏明确立场和关联者的尴尬与风险。


### 九四：包无鱼，起凶。


**原文**：包无鱼，起凶。

**白话**：厨房里没有鱼，兴起争执则有凶险。

**小象传**
**原文**：无鱼之凶，远民也。

**白话**：没有鱼可吃的凶险，是因为远离了民众。


**说明**

这是 相遇的失责——管控失位，动则招灾。

+ “包无鱼”：厨房（包）里没有鱼（无鱼）。
+ “起凶”：兴起行动（起）会有凶险（凶）。
+ 爻传“无鱼之凶，远民也”：没有鱼的凶险，是因为远离了民众（阴爻喻民）。

**相关性**：九四阳居阴位，不中不正，与初六正应却 被九二近水楼台先得“鱼”，故 “包无鱼”。这意味着 九四失去了对初生势力（民众或资源）的管控权。在姤卦的语境下，“鱼”（阴爻）也象征民心、基层力量。“无鱼”即 失去民心、脱离群众。在这种情况下，如果 还轻举妄动（起），无论是想争夺“鱼”，还是想做其他事，都因为 缺乏基础和支持 而必然 招致凶险。爻传“远民也”一针见血：**其凶险的根源在于 脱离了根本（民众）。此爻是 对失职失位者的警告：**当本该由你掌控的事物（鱼/民）失去时，任何冒进都是危险的。


### 九五：以杞包瓜，含章，有陨自天。


**原文**：以杞包瓜，含章，有陨自天。

**白话**：用高大的杞树叶子包住瓜，内含文采，有陨落之物自天而降。

**小象传**
**原文**：九五含章，中正也。有陨自天，志不舍命也。

**白话**：九五内心蕴含美德，是因为他持守中正之道。有福禄自天而降，是因为他的志向不违背天命。


**说明**

这是 相遇的宿命——天命有归，静待其变。

+ “以杞包瓜”：用杞柳枝叶（以杞）包覆（包）瓜果（瓜）。
+ “含章”：内含文采（含章，喻美质）。
+ “有陨自天”：必有陨落（有陨）自天（自天）而降。
+ 爻传“九五含章，中正也；有陨自天，志不舍命也”：九五内含文采，是因为居中守正；有陨落自天，说明其心志不违背天命。

**相关性**：九五阳刚中正，居尊位，是 姤卦的君主。“杞”是 高大坚实的树木，“瓜”是 匍匐在地的阴柔之物。“以杞包瓜”是 生动意象：君主（杞）以美德和权威，包容、覆盖着下方的阴柔势力（瓜）。“含章”指 君主内含中正之美德。然而，爻辞笔锋一转：“有陨自天”。这预示 **即使如此包容，阴柔势力的自然衰落（陨落）也是 天命使然，不可避免。爻传“志不舍命”解释：**君主的 心志（志） 并不执着于强行改变，而是 顺从自然规律（不舍命），静待其变。此爻意境深远：**对于无法根除、又必须面对的“相遇”（如小人、隐患），**最高明的态度是 以中正之德包容之，同时相信天道规律，静观其自败。这是一种 充满自信的、战略性的等待。


### 上九：姤其角，吝，无咎。


**原文**：姤其角，吝，无咎。

**白话**：相遇在角落，有所憾惜，但没有咎害。

**小象传**
**原文**：“姤其角”，上穷吝也。

**白话**：遇到头角相触的对抗，是因为处在最上位，无路可走，所以有麻烦。


**说明**

这是 相遇的终结——无关痛痒。

+ “姤其角”：相遇（姤）在角落（其角）。
+ “吝”：有所憾惜（吝）。
+ “无咎”：但没有咎害（无咎）。
+ 爻传“姤其角，上穷吝也”：相遇在角落，是因为处在上位穷极之地而有所憾惜。

**相关性**：上九阳刚处卦之极，是 离初六阴爻最远者。“角”是 物体最顶端、最尖锐、也最偏僻的部位。“姤其角”比喻 这种“相遇”发生在最边缘、最无关紧要的地方，或者 只是轻微的触碰、摩擦。对于上九而言，下方的风云变幻（姤） 几乎 影响不到它，但它 身处穷极高位，无所作为，也难免有 孤高憾惜（吝） 之感。不过，终究 没有实质性的咎害。此爻描述了 事件（相遇）波及范围的边缘效应：**对于远离风暴中心的人，即使有所感知，也影响甚微。


## 总结

**总结**：姤卦的现代启示

姤卦的 “施命诰四方” 是关于 “邂逅、遭遇、新生事物出现”的深邃哲学，它教导我们 如何识别、评估与应对那些可能改变未来的初始信号。

应对相遇的六种情境：

遇之当制（初六）：系于金柅，羸豕蹢躅。
遇而自制（九二）：包有鱼，不利宾。
孤立不遇（九三）：臀无肤，厉无大咎。
失民致凶（九四）：包无鱼，起凶。
中正待陨（九五）：以杞包瓜，有陨自天。
遇于极末（上九）：姤其角，吝无咎。

核心心法：大象传总纲——“天下有风，姤；后以施命诰四方。” 这意味着：

+ “天下有风，姤”：是 姤卦之象（风行天下，无物不遇）。
+ “后以施命诰四方”：君王（后）效法此象，施布政令，传告四方。

这是 姤卦精神的灵魂：**“姤”是 不期而遇，是 信息与影响的传播（如风）。君子（君王）领悟到，**面对各种相遇与新生事物，**不能被动应付，而应 主动作为。要像风一样，主动将自己的意志、政令、价值观（施命），迅速、广泛地传达至每一个角落（诰四方），以 引领风气、塑造环境、抢占先机。这是 将“被动遭遇”转化为“主动影响”的积极智慧。

根本精神：彖传 “姤，遇也，柔遇刚也……天地相遇，品物咸章也。刚遇中正，天下大行也。姤之时义大矣哉！” 揭示了相遇之道的伟大：

+ “天地相遇，品物咸章”：天地阴阳相遇交感，万物才能彰显昌盛。这是 相遇的积极面——新生与创造。
+ “刚遇中正，天下大行”：阳刚若遇中正之德（指九五），天下教化就能大行其道。这是 相遇的理想结果——以正道引领相遇。
+ “姤之时义大矣哉！”：姤卦的时势意义太重大了！

姤卦告诉我们：**“相遇”本身 无所谓绝对吉凶。它可以是 危机的萌芽（女壮），也可以是 生机的开端（品物咸章）。关键在于 我们如何应对：是 强力遏制（金柅）、内部管控（包有鱼）、失职招凶（包无鱼），还是 以德包容、静待天时（以杞包瓜）？其最高智慧在于 **大象传的主动精神：**在风云际会、万物相遇的时代，**领袖必须 主动发声、树立规范、传播理念（施命诰四方），从而 驾驭相遇，化被动为主动。这便是在 “一阴始生” 的微妙时刻，所蕴含的 关于机遇、风险、管控与引领的深刻洞察。
