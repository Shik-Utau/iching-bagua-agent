# 豫卦（震上坤下）

**卦画**：䷏

## 总论：愉乐的哲学

**核心短词**：“顺以动”

**卦象**：上震（☳）为雷、为动，下坤（☷）为地、为顺。雷地豫。雷出于地，振奋万物；顺理而动，动而和乐。

**核心卦辞**：“豫，利建侯行师。”

**总纲**：豫卦探讨 在安乐、和悦的状态下，如何把握时机，有所作为。

+ “豫”：安乐、和悦、预备（含“预”义）。
+ “利建侯行师”：利于 封建诸侯、建立基业（建侯），也利于 出兵征伐、采取行动（行师）。

**本质**：豫卦的核心是 “乐而有节” 与 “因时而动”。它描述的“乐”，不是放纵享乐，而是 内心愉悦、团队和谐、时机成熟时，那种顺理成章、充满活力的状态。这种状态最有利于 开创事业（建侯）和克服困难（行师）。其根本原理是 “顺以动”——顺应规律、民心、时势而后行动。

## 卦辞

### 经

**原文**：利建侯行师。

**白话**：利于封建诸侯，出兵征伐。

### 彖传

**原文**：豫，刚应而志行，顺以动，豫。豫，顺以动，故天地如之，而况建侯行师乎？天地以顺动，故日月不过，而四时不忒。圣人以顺动，则刑罚清而民服。豫之时义大矣哉！

**白话**：豫卦，是阳刚得到阴柔的应和，志向得以推行，顺承物性而行动，这就是豫。豫卦，顺承物性而行动，所以天地的运行也是如此，更何况建立诸侯、出师征伐这些事呢？天地顺承规律而动，所以日月运行不会出错，四季更替没有偏差。圣人顺承情理而动，就会刑罚清明而百姓顺服。豫卦所蕴含的顺时而动的意义真是大啊！

### 大象传

**原文**：雷出地奋，豫；先王以作乐崇德，殷荐之上帝，以配祖考。

**白话**：雷声从大地响起，万物振奋，这就是豫卦的意象；先代君王因此创制音乐来尊崇美德，隆重地献祭给上天，并让祖先的神灵共享。


## 爻辞

### 初六：鸣豫，凶。


**原文**：鸣豫，凶。

**白话**：沉溺于安乐而自鸣得意，有凶险。

**小象传**
**原文**：初六鸣豫，志穷凶也。

**白话**：初六爻说欢乐时自鸣得意，这是志向穷尽导致的凶险。


**说明**

这是 愉乐的歧途——乐而失志。

+ “鸣豫”：因安乐而 自鸣得意，炫耀快乐（鸣）。
+ “凶”：凶险。
+ 爻传“志穷凶也”：因为 心志穷极，丧失进取心，故凶。
**相关性**：初六阴柔在下，与九四相应，象征 依赖他人（九四）获得快乐。这种快乐是 外在的、被动的。一旦以此自鸣得意，便会 安于现状，不思进取（志穷），失去“豫”卦“顺以动”的活力本质，故预示凶险。这是对 浅薄享乐、依赖成性的警告。


### 六二：介于石，不终日，贞吉。


**原文**：介于石，不终日，贞吉。

**白话**：耿介如磐石，不待终日（即知几速改），守正吉祥。

**小象传**
**原文**：“不终日，贞吉”，以中正也。

**白话**：坚守正道就能吉祥，是因为秉持了中正之道。


**说明**

这是 愉乐的中正——知几速正。

+ “介于石”：耿介、坚定如磐石（石）。
+ “不终日”：不（不）一整天（终日） 都耽于安乐。
+ “贞吉”：守持正道 则吉祥。
+ 爻传“以中正也”：因为 居中守正。
**相关性**：六二柔顺中正，是豫卦中 真正的君子。他身处安乐（豫），但内心 如磐石般坚定（介于石），有明确的道德原则和人生目标。他 能享受安乐，但绝不沉溺（不终日），能迅速从愉悦中回归正事。这种 高度的自律与清醒，使他能长久吉祥。此爻定义了 健康愉悦的应有状态。


### 六三：盱豫，悔；迟有悔。


**原文**：盱豫，悔；迟有悔。

**白话**：仰视（巴结）权贵以求安乐，必有悔恨；悔悟迟了又有悔恨。

**小象传**
**原文**：盱豫有悔，位不当也。

**白话**：瞪大眼睛盯着享乐会有悔恨，是因为所处的位置不恰当。


**说明**

这是 愉乐的谄媚——上视而悔。

+ “盱豫”：睁大眼睛向上谄媚（盱）以求快乐（豫）。
+ “悔”：必有 悔恨。
+ “迟有悔”：如果 迟疑不改，又会产生 新的悔恨。
+ 爻传“位不当也”：因为 所处位置不正当（阴居阳位）。
**相关性**：六三不中不正，象征 心术不正、趋炎附势的小人。他通过 巴结权贵（盱，仰视九四） 来获取快乐。这种快乐是 扭曲的、寄生的，终将招致悔恨。爻辞用“悔”与“有悔”的双重警告，强调 通过不正当手段获取的愉悦，是双重陷阱，必须迅速远离。


### 九四：由豫，大有得；勿疑，朋盍簪。


**原文**：由豫，大有得；勿疑，朋盍簪。

**白话**：由他而得安乐，大有所得；不必疑虑，朋友会像头发束于簪子一样聚合。

**小象传**
**原文**：“由豫，大有得”，志大行也。

**白话**：想要安逸享乐，就会大有收获，这是因为志向得到了极大的实现。


**说明**

这是 愉乐的源泉——刚而得众。

+ “由豫”：众人由（由）他而获得安乐（豫）。
+ “大有得”：大有所得（既指九四，也指众人）。
+ “勿疑，朋盍簪”：不必疑虑，朋友们会像 头发聚于发簪（盍簪） 一样汇聚而来。
+ 爻传“志大行也”：志向得以大力推行。
**相关性**：九四是全卦唯一的阳爻，居大臣之位，是 带来安乐、凝聚人心的核心力量。他阳刚有力，行动（震）能使柔顺的众人（坤）和悦振奋。因为他 大公无私，给大家带来实实在在的好处（由豫，大有得），所以无需疑虑，自然天下归心（朋盍簪）。此爻体现了 “豫”之乐的真正来源：一个有能力、有担当、造福大众的领导者。


### 六五：贞疾，恒不死。


**原文**：贞疾，恒不死。

**白话**：守正以防疾患，长久不至于灭亡。

**小象传**
**原文**：六五贞疾，乘刚也；恒不死，中未亡也。

**白话**：六五爻辞说坚守正道可防疾患，是因为阴爻凌驾于阳刚之上；能够长久不衰，是因为持守中道没有丧失。


**说明**

这是 愉乐的隐患——柔而乘刚。

+ “贞疾”：守持正道（贞）以防备疾病（疾）。
+ “恒不死”：便能 长久不死。
+ 爻传“乘刚也”：因为 凌乘于阳刚之上（指乘九四）。
**相关性**：六五柔居尊位，是 安乐时代的君主。她本身柔弱，却凌驾于刚健的权臣（九四）之上，这是 潜在的危险（疾）。在天下豫乐之时，她必须 坚守正道，时刻警惕这种权力结构带来的隐患（贞疾），如此才能保持君位长久（恒不死）。此爻告诫领导者：在 和谐愉悦的表象下，需清醒认识并防范结构性风险。


### 上六：冥豫，成有渝，无咎。


**原文**：冥豫，成有渝，无咎。

**白话**：昏昧沉迷于安乐，但已成之事能有所改变，没有咎害。

**小象传**
**原文**：冥豫在上，何可长也。

**白话**：处在昏昧的欢愉之中高居上位，这种状态怎么可能长久呢。


**说明**

这是 愉乐的沉溺——知错能改。

+ “冥豫”：昏昧（冥）沉迷于安乐（豫）。
+ “成有渝”：但 既成（成）的沉迷状态能够改变（渝）。
+ “无咎”：则 没有过错。
+ 爻传“何可长也”：（冥豫的状态）怎么可能长久呢？
**相关性**：上六处卦之极，象征 愉悦到了昏头昏脑、乐不思蜀的境地（冥豫），这是危险的。但爻辞给出了 出路：只要 能幡然醒悟，改变（渝）这种状态，仍可免于咎害。这体现了《周易》 重改过、给出路 的慈悲思想。同时，“何可长也”的断语，也宣告了 纵情享乐必然不能持久 的客观规律。


## 总结

**总结**：豫卦的现代启示
豫卦的 “顺以动” 是关于 如何创造、享受并驾驭“快乐与和谐”这种宝贵资源 的深刻智慧。

乐的来源：真正的、可持续的快乐（豫），源于 一个核心力量（九四）带领大家共同创造价值（由豫，大有得），而非个人放纵（鸣豫）或巴结讨好（盱豫）。

乐的品质：健康的愉悦，要求人 内心有磐石般的定力（介于石），能享受但绝不沉溺（不终日），并 迅速回归正轨。

乐的陷阱：

+ 个人层面：自鸣得意（鸣豫） 与 谄媚求乐（盱豫） 是取祸之道。
+ 领导层面：需警惕 权力结构隐患（贞疾） 和 集体性沉迷（冥豫）。

乐的运用：愉悦和谐的状态，是 采取重大行动（建侯行师）的最佳时机，因为此时人心齐，动力足。

核心心法：彖传总纲——“顺以动”。一切行动必须 顺应天时、地利、人心。豫乐是“顺”的结果，也是“动”的良机。

豫卦与谦卦的承续：谦卦（䷎）讲 “卑以自牧”（功成不居），是 成功后的心态；豫卦（䷏）讲 “顺以动”（乐而有为），是 心态平和、团队和谐时的行动。《序卦传》言：“有大而能谦必豫，故受之以豫。” 意思是：拥有巨大成就（大有）而能保持谦逊，就一定会带来安乐和悦（豫）的局面。因此，谦是豫之因，豫是谦之果。一个谦逊的领导者能凝聚人心，创造和谐（豫）；而豫乐和谐的局面，又为 下一步开创事业（利建侯行师） 奠定了绝佳基础。从谦到豫，体现了 “德致和乐，和乐兴事” 的良性循环。
