# 观卦（巽上坤下）

**卦画**：䷓

## 总论：观瞻的哲学

**核心短词**：“省方观民”

**卦象**：上巽（☴）为风、为入，下坤（☷）为地、为顺。风地观。风行地上，遍观万物；以上观下，以德化民。

**核心卦辞**：“观，盥而不荐，有孚颙若。”

**总纲**：观卦探讨 “观察”与“被观察” 的智慧。如何通过观察洞悉本质，以及如何通过自身德行成为被观察、被效法的典范。

+ “观”：观看、观察、瞻仰。
+ “盥而不荐，有孚颙若”：在祭祀时，观看（观）盥洗（盥）的洁净诚敬之礼就已足够，而不必观看后续进献（荐）祭品的细节；心中充满 诚信（有孚），容貌庄严仰慕（颙若）。比喻 观察重在感受其内在的精神与诚意，而非外在形式。

**本质**：观卦的核心是 “大观在上” 与 “下观而化”。它强调，居于上位的领导者（大观）其 德行与诚意 是天下人观察、效法的对象；而通过这种观察，民心自然受到教化（下观而化）。其最高境界是 “圣人以神道设教，而天下服矣”——圣人观察自然神妙之道，设立教化，使天下百姓顺服。

## 卦辞

### 经

**原文**：盥而不荐，有孚颙若。

**白话**：祭祀前洗手自洁，尚未进献祭品，心中已充满诚敬肃穆。

### 彖传

**原文**：大观在上，顺而巽，中正以观天下。观，盥而不荐，有孚颙若，下观而化也。观天之神道，而四时不忒；圣人以神道设教，而天下服矣。

**白话**：宏大景象展现于高处，和顺而谦逊，以中正之德观照天下。观卦的含义，如同祭祀时洗净双手尚未进献祭品，内心充满虔诚与敬畏，在下者观此而受感化。观察天地神妙的运行规律，四季更替毫无差错；圣人效法这种神妙之道来设立教化，天下万民便自然顺服。

### 大象传

**原文**：风行地上，观；先王以省方，观民设教。

**白话**：风在大地上吹拂，象征观仰；先代君王因此巡视四方，观察民情，设立教化。


## 爻辞

### 初六：童观，小人无咎，君子吝。


**原文**：童观，小人无咎，君子吝。

**白话**：像孩童一样观察，小人没有咎害，君子则有憾惜。

**小象传**
**原文**：初六童观，小人道也。

**白话**：初六爻辞说像孩童一样观察，这是小人的见识。


**说明**

这是 观察的初始——幼稚之观。

+ “童观”：像 孩童（童） 一样 肤浅、幼稚地观察。
+ “小人无咎”：对 普通百姓（小人） 来说，这没有过错。
+ “君子吝”：但对 有抱负的君子 来说，则是 憾惜。
**相关性**：初六阴柔在下，远离九五（大观），象征 地位低微、见识浅薄者。其“童观”是 视野狭窄，只能看到表面。对于普通人，这情有可原（无咎）。但对于立志治国平天下的君子，若满足于此等浅见，则无法洞察本质，担当大任，故为“吝”。此爻区分了 不同层次观察者的责任与要求。


### 六二：窥观，利女贞。


**原文**：窥观，利女贞。

**白话**：从门缝中窥视，利于女子守正。

**小象传**
**原文**：窥观女贞，亦可丑也。

**白话**：从门缝里偷看，即使是女子坚守正道，也是可耻的行为。


**说明**

这是 观察的局限——管窥之见。

+ “窥观”：从 门缝、缝隙（窥）中偷看，比喻 观察角度狭隘，不见全局。
+ “利女贞”：利于 女子守持正道（在旧时语境中，女子深居闺中，窥观外界是常态）。
+ 爻传“亦可丑也”：（但对君子而言）也是可羞耻的。
**相关性**：六二柔顺中正，但处于坤卦（内），象征 虽有中正之德，但视野受环境所限。“窥观”比“童观”稍进一步，但仍是 一孔之见，不见全体。爻辞以“利女贞”作比，说明这种观察方式 在特定情境（如女子闺中）下是合宜的，但若用于治国安邦，则显得 格局太小，难堪大用（亦可丑）。


### 六三：观我生，进退。


**原文**：观我生，进退。

**白话**：观察自我的行为得失，以决定进退。

**小象传**
**原文**：“观我生，进退”，未失道也。

**白话**：观察自己的行为，决定前进或后退，这样做并没有偏离正道。


**说明**

这是 观察的内省——反观自身。

+ “观我生”：观察（观）自我（我）的所作所为、人生轨迹（生）。
+ “进退”：从而 决定前进或后退。
+ 爻传“未失道也”：如此便 没有偏离正道。
**相关性**：六三处下卦之极，是 由内观转向外观的临界点。在观察外界（童观、窥观）之后，真正的智慧始于 向内观察自我（观我生），审视自己的动机、行为与处境。基于这种深刻的自我认知，才能做出 合宜的进退抉择。此爻强调了 “观察”的终极目的之一：指导自身的正确行动。


### 六四：观国之光，利用宾于王。


**原文**：观国之光，利用宾于王。

**白话**：观仰国家政教的光辉，利于成为君王的宾客。

**小象传**
**原文**：“观国之光”，尚宾也。

**白话**：观察国家的风土人情，是因为尊重和礼遇贤能的宾客。


**说明**

这是 观察的向上——瞻仰盛德。

+ “观国之光”：观察（观）国家的（国）光明景象与昌盛德政（光）。
+ “利用宾于王”：利于 以宾客（宾）身份辅佐君王（王）。
+ 爻传“尚宾也”：这是 推崇贤能宾客之道。
**相关性**：六四已进入上卦（巽），紧邻九五君王，象征 接近权力中心、有见识的贤士。他的“观”不再局限于自身或狭小范围，而是 向上观察国家的整体气象与君王的德行（国之光）。若所见为光明昌盛，则说明值得辅佐，故“利用宾于王”。此爻描述了 贤才择主而事 的观察过程。


### 九五：观我生，君子无咎。


**原文**：观我生，君子无咎。

**白话**：观察自我的行为得失，君子没有咎害。

**小象传**
**原文**：“观我生”，观民也。

**白话**：观察我的生活，就是观察民众。


**说明**

这是 观察的典范——君临天下。

+ “观我生”：观察自我的行为得失。
+ “君子无咎”：君子（此处特指君王） 没有过错。
+ 爻传“观民也”：因为 （君王）观察自我，其实就是观察民情。
**相关性**：九五阳刚中正，居尊位，是 天下人观瞻的典范（大观）。他的“观我生”境界最高：君王自身的德行就是国家兴衰的缩影。他观察自己的施政得失（观我生），就是在 观察天下百姓的苦乐与民心的向背（观民）。此爻揭示了 最高领导者的观察，是内省与外察的高度统一，故能“无咎”。


### 上九：观其生，君子无咎。


**原文**：观其生，君子无咎。

**白话**：观察他人的行为得失，君子没有咎害。

**小象传**
**原文**：“观其生”，志未平也。

**白话**：观察他的生活状态，是因为内心的志向还未得到安定。


**说明**

这是 观察的超越——旁观者清。

+ “观其生”：观察（观）他人（其）的行为得失、人生轨迹（生）。
+ “君子无咎”：君子 没有过错。
+ 爻传“志未平也”：因为 （心系天下的）志向未曾平息。
**相关性**：上九处卦之极，已 超越于具体职位之上，象征 退休的贤臣、在野的圣人或超然的观察者。他已不直接参与治理（非“我生”），但仍 心系天下，观察着在位者（其，指九五）的作为与民生。这种 冷静、客观、超越利害的观察（观其生），能提供最清醒的借鉴与警示。因其 志在天下（志未平），故“无咎”。这是 观察的终极境界：心怀天下，冷眼热肠。


## 总结

**总结**：观卦的现代启示

观卦的 “省方观民” 是关于 认知、学习、领导与教化 的深邃智慧。

观察的层次：

+ 初级阶段（初六、六二）：警惕 肤浅（童观）与狭隘（窥观） 的认知。
+ 关键转折（六三）：学会 向内观察自我（观我生），以指导行动。
+ 向上学习（六四）：善于 观察和选择更优秀的平台与领导者（观国之光）。
+ 领导境界（九五）：最高领导者要明白 自我观察即是观察民情，以身作则，成为被观察的典范。
+ 终极智慧（上九）：培养 超越自身立场的客观观察力（观其生），心怀天下。

核心心法：大象传总纲——“先王以省方观民设教”。这意味着：

+ “省方”：巡视四方，实地观察。
+ “观民”：观察民情风俗，了解真实情况。
+ “设教”：根据观察所得，设立相应的教化。

这是一个 “观察—理解—教化” 的完整领导循环。

观察的精髓：卦辞 “盥而不荐，有孚颙若” 指出，真正的观察，重在感受内在的精神、诚意与本质，而非纠缠于外在的形式与细节。无论是观察他人，还是展示自己，诚敬之心（孚） 才是根本。

观卦与临卦的承续：临卦（䷒）讲 “亲临治理”（教思无穷），是 领导者主动施加影响；观卦（䷓）则讲 “观察感化”（省方观民），是 领导者通过自身德行成为被观察、被效法的榜样，从而被动地施加影响。《序卦传》言：“临者，大也。物大然后可观，故受之以观。” 意思是：临卦是盛大。事物盛大然后才有可观之处，所以继之以观卦。治理有成（临之“大”），方有可观之象（观）。观卦探讨的，正是 在事业盛大、有“可观”之处时，如何通过“观”来巩固教化、维持盛况。从临到观，体现了 从“主动作为”到“榜样感化” 的领导力深化。
