# 损卦（艮上兑下）

**卦画**：䷨

## 总论：减损之道的哲学

**核心短词**：“惩忿窒欲”

**卦象**：上艮（☶）为山、为止，下兑（☱）为泽、为悦。山泽损。山下有泽，损下益上。

**核心卦辞**：“有孚，元吉，无咎，可贞，利有攸往。曷之用？二簋可用享。”

**总纲**：损卦象征 “减损”，心怀诚信，至为吉祥，没有咎害，可以守持正固，利于有所前往。减损之道如何体现？两簋淡食就可以用来祭祀。

+ “有孚，元吉，无咎，可贞，利有攸往”：这是 损卦的总原则。减损必须出于诚信（有孚），动机至善（元吉），方法得当（无咎），符合正道（可贞），如此才 利于行动发展（利有攸往）。
+ “曷之用？二簋可用享”：这是 损卦的实践象征。“曷之用”——减损之道如何应用？ 答案是：“二簋可用享”——用最简单的两簋（古代盛食物的器皿）淡食就可以进行庄重的祭祀。这象征 **减损的实质是：去除浮华，回归根本；减少形式，注重诚意。只要心诚，简单的形式（二簋）足以沟通神明（享）。

**本质**：损卦描述 “损下益上” 的治理模型，但其哲理远超于此。它探讨 一切“减损”行为的正当性与艺术性。上艮山止，下兑泽悦，泽水侵蚀山脚（损下），山体增益显得更高（益上）。其**核心精神**是：**减损不是目的，而是 手段。正当、适时、有度的减损（损），是为了实现更大的增益（益）。关键在于 心怀诚信，把握时机，损所当损。

## 卦辞

### 经

**原文**：有孚，元吉，无咎，可贞，利有攸往。曷之用？二簋可用享。

**白话**：心怀诚信，至为吉祥，没有咎害，可以守持正固，利于有所前往。如何体现减损之道？用两簋淡食祭祀即可。

### 彖传

**原文**：损，损下益上，其道上行。损而有孚，元吉，无咎，可贞，利有攸往。曷之用？二簋可用享；二簋应有时。损刚益柔有时，损益盈虚，与时偕行。

**白话**：减损，是减损下方来增益上方，其道理是向上运行。减损而心怀诚信，最为吉祥，没有咎害，可以持守正道，利于有所前往。如何运用减损之道呢？两簋淡食就足以奉献给神灵；使用两簋淡食祭祀要顺应时势。减损刚强来增益柔弱要适时，事物的减损增益、盈满亏虚，都是伴随时势而自然运行的。

### 大象传

**原文**：山下有泽，损；君子以惩忿窒欲。

**白话**：山下面有沼泽，这就是损卦的意象；君子因此要克制愤怒，抑制欲望。


## 爻辞

### 初九：已事遄往，无咎，酌损之。


**原文**：已事遄往，无咎，酌损之。

**白话**：完成了自己的事就迅速前往辅助尊者，没有咎害，但应斟酌减损的程度。

**小象传**
**原文**：“已事遄往”，尚合志也。

**白话**：停下自己的事赶快前去，说明与尊上心志相合。


**说明**

这是 损道的开始——量力而助。

+ “已事遄往”：完成了（已）自己的事（事）就迅速（遄）前往（往）。
+ “无咎”：没有咎害（无咎）。
+ “酌损之”：应斟酌（酌）减损（损）的程度（之）。
+ 爻传“尚合志也”：（因为）与上者（九四）心志相合。

**相关性**：初九阳刚处下，与六四相应，是 基层的阳刚力量。“已事”指 先完成自身职责；“遄往”指 然后迅速去辅助上者（六四）。爻辞指出：**这种 损己利上 的行为，因为 动机纯正（合志）且先尽己责，所以没有咎害。但特别强调 “酌损之”——**必须 斟酌度量，根据自身实际情况来减损，不可过度，以免伤及根本。此爻确立了损道的基本原则：**损己助人，一要自愿（合志），二要量力（酌损）。


### 九二：利贞，征凶，弗损益之。


**原文**：利贞，征凶，弗损益之。

**白话**：利于守持正固，前进有凶险，不用减损而能有益于上。

**小象传**
**原文**：九二利贞，中以为志也。

**白话**：九二爻辞说利于守持正固，是因为它以持守中道作为自己的志向。


**说明**

这是 损道的特例——不损而益。

+ “利贞”：利于（利）守持正固（贞）。
+ “征凶”：出征（征）则凶（凶）。
+ “弗损益之”：不用（弗）减损（损）就能有益（益）于上（之）。
+ 爻传“九二利贞，中以为志也”：九二利于守正，是因为以持守中道为心志。

**相关性**：九二阳刚居中，是 下卦的中坚力量。爻辞出现了一个悖论：在“损”卦中，却说 “弗损益之”——不通过减损自己，也能有益于上。这是因为九二 持守中道（中），本身处于 最佳状态。对于整体（上卦）而言，保持九二的完整与稳定（利贞），其产生的价值（如榜样、稳定、产出）本身就是最大的“益上”。若强行让其“损”（征，指行动改变状态），反而会破坏平衡，带来凶险。此爻揭示了损道的深层智慧：有时，“不损”就是最大的“益”**。维护核心力量的完整，比削弱它去补益别处更为重要。


### 六三：三人行，则损一人；一人行，则得其友。


**原文**：三人行，则损一人；一人行，则得其友。

**白话**：三人同行，则会减损一人；一人独行，则会得到朋友。

**小象传**
**原文**：一人行，三则疑也。

**白话**：一个人独自前行可以专心致志，三个人一起走就会互相猜疑。


**说明**

这是 损道的法则——阴阳专应。

+ “三人行，则损一人”：三人（三人）同行（行），就会减损（则损）一人（一人）。
+ “一人行，则得其友”：一人（一人）独行（行），就会得到（则得）朋友（其友）。
+ 爻传“一人行，三则疑也”：一人独行（可以专心），三人同行就会产生猜疑。

**相关性**：六三阴柔，处于上下卦之交，是 损卦中代表“损”的行为主体。爻辞用了一个普遍的社会与自然规律来比喻：**在关系中，多则疑，专则合。“三人行”象征 多而杂，心思不专，容易产生内耗与猜疑（三则疑），最终会 减损掉一部分（损一人），回归到更稳定的“二人”状态。“一人行”象征 心志专一，目标明确，这样反而容易 吸引到志同道合者（得其友），形成稳定的“二人”配对。这揭示了 **损道的根本原理：减损是为了达到精纯与专一，**多余的、分散的、不专的（三人）必须损去，才能实现 稳固的、高效的阴阳结合（一人得友）。这是天地、男女、万物相感的基本法则。


### 六四：损其疾，使遄有喜，无咎。


**原文**：损其疾，使遄有喜，无咎。

**白话**：减损自己的疾患，能迅速痊愈而欣喜，没有咎害。

**小象传**
**原文**：“损其疾”，亦可喜也。

**白话**：减损了疾病，也是值得欣喜的事。


**说明**

这是 损道的应用——去病迎新。

+ “损其疾”：减损（损）他的（其）疾病（疾）。
+ “使遄有喜”：使之（使）迅速（遄）好转，有喜庆（有喜）。
+ “无咎”：没有咎害（无咎）。
+ 爻传“损其疾，亦可喜也”：减损他的疾病，也是值得欣喜的。

**相关性**：六四阴柔得正，与初九相应，是 接受下卦增益的尊者。“疾”比喻 自身的缺点、过错或面临的困难。爻辞描述：**尊者 主动减损、去除自身的弊病（损其疾）。由于 行动及时（遄），且 对症下药，所以能 迅速好转，带来喜庆。这种行为 不仅无咎，更是可喜可贺的。此爻将“损”的对象从“损己益人”转向 “损己之恶”，强调：**最高明的“损”，是 对自身缺点、错误的主动削减与修正。这种 自我革新 带来的“喜”，是内在的、根本的增益。


### 六五：或益之十朋之龟，弗克违，元吉。


**原文**：或益之十朋之龟，弗克违，元吉。

**白话**：有人进献价值十朋的宝龟，无法推辞，至为吉祥。

**小象传**
**原文**：六五元吉，自上祐也。

**白话**：六五爻所说的至为吉祥，是因为有来自上天的保佑。


**说明**

这是 损道的成果——不招而益。

+ “或益之十朋之龟”：有人（或）进献（益之）价值十朋（十朋）的宝龟（之龟）。
+ “弗克违”：无法（弗克）推辞（违）。
+ “元吉”：至为吉祥（元吉）。
+ 爻传“六五元吉，自上祐也”：六五至为吉祥，是来自上天的保佑。

**相关性**：六五柔中居尊，是 损卦的受益之主。“十朋之龟”是 极其贵重的宝物，象征 巨大的、来自各方的增益。“或”字表明 这些增益并非主动索求，而是自然而来。“弗克违”形容 其增益之正当与丰厚，令人无法也不应拒绝。爻辞描绘了一幅 “不求而自得” 的景象：因为尊者（六五） 自身 柔中虚怀，行损道（损下）时公正有孚，所以德能感召，众人（下卦）自愿且丰厚地增益于他，乃至得到 上天庇佑（自上祐也），获得至大吉祥。此爻揭示了损道的终极境界：**真正的“益”，不是通过算计与强求得来，而是 通过践行正当的“损”道，自然感召而来的福报。


### 上九：弗损益之，无咎，贞吉，利有攸往，得臣无家。


**原文**：弗损益之，无咎，贞吉，利有攸往，得臣无家。

**白话**：不用减损他人而能有益于人，没有咎害，守持正固吉祥，利于有所前往，得到臣民的拥戴而不限于一家。

**小象传**
**原文**：“弗损益之”，大得志也。

**白话**：不减少反而增加，说明志向得到极大的实现。


**说明**

这是 损道的升华——惠泽天下。

+ “弗损益之”：不用（弗）减损（损）他人就能有益（益）于人（之）。
+ “无咎，贞吉”：没有咎害（无咎），守正吉祥（贞吉）。
+ “利有攸往”：利于（利）有所前往（有攸往）。
+ “得臣无家”：得到（得）臣服者（臣）而不分私家（无家）。
+ 爻传“弗损益之，大得志也”：不用减损他人就能有益于人，是大大得志。

**相关性**：上九阳刚处卦之极，是 损道的完成者与超越者。爻辞再次出现 “弗损益之”，但与九二内涵不同。上九位于损卦顶端，本身已是“益”的极点。其“益之”的方式，**不是通过损下，而是通过 自身的德政、智慧或资源，直接惠及天下（弗损）。“得臣无家”是关键：**得到众人的归附与效忠（得臣），但 不将这些视为一己之私产（无家），而是 以天下为公。这种 “普益天下而不私” 的境界，使其 心志得以极大实现（大得志也），无往不利。此爻将损道从 “损己益人” 的交换层面，提升到 “不损而益” 的创造与奉献层面，是 圣王治世的理想图景。


## 总结

**总结**：损卦的现代启示

损卦的 “惩忿窒欲” 是关于 “减少”与“失去”的深刻哲学，它教导我们 如何智慧地看待与运用“减损”。

践行损道的六重境界：

+ 量力而助（初九）：已事遄往，酌损合志。
+ 守中不损（九二）：弗损益之，中以为志。
+ 专一得合（六三）：三人损一，一人得友。
+ 去病迎新（六四）：损其疾，遄有喜。
+ 虚中受益（六五）：十朋之龟，自上祐也。
+ 惠泽天下（上九）：弗损益之，得臣无家。

核心心法：大象传总纲——“山下有泽，损；君子以惩忿窒欲。” 这意味着：

+ “山下有泽，损”：是 损卦之象（泽水侵蚀山基，山体看似受损）。
+ “君子以惩忿窒欲”：君子效法此象，抑制忿怒，杜塞贪欲。
这是 损卦精神的灵魂：将“损”的智慧首先应用于 自身修养。“惩忿”** 是 减损不良情绪（损其疾）；“窒欲” 是 减损过度欲望。这是 最根本、最主动的“损”。通过 损去内心的毒素与负累，人才能 轻装上阵，增益德行与智慧。这是 “损”道向内求的至高应用。

根本精神：彖传 “损，损下益上，其道上行。损而有孚，元吉……损刚益柔有时，损益盈虚，与时偕行。” 点明了损道的精髓：

+ “损下益上，其道上行”：描述了 损卦的基本结构。
+ “损而有孚，元吉”：强调了 诚信是损道成功的基石。
+ “损刚益柔有时，损益盈虚，与时偕行”：这是 损卦的总法则。减损阳刚、增益阴柔要讲究时机。**一切减损与增益、盈满与虚空，都要 顺应时势的变化而进行（与时偕行）。、

损卦告诉我们：**“损”不是消极的失去，而是 积极的调节。它关乎 资源的合理再分配（损下益上），关乎 关系的优化（三人损一），关乎 自我的革新（损其疾），更关乎 时机的把握（与时偕行）。无论是个人 戒除坏习惯（惩忿窒欲）、企业 削减成本聚焦核心，还是政府 实施紧缩政策以利长远，都需要 深刻理解“损”的智慧——知道何时损、损什么、损多少，以及如何通过正当的“损”来实现更长远的“益”。这便是在 “二簋可用享” 的朴素中，所蕴含的 至深至广的治理与人生智慧。
