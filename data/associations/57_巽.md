# 巽卦（巽上巽下）

**卦画**：䷸

## 总论：巽顺之道的哲学

**核心短词**：“申命行事”

**卦象**：上巽（☴）为风、为入、为顺，下巽（☴）为风、为入、为顺。巽为风。两风相随，无所不入。

**核心卦辞**：“小亨，利有攸往，利见大人。”

**总纲**：巽卦象征 “巽顺、进入”。小有亨通，利于有所前往，利于出现大德之人。

+ “小亨”：小有亨通（小亨）。巽顺之道，非刚健主导，而是以柔克刚，以顺求进，故其亨通是 渐进、渗透式的，而非 宏大、迅猛的，故称 “小亨”。
+ “利有攸往，利见大人”：利于有所前往（利有攸往），利于出现大德之人（利见大人）。巽顺并非 消极退缩，而是一种积极的 行动策略。以柔顺的姿态 进入、前往，更易 被接受，减少阻力。而 “大人”（指 九五）是巽顺之道的 主持者和榜样，其 中正之德 能使巽顺发挥 正面效用，避免流于 谄媚与软弱。

**本质**：巽卦描述 “随风，巽” 的状态。两风相随，前风引导，后风顺从，象征 一种 深入、顺从、调和、贯彻 的 行为方式。其**核心精神**是：探讨 “巽”的智慧——如何 以 柔顺、深入、灵活 的方式 处理事务、贯彻命令、适应环境。它强调 “重巽以申命”——通过反复的 申明与贯彻（重巽），来**实现 意志的推行（申命）。

## 卦辞



### 经

**原文**：小亨，利有攸往，利见大人。

**白话**：小有亨通，利于有所前往，利于出现大人。

### 彖传

**原文**：重巽以申命。刚巽乎中正而志行，柔皆顺乎刚，是以“小亨，利有攸往，利见大人”。

**白话**：两个巽卦重叠，意在强调命令的传达与执行。阳刚者凭借中正之德被顺从，其志向得以推行；阴柔者都能顺应阳刚，因此说“小有亨通，利于有所前往，利于见到大人”。

### 大象传

**原文**：随风，巽；君子以申命行事。

**白话**：风与风相随，这就是巽卦的意象；君子因此领悟，要反复宣告政令，处理政事。


## 爻辞

### 初六：进退，利武人之贞。


**原文**：进退，利武人之贞。

**白话**：进退犹豫，利于武人守持正固。

**小象传**
**原文**：“进退”，志疑也。“利武人之贞”，志治也。

**白话**：在进退之间犹豫不决，是因为内心有疑虑；利于武人坚守正道，是因为心志坚定而清明。


**说明**

这是 巽顺的开端——柔而失断，需刚正之志。

+ “进退”：进退犹豫（进退）。
+ “利武人之贞”：利于武人守持正固（利武人之贞）。
+ 爻传“进退，志疑也；利武人之贞，志治也”：进退犹豫，说明心志疑虑；利于武人守持正固，说明（需要）用刚武来整治心志。

**相关性**：初六阴柔处下，是巽顺的 初始，但 过于柔弱，缺乏 主见和决断力，故面对抉择时 犹豫不决（进退）。爻传指出 其 “志疑也”，病因在 内心。解药 是 “利武人之贞”。“武人”象征 刚毅、果决 的 品质。并非要初六变成 武夫，而是劝诫其要像武人一样，以刚健、正固的 意志（贞） 来 整治（治） 自己柔弱疑惧的 心志。此爻阐明：巽顺的 起点，不能是无原则的 软弱，而必须建立在内心的 刚正与坚定 之上。


### 九二：巽在床下，用史巫纷若，吉，无咎。


**原文**：巽在床下，用史巫纷若，吉，无咎。

**白话**：谦逊至极，屈居床下，效法史官巫祝以纷繁之礼敬神，吉祥，没有咎害。

**小象传**
**原文**：“纷若之吉”，得中也。

**白话**：事情繁多却仍能吉祥，是因为能够持守中道。


**说明**

这是 巽顺的典范——谦卑至诚，处中得吉。

+ “巽在床下”：谦顺卑居床下（巽在床下）。
+ “用史巫纷若”：效法史巫以至诚敬事（用史巫纷若）。
+ “吉，无咎”：吉祥（吉），没有咎害（无咎）。
+ 爻传“纷若之吉，得中也”：至诚敬事而获吉祥，是因为（九二）得乎中道。

**相关性**：九二阳刚居中，是巽顺之道的优秀实践者。“巽在床下”是极言其谦卑、柔顺的姿态，甘居低位。“用史巫纷若”是点明其巽顺的内在品质。“史”记录言行，“巫”沟通神人，二者皆需要极度虔诚、细致、不厌其烦（纷若）。九二以此自比，说明其巽顺是发自内心的至诚与敬业，而非表面的做作。因其阳刚而能谦（刚而能柔），且持守中道（得中），故虽姿态极低，却能获吉而无咎。此爻描绘了巽顺的理想状态：外在极尽谦卑，内在极尽诚敬，且 符合中道。


### 九三：频巽，吝。


**原文**：频巽，吝。

**白话**：频频表示谦逊，有憾惜。

**小象传**
**原文**：“频巽之吝”，志穷也。

**白话**：频繁地顺从会带来遗憾，是因为心志已经穷尽了。


**说明**

这是 巽顺的偏差——勉强顺从，志气受挫。

+ “频巽”：频频表示巽顺（频巽）。
+ “吝”：而有憾惜（吝）。
+ 爻传“频巽之吝，志穷也”：频频巽顺的憾惜，是因为心志穷困。

**相关性**：九三阳刚过中，处下卦之极，是刚健者身处巽顺环境的尴尬角色。它本性刚强，却不得不频频（频）表现出顺从（巽）的姿态。这种“巽”是被迫的、勉强的、不情愿的，与其内在刚健的心志相冲突。爻传尖锐地指出“志穷也”：其心志被压抑、被扭曲，感到穷困、屈辱。因此，即使表面顺从，内心却充满憾惜与不甘（吝）。此爻揭示了巽顺可能导致的负面心理：当顺从失去真诚，变成一种压抑本性的表演时，人格将受到损伤。


### 六四：悔亡，田获三品。


**原文**：悔亡，田获三品。

**白话**：悔恨消亡，田猎获得多种猎物。

**小象传**
**原文**：“田获三品”，有功也。

**白话**：田猎获得多种猎物，这是有功劳的。


**说明**

这是 巽顺的成功——柔顺当位，行事有成。

+ “悔亡”：悔恨消亡（悔亡）。
+ “田获三品”：田猎获得多种猎物（田获三品）。
+ 爻传“田获三品，有功也”：田猎获得多种猎物，说明（六四）建立功勋。

**相关性**：六四阴柔得正，居 上卦巽顺之始，又 近承 九五之君，是 巽顺之道 的 得位者与执行者。“悔亡” 意味着其巽顺的姿态起初或许令人 有所疑虑（悔），但因其 位置得当、行为端正，最终疑虑 消失。“田获三品”是比喻其巽顺带来的 丰硕成果。“田猎” 象征 有所行动、有所追求；“三品” 指上、中、下 各类猎物，比喻多方面的、不同层次的 收获与成就。爻传肯定其 “有功也”。此爻表明：当巽顺与 正当的职位、明确的目标 相结合时，便能从一种 姿态，**转化为有效率的 行动，并取得实实在在的 功绩。


### 九五：贞吉，悔亡，无不利。无初有终。先庚三日，后庚三日，吉。


**原文**：贞吉，悔亡，无不利。无初有终。先庚三日，后庚三日，吉。

**白话**：守持正固吉祥，悔恨消亡，无所不利。起初不顺利，但最终有好结果。在庚日前后三天（共七日）行事，吉祥。

**小象传**
**原文**：九五之吉，位正中也。

**白话**：九五爻之所以吉祥，是因为它位置既端正又居中。


**说明**

这是 巽顺的核心——君王申命，除弊兴利。

+ “贞吉，悔亡，无不利”：守持正固吉祥（贞吉），悔恨消亡（悔亡），无所不利（无不利）。
+ “无初有终”：起初不顺利（无初）但最终有好结果（有终）。
+ “先庚三日，后庚三日，吉”：在庚日前后三天（共七日）申饬命令（先庚三日，后庚三日），吉祥（吉）。
+ 爻传“九五之吉，位正中也”：九五的吉祥，是因为（其）位置端正而守中。

**相关性**：九五阳刚中正，居 尊位，是巽卦的 卦主，代表以巽顺之道来 发号施令、推行变革 的 君主。“贞吉” 强调其自身必须守持 中正之德，这是一切的 前提。“无初有终” 描述了推行新政的 普遍过程：开始往往遇到 阻力或不适（无初），但只要 方法得当、坚持到底，终将 成功（有终）。“先庚三日，后庚三日” 是巽卦最著名的 行动智慧。“庚” 在天干 中 象征 “变更”。“先庚三日”（丁、戊、己） 是 变更 前的 预备、宣导；“后庚三日”（辛、壬、癸） 是变更后的 执行、巩固。这七日的 完整周期，强调在 推行命令、实施变革 时，必须有充分的 事前沟通（巽入人心） 和事后的 跟进落实（巽入于事），如此方能顺利 除旧布新，获得 吉祥。爻传归结于 “位正中也”，再次强调领导者的 中正品德 是 “申命” 成功的 根本保障。此爻是巽顺之道的 最高应用，即领导者如何以深入、细致、反复的方式，温和而坚定地推行 意志与变革。


### 上九：巽在床下，丧其资斧，贞凶。


**原文**：巽在床下，丧其资斧，贞凶。

**白话**：谦逊至极，屈居床下，丧失了资财和利斧，守持正固以防凶险。

**小象传**
**原文**：“巽在床下”，上穷也。“丧其资斧”，正乎凶也。

**白话**：谦卑顺从到了床底下，是因为居上位者已经无路可走。丢失了钱财和工具，说明正处于凶险之中。


**说明**

这是 巽顺的极端——卑顺至极，失其根本。

+ “巽在床下”：谦顺卑居床下（巽在床下）。（与九二爻辞相同）
+ “丧其资斧”：丧失了资财与利斧（丧其资斧）。
+ “贞凶”：守持正固以防凶险（贞凶）。
+ 爻传“巽在床下，上穷也；丧其资斧，正乎凶也”：谦顺卑居床下，说明（上九）已处于穷极之位；丧失资斧，说明（即使）守正也难免凶险。

**相关性**：上九阳刚处卦之极，是巽顺的、终极，已、过度。它机械地模仿九二的、“巽在床下”，但处境已、完全不同。九二、处中，巽是、美德；上九、处穷极之位（上穷），再一味、卑顺，便是失去原则、尊严和、立身之本。“资斧”、象征旅人的资财与、防身工具，引申为、立身处世的、根本凭借与刚健之力。“丧其资斧”、意味着因、过度巽顺、而丧失了自我保护的、能力、与独立行动的、资本。爻传甚至说、“正乎凶也”：到了、这一步，即使你内心想、守持正道（贞），外在的凶险也已、难以避免。此爻是对巽顺可能导致的最大危险的、警告：巽顺一旦失去、中道，沦为无原则的、卑躬屈膝，将使人丧失、根本，陷入无法自救的、凶险境地。


## 总结

**总结**：巽卦的现代启示

巽卦的 “申命行事” 是关于 “柔顺、深入、贯彻”的行动智慧与权力艺术。它探讨了 从 个人修养 到 领导统御 中，“巽”** 这一 柔性力量 的 运用法则与边界。

实践巽顺之道的六个层次与境界：

+ 过柔不决（初六）：进退，利武人之贞。
+ 卑巽至诚（九二）：巽在床下，用史巫纷若，吉，无咎。
+ 屡顺失刚（九三）：频巽，吝。
+ 柔顺得位（六四）：悔亡，田获三品。
+ 中正申命（九五）：贞吉，悔亡，无不利；无初有终；先庚三日，后庚三日，吉。
+ 巽顺过甚（上九）：巽在床下，丧其资斧，贞凶。

核心心法：大象传总纲——“随风，巽；君子以申命行事。” 这意味着：

+ “随风，巽”：是 巽卦之象（风随风，相随而入）。
+ “君子以申命行事”：君子效法此象，反复申明命令，并付诸行动。

这是巽卦精神的 直接应用。君子从风的 相随、深入、无孔不入 的特性中，领悟到推行政令、贯彻 意志 的 方法：**要像风一样 ，反复地 宣讲、渗透（申命），使之 深入人心；然后要 切实地 执行、推进（行事），使 之 落到实处。“申命” 与 “行事” 构成了巽顺之道在公共管理上的 完整闭环。

根本精神：彖传 “重巽以申命。刚巽乎中正而志行，柔皆顺乎刚，是以小亨，利有攸往，利见大人。” 揭示了巽顺之道的运作机理：

+ “重巽以申命”：上下皆巽（重巽），用以反复申明命令（申命）。开宗明义，**点出巽卦的核心 功用。
+ “刚巽乎中正而志行”：（九五）阳刚以巽顺的姿态持守 中正，从而其志向得以 推行（志行）。解释卦主九五 的 成功模式：刚健的意志 （刚），通过巽顺的方式 （巽乎），并秉持中正的 原则，得以 实现。
+ “柔皆顺乎刚，是以小亨，利有攸往，利见大人”：（初六、六四）阴柔皆顺承 阳刚，所以 小有亨通，利于前往，利于出现大人。解释卦中其他爻的 配合，以及卦辞的 由来。

巽卦告诉我们：“巽” 是一种强大的 “软实力”。它不是 软弱，而是一种有目的的 深入；不是 屈服，而是一种有策略的 顺应；不是 无声，而是一种有效率的 传达与贯彻（申命）。其 最高境界 是九五爻 的 “先庚三日，后庚三日”——在变革中展现的 周全、耐心与坚定。而其 最大陷阱，是上九爻 的 “丧其资斧”——在顺从中迷失自我的根本与 刚健。在 “随风” 的 流动与渗透 中，真正的 力量，在于那驱动风的 “中正之志”，以及那把握风向与分寸的 “申命行事” 的 智慧。这便是在 “巽为风” 的 无所不入 中，所蕴含的关于 沟通、执行、适应与领导 的 深邃法则。
