# 遁卦（乾上艮下）

**卦画**：䷠

## 总论：退避的哲学

**核心短词**：“远小人，不恶而严”

**卦象**：上干（☰）为天、为健，下艮（☶）为山、为止。天山遁。天下有山，山势逼天，天远山而去；君子远小人，不恶而严。

**核心卦辞**：“遁，亨，小利贞。”

**总纲**：遁卦阐述 “退避、隐遁、适时而退” 之道。亨通，柔小者利于守正。

+ “遁”：退避、隐遁、逃离。
+ “亨”：亨通（识时务而退，故亨）。
+ “小利贞”：柔小者（小）利于（利）守持正道（贞）。

**本质**：遁卦的核心是 “遁而亨也” 与 “刚当位而应，与时行也”。卦象上干天、下艮山，象征 天（君子、阳刚）高高在上，但山（小人、阴柔）在下增长，有逼退天势之象。此时 阴气渐长（小人道长），君子（阳）宜 识时务而退避（遁），以保全自身，等待时机。卦中九五阳刚中正，且与六二相应，说明 退避并非消极逃跑，而是 有原则、有准备、顺应时势（与时行） 的主动策略。

## 卦辞

### 经

**原文**：亨，小利贞。

**白话**：亨通，柔小者利于守持正固。

### 彖传

**原文**：遁亨，遁而亨也。刚当位而应，与时行也。小利贞，浸而长也。遁之时义大矣哉！

**白话**：退避就能亨通，退避之后道路自然顺畅。阳刚者居于正位并与下方相应，这是顺应时势而行动。柔弱者利于持守正道，因为其影响正逐渐增长。退避的时机和意义真是重大啊！

### 大象传

**原文**：天下有山，遁；君子以远小人，不恶而严。

**白话**：天下有山，象征退避；君子因此远离小人，不显露憎恶而保持威严。


## 爻辞

### 初六：遁尾，厉，勿用有攸往。


**原文**：遁尾，厉，勿用有攸往。

**白话**：退避时落在末尾，有危险，不宜有所前往。

**小象传**
**原文**：“遁尾之厉”，不往何灾也。

**白话**：退避时落在末尾的危险，不前往又有什么灾祸呢。


**说明**

这是 退避的滞后——迟疑致危。

+ “遁尾”：退避（遁）时落在末尾（尾）。
+ “厉”：危险。
+ “勿用有攸往”：不宜（勿用）有所前往（有攸往）。
+ 爻传“不往何灾也”：不前往（不往）又有什么灾祸呢？

**相关性**：初六阴柔处下，是 “遁”的开始，也是阴长之始。在退避的大势下，它 反应迟钝，行动迟缓，落在了最后（遁尾）。这非常危险（厉），因为 容易被阴势（小人）追上、包围或牵连。爻辞给出的对策是 “勿用有攸往”——此时不宜再有任何积极的行动或前进，而应 静守不动。爻传更直接点明：不妄动，就不会招灾（不往何灾）。此爻警示：退避贵在神速与果断，迟疑不决将陷于险地。


### 六二：执之用黄牛之革，莫之胜说。


**原文**：执之用黄牛之革，莫之胜说。

**白话**：用黄牛皮革捆缚住，无法挣脱。

**小象传**
**原文**：“执用黄牛”，固志也。

**白话**：用黄牛皮绳牢牢捆住，是为了坚定心志。


**说明**

这是 退避的坚守——中正自固。

+ “执之用黄牛之革”：用黄牛皮革（黄牛之革）牢牢捆缚（执之）。
+ “莫之胜说”：无法（莫之）挣脱（胜说，“说”通“脱”）。
+ 爻传“固志也”：为了 巩固（固）自己的心志（志）。

**相关性**：六二柔顺中正，且与九五相应。在“小人道长”的遁世之时，作为 柔小者（阴爻），她 不随波逐流，不与小人同伍，而是 以中正之德（黄，中色）为“革”（约束），牢牢 固守自己的节操与立场（固志），绝不妥协、绝不改变（莫之胜说）。这种 内心的坚定与自我约束，是 在浊世中洁身自好的最高境界。此爻强调：退避不仅是身体的远离，更是心志的固守。


### 九三：系遁，有疾厉，畜臣妾吉。


**原文**：系遁，有疾厉，畜臣妾吉。

**白话**：心有系恋而未能退避，将有疾患和危险，畜养臣仆侍妾则吉祥。

**小象传**
**原文**：“系遁之厉”，有疾惫也。“畜臣妾吉”，不可大事也。

**白话**：捆绑住退避会有危险，说明有疾病缠身导致疲惫不堪。蓄养臣仆侍妾可获吉祥，说明此时不能担当治国大事。


**说明**

这是 退避的牵绊——系恋致疾。

+ “系遁”：心有系恋（系）而退避（遁）。
+ “有疾厉”：有疾病（疾）和危险（厉）。
+ “畜臣妾吉”：畜养（畜）臣仆侍妾（臣妾）则吉。
+ 爻传“不可大事也”：因为 不可担当大事。

**相关性**：九三阳刚处艮卦之顶（止），与下卦二阴亲比，象征 在退避时，内心对现状、利益或情感有所系恋，无法决绝离去。这种 犹豫不决、拖泥带水的状态（系遁），本身就是一种 心病（疾），且会 招致危险（厉）。爻辞“畜臣妾吉”是比喻：此时只宜处理家中琐事、管理仆从（小事），不可外出担当大任（不可大事）。此爻告诫：退避必须彻底，心无挂碍，否则反受其害。


### 九四：好遁，君子吉，小人否。


**原文**：好遁，君子吉，小人否。

**白话**：心怀好感而能退避，君子吉祥，小人则否。

**小象传**
**原文**：君子好遁，小人否也。

**白话**：君子能够从容退避，小人就做不到这一点。


**说明**

这是 退避的洒脱——舍所好遁。

+ “好遁”：即使心怀喜好（好），也能毅然退避（遁）。
+ “君子吉，小人否”：君子（君子）吉祥，小人（小人）则做不到（否）。
+ 爻传“君子否，小人否也”：君子能（否，通“不”，意为“不系恋”），小人则不能。

**相关性**：九四阳居阴位，已脱离下卦艮山（止），进入上卦干天（健）。它象征 在退避的更高阶段：不仅能避开危险，更能 舍弃个人所爱、所好（如权位、名利、享乐），超然离去。这种 克制欲望、不为所累的决断力，是 君子（有德者） 才能做到的，故吉；而 小人（无德者） 贪恋既得利益，绝难做到，故凶（否）。此爻赞美了 “不恶而严”中“严”的一面：对自身欲望的严格克制。


### 九五：嘉遁，贞吉。


**原文**：嘉遁，贞吉。

**白话**：嘉美及时的退避，守持正固吉祥。

**小象传**
**原文**：“嘉遁贞吉”，以正志也。

**白话**：美好的退隐，坚守正道可获吉祥，是因为志向端正。


**说明**

这是 退避的完美——功成身退。

+ “嘉遁”：嘉美（嘉）的退避（遁）。
+ “贞吉”：守持正道（贞）则吉祥。
+ 爻传“以正志也”：因为 以正道（正）来坚定心志（志）。

**相关性**：九五阳刚中正居尊，是 “遁”卦之主，也是“遁”道的最高典范。“嘉遁”意为 在最恰当、最荣耀的时刻，主动、从容、得体地退避。这并非被迫逃亡，而是 功成身退、见好就收的智慧。因其 动机纯正（贞），行为符合时宜（与时行），故获吉祥。爻传“以正志也”强调：其完美的退避，源于 心志始终持守正道，不为权位所迷。此爻是 领导者或成功者在鼎盛时期的全身之道。


### 上九：肥遁，无不利。


**原文**：肥遁，无不利。

**白话**：高飞远退，无所不利。

**小象传**
**原文**：“肥遁无不利”，无所疑也。

**白话**：退隐得彻底而无所不利，是因为心中没有任何疑虑。


**说明**

这是 退避的逍遥——超然物外。

+ “肥遁”：高飞远遁（肥，通“蜚”，飞）。
+ “无不利”：无所不利。
+ 爻传“无所疑也”：因为 心中没有任何疑虑与牵挂。

**相关性**：上九阳刚处卦之极，在干天之上，象征 退避到极致，已完全超脱于世俗纷扰之外。“肥遁”形容 如飞鸟般高飞远走，了无痕迹。此时，一切世俗的利害、牵绊都已消失，内心澄明，毫无疑虑（无所疑也），故能 “无不利”，获得真正的自由与逍遥。此爻描绘了 隐士或得道者“遁世无闷”的至高精神境界。


## 总结

**总结**：遁卦的现代启示

遁卦的 “远小人，不恶而严” 是关于 审时度势、急流勇退、保全自身与坚守原则 的生存与发展智慧。

退避的层次（从被动到主动，从形遁到神遁）：

+ 滞后（初六）：迟疑致危，遁尾则厉。
+ 固守（六二）：中正自固，心志不移。
+ 牵绊（九三）：系恋致疾，不可大事。
+ 洒脱（九四）：舍欲而遁，君子能之。
+ 完美（九五）：嘉美而遁，功成身退。
+ 逍遥（上九）：高飞远遁，无不利。

核心心法：大象传总纲——“天下有山，遁；君子以远小人，不恶而严。” 这意味着：

+ “天下有山”：是 遁卦之象（天高山远，君子远离小人）。
+ “君子以远小人，不恶而严”：君子效法此象，做到：

+ “远小人”：疏远、避开小人（保持物理与心理距离）。
+ “不恶而严”：不表现出憎恶（不恶）的态度，但保持严肃（严）的界限与原则。

这是 处理与小人关系的最高艺术：**既不与之同流合污（远），也不公开对抗、激化矛盾（不恶），而是 以庄重自持、凛然不可犯的态度（严）划清界限。这既是 自保之道，也是 不助长其恶的教化之道。

根本精神：彖传 “遁之时义大矣哉！” 感叹 “遁”的时宜意义太重大了！ 它强调：**“遁”不是失败或怯懦，而是一种 顺应时势、保全实力、以待将来的高级策略。卦辞“亨”与“小利贞”表明：**在阴长阳消的“遁”时，识时务而退，本身就是亨通；而柔小者（如六二）更应 守持正道，以静制动。遁卦给予我们的，不仅是 退却的勇气，更是 “与时行”的智慧。

遁卦与恒卦的承续：恒卦（䷟）讲 “恒久与持守”（立不易方），是 在正确道路上的坚持；遁卦（䷠）则讲 “退避与放弃”（远小人），是 在错误或不利环境下的撤离。《序卦传》言：“物不可以久居其所，故受之以遁；遁者，退也。” 意思是：事物不可能永久停留在某个地方（恒久之后必有变化），所以继之以遁卦；遁，就是退避。“恒”是“进”的持久，“遁”是“退”的智慧。从恒到遁，揭示了 事物发展“久则必变”的规律，以及 在变化来临时，主动、适时地“退”，往往比盲目地“恒”更为重要。这教导我们：既要懂得坚持（恒），也要懂得放弃（遁）。
