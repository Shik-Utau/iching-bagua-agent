# 萃卦（兑上坤下）

**卦画**：䷬

## 总论：会聚之道的哲学

**核心短词**：“除戎器，戒不虞”

**卦象**：上兑（☱）为泽、为悦，下坤（☷）为地、为顺。泽地萃。泽水汇聚于地上，万物荟萃。

**核心卦辞**：“亨。王假有庙，利见大人，亨，利贞。用大牲吉，利有攸往。”

**总纲**：萃卦象征 “会聚、聚集”，亨通。君王以至诚感格于宗庙，利于出现大德之人，亨通，利于守持正固。用大牲祭祀可获吉祥，利于有所前往。

+ “亨”：会聚本身就能带来亨通。
+ “王假有庙”：这是 会聚的精神核心。君王（王）以至诚之心感格（假，通“格”）于宗庙（有庙）。宗庙是 祖先、信仰、精神认同的象征。意味着 **真正的会聚，必须建立在 共同的精神信仰和情感认同 之上，而非仅仅利益的结合。
+ “利见大人，亨，利贞”：这是 会聚的领导与原则。利于出现大德之人（大人）来引领，会聚方能 亨通，且 必须守持正固（利贞），防止聚而生乱。
+ “用大牲吉，利有攸往”：这是 会聚的仪式与行动。用丰盛的祭品（大牲）祭祀，可获吉祥，象征 以丰厚的诚意和资源来巩固聚合；聚合之后，利于有所前往（利有攸往），即 团结力量，共同行动，有所作为。

**本质**：萃卦描述 “聚而能悦” 的状态。上兑喜悦，下坤柔顺，众人和顺而欣悦地聚集在一起。其**核心精神**是：**探讨 如何将人与物有效地聚集起来，形成有力量、有秩序的群体，并 防止聚集过程中和聚集之后可能产生的纷争与混乱。它强调 精神引领（假庙）、德才领袖（大人）、正道原则（利贞） 的重要性。

## 卦辞



### 经

**原文**：亨。王假有庙，利见大人，亨，利贞。用大牲吉，利有攸往。

**白话**：亨通。君王来到宗庙，利于出现大德之人，亨通，利于守持正固。用大牲祭祀吉祥，利于有所前往。

### 彖传

**原文**：萃，聚也。顺以说，刚中而应，故聚也。“王假有庙”，致孝享也。“利见大人，亨”，聚以正也。“用大牲吉，利有攸往”，顺天命也。观其所聚，而天地万物之情可见矣。

**白话**：萃，就是聚集的意思。顺从而又喜悦，刚强者居于中位并与他人呼应，所以能够聚集。“君王来到宗庙”，是为了表达孝心、奉献祭品。“利于见到大人物，亨通”，是因为以正道聚集。“用大牲祭祀吉祥，利于有所前往”，是顺应了天命的安排。观察事物聚集的现象，天地万物的真实情状就可以看清楚了。

### 大象传

**原文**：泽上于地，萃；君子以除戎器，戒不虞。

**白话**：水泽汇聚在大地之上，象征聚集；君子因此修治兵器，以防备意外的变乱。


## 爻辞

### 初六：有孚不终，乃乱乃萃。若号，一握为笑，勿恤，往无咎。


**原文**：有孚不终，乃乱乃萃。若号，一握为笑，勿恤，往无咎。

**白话**：诚信不能保持至终，导致混乱而后聚集。如果呼号求援，一握手间便可破涕为笑，不必忧虑，前往没有咎害。

**小象传**
**原文**：“乃乱乃萃”，其志乱也。

**白话**：心意迷乱又急于聚集，是因为他的心神已经混乱了。


**说明**

这是 会聚的初始——诚信为基，乱则求正。

+ “有孚不终，乃乱乃萃”：诚信（有孚）不能保持至终（不终），导致（乃）紊乱（乱）妄聚（乃萃）。
+ “若号，一握为笑，勿恤，往无咎”：若能（若）呼号求援（号），就能在握手之间（一握）重见欢笑（为笑），不必忧虑（勿恤），前往（往）没有咎害（无咎）。
+ 爻传“乃乱乃萃，其志乱也”：导致紊乱妄聚，是因为其心志混乱。

**相关性**：初六阴柔处下，是 会聚的底层参与者。爻辞描绘了一个 心态不坚定者的典型：开始有诚信参与会聚，但 意志不坚，半途而废（有孚不终），导致自身 行为紊乱，盲目聚合（其志乱也），这是 危险的起点。然而，转机在于 “若号”——**如果能 意识到错误，向上呼号（向九四正应求援），表明心迹，寻求接纳。那么，误会很快就能化解（一握为笑），不必忧虑，继续 前往参与会聚，便 无咎害。此爻强调：**会聚中，个体的诚信与坚定至关重要；若一时迷惑，知错能改、主动沟通是重回正途的关键。


### 六二：引吉，无咎。孚乃利用禴。


**原文**：引吉，无咎。孚乃利用禴。

**白话**：受人牵引而获吉祥，没有咎害。心怀诚信，即使简单的禴祭也有利。

**小象传**
**原文**：“引吉无咎”，中未变也。

**白话**：牵引吉祥没有过错，是因为持守中道没有改变。


**说明**

这是 会聚的核心——柔顺中正，诚心受引。

+ “引吉，无咎”：受人牵引（引）相聚可获吉祥（吉），没有咎害（无咎）。
+ “孚乃利用禴”：只要心怀诚信（孚），即使微薄的禴祭（乃利用禴）也有利。
+ 爻传“引吉无咎，中未变也”：受人牵引可获吉祥而无咎，是因为（六二）中正的本性未曾改变。

**相关性**：六二柔顺中正，与九五君王正应，是 会聚中最理想的臣民或追随者。“引”指 受到尊者（九五）的吸引和牵引。六二 以其柔中美德，自然被核心力量所吸引和接纳，故 吉祥无咎。“禴”是 春季的薄祭，祭品简约。爻辞以此比喻：**在会聚中，**重要的不是贡献的物质多寡，而是 内心的诚信（孚）。只要 心诚，即使力量微薄，也会被认可和接纳。爻传“中未变也”点明其根本优势：**始终持守 中正柔顺的品德。此爻阐述了 **会聚中追随者的最佳姿态：以德配位，诚心相从。


### 六三：萃如嗟如，无攸利。往无咎，小吝。


**原文**：萃如嗟如，无攸利。往无咎，小吝。

**白话**：聚集而叹息，无所利益。前往没有咎害，但有小小的憾惜。

**小象传**
**原文**：“往无咎”，上巽也。

**白话**：前往没有咎害，是因为能够随顺上位。


**说明**

这是 会聚的尴尬——失应无援，求聚有憾。

+ “萃如，嗟如，无攸利”：欲聚（萃如）而不得，叹息不已（嗟如），无所利益（无攸利）。
+ “往无咎，小吝”：前往（往，指向上靠近九四）相聚没有咎害（无咎），但小有憾惜（小吝）。
+ 爻传“往无咎，上巽也”：前往没有咎害，是因为（向上）顺从（九四）。

**相关性**：六三阴柔不中，与上六无应，是 会聚中缺乏直接引荐者的孤立者。它 渴望聚合（萃如），但 无人接应，故徒自叹息（嗟如），无所获益。出路在于 “往”——主动向上（九四）靠近、顺从（上巽）。九四阳刚，虽非正应，但能接纳。如此 虽可融入（无咎），但毕竟 不是最理想、最稳固的关系，故 小有憾惜。此爻描绘了 **社会聚合中常见的现象：**有些人 虽有能力与意愿，但因缺乏“关系”或“引荐”而暂时边缘化。解决方案是 主动向邻近的权威者靠拢并展现顺从，虽不完美，但可入门。


### 九四：大吉，无咎。


**原文**：大吉，无咎。

**白话**：大为吉祥，没有咎害。

**小象传**
**原文**：“大吉无咎”，位不当也。

**白话**：大吉大利没有过错，是因为所处的位置不恰当。


**说明**

这是 会聚的枢纽——大臣之位，聚合有方。

+ “大吉，无咎”：大为吉祥（大吉），没有咎害（无咎）。
+ 爻传“大吉无咎，位不当也”：大为吉祥而没有咎害，是因为（九四）位置不当（阳居阴位）却（因聚合有功而）弥补了。

**相关性**：九四阳刚，居大臣之位，上近九五君王，下抚众阴（初六正应，六三归附），是 会聚的实际组织者和操盘手。爻辞极其简洁有力：“大吉，无咎”。因为 **其 成功地将下方民众聚合起来，上达于君王，使 会聚之道得以实现，故 功莫大焉，大为吉祥。爻传的解读很辩证：九四 阳居阴位，本属“位不当”，可能有咎。但因其 在“萃”之时，履行了聚合上下的大臣职责，且成绩斐然，所以 不仅无咎，反而大吉。此爻强调：**在需要聚合的时势下，**关键位置上的执行者，只要能 出色完成使命，就能超越自身位置的些微瑕疵，成就大功。


### 九五：萃有位，无咎。匪孚，元永贞，悔亡。


**原文**：萃有位，无咎。匪孚，元永贞，悔亡。

**白话**：聚集而保有尊位，没有咎害。但未能广孚众望，须永久守持正固，悔恨消亡。

**小象传**
**原文**：“萃有位”，志未光也。

**白话**：聚集在一起却还讲究身份地位，说明心志还没有真正发扬光大。


**说明**

这是 会聚的领袖——德位兼备，信为根本。

+ “萃有位，无咎”：会聚之时高居尊位（萃有位），没有咎害（无咎）。
+ “匪孚，元永贞，悔亡”：但（若）未能广泛取信于众（匪孚），则须始终保持（元）永久（永）的正固（贞），悔恨才能消亡（悔亡）。
+ 爻传“萃有位，志未光也”：会聚之时高居尊位，但（若未能取信）心志尚未光大。

**相关性**：九五阳刚中正，居尊位，是 会聚的君主与象征。“萃有位”是 其天然优势，故 基础无咎。但爻辞重点在于后半句的告诫：“匪孚，元永贞，悔亡”。这意味着：**居于领袖之位，仅仅有位置是不够的。如果 不能以诚信美德感召众人，赢得广泛信任（匪孚），那么 会聚就只是形式上的，人心并未真正凝聚。此时，领袖必须 “元永贞”——**从根本（元）上，永久（永）地保持 至为正固的德行与政策，持之以恒，才能 逐渐消除信任危机带来的悔恨（悔亡）。爻传“志未光也”深刻指出：**诚信不孚，则 君王的聚合天下之心志，就未能真正发扬光大。此爻是 对领导者的核心要求：聚合人心，“信”比“位”更重要；若信不足，则 须以恒久的正道来弥补和建立。


### 上六：赍咨涕洟，无咎。


**原文**：赍咨涕洟，无咎。

**白话**：悲叹哭泣，涕泪交流，没有咎害。

**小象传**
**原文**：“赍咨涕洟”，未安上也。

**白话**：悲伤哭泣，是因为心中不安于上位。


**说明**

这是 会聚的终点——孤高无应，悲惧自省。

+ “赍咨涕洟”：悲叹哀泣（赍咨），涕泪满面（涕洟）。
+ “无咎”：但没有咎害（无咎）。
+ 爻传“赍咨涕洟，未安上也”：悲叹哀泣，是因为未能安居于上位。

**相关性**：上六阴柔处卦之极，与六三无应，且凌驾于九五君王之上，是 会聚的局外人与孤高者。当天下万物欣悦聚合之时，它却 因身处极位、无人与共（未安上） 而感到 巨大的孤独、恐惧与悲凉，以致于 “赍咨涕洟”。这种 深刻的忧患意识与自我反省，使其 **虽然处境可悲，但 并未主动作恶去破坏聚合，故 最终没有咎害。此爻揭示了 **一个深刻道理：**在集体欢聚的盛宴中，**那个因不合群而痛苦自省的人，虽然可怜，但其 清醒与自制，反而使其 免于真正的祸患。这也警示：**聚合时，要关注那些被边缘化的个体。


## 总结

**总结**：萃卦的现代启示

萃卦的 “除戎器，戒不虞” 是关于 “聚集、团结、整合资源”的宏大哲学，它教导我们 如何构建有凝聚力、有战斗力且能长治久安的群体或组织。

构建会聚之道的六个层次：

+ 始聚以诚（初六）：有孚不终，若号无咎。
+ 柔中受引（六二）：引吉无咎，孚乃利用禴。
+ 求聚有憾（六三）：萃如嗟如，往无咎吝。
+ 近君聚众（九四）：大吉无咎，位不当而功成。
+ 君位以信（九五）：萃有位，匪孚则元永贞。
+ 穷极悲惧（上六）：赍咨涕洟，未安上而无咎。

核心心法：大象传总纲——“泽上于地，萃；君子以除戎器，戒不虞。” 这意味着：

+ “泽上于地，萃”：是 萃卦之象（水聚于地，汇集成泽）。
+ “君子以除戎器，戒不虞”：君子效法此象，修治兵器，戒备不测之患。

这是 萃卦精神的灵魂：**“萃”是 聚集，是 力量的整合。但君子深刻认识到，**人群聚集之时，往往也是 利益交织、矛盾潜伏、易生变乱之际。因此，在 **聚合的同时，必须 “除戎器，戒不虞”——**一方面修治武备（除戎器），保持威慑与自卫能力；另一方面 时刻警惕，防备意外的纷争与祸乱（戒不虞）。这体现了 中国智慧中“居安思危”、“治不忘乱”的深远谋略：**真正的团结，内要有凝聚力，外要有防御力，并始终保持危机意识。

根本精神：彖传 “萃，聚也……观其所聚，而天地万物之情可见矣。” 揭示了会聚之道的终极意义：

+ “观其所聚，而天地万物之情可见矣”：观察万物会聚的道理，天地万物的真情实状就可以明白了。

萃卦告诉我们：**“会聚”是 天地间普遍的现象与力量。小至人群组织，大至国家联盟，乃至万物归类，无不是“萃”。成功的会聚需要 精神感召（假庙）、核心领袖（大人）、正道原则（利贞）、诚信基础（孚）。其最高智慧在于 **大象传的警示：**在享受聚合带来的强大与繁荣时，**切不可忘记 内部可能滋生的腐败、分裂，以及外部可能面临的挑战，必须 常备不懈，警钟长鸣。这便是在 “泽汇于地” 的丰盈景象中，所蕴含的 关于团结、治理与风险防范的永恒法则。
