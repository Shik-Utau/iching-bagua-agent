# 剥卦（艮上坤下）

**卦画**：䷖

## 总论：剥落的哲学

**核心短词**：“厚下安宅”

**卦象**：上艮（☶）为山、为止，下坤（☷）为地、为顺。山地剥。山附于地，风雨侵蚀；阴剥阳消，小人道长。

**核心卦辞**：“剥，不利有攸往。”

**总纲**：剥卦描绘了 阳气被阴气逐渐剥蚀、消落 的严峻形势。象征 小人得势，君子道消，根基动摇。此时不宜有所行动。

+ “剥”：剥落、侵蚀、凋零。
+ “不利有攸往”：不利于有所前往、有所行动。强调 在衰败之势中，应静守待时，避免妄动。

**本质**：剥卦的核心是 “柔变刚” 与 “顺而止之”。卦中五阴在下，一阳在上，形象地展示了 阴柔之力（小人/衰败因素）从下而上，逐渐剥蚀、取代阳刚（君子/正道） 的过程。面对此势，君子应 观察卦象，顺应时势而知所止（顺而止之）。其应对之道是 “君子尚消息盈虚，天行也”——尊崇阴阳消长、盈虚交替的自然规律。

## 卦辞



### 经

**原文**：不利有攸往。

**白话**：不利于有所前往。

### 彖传

**原文**：剥，剥也，柔变刚也。不利有攸往，小人长也。顺而止之，观象也。君子尚消息盈虚，天行也。

**白话**：剥，就是剥落的意思，是柔爻逐渐侵蚀改变刚爻。此时不宜有所前往，因为小人的势力正在增长。要顺应时势而停止行动，这是观察卦象得出的启示。君子重视事物的消长、盈满与虚亏的变化规律，因为这是天地运行的法则。

### 大象传

**原文**：山附于地，剥；上以厚下安宅。

**白话**：山附着在大地上，象征剥落；在上位者因此要加厚基础、稳固家园。


## 爻辞

### 初六：剥床以足，蔑贞凶。


**原文**：剥床以足，蔑贞凶。

**白话**：剥落床脚，灭除正道，凶险。

**小象传**
**原文**：“剥床以足”，以灭下也。

**白话**：剥蚀床脚，是在毁坏下面的根基。


**说明**

这是 剥落的开端——根基动摇。

+ “剥床以足”：剥落（剥）床先从床足（足）开始。
+ “蔑贞凶”：蔑视（蔑）正道（贞），凶险。
+ 爻传“以灭下也”：因为 从毁灭下方根基开始。
**相关性**：初六阴居最下，象征 剥蚀的起点。“床”是安身之所，比喻 事业、国家的根基。“足”是床的支撑。剥落从“足”开始，意味着 衰败始于最基础、最根本处的腐蚀。此时若 不以为意，蔑视正道（蔑贞），不加以补救，凶险便由此滋生。此爻警示：祸患常起于微末，必须防微杜渐。


### 六二：剥床以辨，蔑贞凶。


**原文**：剥床以辨，蔑贞凶。

**白话**：剥落床板，灭除正道，凶险。

**小象传**
**原文**：“剥床以辨”，未有与也。

**白话**：剥蚀床体已经到了床板，说明此时没有人与他应和辅助。


**说明**

这是 剥落的深入——主体受损。

+ “剥床以辨”：剥落（剥）床的床板、床干（辨）。
+ “蔑贞凶”：蔑视正道，凶险。
+ 爻传“未有与也”：因为 没有阳刚的相助者（与）。
**相关性**：六二阴柔中正，但仍在剥蚀进程中。剥蚀已从“足”（基础）上升到“辨”（床的主体结构）。这表明 衰败已侵入核心层面，问题更加严重。爻传“未有与也”点出关键：没有阳刚的力量（君子、正道）来制止、相助。此时若继续“蔑贞”，无视问题的严重性，凶险必然加剧。


### 六三：剥之，无咎。


**原文**：剥之，无咎。

**白话**：处剥落之时，没有咎害。

**小象传**
**原文**：“剥之无咎”，失上下也。

**白话**：剥落却没有灾祸，是因为脱离了上下的小人。


**说明**

这是 剥蚀中的清醒——独善其身。

+ “剥之”：处于剥蚀（剥）的环境中。
+ “无咎”：没有过错。
+ 爻传“失上下也”：因为 脱离了上下众阴（小人）。
**相关性**：六三阴爻，本与上下众阴同类，但 唯独它与上九阳爻相应。这象征 在普遍沉沦、剥蚀的环境中，仍有能保持清醒、不与小人同流合污者。他虽处剥中，但心向光明（上九），故能 独善其身，免于咎害。爻传“失上下也”强调其 与众不同，超然于剥蚀潮流之外。此爻给黑暗时代中的 坚守者以希望。


### 六四：剥床以肤，凶。


**原文**：剥床以肤，凶。

**白话**：剥落触及床席，凶险。

**小象传**
**原文**：“剥床以肤”，切近灾也。

**白话**：床的剥蚀已经触及皮肤，说明灾祸已经迫在眉睫了。


**说明**

这是 剥落的迫近——危及自身。

+ “剥床以肤”：剥落（剥）床已伤及（以）人的肌肤（肤）。
+ “凶”：凶险。
+ 爻传“切近灾也”：因为 灾祸已切近自身。
**相关性**：六四已逼近上卦，剥蚀从“床”（外物）直接伤及“肤”（人身）。这比喻 衰败与祸乱已从外部环境，直接威胁到个体自身的安危。这是 最危险的信号，剥蚀已无可回避，灾难迫在眉睫（切近灾）。此爻描绘了 形势恶化到极点，人人自危 的状态。


### 六五：贯鱼，以宫人宠，无不利。


**原文**：贯鱼，以宫人宠，无不利。

**白话**：像贯穿鱼群一样，带领宫人承宠于君王，无所不利。

**小象传**
**原文**：“以宫人宠”，终无尤也。

**白话**：像宫中嫔妃那样得到宠爱，最终不会有怨尤。


**说明**

这是 应对剥蚀——以柔承刚。

+ “贯鱼”：像 用绳子贯穿（贯）鱼群，比喻 有序统领。
+ “以宫人宠”：带领（以）宫中嫔妃（宫人）承宠于君王。
+ “无不利”：无所不利。
+ 爻传“终无尤也”：最终没有怨尤。
**相关性**：六五阴柔居尊，是 众阴（小人/衰败因素）的统领者。在剥极将复之际，她采取的策略不是对抗，而是 “贯鱼”——将无序的阴柔力量有序地组织、引导起来，并 “以宫人宠”——带领他们去亲近、承顺唯一的阳刚（上九/君王/正道）。这比喻 高明的领导者，能疏导、转化负面力量，使其归附于正道，从而 扭转剥势，化害为利。此爻提供了 在衰败中“止损”并“转化”的智慧。


### 上九：硕果不食，君子得舆，小人剥庐。


**原文**：硕果不食，君子得舆，小人剥庐。

**白话**：丰硕的果实未被摘食，君子将得到车舆，小人则剥落房屋。

**小象传**
**原文**：“君子得舆”，民所载也。“小人剥庐”，终不可用也。

**白话**：君子得到车驾，是受到百姓的拥戴。小人剥蚀屋舍，终究是行不通的。


**说明**

这是 剥蚀的终结——一阳复生。

+ “硕果不食”：硕大（硕）的果实（果）未被摘食（比喻仅存的阳气/希望）。
+ “君子得舆”：君子（君子）得到车舆（舆）（比喻得到承载，可施行教化）。
+ “小人剥庐”：小人（小人）则剥落（剥）房屋（庐）（比喻失去庇护，自食其果）。
+ 爻传“民所载也”：（君子得舆）是 为百姓所承载（即得民心）。

**相关性**：上九是全卦 仅存的一阳，高居极位，犹如 寒冬枝头仅存的硕果，是 剥尽复生的唯一火种。“君子得舆”预示：当剥极之时，坚守正道的君子将 获得民心（民所载），得到施展抱负的机遇与平台（舆），从而引领复兴。而“小人剥庐”则警告：那些制造剥蚀的小人，终将 剥落自己的安身之所，自取灭亡。此爻揭示了 物极必反，剥尽复来 的天道规律，给君子以 最后的信心与使命。


## 总结

**总结**：剥卦的现代启示

剥卦的 “厚下安宅” 是关于 面对衰败、危机与小人当道时局 的生存与转化智慧。

剥蚀的过程：

+ 初萌（初六）：衰败始于 根基（足），须防微杜渐。
+ 深入（六二）：侵蚀 核心结构（辨），因无外力相助而加剧。
+ 特例（六三）：黑暗中仍有 独善其身、心向光明者。
+ 危殆（六四）：祸乱 切近自身（肤），形势极度凶险。
+ 转化（六五）：高明的领导者能 引导、转化负面力量（贯鱼），使其归附正道。
+ 转机（上九）：剥极必复，仅存的 希望（硕果） 将孕育新生，君子得时，小人自败。

核心心法：大象传总纲——“上以厚下安宅”。这意味着：

+ “厚下”：居于上位的统治者，必须 厚待、稳固在下的人民（基础）。
+ “安宅”：如此才能 安定自己的宫室、国家（统治根基）。

这是 从根本上预防“剥”的发生：如果根基（下）厚实稳固，上层建筑（宅）自然安稳，不易被剥蚀。剥卦的根源，往往在于 上不厚下，导致基础动摇。

根本态度：彖传 “君子尚消息盈虚，天行也”。面对无可避免的剥落之势，君子应有的态度是：尊崇并顺应阴阳消长、盈虚交替的自然规律。在“剥”时，知所止，不强为（不利有攸往），静待 “复” 的时机到来。这是一种 深刻的历史耐心与天道信仰。

剥卦与贲卦的承续：贲卦（䷕）讲 “文饰美化”（化成人文），是 追求外在的繁华与装饰；剥卦（䷖）则讲 “剥落凋零”（厚下安宅），是 繁华落尽、装饰剥蚀，露出本质甚至衰败的景象。《序卦传》言：“贲者，饰也。致饰然后亨则尽矣，故受之以剥；剥者，剥也。” 意思是：贲是文饰。极尽文饰之后，亨通就到了尽头，所以继之以剥卦；剥，就是剥落。过度的文饰（贲之极）会导致华而不实，本质被掩盖或掏空，最终必然走向剥落。从贲到剥，揭示了 “文胜质则史” 的规律，以及 盛极而衰 的必然过程。这也提醒我们，在追求文明与装饰的同时，必须 时刻夯实本质，防止“剥”的发生。
