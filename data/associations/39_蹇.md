# 蹇卦（坎上艮下）

**卦画**：䷦

## 总论：险阻面前的哲学

**核心短词**：“反身修德”

**卦象**：上坎（☵）为水、为险，下艮（☶）为山、为止。水山蹇。山上有水，山上有水，险阻在前，见险而止。

**核心卦辞**：“利西南，不利东北。利见大人，贞吉。”

**总纲**：蹇卦象征 “艰难、险阻”，利于走向西南（坤方，平地），不利于走向东北（艮方，高山）。利于出现大人，守持正固可获吉祥。

+ “利西南，不利东北”：这是 方向策略。西南为坤，象征 平地、顺境、众人；东北为艮，象征 高山、险阻、止步。意为：**遇到险阻时，应 走向平坦易行之地（寻求群众支持或缓和环境），避开险峻难行之路（不正面硬闯）。
+ “利见大人”：这是 人物策略。利于 出现或拜见有德有能的“大人”，以获得指引、帮助或凝聚力量。
+ “贞吉”：这是 心志策略。利于 守持正固，即 坚定信念，不改初衷，如此可获吉祥。

**本质**：蹇卦描述 “见险而止，智者之行”。上坎险，下艮止，前有险阻（水），见险则止（山）。其**核心精神**是：**面对艰难险阻，**不是盲目冒进，也不是消极放弃，而是 暂停下来（止），反身自省（反身），修养德行（修德），并寻求正确的方向（利西南）与贵人相助（利见大人），为克服险阻积蓄力量与智慧。

## 卦辞



### 经

**原文**：利西南，不利东北。利见大人，贞吉。

**白话**：利于走向西南（平地），不利于走向东北（山地）。利于出现大德之人，守持正固吉祥。

### 彖传

**原文**：蹇，难也，险在前也。见险而能止，知矣哉！蹇利西南，往得中也；不利东北，其道穷也。利见大人，往有功也。当位贞吉，以正邦也。蹇之时用大矣哉！

**白话**：蹇卦，象征艰难，因为危险就在前方。看到危险而能及时止步，真是明智啊！蹇卦利于向西南方向行动，因为前往能得中正之道；不利于向东北方向，因为那条路会陷入困穷。适宜见到德高望重的大人物，前往能建立功业。居位得当、持守正道可获吉祥，以此可以端正邦国。蹇卦所蕴含的因时制宜的妙用，真是伟大啊！

### 大象传

**原文**：山上有水，蹇；君子以反身修德。

**白话**：山上有水，象征行走艰难；君子因此要反省自身，修养德行。


## 爻辞

### 初六：往蹇，来誉。


**原文**：往蹇，来誉。

**白话**：前往遇险难，退回来守候则获赞誉。

**小象传**
**原文**：“往蹇来誉”，宜待也。

**白话**：前往会遇到险阻，归来将获得赞誉，这是说应当等待时机。


**说明**

这是 险阻的初现——知止待时。

+ “往蹇”：前进（往）则遇艰难（蹇）。
+ “来誉”：归来（来）则获赞誉（誉）。
+ 爻传“宜待也”：适宜等待。

**相关性**：初六阴柔处下，是 艰难局面的开端。力量微弱，地位低下，若贸然前进（往），必陷入险阻（蹇）。爻辞的智慧在于：**此时 “来”（退回、不动）比 “往” 更明智。退回来，既能避免无谓的损失，又能因其 审时度势、知险而止 的明智获得赞誉（来誉）。爻传“宜待也”明确指出：**此时最适宜的策略就是 等待时机。此爻强调：**面对险阻，第一步不是“如何克服”，而是“是否应该前进”。止步与等待，本身就是一种积极的智慧。


### 六二：王臣蹇蹇，匪躬之故。


**原文**：王臣蹇蹇，匪躬之故。

**白话**：君王的臣子（六二）陷于重重险难，不是为了自身的缘故。

**小象传**
**原文**：“王臣蹇蹇”，终无尤也。

**白话**：王公的臣子屡屡犯难，但最终不会有怨尤。


**说明**

这是 险阻的担当——为公非私。

+ “王臣蹇蹇”：君王的臣子（王臣）陷入重重艰难（蹇蹇）。
+ “匪躬之故”：不是（匪）他自身（躬）造成的缘故（之故）。
+ 爻传“王臣蹇蹇，终无尤也”：君王的臣子陷入重重艰难，最终没有过错。

**相关性**：六二柔顺中正，与九五相应，是 身处险境、忠心耿耿的臣子或骨干。“蹇蹇”形容 艰难重重。爻辞点明：**其艰难 并非由于个人过失或私心（匪躬之故），而是 为了国家、集体或上级（王）的事业，勇于担当，主动踏入险境。这种 “鞠躬尽瘁，死而后已” 的精神，虽然过程极其艰苦，但 动机纯正，问心无愧，故爻传断言 “终无尤也”——最终不会有过错，会得到理解与肯定。此爻赞美了 在艰难中 恪尽职守、勇于负责 的崇高品格。


### 九三：往蹇，来反。


**原文**：往蹇，来反。

**白话**：前往遇险难，退返回来。

**小象传**
**原文**：“往蹇来反”，内喜之也。

**白话**：前往会遇到险阻，归来则平安返回，内心为此感到欢喜。


**说明**

这是 险阻的胶着——退而求安。

+ “往蹇”：前进（往）则遇艰难（蹇）。
+ “来反”：返归（来）原位（反）。
+ 爻传“内喜之也”：内部（初、二爻）对此感到欣喜。

**相关性**：九三阳刚处下卦之极，是 前进力量的代表，但前临上卦坎险。若强行前进（往），必遇险阻（蹇）。爻辞指示：**应 退回（来）到原来的位置（反）。爻传“内喜之也”揭示了更深层的意义：**九三作为下卦（内部）唯一的阳爻，是 初六、六二的依靠与核心。它退回原位，能 稳固内部，团结下属，使大家感到安心和欣喜。在整体面临险阻时，保全核心力量、巩固内部团结，比冒险突进更为重要。此爻说明：有时 退一步，是为了 稳住阵脚，凝聚人心，这是克服更大险阻的基础。


### 六四：往蹇，来连。


**原文**：往蹇，来连。

**白话**：前往遇险难，退回来与同类联合。

**小象传**
**原文**：“往蹇来连”，当位实也。

**白话**：前往会遇到险阻，归来会连接同道，这是因为所处的位置得当而坚实。


**说明**

这是 险阻的应对——聚力克难。

+ “往蹇”：前进（往）则遇艰难（蹇）。
+ “来连”：归来（来）联合（连）众人。
+ 爻传“当位实也”：因为 （其）位置适当（当位）且实力充实（实）。

**相关性**：六四阴柔得正，已进入上卦坎险，但下乘九三，下应初六。象征 已接近险阻核心，但自身力量不足，单独前进（往）必陷艰难（蹇）。爻辞的策略是：“来连”——**退回来，主动联合（连）下方的力量（九三及初六等），形成合力。爻传“当位实也”指出：**其 位置适当（当位），使其能起到连接上下的枢纽作用；联合众人后实力充实（实），为克服险阻创造了条件。此爻强调：**面对艰难，个人的力量是有限的，必须 善于团结协作，整合资源，方能共渡难关。


### 九五：大蹇，朋来。


**原文**：大蹇，朋来。

**白话**：处于大险难中，朋友前来相助。

**小象传**
**原文**：“大蹇朋来”，以中节也。

**白话**：遇到大困境时朋友前来相助，是因为坚守了中正的节操。


**说明**

这是 险阻的核心——中正得助。

+ “大蹇”：大难（大蹇）之时。
+ “朋来”：朋友（朋）前来（来）相助。
+ 爻传“大蹇朋来，以中节也”：大难之时朋友来助，是因为（九五）持守中道、有节度。

**相关性**：九五阳刚中正，居尊位，是 处于险难中心的君主或领导者。“大蹇”形容 其面临的艰难是全局性、根本性的。然而，爻辞并非描述其如何奋斗，而是 “朋来”——朋友（指六二、六四等）自然前来相助。这是因为 其 平日持守中正之道（中），行事有节度（节），德行感召，深得人心。故当大难临头时，众人感其德，自愿汇聚在其周围，共赴时艰。此爻揭示了 **克服最大险阻的终极力量来源：**不是权谋，不是强力，而是 领导者自身的中正德行所凝聚的人心与威望。


### 上六：往蹇，来硕，吉。利见大人。


**原文**：往蹇，来硕，吉。利见大人。

**白话**：前往遇险难，退回来可建大功，吉祥。利于出现大德之人。

**小象传**
**原文**：“往蹇来硕”，志在内也。“利见大人”，以从贵也。

**白话**：前往会遇到困难，归来能成就大业，是因为心志专注于内部。利于拜见大人物，是因为要追随尊贵的人。


**说明**

这是 险阻的终结——功成于退。

+ “往蹇”：前进（往）则遇艰难（蹇）。
+ “来硕”：归来（来）可建大功（硕）。
+ “吉”：吉祥（吉）。
+ “利见大人”：利于（利）出现（见）大人（大人）。
+ 爻传“往蹇来硕，志在内也；利见大人，以从贵也”：前进艰难归来建功，是因为心志系于内部；利于出现大人，是为了追随贵人。

**相关性**：上六阴柔处卦之极，是 险阻的尽头、边缘。若再往前（往），已无路可走，只有险阻（蹇）。爻辞指出：此时唯有 回头（来），回归内部（与九五等结合），才能 建立丰功伟绩（硕），获得吉祥。“利见大人”重申卦辞总纲：此时利于 追随有德能的“大人”（指九五），在其领导下共同克服险阻。爻传“志在内也”强调：其成功的关键在于 心志向内，团结内部核心力量，而非向外盲动。此爻说明：**险阻的克服，往往不是通过最后的冲刺，而是通过 明智的回归、内部的整合与对正确领导的追随 来实现的。


## 总结

**总结**：蹇卦的现代启示

蹇卦的 “反身修德” 是关于 面对困境、挫折、艰难险阻时，如何调整心态、积蓄力量、寻求突破的系统方法论。

应对险阻的六种情境与策略：

+ 初现知止（初六）：往蹇来誉，宜待时机。
+ 忠臣赴难（六二）：蹇蹇匪躬，终无尤也。
+ 胶着待援（九三）：往蹇来反，内喜之也。
+ 结伴共济（六四）：往蹇来连，当位实也。
+ 德位感召（九五）：大蹇朋来，以中节也。
+ 险极知返（上六）：往蹇来硕，利见大人。

核心心法：大象传总纲——“山上有水，蹇；君子以反身修德。” 这意味着：

+ “山上有水，蹇”：是 蹇卦之象（山上有险水，前行困难）。
+ “君子以反身修德”：君子效法此象，遇到困难时反求于自身，修养德行。
这是 蹇卦精神的灵魂：**当外部道路不通（蹇）时，最明智的行动不是向外冲撞，而是向内用力（反身）。反省自己的不足（修德），提升自己的能力与境界。因为 很多时候，困境的根源不在外界，而在自身；即使根源在外，强大的德行与能力也是克服一切外部困难的内在基础。

根本精神：彖传 “蹇，难也，险在前也。见险而能止，知矣哉！蹇利西南，往得中也；不利东北，其道穷也。利见大人，往有功也；当位贞吉，以正邦也。蹇之时用大矣哉！” 高度评价了“蹇”的智慧与价值：

+ “见险而能止，知矣哉！”：看见险阻而能停止，真是明智啊！ 这是对“止”的智慧的礼赞。
+ “利见大人，往有功也”：利于出现大人，说明前往可以建功。指明了 “止”之后的方向。
+ “当位贞吉，以正邦也”：各爻位置适当、守正吉祥，可以端正邦国。点明了 克服险阻的最终目的与效果。
+ “蹇之时用大矣哉！”：“蹇”的时宜效用太伟大了！ 这是 对“艰难”价值的深刻洞见：艰难（蹇）不是纯粹的坏事，它是 砥砺意志、检验德行、发现人才、凝聚力量的试金石与催化剂。善于运用“蹇”的时机（时用），可以成就正常情况下无法成就的功业。

蹇卦告诉我们：人生与事业的道路不可能一帆风顺。“蹇”是常态**。真正的智慧不在于 逃避“蹇”，而在于 如何正确地“面对蹇、利用蹇”——止、反身、修德、寻助、聚力、坚持。这套心法，对于个人成长、团队管理、企业转型乃至国家发展，都具有永恒的指导意义。
