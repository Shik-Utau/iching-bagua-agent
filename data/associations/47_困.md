# 困卦（兑上坎下）

**卦画**：䷮

## 总论：困顿之道的哲学

**核心短词**：“致命遂志”

**卦象**：上兑（☱）为泽、为悦，下坎（☵）为水、为险。泽水困。泽中无水，困穷之象。

**核心卦辞**：“亨。贞，大人吉，无咎。有言不信。”

**总纲**：困卦象征 “困穷、窘迫”，亨通。守持正固，大人可获吉祥，没有咎害。此时有所言说也不会被信从。

+ “亨”：困顿之中，反而可能孕育亨通。这是 困卦最深刻的辩证法：困境能 磨砺心志，激发潜能，为未来的通达奠定基础。
+ “贞，大人吉，无咎”：这是 处困之道。守持正固（贞），唯有德才兼备的“大人” 能 在困境中持守正道，故获吉祥，没有咎害。
+ “有言不信”：这是 处困之难。此时有所言说（有言）也不会被信从（不信）。因为 身处困境，人微言轻，或环境闭塞，其主张与辩解难以取信于人。

**本质**：困卦描述 “险以悦” 的状态。下坎险陷，上兑愉悦，身处险境而能保持乐观。其**核心精神**是：**探讨 当人陷入物质匮乏、行动受限、志向难伸的困境时，应如何自处与超越。它强调 守正（贞）、修德（大人）、乐观（悦），并指出 困境是检验与升华人格的试金石。

## 卦辞



### 经

**原文**：亨。贞大人吉，无咎。有言不信。

**白话**：亨通。守持正固，大德之人可获吉祥，没有咎害。此时有所言说也不会被人相信。

### 彖传

**原文**：困，刚揜也。险以说，困而不失其所亨，其唯君子乎！“贞大人吉”，以刚中也。“有言不信”，尚口乃穷也。

**白话**：困卦，是阳刚被掩蔽。面临险境而能保持乐观，在困顿中不丧失通达的希望，这大概只有君子能做到吧！“坚守正道，大人物可获吉祥”，是因为阳刚居于中正之位。“此时虽有言语也难以取信于人”，说明一味崇尚口辩反而会陷入困窘。

### 大象传

**原文**：泽无水，困；君子以致命遂志。

**白话**：水泽干涸，象征困顿；君子因此不惜舍命去实现志向。


## 爻辞

### 初六：臀困于株木，入于幽谷，三岁不觌。


**原文**：臀困于株木，入于幽谷，三岁不觌。

**白话**：臀部困在树桩上，进入幽暗的山谷，三年不得见天日。

**小象传**
**原文**：“入于幽谷”，幽不明也。

**白话**：进入幽暗的山谷，是因为处在昏暗不明的境地。


**说明**

这是 困顿的初始——坐困愁城，深陷不明。

+ “臀困于株木”：臀部（臀）困在（困于）树桩（株木）上。
+ “入于幽谷”：进入（入于）幽暗的山谷（幽谷）。
+ “三岁不觌”：三年（三岁）不得见人（不觌）。
+ 爻传“入于幽谷，幽不明也”：进入幽暗的山谷，是因为幽暗不明（指自身不明智）。

**相关性**：初六阴柔处下，是 困顿的最底层。爻辞描绘了一幅 极度窘迫、孤立无援的图景：“臀困于株木”——坐立不安，被低矮的障碍所困；“入于幽谷”——陷入黑暗、闭塞的环境；“三岁不觌”——长期与世隔绝，无人问津。爻传点明根源：“幽不明也”——**这种困境，部分源于 自身见识不明、选择错误，误入歧途。此爻是 对深度困境的生动刻画，警示：**困境之初，往往源于 错误的定位与不明智的行动。


### 九二：困于酒食，朱绂方来，利用享祀。征凶，无咎。


**原文**：困于酒食，朱绂方来，利用享祀。征凶，无咎。

**白话**：困于酒食匮乏，荣禄（朱绂）即将到来，利于举行祭祀。前进有凶险，但没有咎害。

**小象传**
**原文**：“困于酒食”，中有庆也。

**白话**：困于酒食的处境，是因为坚守中道，终将获得福庆。


**说明**

这是 困顿的中坚——物质或精神之困，待时而动。

+ “困于酒食”：困于（困于）酒食（可解为 酒食匮乏而困，或沉溺酒食而困）。
+ “朱绂方来”：荣禄（朱绂）即将（方）到来（来）。
+ “利用享祀”：利于（利用）举行祭祀（享祀）。
+ “征凶，无咎”：进取（征）有凶险（凶），但没有咎害（无咎）。
+ 爻传“困于酒食，中有庆也”：困于酒食，但（九二）守中道，终有喜庆。

**相关性**：九二阳刚居中，是 困境中有德有才者。“困于酒食”含义双关：既可能是 生活贫困，衣食不周；也可能是 在优渥环境中，精神困顿，意志消沉。“朱绂方来”预示 转机：因其 持守中道（中有庆），荣耀与机遇终将到来。“利用享祀”是 处困时的精神寄托与诚心祈愿。“征凶”告诫：**在困局未解、时机未到之时，不宜主动出击、向外征进，否则有凶险。但因其 本质刚中，即使 不动，也 没有咎害。此爻阐述：**困境中，**有德者应 安守本位，修养身心，等待时机，不宜躁动。


### 六三：困于石，据于蒺藜。入于其宫，不见其妻，凶。


**原文**：困于石，据于蒺藜。入于其宫，不见其妻，凶。

**白话**：困在巨石之下，凭据在蒺藜之上。回到家中，见不到妻子，有凶险。

**小象传**
**原文**：“据于蒺藜”，乘刚也。“入于其宫，不见其妻”，不祥也。

**白话**：站在蒺藜之上，是因为凌驾于阳刚之上。回到家中，却见不到妻子，这是不祥的征兆。


**说明**

这是 困顿的恶化——进退失据，内外交困。

+ “困于石”：困在（困于）巨石（石）下。
+ “据于蒺藜”：倚靠（据于）在蒺藜（蒺藜，多刺植物）上。
+ “入于其宫，不见其妻”：进入（入于）自己的宫室（其宫），见不到（不见）妻子（其妻）。
+ “凶”：有凶险（凶）。
+ 爻传“据于蒺藜，乘刚也；入于其宫不见其妻，不祥也”：倚靠在蒺藜上，是因为（六三）凌乘阳刚（九二）；进入宫室不见妻子，是不祥之兆。

**相关性**：六三阴柔不中不正，且凌乘九二阳刚（乘刚），是 因自身失德失位而陷入绝境者。爻辞描绘了 一系列可怕的困境：“困于石”——前有无法撼动的阻碍；“据于蒺藜”——后无可靠依凭，反受其害；“入于其宫，不见其妻”——内外皆失，连最亲近的家人（支持者）也离散了。这是 全面的、彻底的凶险。爻传指出原因：“乘刚” 导致 “据于蒺藜”；自身不祥（不祥） 导致 众叛亲离。此爻是 对因自身错误而陷入绝境者的严厉警示。


### 九四：来徐徐，困于金车，吝，有终。


**原文**：来徐徐，困于金车，吝，有终。

**白话**：缓缓而来，被金属车子所困，有所憾惜，但终有好结果。

**小象传**
**原文**：“来徐徐”，志在下也。虽不当位，有与也。

**白话**：来得慢吞吞，是因为心意还在下面。虽然位置不恰当，但还有人与他应和。


**说明**

这是 困顿的救援——行动迟缓，终得解脱。

+ “来徐徐”：缓缓（徐徐）而来（来）。
+ “困于金车”：被（困于）金车（金车，贵人所乘）所困。
+ “吝”：有所憾惜（吝）。
+ “有终”：但终有（有）好结果（终）。
+ 爻传“来徐徐，志在下也；虽不当位，有与也”：缓缓而来，是因为心志在于下方（初六）；虽然位置不当，但有应援。

**相关性**：九四阳居阴位，与初六正应，是 困境上方的救援者。“来徐徐”形容 其救援行动迟缓、犹豫。“困于金车”比喻 **救援者自身也被 身份、地位或规则（金车） 所束缚，不能迅速施援。故过程 有所憾惜（吝）。但因其 心志在于救助下方（志在下），且与初六有应（有与），所以 最终（有终） 还是能 克服障碍，完成救援。此爻描绘了 救援行动的复杂性：**即使有心相助，也可能 受制于客观条件而行动迟缓，但 只要意志坚定，终能成功。


### 九五：劓刖，困于赤绂。乃徐有说，利用祭祀。


**原文**：劓刖，困于赤绂。乃徐有说，利用祭祀。

**白话**：像受割鼻断足之刑，困于尊位（赤绂）。于是渐渐能脱困欣喜，利于举行祭祀。

**小象传**
**原文**：“劓刖”，志未得也。“乃徐有说”，以中直也。“利用祭祀”，受福也。

**白话**：削鼻砍脚，是志向未能实现。而后渐渐有喜悦，是因为持守中正刚直。利于进行祭祀，是承受福佑。


**说明**

这是 困顿的君主——高位之困，以诚脱险。

+ “劓刖”：割鼻（劓）断足（刖）之刑（比喻身心遭受严重伤害与屈辱）。
+ “困于赤绂”：困于（困于）尊位（赤绂，比朱绂更尊贵的服饰）。
+ “乃徐有说”：于是（乃）渐渐（徐）获得脱困的欣悦（有说，通“悦”）。
+ “利用祭祀”：利于（利用）举行祭祀（祭祀）。
+ 爻传“劓刖，志未得也；乃徐有说，以中直也；利用祭祀，受福也”：遭受割鼻断足之刑，是因为心志未得实现；于是渐渐获得欣悦，是因为持守中直之道；利于举行祭祀，是为了承受福泽。

**相关性**：九五阳刚中正，居尊位，是 困顿中的君主。其“困”非常特殊：“劓刖”——身为至尊，却 遭受极刑般的打击与屈辱，志不得伸；“困于赤绂”——恰恰是 其尊贵的身份与地位，成了 束缚与负担（如责任重大、众目睽睽、行动受限）。脱困之道在于 “乃徐有说”：“徐” 指 耐心、渐进；“有说” 指 保持乐观（兑悦）。关键原因是 “以中直也”——凭借 中正刚直的品德 来应对。“利用祭祀”** 再次强调 以至诚之心感通天地，寻求精神支撑与福佑。此爻是 对领导者处困的最高要求：**即使身处极困、备受屈辱，也要 以中正之德和乐观之心，徐图解脱。


### 上六：困于葛藟，于臲卼，曰动悔。有悔，征吉。


**原文**：困于葛藟，于臲卼，曰动悔。有悔，征吉。

**白话**：困在葛藤缠绕中，于高危不安之处，动辄有悔恨。有所悔悟，前进可获吉祥。

**小象传**
**原文**：“困于葛藟”，未当也。“动悔有悔”，吉行也。

**白话**：困在葛藤缠绕中，是因为所处的位置不恰当。行动会招致悔恨，但能因此警醒而悔改，这样及时调整就能走向吉祥。


**说明**

这是 困顿的终点——缠缚至极，悔则通变。

+ “困于葛藟，于臲卼”：困在（困于）葛藤（葛藟）缠绕中，于（于）动摇不安（臲卼）之处。
+ “曰动悔”：动辄（曰）得悔（动悔）。
+ “有悔，征吉”：有所悔悟（有悔），向前进取（征）可获吉祥（吉）。
+ 爻传“困于葛藟，未当也；动悔有悔，吉行也”：困在葛藤缠绕中，是因为（上六）所处未得安稳；动辄得悔而能有所悔悟，说明吉祥在于行动。

**相关性**：上六阴柔处卦之极，是 困顿的最终状态。“困于葛藟”形容 被琐事、小人或自身纷乱的思绪所缠绕，无法挣脱。“于臲卼”指 处境高危不安。此时 任何轻举妄动（动）都可能招致悔恨（悔）。然而，转机在于 “有悔”——**能够 深刻反省，认识到困境的根源与自身的问题。一旦 悔悟，便 不宜再坐困愁城，而应 果断行动（征），以 突破重围，如此则 可获吉祥（吉行）。此爻揭示了 困极则通的道理：**当困顿到了极点，**唯一的出路是 在反省（悔）的基础上，勇敢地采取行动（征）。


## 总结

**总结**：困卦的现代启示

困卦的 “致命遂志” 是关于 “逆境、挫折、窘迫”的生命哲学，它教导我们 如何在人生与事业的至暗时刻，保持心志、寻找出路、实现精神的超越。

应对困顿之道的六种情境：

+ 困于卑下（初六）：臀困株木，入幽谷不觌。
+ 刚中受困（九二）：困于酒食，朱绂方来，征凶无咎。
+ 失位致凶（六三）：困于石据蒺藜，不见其妻，凶。
+ 援困有阻（九四）：来徐徐，困于金车，吝有终。
+ 尊位受困（九五）：劓刖困赤绂，乃徐有说，利用祭祀。
+ 困极思动（上六）：困于葛藟，动悔有悔，征吉。

核心心法：大象传总纲——“泽无水，困；君子以致命遂志。” 这意味着：

+ “泽无水，困”：是 困卦之象（泽中干涸，无水为困）。
+ “君子以致命遂志”：君子效法此象，舍弃生命（致命）也要实现崇高志向（遂志）。

这是 困卦精神的灵魂，也是 中国哲学中最悲壮、最崇高的境界之一。“致命”并非轻生，而是 将个人生死、利害、荣辱置之度外；“遂志”是 对理想信念、人格尊严、人生价值的终极追求。在极端困境中，当物质手段全部失效时，唯一不能被剥夺的，是人的精神与志节。君子领悟到，**困境的终极意义，在于 检验并升华人的志气，激励人为了更高的价值，超越苦难，甚至不惜付出一切。这是 对“困境”最深刻的价值转化：**将其变为 锻造伟大灵魂的熔炉。

根本精神：彖传 “困，刚掩也。险以说，困而不失其所亨，其唯君子乎？贞大人吉，以刚中也。有言不信，尚口乃穷也。” 揭示了处困之道的精髓：

+ “险以说，困而不失其所亨”：面临险难而能保持乐观，身处困穷而不失其亨通之道。这是 处困的最高境界。
+ “其唯君子乎？”：大概只有君子能做到吧？
+ “有言不信，尚口乃穷也”：有所言说也不被信从，因为崇尚空谈只会更加穷困。

困卦告诉我们：**“困”是 人生的常态与试炼。面对困境，抱怨（有言不信）、空谈（尚口）都无济于事。唯有 “君子” 或 “大人”，能 以刚中之德守正（贞），能 处险而悦（险以说），能 在绝境中不失亨通之志（不失其所亨）。其最高智慧在于 **大象传的献身精神：**当困顿无法用常规方法解决时，**真正的出路在于 将困境升华为实现生命终极价值的契机，以“致命遂志”的勇气，完成人格的涅槃。这便是在 “泽中无水” 的枯竭景象中，所迸发出的 关于坚韧、乐观与精神不朽的最强音。
