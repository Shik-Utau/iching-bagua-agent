# 革卦（兑上离下）

**卦画**：䷰

## 总论：变革之道的哲学

**核心短词**：“治历明时”

**卦象**：上兑（☱）为泽、为悦，下离（☲）为火、为明。泽火革。泽中有火，水火相息。

**核心卦辞**：“巳日乃孚，元亨，利贞，悔亡。”

**总纲**：革卦象征 “变革、革新”。在亟须变革的“巳日”才能取信于众，至为亨通，利于守持正固，悔恨消亡。

+ “巳日乃孚”：这是 变革的时机与诚信。“巳日”通“祀日”，指 祭祀之日，象征 事物发展至亟须变革的转折点。只有到了非变不可的时刻（巳日），变革的主张才能（乃）取信于众（孚）。时机未到，强行变革，难以服众。
+ “元亨，利贞，悔亡”：这是 变革的性质与条件。变革本身 至为亨通（元亨），但必须 利于守持正道（利贞），如此则 悔恨消亡（悔亡）。强调 变革必须动机纯正、方法得当、遵循正道，否则必有悔吝。

**本质**：革卦描述 “水火相息” 的状态。下离火欲上炎，上兑泽欲下润，二者相克相灭（息），故必须变革以图共存。其**核心精神**是：**探讨 当旧事物、旧制度、旧格局已不合时宜，阻碍发展时，应如何进行彻底而成功的变革。它强调 时机（巳日）、诚信（孚）、正道（贞），并指出 变革是宇宙与社会发展的必然规律。

## 卦辞



### 经

**原文**：巳日乃孚，元亨，利贞，悔亡。

**白话**：在亟需变革的“巳日”才能取信于众，至为亨通，利于守持正固，悔恨消亡。

### 彖传

**原文**：革，水火相息，二女同居，其志不相得，曰革。“巳日乃孚”，革而信之。文明以说，大亨以正。革而当，其悔乃亡。天地革而四时成，汤武革命，顺乎天而应乎人，革之时大矣哉！

**白话**：革卦，象征水火相克相熄，如同两个女子同住一屋，心思各异难以相合，这就叫做变革。“到了巳日才能获得信任”，是说变革需要诚信才能使人信服。变革时文采光明而众人悦服，前景通达且遵循正道。变革得当，悔恨自然消亡。天地变革形成四季更替，商汤、周武的革命，既顺应天理又合乎人心，变革的时机意义真是重大啊！

### 大象传

**原文**：泽中有火，革；君子以治历明时。

**白话**：水泽之中有火焰，象征变革；君子因此制定历法来明确时节。


## 爻辞

### 初九：巩用黄牛之革。


**原文**：巩用黄牛之革。

**白话**：用黄牛皮革牢牢束缚。

**小象传**
**原文**：“巩用黄牛”，不可以有为也。

**白话**：用黄牛皮绳牢牢捆住，这是说不能有所作为。


**说明**

这是 变革的初始——时机未至，不可妄动。

+ “巩用黄牛之革”：牢牢束缚（巩）用（用）黄牛皮革（黄牛之革）。
+ 爻传“巩用黄牛，不可以有为也”：用黄牛皮革牢牢束缚，是因为不可以有所作为。

**相关性**：初九阳刚处下，远离上卦兑泽（变革的主导），是 变革初期、地位卑微者。爻辞用 坚韧的黄牛皮革 作比喻，告诫此时 **必须 **像被牛皮牢牢捆住一样，固守现状，不可轻举妄动。因为 变革时机远未成熟（巳日未至），自身 力量微薄，地位低下，若 强行有为，必遭失败。此爻是 对变革条件不足者的严厉警示：**在变革之初，**首要任务是 积蓄力量、等待时机，而非贸然行动。


### 六二：巳日乃革之，征吉，无咎。


**原文**：巳日乃革之，征吉，无咎。

**白话**：在亟需变革的“巳日”进行变革，前进吉祥，没有咎害。

**小象传**
**原文**：“巳日革之”，行有嘉也。

**白话**：在巳日推行变革，行动会带来美好的结果。


**说明**

这是 变革的进阶——时机已至，顺势而为。

+ “巳日乃革之”：到了亟须变革的“巳日”（巳日）才（乃）进行变革（革之）。
+ “征吉，无咎”：进取（征）吉祥（吉），没有咎害（无咎）。
+ 爻传“巳日革之，行有嘉也”：“巳日”进行变革，行动会有嘉美之功。

**相关性**：六二柔顺中正，上应九五，是 变革的积极拥护与执行者。爻辞直接呼应卦辞“巳日乃孚”，明确指出 “巳日”是行动的信号。当时机成熟（巳日），果断发起或参与变革（乃革之），积极进取（征），则 可获吉祥，没有咎害。爻传“行有嘉也”进一步肯定：此时的行动会带来美好的成果。此爻阐述了 变革的核心行动原则：**耐心等待，直至 最佳时机出现，然后 毫不犹豫地行动。


### 九三：征凶，贞厉。革言三就，有孚。


**原文**：征凶，贞厉。革言三就，有孚。

**白话**：前进有凶险，守持正固以防危险。变革的言论须经再三审议才能施行，要心怀诚信。

**小象传**
**原文**：“革言三就”，又何之矣。

**白话**：变革的主张多次得到赞同和采纳，又何必再前往他处寻求支持呢。


**说明**

这是 变革的关键——躁进则凶，详议则成。

+ “征凶，贞厉”：进取（征）有凶险（凶），守持正固（贞）以防危险（厉）。
+ “革言三就，有孚”：变革的言论（革言）须经再三（三）审议达成一致（就），要心怀诚信（有孚）。
+ 爻传“革言三就，又何之矣”：变革的言论经再三审议达成一致，又何必再疑虑前往呢？

**相关性**：九三阳刚过甚，处下卦之极，躁动易冒进，是 变革中的激进者。“征凶，贞厉”是 严厉警告：在 变革的攻坚阶段，若 一味强攻猛进（征），必有 凶险；此时更需 守持正固（贞），时刻警惕 危险（厉）。那么该如何做？“革言三就，有孚”提供了方法：“革言” 指 变革的方案、主张；“三就”指 反复讨论、审议，直至众人达成共识；“有孚”强调 整个过程必须出于至诚，取信于人。爻传“又何之矣”说：**既然方案已获广泛认同，那就 可以坚定前行，不必再犹豫。此爻强调：**重大变革不能靠个人独断或暴力推行，必须 经过充分民主协商，凝聚共识，才能 减少阻力，确保成功。


### 九四：悔亡，有孚改命，吉。


**原文**：悔亡，有孚改命，吉。

**白话**：悔恨消亡，心怀诚信以革除旧命，吉祥。

**小象传**
**原文**：“改命之吉”，信志也。

**白话**：改变命运之所以吉祥，是因为实现了自己的志向。


**说明**

这是 变革的深入——诚信改命，转危为安。

+ “悔亡”：悔恨消亡（悔亡）。
+ “有孚改命，吉”：心怀诚信（有孚）以革除旧命（改命），吉祥（吉）。
+ 爻传“改命之吉，信志也”：革除旧命的吉祥，在于心志诚信。

**相关性**：九四阳居阴位，已进入上卦兑体（变革的主导方），是 变革的执行核心。“悔亡”承接上爻的“贞厉”，表示 经过审慎周详的筹备（九三），原有的危险和悔恨已经消除。此时进入 “改命”阶段——**即 从根本上改变旧秩序、旧制度（命）。成功的关键在于 “有孚”——**变革者必须 心怀至诚，信念坚定，其变革的意志（信志）才能 感召众人，赢得支持，从而获得 吉祥。此爻标志着 变革从“议”进入“行”，从“革言”进入“改命”的实质性阶段。


### 九五：大人虎变，未占有孚。


**原文**：大人虎变，未占有孚。

**白话**：大德之人推行变革，如虎纹般昭然炳焕，不待占卜就令人信服。

**小象传**
**原文**：“大人虎变”，其文炳也。

**白话**：大人推行变革像猛虎一样威猛，是因为他的文采德行光辉显耀。


**说明**

这是 变革的鼎盛——领袖英明，文明昭彰。

+ “大人虎变”：大人（大人）推行变革，其势如虎纹（虎变）般彪炳昭著。
+ “未占有孚”：不必占问（未占）就知其心怀诚信（有孚）。
+ 爻传“大人虎变，其文炳也”：大人推行变革如虎纹般昭著，是因为其文德光彩彪炳。

**相关性**：九五阳刚中正，居尊位，是 领导变革的“大人”。“虎变”是 极其生动的比喻：老虎秋季换毛，新生的皮毛 纹彩彪炳，光泽鲜明。以此形容 **“大人”领导的变革，**其 成效与气象 如同虎纹般 显著、光明、令人敬畏。“未占有孚”表明：**其 诚信与正道已广为人知，毋庸置疑。爻传“其文炳也”点明：**这种昭著的光彩，源于 **其 文明之德（离火为明）。此爻是对 成功变革领导者的最高赞颂：**其变革 并非依靠暴力，而是以 光辉的德行与文明的政策 服众，成果显著，天下景从。


### 上六：君子豹变，小人革面。征凶，居贞吉。


**原文**：君子豹变，小人革面。征凶，居贞吉。

**白话**：君子变革如豹纹般细密润泽，小人则只是表面改变。前进有凶险，安居守持正固可获吉祥。

**小象传**
**原文**：“君子豹变”，其文蔚也。“小人革面”，顺以从君也。

**白话**：君子的变化如同豹子换毛，其文采华美鲜明。小人改变面貌，是顺从追随君主。


**说明**

这是 变革的终点——成果巩固，防止反复。

+ “君子豹变”：君子（君子）变革如豹纹（豹变）般细密润泽。
+ “小人革面”：小人（小人）表面顺从（革面）。
+ “征凶，居贞吉”：进取（征）有凶险（凶），安守正固（居贞）可获吉祥（吉）。
+ 爻传“君子豹变，其文蔚也；小人革面，顺以从君也”：君子变革如豹纹般细密，是因为其文德蔚然繁盛；小人表面顺从，是勉强顺从君王。

**相关性**：上六阴柔处卦之极，是 变革的完成与巩固阶段。“君子豹变”与“大人虎变”呼应，但程度稍逊：豹纹比虎纹 更细密、更润泽，比喻 变革的成果已渗透到社会细处，文明教化蔚然成风（其文蔚）。“小人革面”则揭示了 变革的不彻底性：**部分人（小人）只是 表面上（革面）顺从新秩序，内心未必真正认同，只是 勉强服从权威（顺以从君）。此时若 继续激进推行（征），可能 激化矛盾，引发反复，故有凶险。正确的做法是 “居贞吉”：**安守变革成果，持守正道，**通过 教化与巩固，使新秩序深入人心，如此则 吉祥。此爻强调：**变革成功后，**重要的不是 继续革命，而是 转向建设与巩固，防范旧势力回潮与表面顺从者的隐患。


## 总结

**总结**：革卦的现代启示

革卦的 “治历明时” 是关于 “变革、革新、革命”的深邃哲学，它系统阐述了 一场成功变革所必须遵循的客观规律与主观修养。

推动变革进程的六个阶段：

+ 固守勿革（初九）：巩用黄牛之革，不可有为。
+ 待时而行（六二）：巳日乃革之，征吉无咎。
+ 审慎周详（九三）：征凶贞厉，革言三就，有孚。
+ 除旧布新（九四）：悔亡，有孚改命，吉。
+ 领袖之革（九五）：大人虎变，未占有孚。
+ 革成守成（上六）：君子豹变，小人革面，征凶居贞吉。

核心心法：大象传总纲——“泽中有火，革；君子以治历明时。” 这意味着：

+ “泽中有火，革”：是 革卦之象（泽水灭火，或火煮泽水，相克而变）。
+ “君子以治历明时”：君子效法此象，制定历法，彰明时序。

这是 革卦精神的灵魂。“治历明时”是 一项伟大的文明创制，它 根据天象变化（变革），制定出指导人事活动的法则（历法），使人们 明晓时令节气（明时），顺应自然规律。君子由此领悟：**真正的变革，**不是 盲目破坏，而是 像制定历法一样，洞察客观规律（天时），建立新的、更合理的秩序与法则。变革的 目的 是 “明时”——让社会运行更符合天道人心，更有章可循。这赋予了 **“变革”以 建设性、文明性的崇高内涵。

根本精神：彖传 “革，水火相息，二女同居，其志不相得，曰革。巳日乃孚，革而信也。文明以说，大亨以正，革而当，其悔乃亡。天地革而四时成，汤武革命，顺乎天而应乎人，革之时大矣哉！” 揭示了变革的宇宙意义与历史合法性：

+ “天地革而四时成”：天地变革而形成四季。这是 变革的宇宙论依据——变革是自然规律。
+ “汤武革命，顺乎天而应乎人”：商汤、周武的革命，上顺天意，下应民心。这是 变革的历史典范——**正义的革命必须 顺应天道（规律），符合人心（民意）。
+ “革之时大矣哉！”：变革的时势意义太伟大了！

革卦告诉我们：**“革”是 宇宙与社会新陈代谢的必然法则。但 人间的变革 不能是 任意妄为，必须 像“治历”一样严谨，像“虎变”、“豹变”一样文明，其 最高标准 是 “顺乎天而应乎人”。其 时机（巳日）、方法（革言三就）、领导者（大人）、成果（虎变、豹变） 都有严格的要求。这便是在 “泽中有火” 的冲突景象中，所升华出的 **关于 除旧布新、顺天应人、开创文明的宏伟哲学。
