# 艮卦（艮上艮下）

**卦画**：䷳

## 总论：艮止之道的哲学

**核心短词**：“时止则止”

**卦象**：上艮（☶）为山、为止，下艮（☶）为山、为止。艮为山。兼山，两山重叠。

**核心卦辞**：“艮其背，不获其身；行其庭，不见其人，无咎。”

**总纲**：艮卦象征 “山、静止、抑止”。抑止于背后，使整个身体不能动弹；行走在庭院中，却看不见里面的人，没有咎害。

+ “艮其背，不获其身”：这是 止的极致与智慧。将止的功夫用在背部（艮其背），因为 背部没有感官，不易被外物牵引。如此，整个身体（不获其身）都无法妄动。比喻止息欲望，应从 根源（感官之背） 入手，达到 身心俱寂 的境界。
+ “行其庭，不见其人，无咎”：这是 止于外境的状态。行走在庭院中（行其庭），却看不见里面的人（不见其人）。比喻当内心 止定 时，*即使身处人群与环境之中，也能 视而不见，听而不闻，外物无法扰动内心，故 没有咎害。

**本质**：艮卦描述 “兼山” 的状态。上下皆山，两山并立，巍然不动，象征 绝对的静止、安止。其**核心精神**是：探讨 “止”的智慧——何时该止，止于何处，如何止得其所。它并非提倡 消极的静止，而是强调 “时止则止，时行则行” 的 动态平衡，即 顺应时势，在该静止时能彻底静止，内心不为外物所动。

## 卦辞



### 经

**原文**：艮其背，不获其身；行其庭，不见其人，无咎。

**白话**：抑止于背后，使整个身子不能动弹；行走在庭院中，却见不到人，没有咎害。

### 彖传

**原文**：艮，止也。时止则止，时行则行，动静不失其时，其道光明。艮其止，止其所也。上下敌应，不相与也。是以“不获其身，行其庭，不见其人，无咎”也。

**白话**：艮卦，讲的是停止的道理。该停的时候就停，该动的时候就动，动静都不错过恰当的时机，前途就会光明。所谓“艮其止”，就是停在恰当的位置上。卦中上下对应的爻都相互敌对，不能配合。所以卦辞说：“感觉不到自己的身体，走在庭院里也看不见人，没有灾祸。”

### 大象传

**原文**：兼山，艮；君子以思不出其位。

**白话**：两座山重叠，象征抑止；君子因此思考问题不超越自己的本位。


## 爻辞

### 初六：艮其趾，无咎，利永贞。


**原文**：艮其趾，无咎，利永贞。

**白话**：抑止在脚趾迈出之前，没有咎害，利于永久守持正固。

**小象传**
**原文**：“艮其趾”，未失正也。

**白话**：止住脚趾，是没有违背正道。


**说明**

这是 艮止的初始——防微杜渐，止于开端。

+ “艮其趾”：抑止在脚趾（艮其趾）。
+ “无咎，利永贞”：没有咎害（无咎），利于永久守持正固（利永贞）。
+ 爻传“艮其趾，未失正也”：抑止在脚趾，说明未失正道。

**相关性**：初六阴柔处下，如 人之脚趾，是 行动的开始。“艮其趾”意味着在 行动刚刚萌发（抬脚）之时 就 加以抑止。这好比 错误的念头或行为，在 尚未成形、影响甚微时 就 被克制住，故能 避免后续的咎害。“利永贞”强调：这种 “止于未动” 的功夫，需要 长久、坚定地保持。爻传“未失正也”指出：因为 止得早，止得及时，所以 根本没有偏离正道。此爻阐明：**艮止的 最高效率，在于 将问题消灭在萌芽状态。


### 六二：艮其腓，不拯其随，其心不快。


**原文**：艮其腓，不拯其随，其心不快。

**白话**：抑止在小腿肚上，不能上承（或拯救）所随从者，心中不痛快。

**小象传**
**原文**：“不拯其随”，未退听也。

**白话**：不能拯救他的随从，是因为没有退让听从。


**说明**

这是 艮止的错位——被动强止，心有不甘。

+ “艮其腓”：抑止在小腿肚上（艮其腓）。
+ “不拯其随”：无法举步（不拯）上承本应随从的躯体（其随）。
+ “其心不快”：内心（其心）不得畅快（不快）。
+ 爻传“不拯其随，未退听也”：无法举步上承，是因为（小腿）未能退而听从（躯干的命令）。

**相关性**：六二阴柔中正，如 人之小腿（腓）。小腿本应 随从大腿（股）和躯干的命令而行动。但“艮其腓”意味着 强行抑止了小腿，导致它 无法履行其“随从”的职责（不拯其随）。这比喻一个人处在 应该行动、配合的位置，却 被外力或错误的自律强行抑制，导致 该做的事做不了，该尽的责尽不到，因而 内心憋闷不畅（其心不快）。爻传“未退听也”点明原因：小腿 未能退一步，听从上级（躯干）的指挥，而是 僵持在原地。此爻警示：“止” 必须得当。**在不该止的地方强行止住，**会 破坏系统的协调，导致内心的痛苦。


### 九三：艮其限，列其夤，厉薰心。


**原文**：艮其限，列其夤，厉薰心。

**白话**：抑止在腰部，脊背肉被撕裂，危险如烈火熏灼其心。

**小象传**
**原文**：“艮其限”，危薰心也。

**白话**：限制腰部的行动，是因为危险的感觉像烈火一样灼烧着内心。


**说明**

这是 艮止的危境——强行止断，身心俱损。

+ “艮其限”：抑止在腰部（艮其限）。
+ “列其夤”：致使脊肉撕裂（列其夤）。
+ “厉薰心”：危险（厉）如烈火灼心（薰心）。
+ 爻传“艮其限，危薰心也”：抑止在腰部，危险如烈火灼心。

**相关性**：九三阳刚过中，处上下卦之间，如 人之腰部（限），是 连接上下的要害枢纽。“艮其限”意味着在 关键、枢纽的位置 强行 止住、阻断。这会导致 上下隔绝，整体失调，如同 脊肉（夤）被撕裂，带来 极大的痛苦和危险。“厉薰心”形容这种痛苦 深入内心，如被火烤。此爻是对 错误、僵硬、不合时宜的“止” 的 最严厉警告：**当止于 不该止的关节之处，强行阻断事物的自然联系与运行，必将 导致系统崩溃，自身也承受巨大煎熬。


### 六四：艮其身，无咎。


**原文**：艮其身，无咎。

**白话**：抑止在自身（心腹胸背），没有咎害。

**小象传**
**原文**：“艮其身”，止诸躬也。

**白话**：艮卦的“艮其身”，意思是说止息要放在自己身上。


**说明**

这是 艮止的得宜——全神贯注，止于己身。

+ “艮其身”：抑止在全身（艮其身）。
+ “无咎”：没有咎害（无咎）。
+ 爻传“艮其身，止诸躬也”：抑止在全身，是说能抑止于自身。

**相关性**：六四阴柔得正，已进入上卦，如 人之躯干。“艮其身”与初爻“趾”、二爻“腓”、三爻“限”不同，它 不是止于某个局部，而是 止于整个自身。这意味着一种 全身心的收敛、静定与修养。爻传“止诸躬也”强调：这种“止”是 向内用功，约束自己，而非 对外干预。因为 止于自身，不干扰外界，所以 没有咎害。此爻指明了艮止的 正确方向与范围：真正的“止”，**首先是 “止于至善” 的 自我修养，是对自身言行、欲望的 管控与净化。


### 六五：艮其辅，言有序，悔亡。


**原文**：艮其辅，言有序，悔亡。

**白话**：抑止在口辅（颊腮），言语有条理，悔恨消亡。

**小象传**
**原文**：“艮其辅”，以中正也。

**白话**：管住嘴巴不乱说，是因为行得正坐得直。


**说明**

这是 艮止的言语——谨言慎语，言而有序。

+ “艮其辅”：抑止在口辅（面颊，指口舌）（艮其辅）。
+ “言有序”：说话有条理（言有序）。
+ “悔亡”：悔恨消亡（悔亡）。
+ 爻传“艮其辅，以中正也”：抑止在口辅，是因为（六五）居中守正。

**相关性**：六五阴柔居中，居尊位，如 人之口辅（面颊），掌管 言语。“艮其辅”不是要求 完全沉默，而是抑止 妄语、躁语、失语。其结果是 “言有序”——说话 有条理、合分寸、有章法。因为 言语谨慎得当，自然避免了口舌是非，所以 悔恨消亡。爻传“以中正也”指出：能做到慎言，根源在于 内心持守中正之道。此爻将 艮止的智慧 应用于 最易惹祸的“言语”领域，教导我们：“止”在言语上，体现为 “寡言” 和 “有序”，这是 修养的重要部分，能免祸致福。


### 上九：敦艮，吉。


**原文**：敦艮，吉。

**白话**：以敦厚笃实的态度抑止邪欲，吉祥。

**小象传**
**原文**：“敦艮之吉”，以厚终也。

**白话**：敦厚而知止，所以获得吉祥，是因为能够以敦厚之道坚持到最后。


**说明**

这是 艮止的终点——止德敦厚，至善至吉。

+ “敦艮”：以敦厚笃实的态度抑止（敦艮）。
+ “吉”：吉祥（吉）。
+ 爻传“敦艮之吉，以厚终也”：以敦厚笃实的态度抑止而获吉祥，是因为能以敦厚终结。

**相关性**：上九阳刚处卦之极，是 艮止之道的完成与升华者。“敦”是 敦厚、笃实、深厚 之意。“敦艮”意味着“止”的功夫已达到 自然而深厚、坚定不移、毫不勉强 的境界。这不再是 刻意、艰难、痛苦的抑制，而是一种 内在的、安详的、厚重的稳定状态。如同 大山（艮为山） 的 根基深厚、巍然不动。因为 止于至善，止得圆满，故获 吉祥。爻传“以厚终也”赞美：**其 吉祥 来自于 以敦厚的美德为终结。此爻是 对艮止修养 最高境界的描绘：“止” 内化为人格的一部分，成为一种 敦厚稳重的生命气质，从而 获得终极的吉祥与安宁。


## 总结

**总结**：艮卦的现代启示

艮卦的 “时止则止” 是关于 “静止、抑止、内省”的深邃智慧。它并非 教人停滞不前，而是教导 在纷繁复杂的行动世界中，掌握“静止”的力量与艺术。

实践艮止之道的六个层次：

+ 止于未动（初六）：艮其趾，无咎，利永贞。
+ 止不当位（六二）：艮其腓，不拯其随，其心不快。
+ 止于要害（九三）：艮其限，列其夤，厉薰心。
+ 止得其所（六四）：艮其身，无咎。
+ 慎言寡语（六五）：艮其辅，言有序，悔亡。
+ 止于至善（上九）：敦艮，吉。

核心心法：大象传总纲——“兼山，艮；君子以思不出其位。” 这意味着：

+ “兼山，艮”：是 艮卦之象（两山并立，静止不动）。
+ “君子以思不出其位”：君子效法此象，所思所虑不超越自己的本位。
这是 艮卦精神的灵魂。“思不出其位”是“止”的 最高应用。它要求君子：**在 思想上 也要 懂得“止”——安于本分，不妄想，不僭越，不纠结于自己权限和能力之外的事情。这并非 限制思考，而是让思考 聚焦、深入、有效，避免 无谓的思虑和精神内耗。这是一种 极其高级的内心管理 和 专注力训练。

根本精神：彖传 “艮，止也。时止则止，时行则行，动静不失其时，其道光明。艮其止，止其所也。上下敌应，不相与也，是以不获其身，行其庭不见其人，无咎也。” 揭示了艮止之道的辩证法则：

+ “时止则止，时行则行，动静不失其时，其道光明”：这是 艮卦的总原则。该静止时就静止，该行动时就行动，动静都不错过恰当的时机，这样前途必然光明。这彻底破除了 “止”是消极 的误解，将其纳入 “时” 的动态哲学中。
+ “艮其止，止其所也”：艮卦所说的止，是止于其所当止。强调“止”要有 恰当的对象和位置（所）。
+ “上下敌应，不相与也”：（艮卦）上下卦同性相斥，不相亲近。解释卦象 上下皆山，互不往来 的 静止状态。
+ “是以不获其身，行其庭不见其人，无咎也”：所以（能做到这样）就会全身静止，行走庭院也视若无人，没有咎害。这是 “止其所” 达到的 理想效果。

艮卦告诉我们：**“艮”是 动与静的平衡器。一个深谙艮道的人，能 在喧嚣中静心（思不出其位），在行动前止念（艮其趾），在言语上守序（艮其辅），最终达到 敦厚安止（敦艮） 的 生命境界。其 最高智慧 在于 “时” 字——因时制宜，当行则行，当止则止。这便是在 “兼山” 的静默景象中，所蕴含的关于 自我控制、时机把握、内心安宁 的 永恒人生哲理。
