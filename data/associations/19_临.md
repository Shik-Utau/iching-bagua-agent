# 临卦（坤上兑下）

**卦画**：䷒

## 总论：临下的哲学

**核心短词**：“教思无穷”

**卦象**：上坤（☷）为地、为顺，下兑（☱）为泽、为悦。地泽临。大地 居高临下，俯视泽水；泽水 欣然承顺，映照大地。以上临下，以刚临柔。

**核心卦辞**：“临，元亨利贞。至于八月有凶。”

**总纲**：临卦探讨 领导者（君临天下者）如何治理、督导、教化下属与民众。

+ “临”：莅临、督导、治理。
+ “元亨利贞”：具备创始、亨通、有利、贞固这 四种美德，是“临”能成功的根本。
+ “至于八月有凶”：但 到了八月（阳气衰退、阴气渐长之时）会有凶险。这是 盛极而衰 的预警。

## 卦辞



### 经

**原文**：元亨，利贞。至于八月有凶。

**白话**：至为亨通，利于守持正固。到了八月将有凶险。

### 彖传

**原文**：临，刚浸而长，说而顺，刚中而应，大亨以正，天之道也。至于八月有凶，消不久也。

**白话**：临卦，是阳刚之气逐渐增长，喜悦而顺从，刚健居中且上下相应，大为亨通且持守正道，这是天地运行的法则。到了八月会有凶险，是因为阳气消退不会长久。

### 大象传

**原文**：泽上有地，临；君子以教思无穷，容保民无疆。

**白话**：水泽之上有大地，象征临察；君子因此要无穷尽地教化关心百姓，无边际地包容保护民众。


## 爻辞

### 初九：咸临，贞吉。


**原文**：咸临，贞吉。

**白话**：以感化之心监临，守正吉祥。

**小象传**
**原文**：“咸临贞吉”，志行正也。

**白话**：用感化的方式治理民众，坚守正道可获吉祥，这说明心意和行为都要端正。


**说明**

这是 临下的基础——感化守正。

+ “咸临”：以 感化、感通（咸）之心莅临治理。
+ “贞吉”：守持正道 则吉祥。
+ 爻传“志行正也”：因为 心志与行为都端正。

**相关性**：初九阳刚处下，是 临之始。它象征 基层管理者或治理的初始阶段。此时，领导者应以 真诚的感化力（咸） 来接近和影响民众，而非依靠权力强制。同时，必须 从一开始就坚守正道（贞），树立正确的导向。心正行正（志行正），方能获吉。这定义了 领导力的道德起点。


### 九二：咸临，吉无不利。


**原文**：咸临，吉无不利。

**白话**：以感化之心监临，吉祥，无所不利。

**小象传**
**原文**：“咸临，吉无不利”，未顺命也。

**白话**：用感化的方式治理百姓，吉祥而无所不利，这是因为没有完全顺从命令。


**说明**

这是 临下的拓展——刚中应柔。

+ “咸临”：以 感化之心莅临治理。
+ “吉无不利”：吉祥，无所不利。
+ 爻传“未顺命也”：因为 （九二）并未一味顺从（六五）君命（而是以刚中之德自行感化）。

**相关性**：九二阳刚居中，与六五君王相应，是 得位的大臣。他的“咸临”比初九 更具影响力与主动性。爻传“未顺命也”点出其关键：他并非机械执行上命，而是 以自身刚健中正的品德（刚中），创造性地感化一方，因此成效卓著（吉无不利）。这体现了 优秀执行者的主体性与担当。


### 六三：甘临，无攸利。既忧之，无咎。


**原文**：甘临，无攸利。既忧之，无咎。

**白话**：以甜言蜜语取悦监临，无所利益。若能忧虑改过，则无咎害。

**小象传**
**原文**：“甘临”，位不当也。“既忧之”，咎不长也。

**白话**：用甜言蜜语去领导众人，说明所处的位置不恰当。既然已经为此忧虑并改过，过错就不会长久。


**说明**

这是 临下的歧途——谄媚无实。

+ “甘临”：以 甜言蜜语、讨好取悦（甘）的方式莅临。
+ “无攸利”：没有任何好处。
+ “既忧之，无咎”：但若 已经（既）为此感到忧患并改正，则可免于过错。

**相关性**：六三阴柔不中不正，象征 无德无才、只知谄媚的领导者。其“甘临”是 虚伪的取悦，缺乏真诚与实力，故终“无攸利”。但爻辞给出了 改过的机会：只要 内心生出真正的忧患意识（既忧之），认识到此路不通而改正，仍可免咎。这是对 华而不实、作风浮夸者的当头棒喝与出路指引。


### 六四：至临，无咎。


**原文**：至临，无咎。

**白话**：以亲至的态度监临，没有咎害。

**小象传**
**原文**：“至临无咎”，位当也。

**白话**：到了亲自处理政事的时候没有过错，是因为所处的位置恰当。


**说明**

这是 临下的亲近——当位尽职。

+ “至临”：极为亲近、到位（至）地莅临治理。
+ “无咎”：没有过错。
+ 爻传“位当也”：因为 所处位置恰当（阴居阴位，紧邻下卦）。
**相关性**：六四柔顺得正，又紧邻下卦（民众），象征 亲民、勤勉的官员。他的“至临”是 深入基层、体察民情、工作到位。因其 位置恰当（位当），且态度真诚，虽无大功，但能 恪尽职守，不出差错（无咎）。这肯定了 踏实、亲民的为官之道。


### 六五：知临，大君之宜，吉。


**原文**：知临，大君之宜，吉。

**白话**：以智慧监临，是伟大君主的合宜之举，吉祥。

**小象传**
**原文**：“大君之宜”，行中之谓也。

**白话**：大君的行为恰当适宜，说的是他行事符合中正之道。


**说明**

这是 临下的智慧——明察善任。

+ “知临”：以 智慧、明察（知）莅临治理。
+ “大君之宜，吉”：这是 伟大君主（大君）的合宜之举，吉祥。
+ 爻传“行中之谓也”：说的是 奉行中道。

**相关性**：六五柔中居尊，是 以智慧治国的君主。她的“知临”，不是事必躬亲，而是 知人善任、明察秋毫、把握全局的智慧。她懂得运用“刚浸而长”的阳刚力量（九二），又能以柔顺（坤）包容天下，奉行 中正之道（行中）。这才是 最高领导者（大君）最适宜的统治方式，故获吉祥。


### 上六：敦临，吉无咎。


**原文**：敦临，吉无咎。

**白话**：以敦厚诚实的态度监临，吉祥，没有咎害。

**小象传**
**原文**：“敦临之吉”，志在内也。

**白话**：以敦厚之心临民之所以吉祥，是因为其心志专注于内部的邦国百姓。


**说明**

这是 临下的归宿——敦厚保终。

+ “敦临”：以 敦厚、诚实（敦）之心莅临治理。
+ “吉无咎”：吉祥，没有过错。
+ 爻传“志在内也”：因为 心志系于内部（邦国百姓）。

**相关性**：上六处卦之极，是 临道之终。在治理的后期或高位，容易产生 懈怠或虚伪。此时，“敦临”强调 返璞归真，以最本真的敦厚诚信来对待民众。其心志始终向内，系于家国百姓（志在内），而非外在虚名。如此，方能 保持晚节，善始善终，得吉无咎。这是对 领导者终极品格的锤炼。


## 总结

**总结**：临卦的现代启示
临卦的 “教思无穷” 是关于 领导力、管理与教化 的全面指南。

领导方式：

+ 初心（初九）：以 感化（咸） 和 正道（贞） 起始。
+ 拓展（九二）：以 刚健中正的品德 创造性地施政。
+ 歧途（六三）：切忌 华而不实、谄媚取悦（甘），但知错能改则善。
+ 亲民（六四）：深入实际、工作到位（至） 是基本要求。
+ 高层（六五）：最高领导者贵在 智慧明察、知人善任（知）。
+ 终极（上六）：最终要回归 敦厚诚信（敦） 的本心。

核心心法：大象传总纲——“君子以教思无穷，容保民无疆”。这意味着：

+ “教思无穷”：领导者的责任不仅是管理，更是 永无止境地教化与思考，提升民众的智慧与道德。
+ “容保民无疆”：要有 无边界的包容心与保护欲，像大地承载泽水一样，容纳并保障万民。

永恒警示：卦辞 “至于八月有凶” 是 盛极而衰 的规律提醒。即使在最好的治理时期（元亨利贞），也需 居安思危，警惕阳气（刚健精神）衰退，阴气（懈怠腐败）滋长 的时刻到来。

临卦与蛊卦的承续：蛊卦（䷑）讲 “整治积弊”（振民育德），是 对混乱局面的革新；临卦（䷒）则讲 “盛世治理”（教思无穷），是 革新成功、步入正轨后的日常领导艺术。《序卦传》言：“蛊者，事也。有事而后可大，故受之以临。” 意思是：整治蛊乱（事）之后，事业就可以盛大发展，所以继之以临卦。治乱（蛊）为兴盛（临）开辟了道路。临卦探讨的，正是 在“可大”的兴盛局面下，如何以正确的领导力（临）来保持并发展这一成果。从蛊到临，体现了 从“破旧立新”到“持盈保泰” 的完整发展周期。
