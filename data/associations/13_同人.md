# 同人卦（乾上离下）

**卦画**：䷌

## 总论：会同的哲学

**核心短词**：“同人于野”

**卦象**：上乾（☰）为天、为刚健，下离（☲）为火、为文明。天火同人。火性炎上，与天亲和；以文明（离）附丽于刚健（乾），光明磊落，志同道合。

**核心卦辞**：“同人于野，亨。利涉大川，利君子贞。”

**总纲**：同人卦探讨 如何超越狭隘，在广阔天地间与人和同、建立共识。

+ “同人于野”：在 旷野（象征 至公至广、没有界限 之地）与人会同。
+ “亨”：如此则亨通。
+ “利涉大川”：有利于 涉越险难（大川）。
+ “利君子贞”：利于 君子守持正道。

**本质**：同人卦的核心是 “大同”与“守正”。它追求的“同”，不是党同伐异的小圈子之“同”（同人于宗），而是 基于正道、光明无私的广泛联合。这种联合具有强大的力量（利涉大川），但其前提是 联合者自身必须是君子，且动机纯正（利君子贞）。

## 卦辞



### 经

**原文**：同人于野，亨。利涉大川，利君子贞。

**白话**：在旷野与人和同，亨通。利于涉越大河巨流，利于君子守持正固。

### 彖传

**原文**：同人，柔得位得中而应乎乾，曰同人。同人曰：“同人于野，亨，利涉大川”，乾行也。文明以健，中正而应，君子正也。唯君子为能通天下之志。

**白话**：同人卦，是柔顺者处在正位、守持中道，又与刚健的乾卦相应和，所以称作同人。同人卦的卦辞说：“在旷野上与众人和同，亨通，利于涉越大河”，这是因为刚健的乾道在运行。禀性文明而又刚健，行为中正而又互相应和，这是君子守持正道的体现。只有君子能够贯通天下人的心志。

### 大象传

**原文**：天与火，同人；君子以类族辨物。

**白话**：天与火相互亲和，象征和同于人；君子因此分析人群的类别，辨别事物的差异。


## 爻辞

### 初九：同人于门，无咎。


**原文**：同人于门，无咎。

**白话**：在门外与人和同，没有咎害。

**小象传**
**原文**：出门同人，又谁咎也。

**白话**：出门与人同心协力，又有谁会责怪你呢。


**说明**

这是 会同的起点——出门求同。

+ “同人于门”：走出自家 门庭，与外人会同。
+ “无咎”：没有过错。
**相关性**：“于门”是 “于野”的第一步。在自家门内，是血缘宗族之私；走出门外，便是迈向更广阔天地的开始。此爻鼓励人们 打破门户之见，主动向外寻求志同道合者。虽然范围尚小（仅及于门），但方向正确，故“无咎”。这是 突破狭隘的第一步。


### 六二：同人于宗，吝。


**原文**：同人于宗，吝。

**白话**：只与同宗族的人和同，有所憾惜。

**小象传**
**原文**：“同人于宗”，吝道也。

**白话**：在宗族内部聚集同党，这是会招致悔恨的做法。


**说明**

这是 会同的歧途——宗党之私。

+ “同人于宗”：只与 同宗族、同党派 的人亲比会同。
+ “吝”：必然导致 憾惜、鄙吝。
+ 爻传“吝道也”：这是 通向憾惜的道路。
**相关性**：此爻是卦辞“同人于野”的 直接反面。六二本与九五正应，理应“同人于野”，但它却 只亲近身边的九三（同宗），格局狭小。这警示：如果联合的动机是基于 血缘、派系等私利，而非公义，那么这种“同”非但不能成事，反而会 制造隔阂、引发纷争（吝），是“同人”之道的大忌。


### 九三：伏戎于莽，升其高陵，三岁不兴。


**原文**：伏戎于莽，升其高陵，三岁不兴。

**白话**：埋伏兵戎于草莽之中，登上高陵观望，三年不敢兴兵。

**小象传**
**原文**：“伏戎于莽”，敌刚也。“三岁不兴”，安行也。

**白话**：埋伏军队在草丛中，是因为敌人太强大。三年都不敢兴兵作战，是因为要等待安全的时机。


**说明**

这是 会同的障碍——强求而惧。

+ “伏戎于莽”：在草莽中 埋伏军队（戎），比喻 暗藏武力，意图以力强求会同。
+ “升其高陵”：登上高陵 窥探形势。
+ “三岁不兴”：多年（三岁） 都不敢 兴兵行动。
**相关性**：九三阳刚过甚，不中不正，欲与六二亲比，但六二心属九五。九三于是 心生争夺之念，暗备武力（伏戎），却又 畏惧九五的强大（升其高陵以窥），迟迟不敢动手（三岁不兴）。这描绘了 以力服人、心怀叵测者在“大同”正道前的虚弱、恐惧与徒劳。真正的“同”无法靠武力胁迫获得。


### 九四：乘其墉，弗克攻，吉。


**原文**：乘其墉，弗克攻，吉。

**白话**：登上城墙，不能攻占，吉祥。

**小象传**
**原文**：“乘其墉”，义弗克也。其吉，则困而反则也。

**白话**：敌人已经登上城墙，按理说我们是守不住了。但最终能获得吉祥，是因为敌人在困境中又回到了正道。


**说明**

这是 会同的转念——知难而退。

+ “乘其墉”：登上（乘）了对方的城墙（墉），已占据优势。
+ “弗克攻”：却 不再进攻（弗克攻）。
+ “吉”：吉祥。
+ 爻传“困而反则也”：在 困阻中能回头遵循法则。
**相关性**：九四与九三类似，也想与六二亲比，并已采取行动（乘墉）。但与九三的“伏戎”不同，九四在关键时刻 能自我克制，放弃进攻。因为他意识到，以力攻取的“同”并非真同，且会违背“同人于野”的公义法则。这种 在优势下主动放弃、回归正道（反则） 的抉择，避免了更大的冲突，故得“吉”。


### 九五：同人，先号咷而后笑，大师克相遇。


**原文**：同人，先号咷而后笑，大师克相遇。

**白话**：与人和同，先号啕大哭，后欣喜欢笑，大军克敌会师。

**小象传**
**原文**：同人之先，以中直也。大师相遇，言相克也。

**白话**：志同道合的人能领先行动，是因为内心正直中道。大军会师相遇，说的是能够克服障碍。


**说明**

这是 会同的达成——破阻而合。

+ “同人，先号咷而后笑”：在 与人会同 的过程中，先遭遇巨大挫折而痛哭（号咷），后因成功而欢笑。
+ “大师克相遇”：需要 动用大军（大师） 克服阻碍，最终才得以 相遇会同。
**相关性**：九五阳刚中正，与六二真心相应，本应自然“同人”。但中间有九三、九四重重阻隔（伏戎、乘墉），致使会同之路异常艰难，故先有“号咷”之悲。最终，凭借 自身强大的正道力量（大师），冲破阻碍（克），才得以与六二相遇（笑）。此爻表明：追求至公至广的“大同”，绝非易事，必遭既得利益者（九三、九四）的强力阻挠，需要坚定的意志和强大的实力去克服。


### 上九：同人于郊，无悔。


**原文**：同人于郊，无悔。

**白话**：在郊野与人和同，没有悔恨。

**小象传**
**原文**：“同人于郊”，志未得也。

**白话**：在郊外与人聚合，是因为志向未能实现。


**说明**

这是 会同的超越——淡然而处。

+ “同人于郊”：在 城郊 与人会同。
+ “无悔”：没有悔恨。
+ 爻传“志未得也”：因为 （大同的）志向未能完全实现。
**相关性**：“郊”介于“门”（私）与“野”（公）之间，是 远离权力中心、清静超然之地。上九处卦极，象征 淡泊名利、不争不抢的隐士或贤者。他虽未能实现“于野”的终极大同之志（志未得），但能在自己力所能及的范围内（于郊）与人和同， 独善其身，保持节操，故可“无悔”。此爻为“同人”之道提供了一种 退而求其次的、个人化的圆满答案。


## 总结

**总结**：同人卦的现代启示
同人卦的 “同人于野” 是关于 建立广泛联盟、凝聚社会共识、实现团队协作 的宏大智慧。

核心境界：追求 超越私利、光明正大（利君子贞）的广泛联合，而非小团体利益。
实践阶梯：

+ 第一步（初九）：打破门户之见，主动向外（于门）。
+ **关键禁忌**（六二）：切忌 搞小圈子、宗派主义（于宗），此为“吝道”。
+ 克服障碍（九三、九四、九五）：联合之路必遇阻挠，需 摒弃武力胁迫（伏戎），懂得 适时退让（弗克攻），并准备用 强大的正道力量（大师） 去克服。

+ 个人境界（上九）：若无力改变大局，可在 自己清净的范围内（于郊） 践行和同之道，独善其身，无愧于心。
+ 终极力量：基于正道的广泛联合，能产生 克服巨大险难（利涉大川） 的磅礴力量。

同人卦与否卦的承续：否卦（䷋）讲 “天地不交” 的闭塞黑暗，人道不通；同人卦（䷌）则讲 “天火相亲” 的光明会同，人心聚合。从否到同人，是 从隔绝走向联合、从黑暗走向光明 的必然趋势。正如《序卦传》所言：“物不可以终否，故受之以同人。” 否塞到了极点，人们必然寻求突破隔绝，走向联合。同人卦正是 打破否塞、建立新共识、开创新局面的卦。它教导我们，在困境中，唯有 跳出狭隘，寻求基于正道的广泛合作，才能“涉大川”，开新天。
