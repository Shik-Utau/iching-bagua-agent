# 兑卦（兑上兑下）

**卦画**：䷹

## 总论：欣悦之道的哲学

**核心短词**：“朋友讲习”

**卦象**：上兑（☱）为泽、为悦，下兑（☱）为泽、为悦。兑为泽。两泽相连，互相滋悦。

**核心卦辞**：“亨，利贞。”

**总纲**：兑卦象征 “欣悦、和悦”。亨通，利于守持正固。

+ “亨”：亨通（亨）。**喜悦能 沟通情感，化解矛盾，促进合作，故本身具有亨通的 特质。
+ “利贞”：利于守持正固（利贞）。这是兑卦的 核心诫命。喜悦虽是 好事，但必须建立在 正道 之上。若为取悦而 阿谀奉承、同流合污，或沉溺于 享乐，则喜悦将 变质，带来 祸患。故必须 以 “贞”（正固） 来规范 “悦”，方能 持久亨通。

**本质**：兑卦描述 “丽泽，兑” 的状态。两泽相连，水泽互相流通浸润，象征一种 相互交流、彼此滋润、共同喜悦 的 人际关系。其**核心精神**是：探讨 “悦”的智慧——如何正确地 表达喜悦、营造和谐、与人同乐，并警惕不当的 取悦与享乐 带来的 危害。它强调 “刚中而柔外”——内心 刚健中正，外在 柔和喜悦，表里如一。

## 卦辞



### 经

**原文**：亨，利贞。

**白话**：亨通，利于守持正固。

### 彖传

**原文**：兑，说也。刚中而柔外，说以利贞，是以顺乎天而应乎人。说以先民，民忘其劳；说以犯难，民忘其死。说之大，民劝矣哉！

**白话**：兑卦，就是喜悦的意思。阳刚居中而柔和显于外，使人喜悦而又利于坚守正道，因此能上顺天理下应人心。用喜悦来引导民众，民众会忘记劳苦；用喜悦来激励民众奔赴危难，民众会舍生忘死。喜悦的意义如此重大，它能使民众自我勉励、奋发有为啊！

### 大象传

**原文**：丽泽，兑；君子以朋友讲习。

**白话**：两泽相连，象征欣悦；君子因此与朋友相互讲解道理、研习学问。


## 爻辞

### 初九：和兑，吉。


**原文**：和兑，吉。

**白话**：平和欣悦，吉祥。

**小象传**
**原文**：“和兑之吉”，行未疑也。

**白话**：和悦相处之所以吉祥，是因为行动没有疑虑。


**说明**

这是 欣悦的开端——平和纯正，无所偏私。

+ “和兑”：平和欣悦（和兑）。
+ “吉”：吉祥（吉）。
+ 爻传“和兑之吉，行未疑也”：平和欣悦的吉祥，说明（初九）行为端正不使人疑虑。

**相关性**：初九阳刚处下，是兑悦的 初始，地位 卑微，无 应爻。其 “悦” 是 最 纯粹、最 本真的：“和兑”。“和” 意味着喜悦是 平和、中正、不偏不倚 的，非为讨好 某人，非因 某事，只是一种健康、阳光的 生活态度。因其动机 纯正，行为自然 光明磊落，不会引起他人的 猜疑（行未疑），故得 吉祥。此爻确立了欣悦之道 的 健康起点：发自内心、不假外求的 平和之悦。


### 九二：孚兑，吉，悔亡。


**原文**：孚兑，吉，悔亡。

**白话**：诚信欣悦，吉祥，悔恨消亡。

**小象传**
**原文**：“孚兑之吉”，信志也。

**白话**：内心真诚和悦而获得吉祥，是因为心志诚信。


**说明**

这是 欣悦的深化——诚信为本，悦以感人。

+ “孚兑”：诚信欣悦（孚兑）。
+ “吉，悔亡”：吉祥（吉），悔恨消亡（悔亡）。
+ 爻传“孚兑之吉，信志也”：诚信欣悦的吉祥，是因为心志诚信。

**相关性**：九二阳刚居中，是兑悦的 中坚力量。其 “悦” 的 特质 是 “孚”（诚信）。“孚兑” 意味着喜悦是建立在真诚、信实 的基础之上。与人交往，以真心换 欢心；处理事务，以信义求和乐。因其内心充满诚信（信志），外在的喜悦便自然具有感染力与说服力，不仅能获吉，还能消除因误解或虚伪可能带来的悔恨（悔亡）。此爻指明了欣悦得以深入持久的关键：诚信。无诚之悦，如同无根之木。


### 六三：来兑，凶。


**原文**：来兑，凶。

**白话**：前来谄媚求悦，有凶险。

**小象传**
**原文**：“来兑之凶”，位不当也。

**白话**：有人主动来讨好献媚，之所以会有凶险，是因为居位不正当。


**说明**

这是 欣悦的歧途——谄媚取悦，自招凶险。

+ “来兑”：前来谋求欣悦（来兑）。
+ “凶”：凶险（凶）。
+ 爻传“来兑之凶，位不当也”：前来谋求欣悦的凶险，是因为（六三）位置不当。

**相关性**：六三阴柔不中不正，处下卦之极，是兑悦的反面典型。“来兑”与初九的“和兑”、九二的“孚兑”形成鲜明对比。“来”字生动刻画了一种主动的、有目的的“讨好”姿态。六三自身无德（不中不正），却想通过外在的巧言令色、谄媚逢迎来博取他人的欢心与利益。这种“悦”是虚伪的、功利的、低贱的。爻传直指其“位不当也”：既指其爻位不中不正，也喻其为人处世方式不当。以此方式求悦，不仅无法得吉，反而会暴露人品，失去尊严，招致轻蔑与祸患，故“凶”。此爻是对阿谀奉承、曲意逢迎的严厉批判。


### 九四：商兑未宁，介疾有喜。


**原文**：商兑未宁，介疾有喜。

**白话**：商议如何欣悦，心中未宁，隔绝邪疾则有喜庆。

**小象传**
**原文**：九四之喜，有庆也。

**白话**：九四爻的喜兆，是因为有值得庆贺的好事。


**说明**

这是 欣悦的抉择——分辨悦道，去邪得喜。

+ “商兑，未宁”：商量如何欣悦（商兑），心中未曾安宁（未宁）。
+ “介疾有喜”：隔绝邪疾必有喜庆（介疾有喜）。
+ 爻传“九四之喜，有庆也”：九四的喜庆，是有福庆之事。

**相关性**：九四阳刚失正，居 上卦之始，下比六三 之“来兑”，上承九五 之“孚于剥”，身处两种 不同的 “悦” 之间，故内心 充满 矛盾与挣扎。“商兑，未宁” 描绘了 其 反复权衡、无法安宁 的 心理状态。“商” 是 思量、斟酌。“介疾” 是 关键转机：“介” 是 隔绝、划清界限；“疾” 指邪僻、不正当的 悦道（如六三的“来兑”）。九四最终 做出 正确抉择：毅然与邪僻的悦道 划清界限（介疾）。如此，心中的不安 消散，正道的喜悦 来临，故 “有喜”。爻传更称其 “有庆也”，是值得庆贺的 正确选择。此爻揭示了在复杂的人际悦乐 中，保持清醒，分辨正邪，并勇于割舍不当的 关系与诱惑，才能获得真正的、长久的 喜悦。


### 九五：孚于剥，有厉。


**原文**：孚于剥，有厉。

**白话**：诚信施于剥蚀小人，有危险。

**小象传**
**原文**：“孚于剥”，位正当也。

**白话**：诚信被剥夺，是因为所处的位置正当。


**说明**

这是 欣悦的危机——君王信邪，正道剥蚀。

+ “孚于剥”：诚信施与（孚于）剥蚀正道的小人（剥）。
+ “有厉”：有危险（有厉）。
+ 爻传“孚于剥，位正当也”：诚信施与剥蚀正道的小人，可惜啊！（九五）位置正当（却行为不当）。

**相关性**：九五阳刚中正，居 尊位，本应是兑悦之道的 楷模。但爻辞却出人意料地给出 警告。“剥” 指上六 阴爻，象征剥蚀阳刚正道的 小人（“剥”卦即阴剥阳）。九五与上六 相比相亲，对其施加 诚信（孚），意味着君王信任亲近 小人。爻传意味深长地说 “位正当也”：这是一种惋惜与 反讽——你的位置如此 正当（中正之君位），行为却 如此 不当（孚于剥）！亲信 小人，纵容其剥蚀 正气，即使君王自身初衷或许是为了 “和悦”，但其结果必然是正道 受损，朝纲 混乱，故 “有厉”（有危险）。此爻是对领导者 的 严重警示：和悦的氛围不能以牺牲原则和亲近 小人为代价，否则将危及 根本。


### 上六：引兑。


**原文**：引兑。

**白话**：引诱他人相悦。

**小象传**
**原文**：上六“引兑”，未光也。

**白话**：上六爻辞所说的“引诱他人取悦”，说明其心术不够光明正大。


**说明**

这是 欣悦的终结——静而不发，引则有失。

+ “引兑”：引诱他人相悦（引兑）。
+ 爻传“上六引兑，未光也”：上六引诱他人相悦，说明（其）欣悦之道未能光大。

**相关性**：上六阴柔处卦之极，是兑悦之道的 终点。爻辞仅有 “引兑” 二字，无吉凶 断语，但 意味深长。“引” 是 牵引、引诱。上六已无更高可悦 的对象，却仍试图主动去“牵引”他人来与自己 相悦。这与初九的 “和兑”（自然平和）、九二的 “孚兑”（诚信感召）形成 对比。这种 “悦” 带有一种勉强、刻意、甚至操控的 意味。爻传评价其 “未光也”：说明这种欣悦方式并不 光明正大，其境界也未能达到“兑道”的 光大 圆满。此爻暗示：最高的欣悦 境界，或许是如泽水般静默 自足，滋润万物而不刻意索取 回应；若强求 牵引，反而 落了下乘，有失兑悦的本真与 尊严。


## 总结

**总结**：兑卦的现代启示

兑卦的 “朋友讲习” 是关于 “喜悦、和谐、沟通”的交往艺术与道德准则。它深入剖析了 “悦” 的 不同层次、动机与后果，**旨在引导人们追求健康、正面、持久的人际关系与 内心快乐。

实践欣悦之道的六个层次与境界：

+ 悦不失正（初九）：和兑，吉。
+ 以诚为悦（九二）：孚兑，吉，悔亡。
+ 谄媚求悦（六三）：来兑，凶。
+ 抉择于悦（九四）：商兑，未宁，介疾有喜。
+ 亲比小人（九五）：孚于剥，有厉。
+ 静待不引（上六）：引兑。

**核心心法**：大象传总纲——“丽泽，兑；君子以朋友讲习。” 这意味着：

+ “丽泽，兑”：是 兑卦之象（两泽相连，互相滋悦）。
+ “君子以朋友讲习”：君子效法此象，与朋友互相讲论道理，研习学业。

这是兑卦精神的 最高升华。君子从两泽的 互相交流滋润 中，领悟到最美好、最有益的 “悦”，并非单纯的 嬉戏娱乐，而是与 志同道合的朋友（朋友） 在一起，互相讲解 道理，切磋 学问（讲习）。这种 “悦” 是理性的、成长的、精神层面的 深层愉悦，能使彼此的德业共同 进步。这指出了欣悦之道的 终极价值——用于提升自我与促进文明的 传承与发展。

**根本精神**：彖传 “兑，说也。刚中而柔外，说以利贞。是以顺乎天而应乎人。说以先民，民忘其劳；说以犯难，民忘其死。说之大，民劝矣哉！” 揭示了欣悦之道的巨大力量：

+ “兑，说也。刚中而柔外，说以利贞”：兑，就是欣悦。（九五、九二）阳刚居中而（六三、上六）阴柔处外，欣悦而利于守正。解释卦名与 卦德，强调 “悦” 需 “刚中”（内心刚正）为 骨，“柔外”（外表柔和）为 表，且以 “贞” 为 导向。
+ “是以顺乎天而应乎人”：因此（兑道）既顺乎天道又应合人心。将正当的欣悦提升到符合天理人情的 高度。
+ “说以先民，民忘其劳；说以犯难，民忘其死。说之大，民劝矣哉！”：（君王）以欣悦之道引导百姓，百姓就会忘记劳苦；以欣悦之道激励百姓奔赴危难，百姓就会忘记死亡。欣悦之道的伟大作用，在于能使百姓自我勉励啊！ 这是对 “悦” 的政治与社会功能的 极致推崇。阐明了 “悦” 作为一种领导艺术和凝聚力 的 巨大威力：真正的欣悦 （非小恩小惠），能激发民众内在的 积极性，克服 艰难险阻，创造 奇迹。

兑卦告诉我们：“悦” 是人世间最宝贵的情感与 动力 之一。健康 的 “悦”（和兑、孚兑） 是人际关系的 润滑剂，团队的 凝聚力，个人幸福的 源泉。而病态 的 “悦”（来兑、引兑） 则是人格的 腐蚀剂，社会的 虚伪面。其核心在于彖传 所言的 “刚中而柔外”——内心的正直与 原则（刚中），结合外在的温和与 友善（柔外）。在 “丽泽” 的 相互滋润 中，真正的 喜悦，来自于与同道中人的 “讲习” 与 共同成长，来自于以正道引导民众而获得的 “民劝”。这便是在 “兑为泽” 的 欢愉交流 中，所蕴含的关于 快乐、沟通、感召与团结 的 深刻智慧。
