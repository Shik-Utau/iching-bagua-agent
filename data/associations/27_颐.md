# 颐卦（艮上震下）

**卦画**：䷚

## 总论：颐养的哲学

**核心短词**：“慎言语，节饮食”

**卦象**：上艮（☶）为山、为止，下震（☳）为雷、为动。山雷颐。山下有雷，养物之象；外实内虚，自求口实。

**核心卦辞**：“颐，贞吉。观颐，自求口实。”

**总纲**：颐卦探讨 “养育、养生” 的根本法则。守正则吉，观察养育之道，在于自食其力。

+ “颐”：面颊、颐养、养育。
+ “贞吉”：守持正道则吉祥（养育之道必须正）。
+ “观颐”：观察（观）养育（颐）之道。
+ “自求口实”：自己谋求（自求）口中食物（口实）（喻自养、自立）。

**本质**：颐卦的核心是 “养正则吉” 与 “观其所养”。卦象上下两阳爻（实），中间四阴爻（虚），形如 张开的嘴巴，故取“颐”（面颊）为名。这形象地比喻了 养育的行为：既需要获取（下震动），也需要消化与止息（上艮止）。其主旨是：无论是养育自身、他人还是万物，都必须遵循正道（养正）。观察一个人或一个社会，就看它 养育什么、如何养育（观颐）。

## 卦辞



### 经

**原文**：贞吉。观颐，自求口实。

**白话**：守持正固可获吉祥。观察颐养之道，在于自求口中食物（自食其力）。

### 彖传

**原文**：颐，贞吉，养正则吉也。观颐，观其所养也。自求口实，观其自养也。天地养万物，圣人养贤以及万民，颐之时大矣哉！

**白话**：颐卦，坚守正道可获吉祥，养育遵循正道就会吉祥。观察养育之道，是看如何养育他人。自己谋求食物，是看如何自我养育。天地养育万物，圣人养育贤人并惠及万民，颐卦的时势意义真是伟大啊！

### 大象传

**原文**：山下有雷，颐；君子以慎言语，节饮食。

**白话**：山下响动着雷声，象征颐养；君子因此言语谨慎，节制饮食。


## 爻辞

### 初九：舍尔灵龟，观我朵颐，凶。


**原文**：舍尔灵龟，观我朵颐，凶。

**白话**：舍弃你灵龟般自养的美德，却来观看我（初九）鼓腮进食，凶险。

**小象传**
**原文**：“观我朵颐”，亦不足贵也。

**白话**：看我自己大嚼大吃，这也不值得看重。


**说明**

这是 颐养的歧途——慕外失内。

+ “舍尔灵龟”：舍弃（舍）你（尔）灵龟般的（灵龟）智慧（灵龟能咽气不食，喻内在自养之德）。
+ “观我朵颐”：盯着（观）我（我）鼓动腮帮进食（朵颐）的样子。
+ “凶”：凶险。
+ 爻传“亦不足贵也”：（这种行为）也不值得尊重。

**相关性**：初九阳刚处下，本应如“灵龟”般 静养内气，自足自得。但他却 舍弃了这种宝贵的自养能力（舍尔灵龟），去 羡慕、觊觎他人（六四）口中的食物（观我朵颐）。这象征 放弃内在的精神追求与自力更生，转而羡慕、依赖他人的物质供养。这种 丧失自立、心向外求 的养育态度，是根本性的错误，故凶险且 “不足贵”。此爻警示：颐养之道，首在自立、自养。


### 六二：颠颐，拂经；于丘颐，征凶。


**原文**：颠颐，拂经；于丘颐，征凶。

**白话**：颠倒颐养之道，违背常理；向高丘上的尊者（上九）求养，前往有凶险。

**小象传**
**原文**：六二征凶，行失类也。

**白话**：六二爻辞说征伐有凶险，是因为行动失去了同类。


**说明**

这是 颐养的错位——求养非人。

+ “颠颐”：颠倒（颠）了养育（颐）的关系（下求养于上）。
+ “拂经”：违背（拂）常理（经）。
+ “于丘颐”：向山丘（高处，喻上九）求取养育。
+ “征凶”：前往（征）则凶险。
+ 爻传“行失类也”：因为 行动失去了同类（正应）。

**相关性**：六二柔顺中正，本应与六五相应（同类相养）。但她却 向下求养于初九（颠颐），或 向上远求于上九（于丘颐），这都 违背了“自求口实”和“同类相养”的正道（拂经）。爻传“行失类也”点明：她 行动（行）时，没有寻求与自己匹配、相应的对象（失类）。这种 错位的依赖与索取，必然导致失败与凶险。此爻强调：养育关系必须建立在正当、相应的基础之上。


### 六三：拂颐，贞凶，十年勿用，无攸利。


**原文**：拂颐，贞凶，十年勿用，无攸利。

**白话**：违背颐养之道，守持正固也有凶险，十年之久不可施展才用，无所利益。

**小象传**
**原文**：“十年勿用”，道大悖也。

**白话**：十年都不能有所作为，是因为与正道严重背离。


**说明**

这是 颐养的邪僻——违道招凶。

+ “拂颐”：违背（拂）养育（颐）的正道。
+ “贞凶”：即使意图守正（贞）也是凶险（因为方法根本错误）。
+ “十年勿用”：十年（喻长期）不可有所作为。
+ “无攸利”：没有任何利益。
+ 爻传“道大悖也”：因为 大大违背（悖）了正道。

**相关性**：六三阴柔不中不正，且处震动之极，象征 为求养育而不择手段，走上了邪路。“拂颐”是其根本错误。爻辞用词极重：“贞凶”意味着 即便动机不坏，但方法错了，结果也凶；“十年勿用”形容 长期无法走上正轨。这是因为其行为 与“养正”之道完全背道而驰（道大悖）。此爻是对 一切歪门邪道、不当得利、畸形养育关系 的彻底否定。


### 六四：颠颐，吉。虎视眈眈，其欲逐逐，无咎。


**原文**：颠颐，吉。虎视眈眈，其欲逐逐，无咎。

**白话**：颠倒颐养之道（向下求养），吉祥。像老虎一样眈眈注视，欲望迫切，没有咎害。

**小象传**
**原文**：“颠颐之吉”，上施光也。

**白话**：颠倒养育方式而获得吉祥，是因为居上位者能够向下广施光明恩德。


**说明**

这是 颐养的权宜——柔顺求贤。

+ “颠颐”：颠倒养育关系（下求于初九）。
+ “吉”：吉祥。
+ “虎视眈眈，其欲逐逐”：像老虎（虎）那样专注凝视（眈眈），其欲求迫切（逐逐）。
+ “无咎”：没有过错。
+ 爻传“上施光也”：因为 在上位者（六四）向下施予了光明（或：其求养是为了施惠于下）。

**相关性**：六四与六二爻辞都有“颠颐”，但结果迥异。六四柔顺得正，且与初九阴阳正应。她的“颠颐”是 作为在上位者（大臣），为了养育百姓（或完成职责），而迫切（虎视眈眈）地向下求取贤才（初九）的辅助。这种“下求”是 出于公心，为了更大的养育目标（上施光），而非一己私利。因此，这种 打破常规的求养方式，在特定情境下是正当且吉祥的。此爻说明了 原则性与灵活性的统一。


### 六五：拂经，居贞吉，不可涉大川。


**原文**：拂经，居贞吉，不可涉大川。

**白话**：违背常理（向下求养），安居守正可获吉祥，不可涉越大河巨流。

**小象传**
**原文**：“居贞之吉”，顺以从上也。

**白话**：安于正道而获得吉祥，是因为能够柔顺地遵从上位者。


**说明**

这是 颐养的依赖——顺承得养。

+ “拂经”：违背（拂）常理（经）（指阴柔的六五不能自养，需依赖上九）。
+ “居贞吉”：安居（居）守正（贞）则吉祥。
+ “不可涉大川”：不可涉越大河险阻（喻不可冒险行动）。
+ 爻传“顺以从上也”：因为 柔顺（顺）以遵从（从）上位者（上九）。

**相关性**：六五柔中居尊，是 被养育的君主（如幼主或才德不足的君主）。她自身缺乏养育天下的能力（拂经），其吉祥之道在于 安居其位，恪守柔顺中正之德（居贞），完全信任并依赖贤能的上九来养育天下（顺以从上）。她不可强为、不可冒险（不可涉大川）。此爻描述了 一种特殊的养育关系：位尊者依赖德能者来实行养育。关键在于 居位者要“贞”（心正）且“顺”（不刚愎自用）。


### 上九：由颐，厉吉，利涉大川。


**原文**：由颐，厉吉，利涉大川。

**白话**：天下由之获得颐养，虽有危险终获吉祥，利于涉越大河巨流。

**小象传**
**原文**：“由颐厉吉”，大有庆也。

**白话**：遵循颐养之道而能戒慎惕厉，终获吉祥，这是大有福庆的事。


**说明**

这是 颐养的担当——养贤任重。

+ “由颐”：天下由此（由）而获得养育（颐）。
+ “厉吉”：虽有危险（厉）但终获吉祥。
+ “利涉大川”：利于涉越大河险阻。
+ 爻传“大有庆也”：大有福庆。

**相关性**：上九阳刚处卦之极，是 全卦唯一的阳爻（实），且为艮山之巅，象征 德高望重、肩负养育天下重任的贤臣或师长（如周公、伊尹）。他 不居君位（六五）而实际承担养育之责（由颐），这种 “功高震主”或“任重道远”的位置是危险的（厉）。但只要他 动机纯正，行为光明，最终必能 克服艰险（利涉大川），成就养育天下的大业，获得万民庆贺（大有庆）。此爻是 对“养贤以及万民”这一最高养育理想的礼赞。


## 总结

**总结**：颐卦的现代启示

颐卦的 “慎言语，节饮食” 是关于 生存、发展、教育与管理 的根本法则。

颐养的层次：

+ 自立（初九）：自养为本，忌慕外失内。
+ 正求（六二）：求养需正，忌错位失类。
+ 正道（六三）：养必以正，邪道万不可行。
+ 权变（六四）：为公求贤，可权宜下求。
+ 承顺（六五）：依赖贤能，需安居守正。
+ 担当（上九）：养贤及民，虽危终吉。

核心心法：大象传总纲——“山下有雷，颐；君子以慎言语，节饮食。” 这意味着：

+ “山下有雷”：是 颐养之象。
+ “君子以慎言语，节饮食”：君子效法此象，谨慎言语，节制饮食。

这是 最具体、最根本的颐养之道：

+ “慎言语”：言语一出，不可收回。修养口德，不妄言、不恶语、不泄密，是 精神与社交层面的颐养。
+ “节饮食”：饮食入腹，不可复出。节制欲望，合理膳食，是 身体与物质层面的颐养。

这两者，一个关乎 “出”（言语），一个关乎 “入”（饮食），涵盖了 个人养生与修德最基本、最日常的功课。由己及人，由身及国，“养正”之道，皆由此起。

根本精神：彖传 “天地养万物，圣人养贤以及万民” 将颐养之道提升到宇宙与政治的高度。天地养育万物，是自然法则；圣人（君主）养育贤才，并通过贤才养育万民，是社会法则。卦辞 “观颐，自求口实” 则强调：观察一个人、一个组织、一个国家的兴衰，就看它如何解决“养育”问题，以及是否秉持“自食其力”的精神。

颐卦与大畜卦的承续：大畜卦（䷙）讲 “大为蓄积”（日新其德），是 对力量、德行、人才的蓄养和储备；颐卦（䷚）则讲 “养育施用”（慎言语节饮食），是 将蓄积的力量用于实际的养育行为——养育自身、他人与社会。《序卦传》言：“物畜然后可养，故受之以颐；颐者，养也。” 意思是：事物蓄积之后才可以养育，所以继之以颐卦；颐，就是养育。“大畜”是“颐”的前提和资本，“颐”是“大畜”的目的和施用。从大畜到颐，构成了 “厚积”而后“薄发” 的完整过程，也是 个人成长与事业发展的必然逻辑。
