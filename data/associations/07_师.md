# 师卦（坤上坎下）

**卦画**：䷆

## 总论：用众的哲学

**核心短词**：“行师之律”

**卦象**：上坤（☷）为地、为顺，下坎（☵）为水、为险。地中有水，水藏于地中，寓兵于民之象。又象征 在柔顺的外表下，隐藏着险阻与力量。

**核心卦辞**：“师，贞，丈人吉，无咎。”

**总纲**：师卦探讨 如何统领众人、动用力量（尤其是武力） 的根本原则。

+ “师”：兵众，引申为一切有组织的集体力量。
+ “贞”：正。用兵之道，首在 目的正义（“能以众正”）。
+ “丈人吉”：由 德高望重、老成持重的统帅（丈人） 来领导，方可吉祥。
+ “无咎”：如此才能避免灾祸。

**本质**：师卦的核心是 “纪律”与“责任”。它强调动用集体力量是 极度危险之事，必须出于正道，并由绝对可靠的统帅，以严明纪律统领，方能化险为顺（“行险而顺”），否则必致凶咎。

## 卦辞



### 经

**原文**：贞，丈人吉，无咎。

**白话**：守持正固，任用老成持重的长者统兵可获吉祥，没有咎害。

### 彖传

**原文**：师，众也。贞，正也。能以众正，可以王矣。刚中而应，行险而顺，以此毒天下，而民从之，吉又何咎矣。

**白话**：师，就是众人。贞，就是正道。能够带领众人走正道，就可以称王天下。刚健居中而上下相应，虽然行动有险阻但能顺利，用这样的方式治理天下，民众都会追随，这是吉祥的，又怎么会有灾祸呢。

### 大象传

**原文**：地中有水，师；君子以容民畜众。

**白话**：大地之中蕴藏着水源，象征兵众；君子因此领悟要包容百姓、蓄养民众。


## 爻辞

### 初六：师出以律，否臧凶。


**原文**：师出以律，否臧凶。

**白话**：军队出征必须严明纪律，军纪不良必有凶险。

**小象传**
**原文**：“师出以律”，失律凶也。

**白话**：军队出征要严明纪律，纪律败坏就会招致凶险。


**说明**

这是 行师的第一铁律——纪律为先。

+ “师出以律”：军队一出动，就必须 有严明的纪律。
+ “否臧凶”：否，不；臧，善。意思是：无论纪律严明（臧）与否（否），只要出师，就隐含凶险。 但若 无律，则凶险必至。
**相关性**：开宗明义，点出用兵的本质：本身就是凶事。而 严明纪律 是控制凶险、避免惨败的 最低底线和首要条件。没有纪律的乌合之众，必败无疑。


### 九二：在师中，吉，无咎。王三锡命。


**原文**：在师中，吉，无咎。王三锡命。

**白话**：在军中统率，吉祥，没有咎害。君王多次颁赐嘉奖命令。

**小象传**
**原文**：“在师中吉”，承天宠也。“王三锡命”，怀万邦也。

**白话**：在军队中担任统帅吉祥，是因为承受了上天的恩宠。君王多次赐予荣誉和命令，是因为心中怀有安抚天下万国的志向。


**说明**

这是 行师的核心关键——统帅中正。

九二阳刚居中，为全卦唯一阳爻，是 统率五阴的“丈人”。
+ “在师中，吉”：统帅 坐镇军中，指挥若定，则吉祥。
+ “王三锡命”：君王多次 赐予嘉奖命令，赋予全权，表示绝对信任。
**相关性**：阐述了成功行师的 核心要素：必须有一个 刚健、中正、得众心（统五阴）且获君权完全信任（王三锡命）的统帅。这是 “丈人吉” 的具体体现，也是化险为顺的保证。


### 六三：师或舆尸，凶。


**原文**：师或舆尸，凶。

**白话**：军队或许载尸而归，凶险。

**小象传**
**原文**：“师或舆尸”，大无功也。

**白话**：军队或许用车运载尸体，说明太没有功绩了。


**说明**

这是 行师的典型败象——任用不当。

+ “师或舆尸”：军队 或许（或） 载着阵亡者的尸体（舆尸）回来。
+ “凶”：大凶。
+ 爻传“大无功也”：大败而无功。
**相关性**：六三阴柔失位，象征 才德不配、能力不足的指挥者。此爻警示：如果让错误的人（非“丈人”）担任统帅或重要职位，必然导致惨败，伤亡惨重（舆尸）。 这是对领导责任的严厉警告。


### 六四：师左次，无咎。


**原文**：师左次，无咎。

**白话**：军队退守驻扎，没有咎害。

**小象传**
**原文**：“左次无咎”，未失常也。

**白话**：军队向左撤退没有灾祸，这说明用兵没有违背常理。


**说明**

这是 行师的灵活策略——知难而退。

+ “师左次”：军队 向左后方（“左”为退，“次”为驻扎） 撤退布防。
+ “无咎”：没有过错。
+ 爻传“未失常也”：这并未违背用兵的 常道。
**相关性**：阐明了“行师”并非一味进攻。根据形势，主动退守、保存实力，是符合军事规律的明智之举。这体现了统帅（丈人）的 审慎与灵活，而非懦弱。


### 六五：田有禽，利执言，无咎。长子帅师，弟子舆尸，贞凶。


**原文**：田有禽，利执言，无咎。长子帅师，弟子舆尸，贞凶。

**白话**：田猎获得禽兽，利于发表意见，没有咎害。委任长子统帅军队，任用弟子载运尸体，守持正固以防凶险。

**小象传**
**原文**：“长子帅师”，以中行也。“弟子舆尸”，使不当也。

**白话**：长子统率军队，是因为他行事中正。弟子们用车载着尸体，是用人不当的结果。


**说明**

这是 行师的最高决策——君主任帅。

+ “田有禽，利执言”：田中有害兽（禽），比喻 有正当理由（执言） 出兵讨伐（呼应卦辞“贞”）。
+ “长子帅师，弟子舆尸”：但必须任命 德才兼备的“长子”（即九二“丈人”） 统帅。若让 无能的“弟子” 统帅，就会“舆尸”惨败。
+ “贞凶”：即使出师有名（贞），用人不当也 必凶。
**相关性**：此爻居于君位，点明 最高领导者的责任：一要确保 出师正义（田有禽）；二要 知人善任，将权柄绝对交付给可靠的“丈人”。决策的正义性（贞）与执行的可靠性（丈人）缺一不可，否则“贞凶”。


### 上六：大君有命，开国承家，小人勿用。


**原文**：大君有命，开国承家，小人勿用。

**白话**：天子颁赐命令，封赏功臣，开创诸侯国，继承大夫家，小人不可重用。

**小象传**
**原文**：“大君有命”，以正功也。“小人勿用”，必乱邦也。

**白话**：天子颁布命令，是为了公正地评定功绩。不能任用小人，否则必定会使国家陷入混乱。


**说明**

这是 行师的战后法则——赏罚明慎。

+ “大君有命”：战争结束，君王 颁布封赏命令。
+ “开国承家”：分封诸侯（开国），赏赐卿大夫（承家），论功行赏。
+ “小人勿用”：但 切不可重用小人（指无德者，如六三之流）。
**相关性**：阐述了行师全过程的 最后关键一环：战后权力与利益的分配。若赏罚不公，或让投机取巧的小人上位，将埋下新的祸乱种子。这体现了 “丈人”原则的延续——不仅在战时，更在治时。


## 总结

**总结**：师卦的现代启示
师卦的 “行师之律” 是一套关于 组织领导、危机管理、资源动用 的深刻法则，远超军事范畴。

根本前提（贞）：任何集体行动，必须有 正当、崇高的目标（“能以众正”）。为私利而动用集体力量，必遭反噬。

核心保障（丈人）：必须由 德才兼备、众望所归的领导者 核心。用人不当是最大风险（六三、六五）。

运行基础（律）：必须有 严明、统一的制度和纪律（初六），这是组织战斗力的来源。

策略智慧（左次）：要懂得 审时度势，能进能退，灵活应变，不盲目硬拼。

终极责任（大君）：最高决策者肩负 双重责任：把握方向正义，并完成 最关键的人事任命。

善后原则（勿用小人）：成功后的 利益分配与权力结构重组，必须公正、明智，防止小人窃取果实，导致前功尽弃。

师卦与讼卦的承续：讼卦讲 “言语之争”（止讼），师卦则讲 “行动之争”（行师）。从讼的 内部口舌冲突，升级到师的 外部集体对抗，体现了矛盾激化、冲突升级的形态。同时，两卦都强调 “中吉终凶”（讼）与 “贞凶”（师）——即若处理不当，无论争讼还是战争，即便起初有理，最终也将导向凶险。这体现了《周易》对 冲突与对抗 一以贯之的审慎与警惕。
