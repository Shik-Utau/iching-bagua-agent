# 益卦（巽上震下）

**卦画**：䷩

## 总论：增益之道的哲学

**核心短词**：“见善则迁，有过则改”

**卦象**：上巽（☴）为风、为入，下震（☳）为雷、为动。风雷益。风雷激荡，损上益下。

**核心卦辞**：“利有攸往，利涉大川。”

**总纲**：益卦象征 “增益、受益”，利于有所前往，利于涉越大河巨流。

+ “利有攸往”：利于（利）有所前往（有攸往）。在受益的时势下，应积极行动，开拓进取。
+ “利涉大川”：利于（利）涉越（涉）大河巨流（大川）。象征 能够克服巨大艰难险阻。因为 上巽为木（木道乃行），下震为动，木舟行于水上，动而顺，故能“涉大川”。

**本质**：益卦是损卦的覆卦，描述 “损上益下” 的治理模型。上巽风顺，下震动进，风雷相激，声势壮大。其**核心精神**是：统治者（或上位者） 减损自身以增益百姓（损上益下），从而 赢得民心，激发活力（民说无疆），最终 上下皆益，道义光大（其道大光）。这是一种 通过让利、赋能来实现整体繁荣与稳固 的智慧。

## 卦辞



### 经

**原文**：利有攸往，利涉大川。

**白话**：利于有所前往，利于涉越大河巨流。

### 彖传

**原文**：益，损上益下，民说无疆。自上下下，其道大光。利有攸往，中正有庆。利涉大川，木道乃行。益动而巽，日进无疆。天施地生，其益无方。凡益之道，与时偕行。

**白话**：益卦，减损上方而增益下方，民众的喜悦无边无际。从上施惠于下，其道义大为光明。利于有所前往，因为持守中正必有吉庆。利于涉越大河，是因为木舟渡水的道理可以通行。增益之时行动谦逊，每日进步没有边界。上天施予、大地化生，增益的作用遍及万方。所有关于增益的法则，都要顺应时机而推行。

### 大象传

**原文**：风雷，益；君子以见善则迁，有过则改。

**白话**：风与雷组合，是益卦的象征；君子因此看见善行就追随，有了过错就改正。


## 爻辞

### 初九：利用为大作，元吉，无咎。


**原文**：利用为大作，元吉，无咎。

**白话**：利于大有作为，至为吉祥，没有咎害。

**小象传**
**原文**：元吉无咎，下不厚事也。

**白话**：大吉大利没有过错，是因为下属没有承担繁重的任务。


**说明**

这是 益道的开端——得时奋起。

+ “利用为大作”：利于（利用）用来进行（为）大作为（大作）。
+ “元吉，无咎”：至为吉祥（元吉），没有咎害（无咎）。
+ 爻传“下不厚事也”：（因为）在下位者本不适宜承担厚重事务。

**相关性**：初九阳刚处下，是 益卦“损上益下”的首要受益者，得到来自上卦（六四）的强力增益。爻辞充满力量：**得到增益后，不应保守，而应 抓住时机，进行大规模的建设与开创（大作）。因为 其基础（下位）原本薄弱（下不厚事），此刻的增益如同雪中送炭，能爆发出巨大能量，故 至为吉祥，且无过咎。此爻描绘了 **受益者最理想的反应：将所得资源与机遇，迅速转化为积极有为的行动。


### 六二：或益之十朋之龟，弗克违，永贞吉。王用享于帝，吉。


**原文**：或益之十朋之龟，弗克违，永贞吉。王用享于帝，吉。

**白话**：有人进献价值十朋的宝龟，无法推辞，永久守持正固可获吉祥。君王用以祭祀天帝，吉祥。

**小象传**
**原文**：“或益之”，自外来也。

**白话**：有人来增益，这是从外部主动送来的。


**说明**

这是 益道的核心——柔中承天。

+ “或益之十朋之龟，弗克违”：有人（或）进献（益之）价值十朋（十朋）的宝龟（之龟），无法（弗克）推辞（违）。
+ “永贞吉”：永久（永）守持正固（贞）可获吉祥（吉）。
+ “王用享于帝，吉”：君王（王）用以（用）祭祀（享）天帝（于帝），吉祥（吉）。
+ 爻传“或益之，自外来也”：有人进献宝物，是从外部自来。

**相关性**：六二柔顺中正，是 下卦的受益核心。爻辞与损卦六五相似，都出现了 “十朋之龟” 这样 来自外部的、丰厚的、非求而得的增益（自外来）。但语境不同：损卦六五是 尊者因行损道而受祐；益卦六二是 在下者因柔中守正而获天赐。“王用享于帝”是关键：六二（或代表六二的君王） 并未将厚益据为己用，而是 用以祭祀上天（享于帝），象征 将所受之益，用于至公至正的事业，回报天地。因其 动机至公，行为永贞，故获吉祥。此爻强调：**受益者应 心怀敬畏，将所得用于正道，方能持盈保泰，永受其益。


### 六三：益之用凶事，无咎。有孚中行，告公用圭。


**原文**：益之用凶事，无咎。有孚中行，告公用圭。

**白话**：将增益用于救助凶险之事，没有咎害。心怀诚信，持中而行，手持玉圭禀告王公。

**小象传**
**原文**：益用凶事，固有之也。

**白话**：增益用于凶险之事，这是本来就有的道理。


**说明**

这是 益道的应用——救急扶危。

+ “益之用凶事，无咎”：受益（益之）之时却用于（用）凶险之事（凶事，如灾荒战乱），没有咎害（无咎）。
+ “有孚中行”：心怀诚信（有孚），持中而行（中行）。
+ “告公用圭”：手持玉圭（用圭）禀告（告）王公（公）。
+ 爻传“益用凶事，固有之也”：受益用于凶险之事，是本来就有的（职责或情况）。

**相关性**：六三阴柔不中，处下卦之极，多凶之位，象征 可能面临危机或身处险境。“凶事”指 天灾人祸等紧急状况。爻辞指出：**在受益的时势下，将所得资源用于解救凶险、扶助危难，是 正当且必须的（固有之也），故无咎害。但过程必须 严谨：一要心怀诚信（有孚），二要方法得当（中行），三要遵循程序，向上级（公）正式报告（告公用圭），以示郑重与合规。此爻展现了 **益道的另一面：**增益不仅用于发展，更应用于 化解危机、保障民生，且必须 规范、透明、诚信。


### 六四：中行，告公从。利用为依迁国。


**原文**：中行，告公从。利用为依迁国。

**白话**：持中而行，禀告王公并获得同意。利于依附君主进行迁都（或重大变革）。

**小象传**
**原文**：“告公从”，以益志也。

**白话**：告诉王公要听从，这是为了增强他的意志。


**说明**

这是 益道的施行——徙民利众。

+ “中行，告公从”：持中而行（中行），禀告（告）王公（公）并获得同意（从）。
+ “利用为依迁国”：利于（利用）用以（为）作为依凭（依）迁都（迁国）。
+ 爻传“告公从，以益志也”：禀告王公并获得同意，是为了实现增益天下的心志。

**相关性**：六四阴柔得正，是 上卦巽顺之主，也是“损上益下”政策的直接执行者。“迁国”是 古代最大的惠民工程之一，意味着 将统治中心迁往更富庶、更安全之地，以更好地养育百姓。爻辞描述：执行者（六四） 秉持 中正之道（中行） 制定方案，向上级（公，指九五）正式汇报并获得批准（告公从），然后 利用（利用）这一政策（益下）作为根本依凭（为依），实施迁都大业。爻传“以益志也”点明：**这一切程序的根本目的，是为了 实现“损上益下、造福万民”的宏大志向。此爻强调：**重大的惠民政策，必须 决策科学（中行）、程序合法（告公从）、目标远大（益志）。


### 九五：有孚惠心，勿问元吉。有孚惠我德。


**原文**：有孚惠心，勿问元吉。有孚惠我德。

**白话**：怀有诚信施惠于民之心，不必占问就知道至为吉祥。民众也必将以诚信回报我的恩德。

**小象传**
**原文**：“有孚惠心”，勿问之矣。“惠我德”，大得志也。

**白话**：心怀诚信施惠于人，不必多问是否吉祥。别人以德回报我的恩惠，这样就能充分实现心志。


**说明**

这是 益道的境界——诚信感通。

+ “有孚惠心，勿问元吉”：心怀诚信（有孚）施惠（惠）于民之心（心），不必占问（勿问）就知至为吉祥（元吉）。
+ “有孚惠我德”：民众也必将心怀诚信（有孚）回报（惠）我的恩德（我德）。
+ 爻传“有孚惠心，勿问之矣；惠我德，大得志也”：心怀诚信施惠于民，不必再问了；民众回报我的恩德，是（君王）心志大大得偿。

**相关性**：九五阳刚中正，居尊位，是 益卦的君主，也是“损上益下”的决策者与象征。爻辞超越了具体的政策，直达 治理的核心——心与心的感通。“惠心”指 发自内心的、真诚的惠民之念，而非功利计算。君主以 至诚之心（有孚） 惠及百姓，这种 “德政” 本身就会带来 至大的吉祥（元吉），无需怀疑。更重要的是，民心如镜，百姓感受到君主的诚心德政后，也必会 以诚信和拥戴来回报（惠我德），形成 良性的政治循环。爻传“大得志也”指出：**这才是统治者 心志最大的实现与满足。此爻是 **益卦精神的最高体现：**增益的最高形式，是 诚信与美德的相互增益。


### 上九：莫益之，或击之，立心勿恒，凶。


**原文**：莫益之，或击之，立心勿恒，凶。

**白话**：没有人来增益他，反而有人攻击他，立心不恒常，有凶险。

**小象传**
**原文**：“莫益之”，偏辞也。“或击之”，自外来也。

**白话**：没有人来帮助他，是因为大家普遍都言辞冷漠。有人来攻击他，是因为祸患从外部降临。


**说明**

这是 益道的反面——求益无厌。

+ “莫益之”：没有人（莫）来增益（益）他（之）。
+ “或击之”：反而有人（或）攻击（击）他（之）。
+ “立心勿恒，凶”：立心（立心）不恒常（勿恒），有凶险（凶）。
+ 爻传“莫益之，偏辞也；或击之，自外来也”：没有人增益他，是片面之辞（指其只求益）；有人攻击他，是从外部自来。

**相关性**：上九阳刚处卦之极，是 益道的终点，也是走向反面的转折点。它已居于极高受益之位，却仍 贪求不止，期望继续被增益（立心勿恒）。这种 不知足、不感恩、只求获取的心态，导致 无人再愿助益他（莫益之），反而因其贪鄙招致众人的反感与攻击（或击之）。爻传“偏辞也”一针见血：其问题在于 心态偏颇，只想着“益己”，忘记了“益人”与“损上”的初心。此爻作为全卦结尾，是 严厉的警告：益道虽好，但若 心术不正，贪得无厌，必将从“受益”的顶峰跌入“被击”的凶险深渊。“恒”——持守中正惠民之心，是益道得以持续的根本。


## 总结

**总结**：益卦的现代启示

益卦的 “见善则迁，有过则改” 是关于 “增加”与“获得”的深刻哲学，它教导我们 如何正确地创造、分配与运用“增益”。

践行益道的六重境界：

+ 得时奋起（初九）：利用大作，元吉无咎。
+ 虚中承天（六二）：十朋之龟，永贞享帝。
+ 救难有章（六三）：益用凶事，孚告用圭。
+ 徙民利众（六四）：中行告公，为依迁国。
+ 诚信感通（九五）：有孚惠心，勿问元吉。
+ 贪求致凶（上九）：莫益或击，立心勿恒。

核心心法：大象传总纲——“风雷，益；君子以见善则迁，有过则改。” 这意味着：

+ “风雷，益”：是 益卦之象（风雷相助，声势益增）。
+ “君子以见善则迁，有过则改”：君子效法此象，看见善行就向往追随，发现自己有过错就立即改正。

这是 益卦精神的灵魂：将“益”的智慧首先应用于 自身的道德成长。“见善则迁”** 是 主动增益自己的德行；“有过则改” 是 主动减损自己的过错（结合了损卦的“惩忿窒欲”）。这是 最主动、最积极的“益”。通过 不断学习善行、修正错误，人才能 日进无疆，实现真正的自我增益。这是 “益”道向内求的至高应用。

根本精神：彖传 “益，损上益下，民说无疆。自上下下，其道大光……天施地生，其益无方。凡益之道，与时偕行。” 阐明了益道的伟大：

+ “损上益下，民说无疆”：减损上方以增益下方，百姓的欢悦没有边际。这是 益卦的政治理想。
+ “天施地生，其益无方”：上天施予（阳光雨露），大地化生（万物），其增益作用遍及万方。这是 益卦的宇宙法则。
+ “凡益之道，与时偕行”：这是 益卦的总法则。**一切增益之道，都要 顺应时势的变化而进行（与时偕行）。

益卦告诉我们： “益”不仅是 资源的增加，更是 活力的激发、民心的凝聚、道德的提升。它要求上位者有 让利的胸怀（损上），受益者有 奋进的作为（大作）；既可用于 日常发展（利有攸往），也应用于 救急救难（用凶事）；其核心在于 至诚之心（有孚），其成败在于 是否顺应时势（与时偕行）。无论是个人 提升自我（见善迁过）、企业 让利员工与客户，还是国家 推行惠民政策，都需要 深刻领悟“益”的智慧——知道如何创造增益、如何分配增益、以及如何让增益可持续且充满正能量。这便是在 “风雷激荡” 的蓬勃景象中，所蕴含的 关于成长、繁荣与和谐的永恒法则。
