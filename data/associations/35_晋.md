# 晋卦（离上坤下）

**卦画**：䷢

## 总论：晋升的哲学

**核心短词**：“自昭明德”

**卦象**：上离（☲）为火、为日、为明，下坤（☷）为地、为顺。火地晋。日出地上，明出地上，光明普照，晋升之象。

**核心卦辞**：“康侯用锡马蕃庶，昼日三接。”

**总纲**：晋卦象征 “前进、晋升”。卦辞以“康侯”（安邦的诸侯）受赏为例：康侯得到天子赏赐众多车马，并在一天之内受到三次接见。

+ “康侯”：安邦定国的诸侯，象征 有德有能的臣子。
+ “用锡马蕃庶”：得到（用）赏赐（锡）众多（蕃庶）车马（马），代表 获得丰厚的物质奖赏与信任。
+ “昼日三接”：一天之内（昼日）受到三次接见（三接），代表 获得极高的荣誉与亲近。

**本质**：晋卦描述 “晋升”之道。上离为日，为明君；下坤为地，为顺臣。太阳从大地升起（明出地上），象征 臣子以柔顺、明德之道上进，获得君王的赏识与提拔。其

**核心精神**是：晋升的关键在于 内在德行的彰显（自昭明德）与外在行为的柔顺（顺而丽乎大明），而非投机钻营。

## 卦辞



### 经

**原文**：康侯用锡马蕃庶，昼日三接。

**白话**：尊贵的公侯蒙受天子赏赐众多车马，一天之内荣获三次接见。

### 彖传

**原文**：晋，进也。明出地上，顺而丽乎大明，柔进而上行。是以康侯用锡马蕃庶，昼日三接也。

**白话**：晋卦，象征着前进。光明从地面升起，柔顺地依附于太阳的光辉，以柔和的姿态不断向上行进。因此，就像尊贵的诸侯得到赏赐众多马匹，一天之内多次受到君王的接见一样。

### 大象传

**原文**：明出地上，晋；君子以自昭明德。

**白话**：光明出现在大地之上，象征进长；君子因此自我彰显光辉的美德。


## 爻辞

### 初六：晋如，摧如，贞吉。罔孚，裕无咎。


**原文**：晋如，摧如，贞吉。罔孚，裕无咎。

**白话**：前进之初就受挫，守持正固可获吉祥。虽未受信任，宽裕待时则无咎害。

**小象传**
**原文**：“晋如摧如”，独行正也。“裕无咎”，未受命也。

**白话**：前进时遭遇挫折，是因为独自坚守正道。从容不迫没有灾祸，是因为尚未接受任命。


**说明**

这是 晋升的初阶——以退为进。

+ “晋如，摧如”：前进（晋如），受挫（摧如）。
+ “贞吉”：守持正固（贞）则吉祥（吉）。
+ “罔孚”：暂未获得信任（罔孚）。
+ “裕无咎”：宽裕（裕）待时则无咎害（无咎）。
+ 爻传“独行正也”：因为 独自（独）践行正道（行正）。

**相关性**：初六阴柔处下，是 晋升之路的起点。地位卑微，才德未显，故前进时容易遇到阻力与挫折（摧如）。此时 尚未获得上级的信任（罔孚）。爻辞给出的策略是：**坚守正道，不改初衷（贞吉）；同时 心态宽裕，不急于求成，耐心等待时机（裕无咎）。爻传“独行正也”赞美其 在孤独与挫折中仍能持守正道 的品格。此爻强调：**晋升之初，挫折是常态，诚信需要时间建立。关键在于 修德以待，而非怨天尤人。


### 六二：晋如，愁如，贞吉。受兹介福，于其王母。


**原文**：晋如，愁如，贞吉。受兹介福，于其王母。

**白话**：前进之时充满忧愁，守持正固可获吉祥。将承受宏大的福泽，来自尊贵的王母。

**小象传**
**原文**：“受兹介福”，以中正也。

**白话**：承受这样的大福，是因为他持守中正之道。


**说明**

这是 晋升的忧虑——柔中获福。

+ “晋如，愁如”：前进（晋如），充满忧愁（愁如）。
+ “贞吉”：守持正固（贞）则吉祥（吉）。
+ “受兹介福，于其王母”：将承受（受）此（兹）大福（介福），来自（于）其（其）王母（王母）。
+ 爻传“受兹介福，以中正也”：承受此大福，是因为（其）居中守正（以中正）。

**相关性**：六二柔顺中正，与六五不应，但上承九四（互卦艮）。象征 在晋升过程中，虽因前景不明或无人直接提携而心怀忧愁（愁如），但其 中正柔顺的品德（贞） 终将被人发现。“王母”（六五阴爻）象征 柔中、慈祥、有影响力的上位者（或指间接的贵人）。爻辞预示：因其 中正的德行，将获得来自高层（王母）的赏识与福佑（介福）。此爻说明：**晋升不必强求直达，保持中正，自会有间接的机遇与贵人相助。


### 六三：众允，悔亡。


**原文**：众允，悔亡。

**白话**：获得众人的信任，悔恨消亡。

**小象传**
**原文**：众允之，志上行也。

**白话**：大家一致赞同，是因为志向向上进取。


**说明**

这是 晋升的合力——民心所向。

+ “众允”：获得众人（众）的信允（允）。
+ “悔亡”：悔恨消亡（悔亡）。
+ 爻传“志上行也”：因为 心志（志）向上行进（上行）。

**相关性**：六三阴居阳位，不中不正，本应有“悔”。但其处于下卦坤（众）之顶，且与上九相应。象征 其晋升的志向与行动，获得了基层群众（众）的普遍认可与支持（允）。有了 广泛的群众基础，之前的不足与悔恨自然消亡（悔亡）。爻传“志上行也”指出：其心志向上，且行为得众，故能顺利晋升。此爻强调：**真正的晋升，不能只走上层路线，更要 赢得人心，获得同僚与下属的支持。众允是晋升最稳固的基石。


### 九四：晋如鼫鼠，贞厉。


**原文**：晋如鼫鼠，贞厉。

**白话**：像鼫鼠一样贪进，守持正固以防危险。

**小象传**
**原文**：“鼫鼠贞厉”，位不当也。

**白话**：像鼫鼠那样贪多却能力不足，即使坚守正道也会有危险，这是因为所处的位置不恰当。


**说明**

这是 晋升的警告——贪而失正。

+ “晋如鼫鼠”：像鼫鼠（鼫鼠）一样贪求晋升（晋如）。
+ “贞厉”：守持正固（贞）以防危险（厉）。
+ 爻传“位不当也”：因为 （其）位置（位）不适当（不当）。

**相关性**：九四阳居阴位，已进入上卦离（明）体，逼近君位（六五）。“鼫鼠”（又称“五技鼠”）比喻 身无专长、贪得无厌、畏首畏尾的小人。此爻象征 **在接近权力核心时，有人 无其德而居其位，贪求禄位，患得患失。这种行为非常危险（厉）。爻辞告诫：必须 竭力回归正道（贞），才能避免灾祸。爻传“位不当也”点明其根源：才德与位置不匹配。此爻是 对投机钻营者的严厉批判，提醒：晋升若不以德行为本，高位反成险地。


### 六五：悔亡，失得勿恤，往吉，无不利。


**原文**：悔亡，失得勿恤，往吉，无不利。

**白话**：悔恨消亡，得失不必忧虑，前往吉祥，无所不利。

**小象传**
**原文**：“失得勿恤”，往有庆也。

**白话**：不要为得失而忧虑，勇往直前会有吉庆。


**说明**

这是 晋升的君位——光明磊落。

+ “悔亡”：悔恨消亡（悔亡）。
+ “失得勿恤”：不必忧虑（勿恤）得失（失得）。
+ “往吉，无不利”：前往（往）吉祥（吉），无所不利（无不利）。
+ 爻传“往有庆也”：因为 前往（往）必有福庆（有庆）。

**相关性**：六五阴柔居尊，是 晋卦的明君之位。作为君主，其“晋升”是 国家事业的推进与昌明。因其 柔中文明，虚怀若谷，能 不计较个人得失（失得勿恤），一心为公，所以 所有的悔恨都消亡（悔亡）。以此心态行事（往），则 天下归心，吉祥如意，无所不利。爻传“往有庆也”盛赞其 前行必带来普天同庆。此爻描绘了 **理想领导者的境界：以 光明之德治国，大公无私，故能无往不利。


### 上九：晋其角，维用伐邑，厉吉无咎，贞吝。


**原文**：晋其角，维用伐邑，厉吉无咎，贞吝。

**白话**：晋升到顶点，犹如兽角，可用于讨伐属邑，虽有危险但终获吉祥而无咎害，守持正固以防憾惜。

**小象传**
**原文**：“维用伐邑”，道未光也。

**白话**：虽然出兵讨伐属国，但王道还未能发扬光大。


**说明**

这是 晋升的极顶——刚极则折。

+ “晋其角”：晋升（晋）到顶点，犹如兽角（其角）。
+ “维用伐邑”：只宜（维）用来（用）征伐（伐）属邑（邑）。
+ “厉吉，无咎”：虽有危险（厉）但可获吉祥（吉），无咎害（无咎）。
+ “贞吝”：但守持正固（贞）以防憾惜（吝）。
+ 爻传“道未光也”：因为 （晋升之）道（道）未能光大（未光）。

**相关性**：上九阳刚处卦之极，是 晋升的尽头。“角”象征 尖锐、顶端、再无进路。晋升到极致，容易 刚愎自用，脱离群众。爻辞指出，此时的力量只适合用来 处理内部问题（伐邑），整顿边鄙，而不宜对外扩张或继续冒进。这样做虽有风险（厉），但可保吉祥无咎。然而，爻辞最后警告 “贞吝”：**即使动机正确，这种 处于极顶、刚猛过甚的状态本身，就潜藏着憾惜与不足。爻传“道未光也”深刻指出：因为其 晋升之道未能以柔济刚、未能光大中正之德，故有局限。此爻揭示：**晋升有止境，过刚的进取会带来新的问题，需 懂得收敛与自省。


## 总结

**总结**：晋卦的现代启示

晋卦的 “自昭明德” 是关于 个人进步、职位晋升、事业发展的正道。

晋升的六个阶段与心法：

+ 初阶受挫（初六）：宽裕待时，独行正道。
+ 中正获福（六二）：守正解忧，柔中得助。
+ 得众上行（六三）：众允无悔，民心所向。
+ 贪位致厉（九四）：戒如鼫鼠，德须配位。
+ 明君治世（六五）：勿恤得失，往有庆也。
+ 极顶知限（上九）：刚极宜敛，道未光也。

核心心法：大象传总纲——“明出地上，晋；君子以自昭明德。” 这意味着：

+ “明出地上，晋”：是 晋卦之象（太阳从大地升起，光明渐进）。
+ “君子以自昭明德”：君子效法此象，自我彰显光明的德行。
这是 晋卦精神的灵魂：**晋升的根本动力与资格，不来自于外在的钻营，而来自于 内在德行的积累与彰显（自昭明德）。如同太阳升起是自身发光，君子的晋升也是 其德辉的自然流露与外现。它教导我们：专注于 修养品德、提升能力、做出贡献，晋升将是水到渠成的结果。

根本精神：彖传 “晋，进也。明出地上，顺而丽乎大明，柔进而上行。” 精妙地概括了晋卦成功的三要素：

+ “明出地上”：有光明的目标与德行（离明）。
+ “顺而丽乎大明”：以柔顺的态度（坤顺）附丽、追随更大的光明（代表正道、上级或时代趋势）。
+ “柔进而上行”：以柔和、渐进的方式（柔进）向上发展（上行）。

这三者结合，就是 “是以康侯用锡马蕃庶，昼日三接也” 的盛况。晋卦告诉我们：**最佳的晋升之道，是 内修明德，外行柔顺，顺势而为。它反对冒进与投机，崇尚 稳健、持正、赢得人心的自然成长。无论是个人职场发展，还是企业市场开拓，此卦皆有永恒的指导价值。
