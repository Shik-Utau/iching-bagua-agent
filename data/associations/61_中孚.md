# 中孚卦（巽上兑下）

**卦画**：䷼

## 总论：诚信之道的哲学

**核心短词**：“议狱缓死”

**卦象**：上巽（☴）为风、为木，下兑（☴）为泽、为悦。风泽中孚。风行泽上，感化万物。卦形 中间两爻为阴，上下四爻为阳，如虚心之舟或中空之 卵，象征内心诚信、中虚 外实。

**核心卦辞**：“豚鱼吉，利涉大川，利贞。”

**总纲**：中孚卦象征 “中心诚信”。诚信能感化小猪小鱼（豚鱼），吉祥，利于涉越大河巨流，利于守持正固。

+ “豚鱼吉”：诚信能感化小猪小鱼（豚鱼），吉祥（吉）。“豚鱼” 是微贱、冥顽难以感通之物。连它们都能被诚信所 感化，获得 吉祥，可见 “中孚”（诚信） 的力量之广大与 神奇。这是极言诚信感通之 深。
+ “利涉大川”：利于涉越大河巨流（利涉大川）。“大川” 象征巨大的 艰难险阻。诚信具有凝聚人心、克服猜疑、建立信任的 力量，因此能集合众人 之力，共渡 难关。这是诚信的实践 力量。
+ “利贞”：利于守持正固（利贞）。诚信本身 就是 “贞”（正） 的 体现，但仍需 强调，意味着诚信必须始终与正道 相结合，不能用于邪僻 之事。

**本质**：中孚卦描述 “柔在内而刚得中” 的状态。内心（卦中）柔顺 虚心，外在（上下）刚健 中正。象征一种内心真诚、信念坚定、表里如一的品德与 状态。其**核心精神**是：探讨 “信”的智慧——诚信如何从内心 发出，感化 外物，凝聚 力量，克服 险阻。它强调 “说而巽，孚乃化邦”——下悦 （兑） 而上顺 （巽），诚信就能化育 邦国。

## 卦辞



### 经

**原文**：豚鱼吉，利涉大川，利贞。

**白话**：诚信能感化小猪小鱼，吉祥，利于涉越大河巨川，利于守持正固。

### 彖传

**原文**：中孚，柔在内而刚得中。说而巽，孚，乃化邦也。“豚鱼吉”，信及豚鱼也。“利涉大川”，乘木舟虚也。中孚以利贞，乃应乎天也。

**白话**：中孚卦的卦象，是柔顺在内而刚健居中。下卦为兑表示喜悦，上卦为巽表示谦逊，内心诚信，就能感化邦国。“用豚和鱼祭祀可获吉祥”，是说诚信已施及豚鱼这类微贱之物。“利于涉越大河”，是因为能像乘坐中空的木船那样畅通无阻。内心诚信而又利于坚守正道，是因为顺应了上天的美德。

### 大象传

**原文**：泽上有风，中孚；君子以议狱缓死。

**白话**：水面上吹拂着和风，象征内心诚信；君子因此审议讼狱，宽缓死刑。


## 爻辞

### 初九：虞吉，有它不燕。


**原文**：虞吉，有它不燕。

**白话**：安守诚信则吉，别有他求则不得安宁。

**小象传**
**原文**：初九“虞吉”，志未变也。

**白话**：初九爻辞说“安守本分可获吉祥”，是因为此时的心志还没有改变。


**说明**

这是 诚信的奠基——专心致志，不存杂念。

+ “虞吉”：安守（诚信）（虞）吉祥（吉）。“虞” 有安、度、预期之意。指安于本分的 诚信，或预期诚信会带来 吉祥。
+ “有它不燕”：别有他求（有它）则不得安宁（不燕）。“燕” 通 “宴”，安乐。
+ 爻传“初九虞吉，志未变也”：初九安守诚信而吉祥，是因为心志未曾改变。

**相关性**：初九阳刚处下，是诚信的 开端。其关键 在于 “虞”——安守、专注于内心的 诚信，不 三心二意。爻传说其 “志未变也”，强调心志的专一与 坚定。如果在此基础上 还 “有它”——怀有其他的、不纯的动机或 期待，诚信就不 纯粹了，内心便会失去平静与 安乐（不燕）。此爻确立了诚信修养 的 第一原则：心志 专一，动机 纯正。


### 九二：鸣鹤在阴，其子和之，我有好爵，吾与尔靡之。


**原文**：鸣鹤在阴，其子和之，我有好爵，吾与尔靡之。

**白话**：鹤在树荫下鸣叫，它的幼鹤应声相和；我有美酒，愿与你共饮。

**小象传**
**原文**：“其子和之”，中心愿也。

**白话**：它的孩子应和它，是发自内心的愿望。


**说明**

这是 诚信的感通——发自中心，应者自来。

+ “鸣鹤在阴，其子和之”：鹤（鸣鹤）在树荫下（在阴）鸣叫，它的同类（其子）声声应和（和之）。
+ “我有好爵，吾与尔靡之”：我有美酒（好爵），愿与你（吾与尔）共饮（靡之）。
+ 爻传“其子和之，中心愿也”：它的同类声声应和，是出于内心的意愿。

**相关性**：九二阳刚居中，是下卦兑悦的 核心，也是全卦 “中孚” 之德的主要 体现者。爻辞用两个优美的比喻来描绘诚信 的 感通 力量。“鸣鹤在阴”：鹤在幽暗处 鸣叫，其声并非为求 应和，只是发自 天性。但同类 闻之，自然 “和之”。这象征诚信发自内心 （在阴），不求 闻达，却 能 感召 志同道合 者 自然 响应。“我有好爵”：“好爵”（美酒） 象征美好的 东西 或 心意。“吾与尔靡之” 体现了一种无私的分享 精神。诚信者不仅能感召 人，也乐于与人共享 美好。爻传 点明 “中心愿也”：应和与 分享，都是出于内心真诚的 意愿，非外力 强求。此爻是中孚之德最动人的 写照，展现了诚信的感染力与 亲和力。


### 六三：得敌，或鼓或罢，或泣或歌。


**原文**：得敌，或鼓或罢，或泣或歌。

**白话**：面临敌对者，时而击鼓进攻，时而疲惫退止，时而哭泣，时而歌唱。

**小象传**
**原文**：“或鼓或罢”，位不当也。

**白话**：有时击鼓前进有时疲惫后退，这是因为所处的位置不恰当。


**说明**

这是 诚信的动摇——心存猜疑，举止失措。

+ “得敌”：面临敌对者（得敌）。
+ “或鼓或罢，或泣或歌”：时而击鼓进攻（或鼓），时而疲惫退守（或罢），时而悲泣（或泣），时而欢歌（或歌）。
+ 爻传“或鼓或罢，位不当也”：时而击鼓时而退守，是因为（六三）位置不当。

**相关性**：六三阴柔不中不正，处下卦兑悦之 极，与上九 相应，但 自身 居位 不当。“得敌” 并非真有 外敌，更可能是内心的猜疑与对立 情绪，或因诚信不固而导致的人际 紧张。爻辞用一连串矛盾的动作与情绪 （鼓、罢、泣、歌），生动描绘了其心神不宁、进退失据的 状态。因为内心缺乏坚定的诚信 （位不当也），所以对外的反应就失去了 准绳，只能随外界的风吹草动而 忽喜忽悲，忽进忽退。此爻是作为 “中孚” 的反面 教材，展示了内心不诚不信所导致的混乱与 痛苦。


### 六四：月几望，马匹亡，无咎。


**原文**：月几望，马匹亡，无咎。

**白话**：月亮接近圆满，马匹丧失匹配，没有咎害。

**小象传**
**原文**：“马匹亡”，绝类上也。

**白话**：马匹丢失了，意味着要断绝同类而向上发展。


**说明**

这是 诚信的抉择——破除私系，顺承中正。

+ “月几望”：月亮接近圆满（几望）。
+ “马匹亡”：马匹丢失（亡）。
+ “无咎”：没有咎害（无咎）。
+ 爻传“马匹亡，绝类上也”：马匹丢失，是断绝与同类（初九）的联系而上从（九五）。

**相关性**：六四阴柔得正，居上卦巽顺之 始，下应 初九，上承九五 中正 之 君。“月几望” 象征其德行接近 圆满，光明 皎洁。“马匹” 指其下应的 初九（匹 配 之 交）。“马匹亡” 并非真的 丢失，而是比喻主动断绝与初九的私下应和 关系。为何要 这样做？因为六四作为 近君大臣，其首要的诚信对象应是九五 君王（代表国家与 正道）。如果仍系心于下面 的 私交（初九），就可能因私害 公。爻传明确 指出 “绝类上也”：断绝与同类 （初九） 的 联系，以便专心向上顺承 九五。这是一种以更高的诚信 （对君、对国） 取代较低的诚信 （私交） 的 抉择，虽然看似 有 损失（马匹亡），但符合 大义，故 “无咎”。


### 九五：有孚挛如，无咎。


**原文**：有孚挛如，无咎。

**白话**：诚信广系天下，没有咎害。

**小象传**
**原文**：“有孚挛如”，位正当也。

**白话**：心怀诚信紧密相连，是因为所处的位置正当合适。


**说明**

这是 诚信的核心——君王中正，天下归心。

+ “有孚挛如”：诚信（有孚）广系（挛）天下人心（如）。“挛” 是牵系、连结。
+ “无咎”：没有咎害（无咎）。
+ 爻传“有孚挛如，位正当也”：诚信广系天下人心，是因为（九五）位置正当。

**相关性**：九五阳刚中正，居 尊位，是 “中孚” 之德的卦主 与 典范。其 “孚”（诚信） 不是针对 某 一个人，而是 “挛如”——像纽带一样广泛地牵系、连结着天下的 人心。这就是彖传所说的 “孚乃化邦”。因为其 “位正当也”（既中且 正），所以其诚信自然具有公信力与 感召力，能将众人团结在 一起，形成稳固的 共同体。作为 君王，以此诚信 治国，自然 “无咎”，且能成就 大业。此爻指明了领导者的 根本 品德：以至诚至信团结 大众。


### 上九：翰音登于天，贞凶。


**原文**：翰音登于天，贞凶。

**白话**：鸡的鸣叫声响彻天空（虚声远闻），守持正固以防凶险。

**小象传**
**原文**：“翰音登于天”，何可长也？

**白话**：高亢的鸡鸣声传扬到天上，这种虚浮不实的状态怎么可能长久保持呢？


**说明**

这是 诚信的虚浮——声过其实，必有凶险。

+ “翰音登于天”：鸡鸣之声（翰音）响彻天空（登于天）。“翰音” 指鸡的 叫声，鸡本不能 高飞，其声却传于 天，比喻名声超过 实际，虚声 远闻。
+ “贞凶”：守持此道（贞）有凶险（凶）。
+ 爻传“翰音登于天，何可长也”：鸡鸣之声响彻天空，这种状况怎么可以长久呢？

**相关性**：上九阳刚处卦之极，是 “中孚” 之道的终点与 异化。它失去了 “中孚” 内心中虚诚信的 本质，只剩下 外在 的 “声名”。“翰音登于天” 正是描绘这种内在 空虚，却极力向外宣扬名声的 状态。这是一种虚伪的 “信”，或是对 “信” 的 滥用。爻传 反问 “何可长也？”：这种虚张声势的状况怎么可能持久 呢？一旦被 识破，必然从高处 跌落，故 “贞凶”（固守此道必凶）。此爻作为卦的 终结，与初九的“虞吉”（专心 内修） 形成首尾 对比，严厉警告 ：诚信必须根植于内心的 实在，切忌流于外在的 虚声。


## 总结

**总结**：中孚卦的现代启示

中孚卦的 “议狱缓死” 是关于 “诚信、感通、信任”的品德力量与社会治理智慧。它深刻阐述了 “信” 如何从个人内心 发出，影响 他人，凝聚 社会，并在极端情况下体现为司法的 仁恕。

实践诚信之道的六个层次与境界：

+ 信之始基（初九）：虞吉，有它不燕。
+ 诚信感通（九二）：鸣鹤在阴，其子和之；我有好爵，吾与尔靡之。
+ 诚信不固（六三）：得敌，或鼓或罢，或泣或歌。
+ 诚信至上（六四）：月几望，马匹亡，无咎。
+ 君以诚信（九五）：有孚挛如，无咎。
+ 诚信不实（上九）：翰音登于天，贞凶。

核心心法：大象传总纲——“泽上有风，中孚；君子以议狱缓死。”这意味着：

+ “泽上有风，中孚”：是中孚卦之象（风行泽上，感化万物）。
+ “君子以议狱缓死”：君子效法此象，审议狱讼，宽缓死刑。

这是中孚之德在司法这一最需要公正与良知的领域的 最高 应用。“议狱” 是慎重 审理，不枉 不 纵；“缓死” 是对死刑的执行持特别谨慎甚至宽缓的 态度。这背后的精神 正是 “中孚”——以至诚恻隐之心对待人的生命与 权利，不因愤怒或功利而轻易 剥夺。将诚信仁爱之心推及于 司法，乃至于对待最有过错的 人，这是 “孚乃化邦” 的极致 体现。

根本精神：彖传“中孚，柔在内而刚得中，说而巽，孚乃化邦也。‘豚鱼吉’，信及豚鱼也。‘利涉大川’，乘木舟虚也。中孚以利贞，乃应乎天也。”揭示了诚信之道的本质与力量源泉：

+ “中孚，柔在内而刚得中，说而巽，孚乃化邦也”：解释卦名与卦德，指出诚信能化育邦国。
+ “‘豚鱼吉’，信及豚鱼也”：解释感化之深。
+ “‘利涉大川’，乘木舟虚也”：解释克服险阻的原因。卦象 上巽为木、为舟，下兑为泽，中间 虚，正是“中虚之 舟” 的 形象。诚信如同中空的 舟船，因其 “虚”（虚心、中空） 而能 “容”（承载），故能 “涉川”。
+ “中孚以利贞，乃应乎天也”：中孚之道利于守正，是因为它顺应了天道。将 “诚信” 提升到 “天” 的 高度。天道最大的 特点 就是 “诚”（真实 无妄）。《中庸》云：“诚者，天之道也。” 所以，人 的 “中孚”（诚信），正是对天道的效法与 回应。

中孚卦告诉我们：“信”是人与人之间最宝贵的 纽带，是社会得以运行的 基石。真正的 诚信（中孚），源于内心的中虚与 纯正（柔在内），表现为外在的刚健与 中直（刚得中）。它能产生 “鸣鹤” 般的自然 感召力，能成就 “挛如” 般的强大 凝聚力，甚至能在 “议狱缓死” 中展现至高的仁恕 精神。同时，它也警惕我们避免 “得敌” 般的猜疑与 “翰音” 般的 虚浮。这便是在 “风行泽上” 的感化意象中，所蕴含的关于 真诚、信任、感通与仁爱 的永恒法则。
