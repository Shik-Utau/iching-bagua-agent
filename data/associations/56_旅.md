# 旅卦（离上艮下）

**卦画**：䷷

## 总论：羁旅之道的哲学

**核心短词**：“明慎用刑，而不留狱”

**卦象**：上离（☲）为火、为明、为附丽，下艮（☶）为山、为止、为门阙。火山旅。山上有火，火行不止，旅人奔波。

**核心卦辞**：“小亨，旅贞吉。”

**总纲**：旅卦象征 “羁旅、行旅”。小有亨通，行旅中守持正固可获吉祥。

+ “小亨”：小有亨通（小亨）。旅居在外，寄人篱下，势单力薄，故不可能有 大亨大通，只能是小心谨慎，以求 小得亨通。这点明了 旅居状态的根本特征—— 不占主场，力量有限。
+ “旅贞吉”：行旅中守持正固可获吉祥（旅贞吉）。这是旅卦的 核心诫命。在 漂泊不定、环境陌生、根基不稳 的 旅途中，最大的依靠 不是 外在的强力，而是 内在的 “贞”—— 守持正道、固守本心、行为端正。唯有 “贞”，才能 避免祸患，获得吉祥。

**本质**：旅卦描述 “山上有火” 的状态。火（离） 依附于 山（艮） 而燃烧，但 火性炎上，行而不居；山性静止，是 暂时的依托。这象征 一种 行旅、客居、漂泊不定 的 人生状态。其核心精神是：探讨 “旅”的智慧——在 身处异乡、暂居客位、动荡不安 的环境中，如何 安身立命、避祸求吉。它强调 “明而止”——以 明智（明） 知道 何时该止、何处可依（止），在 流动中 保持内心的贞固与行为的审慎。

## 卦辞



### 经

**原文**：小亨，旅贞吉。

**白话**：小有亨通，行旅中守持正固可获吉祥。

### 彖传

**原文**：旅，小亨，柔得中乎外而顺乎刚，止而丽乎明，是以“小亨，旅贞吉”也。旅之时义大矣哉！

**白话**：旅卦，象征小的通达。柔顺者在外获得中位而又能顺应刚强者，静止而依附于光明，因此说“小有通达，旅行中守持正固可获吉祥”。旅行的时机和意义真是重大啊！

### 大象传

**原文**：山上有火，旅；君子以明慎用刑，而不留狱。

**白话**：山上有火，象征行旅；君子因此明智审慎地动用刑罚，而不拖延讼案。


## 爻辞

### 初六：旅琐琐，斯其所取灾。


**原文**：旅琐琐，斯其所取灾。

**白话**：行旅之初，行为猥琐卑贱，这是自我招取灾祸。

**小象传**
**原文**：“旅琐琐”，志穷灾也。

**白话**：旅途中表现得卑微猥琐，是因为志向穷尽而招致灾祸。


**说明**

这是 旅行的开端——心态卑微，自招祸患。

+ “旅琐琐”：行旅之初，猥琐卑贱（旅琐琐）。
+ “斯其所取灾”：这正是（斯）自我招取灾祸（所取灾）的原因。
+ 爻传“旅琐琐，志穷灾也”：行旅之初猥琐卑贱，说明（初六）心志穷困而招致灾祸。

**相关性**：初六阴柔处下，是旅行的 初始与底层。“琐琐”形容 器量狭小、行为卑琐、斤斤计较 的样子。一个 旅人，在 陌生的环境 中，如果一开始就表现出 卑微、吝啬、患得患失 的 姿态，不仅 无法赢得尊重，反而会 暴露自身的软弱与可欺，自然容易招致 轻蔑、欺凌和灾祸。爻传“志穷灾也”一针见血：灾祸的根源不在于 外在环境，而在于内在心志的 穷蹙与卑下。此爻是 严厉的当头棒喝：旅居在外，首要是 端正心态，提振精神，不可 自轻自贱。


### 六二：旅即次，怀其资，得童仆，贞。


**原文**：旅即次，怀其资，得童仆，贞。

**白话**：行旅中住进客舍，怀藏资财，得到忠贞的童仆。

**小象传**
**原文**：“得童仆贞”，终无尤也。

**白话**：得到忠实的童仆，终究不会有怨尤。


**说明**

这是 旅行的安定——得所安顿，资用俱全。

+ “旅即次”：旅人住进客舍（旅即次）。
+ “怀其资”：怀藏资财（怀其资）。
+ “得童仆，贞”：得到忠实的童仆（得童仆），守持正固（贞）。
+ 爻传“得童仆贞，终无尤也”：得到忠实的童仆而守持正固，说明最终没有怨尤。

**相关性**：六二阴柔中正，是旅途中 最得宜、最安稳的状态。“即次”是找到 合适的住所（次，旅舍），得以安顿。“怀其资”是拥有 必要的旅费资财，经济无忧。“得童仆”是获得 忠实可靠的帮手或伙伴，行事有助。这三者构成了旅居在外最基本的 安全保障。但爻辞最后强调 “贞”，并 以此断语。这意味着：即使具备了这些 有利的外部条件，根本仍在于旅人自身行为的端正与内心的 贞固。唯有 守正，才能长久地保有这些条件，避免因 行为失当 而 失去它们。爻传“终无尤也”指出：如此便能自始至终没有 过失与怨悔。此爻描绘了理想的 旅居状态，并点明其 基石 在于 “贞”。


### 九三：旅焚其次，丧其童仆，贞厉。


**原文**：旅焚其次，丧其童仆，贞厉。

**白话**：行旅中客舍被焚，丧失童仆，守持正固以防危险。

**小象传**
**原文**：“旅焚其次”，亦以伤矣。以旅与下，其义丧也。

**白话**：旅途中旅舍被火烧毁，已经够令人悲伤的了。作为旅客却还要对下人摆出主人的架势，从道理上讲必然会失去一切。


**说明**

这是 旅行的灾变——刚亢招损，处境危厉。

+ “旅焚其次”：旅人所居客舍被焚（旅焚其次）。
+ “丧其童仆”：丧失忠实的童仆（丧其童仆）。
+ “贞厉”：守持正固以防危险（贞厉）。
+ 爻传“旅焚其次，亦以伤矣；以旅与下，其义丧也”：客舍被焚，已经受到伤害；以旅人的身份对待下属，按照道理是会丧失（童仆）的。

**相关性**：九三阳刚过中，处 下卦艮山之顶，是 刚亢躁进、不知止的旅人。它将六二爻安稳的局面 彻底颠覆：“焚其次”——住所 被毁，失去安身之所；“丧其童仆”——助手 离去，失去得力支持。爻传分析原因：“以旅与下，其义丧也”。身为 旅人（客居者），本应 谦和待人，却以 高傲刚猛的态度（与下） 对待 下属或同伴（童仆），按照 旅道之义，失去他们 是 理所当然（其义丧） 的。“贞厉” 是在此危厉处境下的 告诫：此时更要牢牢 守持正道（贞），行为 加倍谨慎，才能防止 灾祸进一步扩大。此爻揭示了旅居者因自身 刚愎自用、态度不当 而引发的 重大危机。


### 九四：旅于处，得其资斧，我心不快。


**原文**：旅于处，得其资斧，我心不快。

**白话**：行旅中暂得栖身之处，获得资财和利斧，但心中仍不愉快。

**小象传**
**原文**：“旅于处”，未得位也。“得其资斧”，心未快也。

**白话**：旅途中暂时安顿，是因为还没找到合适的位置。虽然得到了资助和工具，但心里并不畅快。


**说明**

这是 旅行的暂安——身虽得安，心未愉悦。

+ “旅于处”：旅人暂得栖身之处（旅于处）。
+ “得其资斧”：获得资财与利斧（得其资斧）。
+ “我心不快”：但心中仍不痛快（我心不快）。
+ 爻传“旅于处，未得位也；得其资斧，心未快也”：暂得栖身之处，说明（九四）未得适当之位；获得资斧而心中不快，说明心志未能畅快。

**相关性**：九四阳刚失正，已入 上卦离明 之体，是有才识但 处境尴尬 的旅人。“处”与“次”不同，“次”是 正规旅舍，“处”是 临时居所、野外栖身地。九四虽有 安身之地（处） 和 防身的资财工具（资斧），生存 暂无虞。但爻传指出 其 “未得位也”——找不到与自己才能、身份相匹配的 正当位置。因此，身 虽暂安，心却漂泊不定，怀才不遇，故 “心未快也”。此爻刻画了旅居中一种常见的 心理状态：物质上或许已 解决温饱，但精神上仍感到 失落、不安与不满足。它提醒：旅人的 “安”，不仅在于身体的 栖止，更在于心灵的 归属与价值的实现。


### 六五：射雉，一矢亡，终以誉命。


**原文**：射雉，一矢亡，终以誉命。

**白话**：射取野鸡，虽丢失一支箭，但终将获得美誉和爵命。

**小象传**
**原文**：“终以誉命”，上逮也。

**白话**：最终获得美誉和任命，是因为得到上层的提携。


**说明**

这是 旅行的成就——以明致誉，失微得显。

+ “射雉，一矢亡”：射取野鸡（射雉），虽丢失一支箭（一矢亡）。
+ “终以誉命”：但终将获得美誉和爵命（终以誉命）。
+ 爻传“终以誉命，上逮也”：终获美誉爵命，说明（六五）的才德上达于天（或君王）。

**相关性**：六五阴柔居中，居 尊位，是旅途中 地位最高、最有智慧的旅人。“雉”是 有文采的野鸡，象征 文明、才华。“射雉”比喻 施展才华，有所作为。“一矢亡”是过程中的 小损失、小代价。六五以 柔中之德，明智地在异乡 展现才能，虽然 付出了一些代价，但其 文明之德（离明） 与 中正之行，终将被 上层（君王或天道）所察知（上逮），从而获得崇高的 声誉（誉） 与正式的 任命或地位（命）。此爻指明了旅居者的 最高追求与可能成就：不在于 积聚资财，而在于以 文明之德 与 中正之行，赢得社会的 广泛认可与尊重，实现个人价值的 升华。


### 上九：鸟焚其巢，旅人先笑后号咷。丧牛于易，凶。


**原文**：鸟焚其巢，旅人先笑后号咷。丧牛于易，凶。

**白话**：鸟巢被焚，行旅之人先欢笑后号啕大哭。在田畔丢失了牛，有凶险。

**小象传**
**原文**：以旅在上，其义焚也。“丧牛于易”，终莫之闻也。

**白话**：旅居在外却高高在上，其情势必然招致焚毁之灾。“在田畔丢失了牛”，终究是无人过问的结局。


**说明**

这是 旅行的终结——高傲失据，凶险临头。

+ “鸟焚其巢”：鸟巢被焚（鸟焚其巢）。
+ “旅人先笑后号咷”：旅人先得高位欢笑（先笑）后遭祸号啕大哭（后号咷）。
+ “丧牛于易，凶”：在田畔（易，通“埸”，田界）丢失了牛（丧牛），凶险（凶）。
+ 爻传“以旅在上，其义焚也；丧牛于易，终莫之闻也”：以旅人的身份而高居上位，按照道理是会（像鸟巢一样）被焚毁的；在田畔丢失了牛，说明最终无人过问。

**相关性**：上九阳刚处卦之极，居 离明之终，是旅途中 高傲到极点、忘乎所以者。“鸟焚其巢”是惊心动魄的 比喻：鸟将巢筑在 高高的、易燃的树上（喻旅人 攀附高位），一旦起火（喻 灾祸），巢 必被焚毁，无家可归。“先笑后号咷”生动描绘了其 命运转折：起初因 身居高位（旅在上） 而 得意欢笑，最终 因 灾祸骤临 而 悲恸号哭。“丧牛于易”是 另一个 象征：“牛” 象征柔顺、厚重的 德行（坤为牛）。在 田界（易） 这种 边界、交接之地 丢失了牛，意味着 彻底 丧失了 旅人 最应持守的 柔顺、谦卑之德。爻传 冷酷地 宣判：“其义焚也”—— 咎由自取；“终莫之闻也”—— 下场凄凉，无人同情。此爻是对旅居者最严重的 警告：若因一时得意而忘记自己 “客居” 的 根本身份，行为亢奋失度，德行 丧失殆尽，必将从巅峰跌入万劫不复的 凶险深渊。


## 总结

**总结**：旅卦的现代启示

旅卦的 “明慎用刑，而不留狱” 是关于 “漂泊、客居、动荡”的生存智慧与深刻警示。它聚焦于人在 失去稳固根基、身处陌生环境 时的 心态、行为与结局。

实践羁旅之道的六个阶段与教训：

+ 卑贱自辱（初六）：旅琐琐，斯其所取灾。
+ 安居得助（六二）：旅即次，怀其资，得童仆，贞。
+ 过刚失所（九三）：旅焚其次，丧其童仆，贞厉。
+ 暂得资具（九四）：旅于处，得其资斧，我心不快。
+ 柔中文明（六五）：射雉，一矢亡，终以誉命。
+ 亢极失所（上九）：鸟焚其巢，旅人先笑后号咷；丧牛于易，凶。

核心心法：大象传总纲——“山上有火，旅；君子以明慎用刑，而不留狱。” 这意味着：

+ “山上有火，旅”：是 旅卦之象（火行于山上，暂附而不住）。
+ “君子以明慎用刑，而不留狱”：君子效法此象，明智而审慎地动用刑罚，并且不滞留狱案。

这是旅卦精神的 独特应用。君子从火依附于山而 明照，但终将 流动前行 的 意象 中，领悟到司法 也应如此：处理案件要 明察秋毫（明），量刑要 谨慎得当（慎）——此乃 “明慎”；同时，判决要 迅速果断，不使案件 积压滞留（不留狱）——此乃效法火之 流动不居。这指出了 在 社会管理（如同治理旅人） 中，法治应有的 效率与公正。

根本精神：彖传 “旅，小亨，柔得中乎外，而顺乎刚，止而丽乎明，是以小亨，旅贞吉也。旅之时义大矣哉！” 揭示了羁旅之道的核心法则：

+ “旅，小亨，柔得中乎外，而顺乎刚”：旅卦，小有亨通，是因为（六五）柔顺而得中于外卦，并且能顺承阳刚（上九）。解释 “小亨” 的 卦德依据：旅居在外（乎外），**以 柔顺中道（柔得中） 处事，并能顺应环境中的 强者（顺乎刚），故能 得小亨。
+ “止而丽乎明，是以小亨，旅贞吉也”：（内卦艮）静止而（外卦离）附丽于光明，所以小有亨通，行旅守正则吉。解释 卦象组合：内心 知道 静止、安分（止），外表 则 依附、展现 文明与明智（丽乎明）。内外配合，故能 “小亨”。而 这一切的 保障 在于 “旅贞吉”—— 守持正固 是 获得吉祥 的 根本。
+ “旅之时义大矣哉！”：旅卦的 时态意义 真是 太重大了！这是 对 旅卦 价值的 极高赞叹。人生在世，谁 不曾是 “旅人”？无论是 地理上的 漂泊，事业上的 奋斗，人生阶段的 过渡，还是 心灵上的 寻觅，都 带有 “旅” 的 色彩。懂得 “旅”的智慧—— 在 动荡中 求安，在 陌生中 守贞，在 卑微中 振作，在 得意时 谦慎——对于 安顿人生、应对变化，具有 普遍而重大的 意义。

旅卦告诉我们：“旅”是 人生的 一种 基本境遇。其 智慧 在于 深刻认识 “客居” 的 本质（小亨），并 将 “贞”（守正） 作为 贯穿始终的 生命线。从 初爻的 “琐琐”招灾，到 上爻的 “焚巢”大凶，无不 从反面 证明了 “贞” 的 重要性。而 六二之 “贞”得安，六五之 “明”得誉，则 从正面 展示了 “贞”与“明” 带来的 吉祥。在 “山上有火” 的 漂泊图景 中，真正的 家园，不在 固定的 山石，而在于 流动的 火焰 所 始终持守的 那份 光明与中正。这便是在 “行旅” 的 人生常态 中，所 蕴含的 关于 适应、持守、明哲与归宿 的 深邃哲理。
