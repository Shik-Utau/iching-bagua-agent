# 离卦（离上离下）

**卦画**：䷝

## 总论：附丽的哲学

**核心短词**：“继明照于四方”

**卦象**：上离（☲）为火、为明，下离（☲）为火、为明。离为火。明两作，光明相继；柔丽乎中正，化成天下。

**核心卦辞**：“离，利贞，亨。畜牝牛，吉。”

**总纲**：离卦阐述 “附丽、依附、光明” 之道。利于守持正道，亨通。畜养母牛般的柔顺之德，吉祥。

+ “离”：附丽、依附、光明（火必须附着于物才能发光）。
+ “利贞”：利于守持正道（依附必须选择正道的对象）。
+ “亨”：亨通。
+ “畜牝牛，吉”：畜养（畜）母牛（牝牛）般的柔顺之德，吉祥。

**本质**：离卦的核心是 “柔丽乎中正” 与 “重明以丽乎正，乃化成天下”。卦象上下皆明，象征 光明接连升起（明两作）。离为火，火不能自现，必须 附着于可燃之物（丽） 才能发光发热。这比喻：人（尤其是柔顺者）必须依附于中正之道或贤明的君主，才能发挥价值，成就事业。卦中六二、六五两阴爻 柔顺且分别居于上下卦的中位（中正），是“离”德的完美体现。通过这种 光明而又柔顺的依附，可以 教化、成就天下。

## 卦辞



### 经

**原文**：利贞，亨。畜牝牛，吉。

**白话**：利于守持正固，亨通。畜养母牛，吉祥。

### 彖传

**原文**：离，丽也。日月丽乎天，百谷草木丽乎土，重明以丽乎正，乃化成天下。柔丽乎中正，故亨，是以畜牝牛吉也。

**白话**：离，就是附丽的意思。日月附丽在天上，百谷草木附丽在地上，光明重叠而又附丽于正道，于是就能教化成就天下。柔顺附丽于中正之道，所以亨通，因此蓄养母牛是吉祥的。

### 大象传

**原文**：明两作，离；大人以继明照于四方。

**白话**：光明接连升起，这就是离卦的意象；大德之人因此用持续不断的光明照耀四方。


## 爻辞

### 初九：履错然，敬之，无咎。


**原文**：履错然，敬之，无咎。

**白话**：步履错杂，保持恭敬谨慎，没有咎害。

**小象传**
**原文**：“履错之敬”，以辟咎也。

**白话**：走路时步伐交错但保持恭敬，是为了避免过错。


**说明**

这是 附丽的初阶——敬慎择主。

+ “履错然”：步履（履）错杂（错然）的样子（形容初涉世事，方向纷繁）。
+ “敬之”：保持恭敬（敬）的态度。
+ “无咎”：没有过错。
+ 爻传“以辟咎也”：为了 避免（辟）过错。

**相关性**：初九阳刚处下，是 “离”的开始。如同年轻人初入社会，面临众多选择（履错然），不知该依附于谁。此时，爻辞给出的指导是 “敬之”——对一切可能依附的对象（尤指上位的六二）保持恭敬、谨慎的态度。不轻慢，不冒犯，以此 避免因鲁莽或失礼而招致咎害（辟咎）。此爻定义了 寻求依附时的首要原则：敬慎。


### 六二：黄离，元吉。


**原文**：黄离，元吉。

**白话**：附丽于中正黄色，至为吉祥。

**小象传**
**原文**：“黄离元吉”，得中道也。

**白话**：黄色依附于物大吉大利，是因为得到了中正之道。


**说明**

这是 附丽的完美——柔中得正。

+ “黄离”：以黄色（黄，中色）所象征的中道来附丽（离）。
+ “元吉”：至为吉祥。
+ 爻传“得中道也”：因为 获得了中正之道。

**相关性**：六二柔顺中正，是 下卦离明之主，也是全卦“离”德的典范。“黄”是 土地之色，象征中道、中和与包容。“黄离”意为：以柔顺之姿，依附于中正之道；或自身秉持中道，成为他人依附的完美对象。因其 完全契合“柔丽乎中正”的卦德，故获 根本性的、最大的吉祥（元吉）。此爻是 个人修养与处世的最佳状态。


### 九三：日昃之离，不鼓缶而歌，则大耋之嗟，凶。


**原文**：日昃之离，不鼓缶而歌，则大耋之嗟，凶。

**白话**：太阳西斜时的光明，若不击缶唱歌自乐，就会发出垂老之人的哀叹，凶险。

**小象传**
**原文**：“日昃之离”，何可久也。

**白话**：太阳西斜时的光辉，怎么能够长久呢。


**说明**

这是 附丽的黄昏——知衰乐天。

+ “日昃之离”：太阳西斜（日昃）时的光明（离）（喻光明将尽，盛极而衰）。
+ “不鼓缶而歌，则大耋之嗟”：若不（不）敲着瓦缶（鼓缶）唱歌自乐（而歌），就会（则）发出垂老（大耋）的哀叹（嗟）。
+ “凶”：凶险。
+ 爻传“何可久也”：（这种状态）怎么能够长久呢？

**相关性**：九三阳刚处下卦之极，如 日过中天，开始西斜。象征 依附的对象（或自身的荣光）已过鼎盛，走向衰落。面对必然的衰减，爻辞给出两种态度：一是 “鼓缶而歌”——坦然接受，自得其乐，安享晚年；二是 “大耋之嗟”——哀叹不已，无法释怀。前者通达，后者凶险。此爻揭示：在依附关系或人生阶段发生更替时，需要有 豁达的胸怀和“乐天知命”的智慧，否则将陷入悲苦。


### 九四：突如其来如，焚如，死如，弃如。


**原文**：突如其来如，焚如，死如，弃如。

**白话**：突然而来，气势灼人，终将灭亡，被抛弃。

**小象传**
**原文**：“突如其来如”，无所容也。

**白话**：突然地出现，没有地方可以容身。


**说明**

这是 附丽的暴虐——刚而失正。

+ “突如其来如”：突然（突如其）而来（来如）的样子。
+ “焚如，死如，弃如”：像烈火般焚烧（焚如），致死（死如），最终被抛弃（弃如）。
+ 爻传“无所容也”：因为 （其暴烈）为天地所不容。

**相关性**：九四阳居阴位，不中不正，且逼近六五君位。它象征一种 强横、暴烈、不得体的依附或进取方式——不是以柔顺中正之道来亲附，而是 以突然、激烈、甚至毁灭性的方式（突如其来如）来逼迫或取代。这种行径如同 野火（焚如），虽一时猛烈，但 终将耗尽自身，被众人唾弃（死如，弃如），为天地所不容（无所容也）。此爻是对 一切强附、逼宫、篡逆等非正道行为的严厉批判。


### 六五：出涕沱若，戚嗟若，吉。


**原文**：出涕沱若，戚嗟若，吉。

**白话**：泪如雨下，忧伤叹息，（然终获众助）吉祥。

**小象传**
**原文**：六五之吉，离王公也。

**白话**：六五爻之所以吉祥，是因为它依附于王公的尊位。


**说明**

这是 附丽的忧惧——柔君之明。

+ “出涕沱若”：涕泪滂沱（出涕沱若）的样子。
+ “戚嗟若”：忧戚（戚）叹息（嗟若）的样子。
+ “吉”：吉祥。
+ 爻传“离王公也”：因为 （六五）附丽于王公（上九）之德（或：因其居王公之位而心怀忧惧）。

**相关性**：六五柔中居尊，是 依附于贤臣（上九）的明君，或是 身处高位而自知柔弱的领导者。“出涕沱若，戚嗟若”描绘了她 因责任重大、才德不足（柔）或处境艰难而忧惧悲泣 的状态。但这种 **忧惧不是软弱，而是 明察危机、敬畏职责的表现。正因心怀忧惧，她才能 柔顺地依附、任用贤能（上九），持守中道，从而 化险为夷，转忧为吉。此爻说明：居高位者，忧患意识（明）与柔顺之德（丽）结合，方能获吉。


### 上九：王用出征，有嘉折首，获匪其丑，无咎。


**原文**：王用出征，有嘉折首，获匪其丑，无咎。

**白话**：君王用兵出征，有嘉美之功斩获敌首，俘获的不是一般的随从，没有咎害。

**小象传**
**原文**：“王用出征”，以正邦也。

**白话**：君王出兵征讨，是为了匡正邦国。


**说明**

这是 附丽的征伐——除邪扶正。

+ “王用出征”：君王（王）动用（用）军队出征（出征）。
+ “有嘉折首”：有嘉奖（有嘉）斩获敌首（折首）之功。
+ “获匪其丑”：俘获（获）的不是（匪）其同类胁从（丑）（即只惩首恶，不究胁从）。
+ “无咎”：没有过错。
+ 爻传“以正邦也”：为了 端正（正）邦国。

**相关性**：上九阳刚处卦之极，是 “离”明之极，也是 光明（离）的捍卫者与执行者。当黑暗（邪佞、叛乱）威胁到光明秩序时，必须以 光明（王师）征伐黑暗。“折首”是 铲除祸首，“获匪其丑”体现了 区别对待、只惩元凶的公正与节制。这样的征伐 目的纯正（以正邦），手段有度，故 “无咎”。此爻阐述了 “离”道的另一面：光明有责任、也有力量去清除黑暗，维护正义。


## 总结

**总结**：离卦的现代启示

离卦的 “继明照于四方” 是关于 合作、追随、发光发热以及文明教化 的智慧。

附丽的层次：

+ 敬慎（初九）：初附之时，恭敬谨慎。
+ 中正（六二）：完美依附，柔顺守中。
+ 乐天（九三）：盛极而衰，知命乐天。
+ 暴虐（九四）：强附逼宫，暴烈被弃。
+ 忧明（六五）：柔君居尊，忧惧得吉。
+ 征伐（上九）：明除黑暗，正邦无咎。

核心心法：大象传总纲——“明两作，离；大人以继明照于四方。” 这意味着：

+ “明两作”：是 离卦之象（光明接连升起）。
+ “大人以继明照于四方”：大人（领导者）效法此象，继承（继）前人的光明德业，持续不断地照耀（照于）四方天下。

其核心是 “继明”：**文明、智慧、德政需要 代代相传，永不熄灭。领导者不仅要 自身光明（有德），更要 致力于让这光明延续和传播，教化天下，使文明之火长明。这既是 文化的传承，也是 领导者的终极使命。

根本精神：彖传 “柔丽乎中正，故亨” 点明了 “离”道亨通的根本：柔顺者（六二、六五）能够依附于中正之道或对象。卦辞 “畜牝牛，吉” 则形象地强调了 柔顺之德的重要性：母牛（牝牛）温顺、负重、有生育力，比喻 在依附关系中，柔顺、耐劳、滋养的特质是吉祥的保障。离卦告诉我们：无论是依附者还是被依附者，“柔中”与“光明”** 的结合，是达成和谐、持久、共赢关系的关键。

离卦与坎卦的承续：坎卦（䷜）讲 “重险环生”（常德行习教事），是 陷入黑暗与困境；离卦（䷝）则讲 “重明相继”（继明照于四方），是 迎来光明与文明。《序卦传》言：“坎者，陷也。陷必有所丽，故受之以离；离者，丽也。” 意思是：坎是陷落。陷入险境后必然要有所依附（才能脱险），所以继之以离卦；离，就是附丽。“坎”是“离”的起因（陷而求丽），“离”是“坎”的出路（丽而脱险）。从坎到离，构成了 “绝处逢生”、“重见光明” 的必然希望，也揭示了 人类在困境中总会寻求光明、依附希望 的本性。这给予人们 在黑暗中永不放弃寻找光明的勇气。
