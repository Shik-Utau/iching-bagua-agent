# 大畜卦（艮上乾下）

**卦画**：䷙

## 总论：大畜的哲学

**核心短词**：“日新其德”

**卦象**：上艮（☶）为山、为止，下干（☰）为天、为健。山天大畜。天在山中，其蕴无穷；止健养贤，厚积薄发。

**核心卦辞**：“大畜，利贞。不家食，吉。利涉大川。”

**总纲**：大畜卦阐述 “大为蓄止、蓄养与积累” 之道。利于守正，蓄养贤才，可成大事。

+ “大畜”：大为蓄止、大为蓄养、大为积累。
+ “利贞”：利于守持正道（蓄止与蓄养必须依循正道）。
+ “不家食，吉”：（贤人）不在家中自食，吉祥（意为被国家蓄养、任用）。
+ “利涉大川”：利于涉越大河巨流（喻可克服巨大艰难险阻）。

**本质**：大畜卦的核心是 “刚健笃实辉光，日新其德” 与 “能止健，大正也”。卦象下干（刚健）上艮（笃实），意味着 内在刚健有为的创造力（干），被外在笃实厚重的山体（艮）所蓄止和涵养。这种蓄止不是压制，而是 “养”，目的是让刚健之力 更加充实、光辉，且德行日日更新（日新其德）。“止健” 是手段，“大正”（至大的正道）是目的。通过蓄养，最终能成就 “涉大川” 的伟业。

## 卦辞



### 经

**原文**：利贞。不家食，吉。利涉大川。

**白话**：利于守持正固。不依靠家中食物（自食其力），吉祥。利于涉越大河巨流。

### 彖传

**原文**：大畜，刚健笃实辉光，日新其德。刚上而尚贤，能止健，大正也。不家食吉，养贤也。利涉大川，应乎天也。

**白话**：大畜卦，刚强劲健，敦厚笃实，焕发辉光，日日更新其美德。阳刚居上而崇尚贤能，能够止住刚健而归于正道，这是至大的正道。不在家中自食吉利，是为了蓄养贤才。利于涉越大河巨流，是因为顺应了天道。

### 大象传

**原文**：天在山中，大畜；君子以多识前言往行，以畜其德。

**白话**：天空涵容在山脉之中，象征广大的蓄聚；君子因此多方记取前贤的言论与过往的事迹，以此积累培养自己的德行。


## 爻辞

### 初九：有厉，利已。


**原文**：有厉，利已。

**白话**：有危险，利于停止。

**小象传**
**原文**："有厉利已"，不犯灾也。

**白话**：有危险，利于停止，这样就不会遭受灾祸。


**说明**

这是 大畜的初阶——知险而止。

+ “有厉”：存在危险（厉）。
+ “利已”：利于停止（已）。
+ 爻传“不犯灾也”：为了 不触犯灾祸。

**相关性**：初九阳刚处下，是 干（健）的初爻，象征 刚健之力初发，锐意进取。但在“大畜”的卦时下，首要任务是 蓄积，而非冒进。爻辞告诫：此时若强行前进，会有危险（有厉）；最有利的做法是 主动停止（利已），积蓄力量。这是 “止健”的第一步：在力量尚微时，懂得审时度势，自我约束，以避免无谓的损耗与灾祸（不犯灾）。此爻定义了 大畜的起点：自我克制。


### 九二：舆说輹。


**原文**：舆说輹。

**白话**：车厢脱卸了轮輹。

**小象传**
**原文**："舆说輹"，中无尤也。

**白话**：车子脱落了车輹，是因为居中而没有过失。


**说明**

这是 大畜的调整——中道而止。

+ “舆说輹”：车厢（舆）脱离了（说，通“脱”）车轴（輹）（车无法前行）。
+ 爻传“中无尤也”：因为 持守中道，没有过失。

**相关性**：九二阳刚居中，与六五相应，本可前进。但“舆脱輹”是 行进工具（车）的关键部件自动脱离，象征 一种来自系统内部或客观条件的、自然而然的停止。九二因 处中位，有自知之明，能顺应“大畜”之时，主动（或被迫）停下前进的步伐。这种停止不是失败，而是 蓄积过程中的必要调整与巩固。因为符合中道，适时而止，所以 没有过失（无尤）。此爻强调 蓄积过程中“止”的智慧与必然性。


### 九三：良马逐，利艰贞。曰闲舆卫，利有攸往。


**原文**：良马逐，利艰贞。曰闲舆卫，利有攸往。

**白话**：良马驰逐，利于在艰难中守正。每日练习车马防卫，利于有所前往。

**小象传**
**原文**："利有攸往"，上合志也。

**白话**：利于有所前往，是因为与上位者心意相合。


**说明**

这是 大畜的砺练——畜而待发。

+ “良马逐”：良马奔驰追逐（喻才干已备）。
+ “利艰贞”：利于在艰难（艰）中守持正道（贞）。
+ “日闲舆卫”：每日（日）娴熟（闲）车马（舆）与防卫（卫）之术（喻持续精进）。
+ “利有攸往”：利于有所前往。
+ 爻传“上合志也”：因为 与上爻（上九或艮止之道）志趣相合。

**相关性**：九三处下卦之极，与上卦艮山相接，是 “健”与“止”交锋、融合的关键位置。“良马逐”显示其 内在的刚健之力（干德）已经蓄养得十分充沛。但此时并非冒进之时，爻辞强调 “利艰贞” 与 “日闲舆卫”，意为：在力量充实时，更要 在艰难的环境中磨练心志，坚守正道，并每日精进技艺，做好万全准备。这样，其行动（攸往）才能 与“大畜”的终极目标（上合志）相契合，为最后的“涉大川”打下坚实基础。


### 六四：童牛之牿，元吉。


**原文**：童牛之牿，元吉。

**白话**：在小牛角上绑上横木以防顶人，至为吉祥。

**小象传**
**原文**：六四元吉，有喜也。

**白话**：六四爻辞说大吉大利，是因为有喜庆之事。


**说明**

这是 大畜的防护——防患未然。

+ “童牛之牿”：在童牛（小牛）的角上加上防止顶人的横木（牿）。
+ “元吉”：至为吉祥。
+ 爻传“有喜也”：值得欣喜。

**相关性**：六四已进入上卦艮（止），且柔顺得正。小牛（童牛）有角，象征 潜在的、未成形的破坏力或错误倾向。“牿”是 预防措施。在牛角未硬、恶习未成之时，就 预先加以约束和防范（止），这是 成本最低、效果最好的“畜止”之道。六四以柔制刚（止初九之健），体现了 “大畜”中“止”的智慧：不是等力量壮大、问题爆发后再去压制，而是在萌芽状态就进行疏导和规范。故获 根本性的吉祥（元吉）。


### 六五：豮豕之牙，吉。


**原文**：豮豕之牙，吉。

**白话**：阉割过的猪，其牙齿（虽在）也不凶猛，吉祥。

**小象传**
**原文**：六五之吉，有庆也。

**白话**：六五爻之所以吉祥，是因为有值得庆贺的好事。


**说明**

这是 大畜的治本——釜底抽薪。

+ “豮豕之牙”：被阉割（豮）的公猪（豕），它的獠牙（牙）。
+ “吉”：吉祥。
+ 爻传“有庆也”：值得庆贺。

**相关性**：六五柔中居尊，是 “大畜”之道的施行者。野猪的獠牙（牙）是 凶猛的象征，但若从根本上 阉割（豮）了它，它就失去了凶猛的本性，獠牙也就无害了。这比喻 对强大的、有危害性的力量（九二、九三之刚健），不是简单地从外部制止其锋芒（牙），而是从根本上转化其性质，消除其危害的根源。六五以柔德（中正）涵养、转化刚暴之力，是 更高明的“止健”，故吉而有庆。


### 上九：何天之衢，亨。


**原文**：何天之衢，亨。

**白话**：何等畅达的天上大路，亨通。

**小象传**
**原文**："何天之衢"，道大行也。

**白话**：为什么能通达天上的大路，是因为正道得以广泛推行。


**说明**

这是 大畜的终境——畅通无阻。

+ “何天之衢”：何等（何）畅达的天街大道（天之衢）！
+ “亨”：亨通。
+ 爻传“道大行也”：（畜养之）道大为畅行。

**相关性**：上九处艮山之巅、全卦之终，是 “大畜”之道圆满成就的象征。经过初爻的“止”、二爻的“脱”、三爻的“练”、四爻五爻的“防”与“制”，内在的刚健之力（干）已被充分 蓄养、驯化、升华。此时， 一切阻碍都已化为通途，如同 行走在四通八达的天街（何天之衢）之上，可以 尽情施展，无往不利。这并非不再需要“止”，而是 “止”已内化为自律，“健”已升华为德能，二者完美融合，故能 亨通无阻，道大行于天下。


## 总结

**总结**：大畜卦的现代启示

大畜卦的 “日新其德” 是关于 蓄积、涵养、克制与升华 的成长哲学。

大畜的层次：

+ 知止（初九）：见险而止，蓄力之初。
+ 自止（九二）：中道而止，自动调整。
+ 砺止（九三）：畜而待发，在蓄积中磨练。
+ 防止（六四）：止恶于初，预防性约束。
+ 化止（六五）：制其根本，从根源上转化。
+ 通止（上九）：畜道大成，止健合一，畅通无阻。

核心心法：大象传总纲——“天在山中，大畜；君子以多识前言往行，以畜其德。” 这意味着：

+ “天在山中”：天（浩瀚无穷的智慧与潜能）被包容在山（笃实厚重的载体）之中。这是 “大畜”之象。
+ “君子以多识前言往行，以畜其德”：君子效法此象，多多学习、记识（多识）前贤的言论（前言）与过往的事迹（往行），用以 蓄养、增进自己的道德与才能（畜其德）。

其核心是 “畜德”：“大畜”的终极目的，不是蓄积财富或权力，而是蓄积“德”——包括品德、智慧、学识与能力。这需要通过 学习历史（前言往行）、静心思考、克制欲望、磨练心志 来实现。这就是 “日新其德” 的日常功课。

根本精神：彖传 “刚健笃实辉光，日新其德” 描绘了 “大畜”之人的理想状态：内在 刚健有力，外在 笃实厚重，散发 光辉，且 德行每日都在更新进步。这不仅是个人修养的至高境界，也是 组织、国家蓄积力量、培养人才的蓝图。卦辞 “不家食，吉” 点明：“大畜”是为了“用”，蓄养的贤才应当走出家门，为国家社会所用，这才是吉祥。而 “利涉大川” 则宣告：经过充分蓄积的力量，足以担当大任，克服任何艰难险阻。

大畜卦与无妄卦的承续：无妄卦（䷘）讲 “动以天行”（茂对时育），是 行动必须至诚真实、遵循天理；大畜卦（䷙）则讲 “止健养贤”（日新其德），是 在懂得如何正确行动（无妄）之后，进一步强调行动之前和之中，需要 暂停、蓄积、涵养与准备。《序卦传》言：“有无妄，然后可畜，故受之以大畜。” 意思是：能够不虚妄，然后才可以蓄积，所以继之以大畜卦。“无妄”是行动的质量（心正行正），“大畜”是行动的资本与底蕴（力厚德充）**。从无妄到大畜，构成了 “有德”而后“蓄德”，“能行”而后“备行” 的完整战略，是 成就任何长久事业的必经阶段。
