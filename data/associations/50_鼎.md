# 鼎卦（离上巽下）

**卦画**：䷱

## 总论：鼎新之道的哲学

**核心短词**：“正位凝命”

**卦象**：上离（☲）为火、为明，下巽（☴）为风、为木。火风鼎。木上有火，烹物成新。

**核心卦辞**：“元吉，亨。”

**总纲**：鼎卦象征 “鼎器、鼎新”。至为吉祥，亨通。

+ “元吉，亨”：鼎卦的卦辞 极其简洁而吉祥。“元吉” 是 最高层次的吉祥，“亨” 是 亨通顺利。这表明 **“鼎”所象征的 立新、养贤、稳固 的状态，是 至善至美、大吉大利 的。

**本质**：鼎卦描述 “以木巽火” 的状态。下巽木（为入、为柴），上离火，以木柴生火，烹煮食物。其**核心精神**是：**以 “鼎” 为喻，探讨 **在革故（革卦）之后，如何 建立新秩序、巩固新成果、培育新人才。鼎是 权力的象征（国之重器）、养贤的器具（大亨以养圣贤）、稳定的标志（定鼎）。它强调 稳固（正位）、滋养（养贤）、光明（明），是 革卦的延续与巩固。

## 卦辞

### 经

**原文**：元吉，亨。

**白话**：至为吉祥，亨通。

### 彖传

**原文**：鼎，象也。以木巽火，亨饪也。圣人亨以享上帝，而大亨以养圣贤。巽而耳目聪明，柔进而上行，得中而应乎刚，是以元亨。

**白话**：鼎是烹煮食物的器具。用木柴顺从火势，就能烹饪食物。圣人烹煮食物来祭祀上天，用丰盛的食物来供养圣贤。谦逊而耳聪目明，柔顺地前进上升，持守中道又与阳刚相应，因此大为亨通。

### 大象传

**原文**：木上有火，鼎；君子以正位凝命。

**白话**：树木上燃烧着火焰，象征鼎器；君子因此端正自己的位置，稳固使命。


## 爻辞

### 初六：鼎颠趾，利出否。得妾以其子，无咎。


**原文**：鼎颠趾，利出否。得妾以其子，无咎。

**白话**：鼎足颠倒，利于倒出鼎中污秽之物。就像娶妾而得到儿子，没有咎害。

**小象传**
**原文**：“鼎颠趾”，未悖也。“利出否”，以从贵也。

**白话**：鼎脚颠倒，并非悖逆。利于倒出污物，是为了追随尊贵。


**说明**

这是 鼎新的初始——清除积弊，奠定基础。

+ “鼎颠趾”：鼎足颠倒（鼎颠趾）。
+ “利出否”：利于（利）倒出污秽之物（出否）。
+ “得妾以其子，无咎”：娶得妾室（得妾）并因其子（以其子）而贵，没有咎害（无咎）。
+ 爻传“鼎颠趾，未悖也；利出否，以从贵也”：鼎足颠倒，并非悖乱；利于倒出污秽，是为了遵从尊贵。

**相关性**：初六阴柔处下，如 鼎之足。爻辞描绘了 新鼎使用的第一个动作：将鼎倒置（颠趾），以 清除其中旧有的污秽渣滓（出否）。这比喻 **建立新秩序之初，**必须 彻底清理旧时代的弊端与腐败。“得妾以其子”是 进一步的比喻：妾（比喻非正统、次要的力量） 因其 生子（比喻产生新的、有益的结果） 而 获得地位。意指 **在除旧布新的过程中，**即使 启用非常规的人或方法（妾），只要 能产生积极成果（其子），就是 可行的，没有咎害。爻传强调：**这种“颠倒”是 必要的清理过程（未悖），目的是 使鼎更好地服务于尊贵者（从贵）。此爻阐明：**鼎新的第一步是 彻底的“大扫除”，为 容纳新物（养贤） 做好准备。


### 九二：鼎有实，我仇有疾，不我能即，吉。


**原文**：鼎有实，我仇有疾，不我能即，吉。

**白话**：鼎中装满食物，我的配偶（或对手）有疾患，不能接近我，吉祥。

**小象传**
**原文**：“鼎有实”，慎所之也。“我仇有疾”，终无尤也。

**白话**：鼎中装满实物，要谨慎选择去向。我的配偶虽有疾病，但最终没有过失。


**说明**

这是 鼎新的积累——内怀实才，外避干扰。

+ “鼎有实”：鼎中装满食物（鼎有实）。
+ “我仇有疾，不我能即”：我的配偶（或对手）（我仇）有疾患（有疾），不能（不）前来接近我（我能即）。
+ “吉”：吉祥（吉）。
+ 爻传“鼎有实，慎所之也；我仇有疾，终无尤也”：鼎中装满食物，要谨慎去处；我的配偶有疾患，终究没有过尤。

**相关性**：九二阳刚居中，是 鼎中充实之才。“鼎有实”比喻 自身才德充实，有可用之资。“我仇有疾”中的“仇”可解为 配偶（匹配者） 或 怨敌（干扰者）。无论哪种解释，“有疾”都意味着 **其 暂时无法正常发挥作用或构成威胁。“不我能即”指 其不能来接近、干扰或分享。这对于 专注于积累和成长的九二 而言，反而是 好事，因为可以 不受干扰地充实自己，故为 吉祥。爻传“慎所之也”告诫：**虽然才德已实，但 去向（之所之） 仍需 谨慎选择；“终无尤也”说明：**外界的暂时隔离，**最终 不会造成过错。此爻强调：**在新秩序建立期，**人才 **首要任务是 厚积其实，避免过早卷入纷争。


### 九三：鼎耳革，其行塞，雉膏不食。方雨亏悔，终吉。


**原文**：鼎耳革，其行塞，雉膏不食。方雨亏悔，终吉。

**白话**：鼎耳脱落，移动受阻，美味的野鸡汤无法食用。正逢下雨，悔恨有所消减，最终吉祥。

**小象传**
**原文**：“鼎耳革”，失其义也。

**白话**：鼎的耳环变了形，就失去了它应有的作用。


**说明**

这是 鼎新的小挫——局部失调，终归顺畅。

+ “鼎耳革，其行塞”：鼎耳脱落变革（鼎耳革），移动受阻（其行塞）。
+ “雉膏不食”：肥美的野鸡肉（雉膏）无法食用（不食）。
+ “方雨亏悔，终吉”：刚好（方）下雨（雨），减损（亏）悔恨（悔），终获吉祥（终吉）。
+ 爻传“鼎耳革，失其义也”：鼎耳脱落变革，失去了其应有的作用。

**相关性**：九三阳刚过甚，处下卦之极，是 鼎新过程中遇到小故障者。“鼎耳”是 穿铉以移动鼎的关键部件。“鼎耳革”比喻 新体制的某个环节（如沟通渠道、执行机构）出现问题或需要调整，导致 整体运作受阻（其行塞），美好的资源（雉膏）无法被享用（不食）。这会造成 一时的悔恨。但转机在于 “方雨”：雨（象征阴阳调和、润泽） 的 及时出现，化解了燥热（离火过旺），弥补了缺陷，从而 减损了悔恨（亏悔），事情 最终回归吉祥。爻传“失其义也”点明：**问题在于 该部件失去了它本来的功能与意义。此爻说明：**任何新体系的建立都 不可能一帆风顺，会出现 局部失调，但只要 具备调和的机制（如雨），能够 及时修正，就能 渡过难关，终获成功。


### 九四：鼎折足，覆公餗，其形渥，凶。


**原文**：鼎折足，覆公餗，其形渥，凶。

**白话**：鼎足折断，倾覆了王公的美食，汁液狼藉，有凶险。

**小象传**
**原文**：“覆公餗”，信如何也。

**白话**：打翻了王公的美食，怎么还能被信任呢。


**说明**

这是 鼎新的大败——才不配位，酿成大祸。

+ “鼎折足”：鼎足折断（鼎折足）。
+ “覆公餗”：倾覆（覆）了王公的美食（公餗）。
+ “其形渥，凶”：汁液狼藉（其形渥），有凶险（凶）。
+ 爻传“覆公餗，信如何也”：倾覆了王公的美食，信任（其）又能怎么样呢？

**相关性**：九四阳居阴位，不中不正，且已脱离下卦巽木（基础），是 才德薄弱却身居高位、承担重任者。“鼎足”是 支撑鼎身的基础。“折足”意味着 根本崩溃。这导致 鼎身倾覆，将 供养王公（象征国家、重要事务）的珍贵食物（餗） 全部 打翻浪费，场面 一片狼藉（形渥），后果 极其严重，故为凶险。爻传“信如何也”是 沉痛的反问：**即使你信任他（或他自称诚信），**酿成如此大祸，信任又有何用？ 此爻是 对德不配位、力不胜任者的严厉警告，也是 “鼎新”过程中最需防范的风险：**若将 关键职位（鼎足） 授予 无能之辈，将导致 整个事业（公餗）的倾覆。


### 六五：鼎黄耳金铉，利贞。


**原文**：鼎黄耳金铉，利贞。

**白话**：鼎配以黄色的鼎耳和金属的鼎杠，利于守持正固。

**小象传**
**原文**：“鼎黄耳”，中以为实也。

**白话**：鼎卦中“鼎耳呈黄色”的爻辞，象征着居中而能充实自身。


**说明**

这是 鼎新的核心——虚怀纳贤，刚柔相济。

+ “鼎黄耳，金铉”：鼎配以黄色的鼎耳（鼎黄耳），金属的鼎杠（金铉）。
+ “利贞”：利于守持正固（利贞）。
+ 爻传“鼎黄耳，中以为实也”：鼎配以黄色的鼎耳，是因为（六五）以中道为实。

**相关性**：六五阴柔居中，居尊位，是 鼎新事业的领导者。“黄”为 中色，象征 中庸、尊贵；“金”为 刚坚 之物。“鼎耳”是 贯铉以举鼎的部件，象征 领导者接纳贤才的“耳朵”与渠道；“铉”是 举鼎的杠子，象征 提拔、任用贤才的“手段”与“力量”。爻辞说：鼎（新秩序） 配备了 尊贵而中庸的鼎耳（黄耳） 和 坚固有力的金杠（金铉）。这比喻 领导者（六五） 自身 柔顺虚心（阴爻），但能 以中道为实（中以为实），建立尊贵而畅通的渠道（黄耳） 来 接纳贤才（耳以听），并 以刚健有力的方式（金铉） 来 举用他们。如此，则 利于长久守持这份鼎新的事业（利贞）。此爻阐述了 领导鼎新的关键：**领导者不必事事躬亲（阴柔），但必须 具备中庸之德，并善于建立机制、任用刚贤 来 成就大业。


### 上九：鼎玉铉，大吉，无不利。


**原文**：鼎玉铉，大吉，无不利。

**白话**：鼎配以玉制的鼎杠，大为吉祥，无所不利。

**小象传**
**原文**：玉铉在上，刚柔节也。

**白话**：玉制的鼎铉高居在上，象征着刚强与柔顺相互调节。


**说明**

这是 鼎新的终点——功成器成，温润高洁。

+ “鼎玉铉”：鼎配以玉制的鼎杠（鼎玉铉）。
+ “大吉，无不利”：至为吉祥（大吉），无所不利（无不利）。
+ 爻传“玉铉在上，刚柔节也”：玉制的鼎杠在上位，是因为刚柔有节。

**相关性**：上九阳刚处卦之极，是 鼎新事业的完成与升华者。“玉”兼具 刚坚（质地硬） 与 温润（光泽柔） 的双重美德，是 比“金”更高级、更完美的象征。“玉铉”意味着 举鼎（任用贤才、推行新政）的“手段” 达到了 刚柔并济、温文尔雅、尽善尽美的境界。此时，鼎新大业圆满完成，其 制度与文教（玉铉） 不仅 有效有力，而且 充满文明的光辉与和谐的节律（刚柔节）。故 至为吉祥，无所不利。此爻是 对鼎新事业最高成就的描绘：**它不仅是 稳固和有效的，更是 文明、高雅、和谐的，代表了 一种理想的社会政治状态。


## 总结

**总结**：鼎卦的现代启示

鼎卦的 “正位凝命” 是关于 “巩固、建设、养贤”的构建哲学，它是 革卦的必然延续，教导我们 在破旧之后，如何立新，并使之稳固、繁荣、文明。

实现鼎新事业的六个环节：

+ 除旧奠基（初六）：鼎颠趾，利出否，得妾以其子。
+ 才德充积（九二）：鼎有实，我仇有疾，不我能即，吉。
+ 小有阻逆（九三）：鼎耳革，其行塞，雉膏不食，方雨亏悔，终吉。
+ 力小任重（九四）：鼎折足，覆公餗，其形渥，凶。
+ 虚中纳贤（六五）：鼎黄耳，金铉，利贞。
+ 功成德美（上九）：鼎玉铉，大吉，无不利。

核心心法：大象传总纲——“木上有火，鼎；君子以正位凝命。” 这意味着：

+ “木上有火，鼎”：是 鼎卦之象（以木生火，烹物于鼎）。
+ “君子以正位凝命”：君子效法此象，端正职位，严守使命。

这是 鼎卦精神的灵魂。“正位”指 使每个人（尤其是领导者）都居于恰当的位置，各司其职，如同 鼎之三足，稳固支撑。“凝命”指 凝聚、巩固天命（或重大使命），使之 不可动摇。君子从“鼎”的稳固与养人功能中领悟到：**在变革之后，**首要任务是 “立”——**建立 稳固的权力结构（正位） 和 崇高的价值目标（凝命），并 通过“鼎”的烹煮功能，培育人才（养贤），化生新的文明成果。这体现了 从“破”到“立”，从“革命”到“建设”的完整政治智慧。

根本精神：彖传 “鼎，象也。以木巽火，亨饪也。圣人亨以享上帝，而大亨以养圣贤。巽而耳目聪明，柔进而上行，得中而应乎刚，是以元亨。” 揭示了鼎道的多重崇高价值：

+ “圣人亨以享上帝，而大亨以养圣贤”：圣人用鼎烹煮食物来祭祀上帝，用丰盛的食物来供养圣贤。这指出了 鼎的两大神圣用途：**一是 沟通天人（享上帝），代表 精神信仰与礼仪的巩固；二是 养育贤才（养圣贤），代表 物质基础与人才队伍的巩固。二者是 新秩序得以长治久安的根本。
+ “巽而耳目聪明”：（下卦）巽顺而（上卦离）使耳目聪明。指 **新秩序下，**领导者 谦逊纳谏（巽），因而 明察秋毫（耳目聪明）。
+ “是以元亨”：所以至为亨通。

鼎卦告诉我们：**“鼎”是 秩序、文明与繁荣的象征。一个成功鼎新的社会，必定是 职位端正、使命凝聚（正位凝命） 的，是 信仰崇高、贤才得养（享上帝、养圣贤） 的，是 上下沟通顺畅、政治清明（巽而耳目聪明） 的。其 最高境界 是 上九爻的“玉铉”——刚柔有节，温润文明。这便是在 “木上有火” 的烹任景象中，所寄托的 **关于 建国立业、礼乐文明、天下太平 的终极理想。
