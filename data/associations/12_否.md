# 否卦（乾上坤下）

**卦画**：䷋

## 总论：闭塞的哲学

**核心短词**：“大往小来”

**卦象**：上乾（☰）为天、为刚健，下坤（☷）为地、为顺。天地否。天本在上而愈上，地本在下而愈下，二者背道而驰，阴阳隔绝，不相交通。

**核心卦辞**：“否之匪人，不利君子贞。大往小来。”

**总纲**：否卦描绘了 天地不交、上下隔绝、万物闭塞 的至暗局面。

+ “否”：闭塞、阻隔、黑暗。
+ “否之匪人”：闭塞的时代，是 人道不通、非人之境。
+ “不利君子贞”：不利于君子 守持正道、有所作为。
+ “大往小来”：阳刚君子（大）往外离去（往），阴柔小人（小）来内掌权（来）。与泰卦完全相反。

**本质**：否卦的核心是 “隔绝”与“守静”。它揭示了当系统内部 上下失联、正气消退、邪气充斥 时，整个局面将陷入停滞与黑暗。此时，君子之道难以施行，强行作为必受其害。卦辞的核心智慧是 “俭德辟难，不可荣以禄”——收敛德行以避祸，不可追求荣华禄位。

## 卦辞



### 经

**原文**：否之匪人，不利君子贞，大往小来。

**白话**：闭塞不通的时代，人道不行，不利于君子守持正固，阳刚（君子）往外，阴柔（小人）来内。

### 彖传

**原文**：“否之匪人，不利君子贞，大往小来”，则是天地不交而万物不通也，上下不交而天下无邦也。内阴而外阳，内柔而外刚，内小人而外君子。小人道长，君子道消也。

**白话**：《否》卦所说的“否闭之世违背人道，不利于君子持守正道，此时刚大者往外、柔小者来内”，指的是天地阴阳不交感而万物生长阻滞，上下隔绝不相沟通而天下分崩离析。卦象内里属阴而外表属阳，内里柔顺而外表刚强，内里是小人而外表是君子。这表明小人之道日益滋长，君子之道日渐消退。

### 大象传

**原文**：天地不交，否；君子以俭德辟难，不可荣以禄。

**白话**：天地之气不相交融，象征闭塞不通；君子因此收敛才德以避开危难，不可追求荣华禄位。


## 爻辞

### 初六：拔茅茹，以其汇，贞吉，亨。


**原文**：拔茅茹，以其汇，贞吉，亨。

**白话**：拔起茅草，根系牵连同类，守正吉祥，亨通。

**小象传**
**原文**：“拔茅贞吉”，志在君也。

**白话**：拔除茅草，守正得吉，是因为心志向着君王。


**说明**

这是 闭塞的初现——同类牵连。

+ “拔茅茹，以其汇”：与泰卦初九爻辞相同，拔茅草时根须相连，同类一并带起。
+ “贞吉亨”：守持正道（贞） 则吉祥亨通。
**相关性**：否卦之初，三阴在下（初六、六二、六三），象征小人势力开始聚集。初六作为开端，其行动也会 牵连同类小人（六二、六三）一同得势。但爻辞却告诫“贞吉亨”，这是对 处于此位的个人 而言：即便身处小人开始得势的环境，只要你 个人坚守正道（贞），不与之同流合污，依然可以获得吉祥和内心的亨通。这是 乱世中的个人守则。


### 六二：包承，小人吉，大人否，亨。


**原文**：包承，小人吉，大人否，亨。

**白话**：包容承顺，小人吉祥，大人闭塞，但可亨通。

**小象传**
**原文**：“大人否亨”，不乱群也。

**白话**：大人物身处闭塞时也能亨通，是因为他不与小人为伍。


**说明**

这是 闭塞的深化——小人得势。

+ “包承”：被包容（包）并承受奉承（承）。指小人（六二）用柔媚手段取悦上位者（九五）。
+ “小人吉”：小人（六二） 因此得吉。
+ “大人否亨”：但 君子大人 则 闭塞不通（否亨）。
**相关性**：六二柔顺中正，本是好爻，但在否卦的大环境下，其“柔顺”表现为 谄媚逢迎。此爻清晰揭示了否世的特征：善于阿谀奉承的小人（包承）左右逢源，获得好处（吉）；而正直的君子（大人）则被排挤，寸步难行（否亨）。这是对世道不公的直白描述。


### 六三：包羞。


**原文**：包羞。

**白话**：包容羞耻。

**小象传**
**原文**：“包羞”，位不当也。

**白话**：蒙受羞辱，是因为所处的位置不恰当。


**说明**

这是 闭塞的耻辱——妄求招辱。

+ “包羞”：（因妄求包容而）招致羞辱。
+ 爻传“位不当也”：因为 所处位置不正当（阴居阳位）。
**相关性**：六三不中不正，象征 德才皆劣的小人。在否世中，它也想向上（上九）攀附求容，但因其 位不当、质更劣，非但求而不得，反而 自取其辱（包羞）。此爻描绘了小人群体中，那些 更为不堪者 的丑态和下场。


### 九四：有命无咎，畴离祉。


**原文**：有命无咎，畴离祉。

**白话**：奉行天命没有咎害，同类共受福泽。

**小象传**
**原文**：“有命无咎”，志行也。

**白话**：有天命安排，没有灾祸，这是心志得以施行。


**说明**

这是 闭塞的松动——奉命而动。

+ “有命”：得到（正确的）命令（来自九五之君）。
+ “无咎”：没有过错。
+ “畴离祉”：同类（畴） 都能 依附（离，通“丽”） 而获得 福泽（祉）。
**相关性**：九四已进入上卦（乾），是 君子力量在否世中的代表。但它处于近君多惧之位，不可妄动。爻辞指出，在否世中，君子若想有所作为而不惹祸，必须 等待并遵从来自上层（九五）的明确指令（有命）。如此，不仅能自身无咎，还能 带领其他君子（畴）一起获得转机（离祉）。这是 在黑暗中保存实力、等待时机的智慧。


### 九五：休否，大人吉。其亡其亡，系于苞桑。


**原文**：休否，大人吉。其亡其亡，系于苞桑。

**白话**：止息闭塞，大人吉祥。心中常念“将要灭亡，将要灭亡”，就能像系结于丛生的桑树一样牢固。

**小象传**
**原文**：大人之吉，位正当也。

**白话**：大人之所以吉祥，是因为他所处的位置正当合适。


**说明**

这是 闭塞的扭转——中正惕惧。

+ “休否”：闭塞的局面暂时休止（休）。
+ “大人吉”：刚健中正的君子（大人，指九五） 得吉。
+ “其亡其亡，系于苞桑”：心中不断念着 “要灭亡了！要灭亡了！” ，（国家）才能像 系在根深叶茂的桑丛（苞桑） 上一样稳固。
**相关性**：九五阳刚中正，居尊位，是 否世中拨乱反正的希望。他能使否运暂停（休否），故“大人吉”。但爻辞的精髓在于后半句：真正的安全，来自于极度的危机感。只有时刻怀有 “其亡其亡” 的警惕，戒慎恐惧，奋发图强，才能巩固根基，避免重蹈覆辙。这是 治国、立身的永恒真理。


### 上九：倾否，先否后喜。


**原文**：倾否，先否后喜。

**白话**：倾覆闭塞的局面，先有闭塞，后有欣喜。

**小象传**
**原文**：否终则倾，何可长也。

**白话**：坏运到了头就会翻转，怎么可能长久不变呢。


**说明**

这是 闭塞的终结——否极泰来。

+ “倾否”：倾覆（倾）闭塞的局面（否）。
+ “先否后喜”：先经历闭塞（否），然后才有喜悦（喜）。
**相关性**：上九处否卦终极，物极必反，闭塞到了极点，必然被倾覆。此爻给身处否世的人们以 最大的希望：黑暗终将过去，光明必会到来（先否后喜）。它揭示了 “否”与“泰”相互转化 的客观规律，鼓励人们 在至暗时刻坚守希望。


## 总结

**总结**：否卦的现代启示
否卦的 “大往小来” 深刻剖析了 组织僵化、沟通断绝、正气不彰、小人当道 的困境及生存、转化之道。

识别阶段：清醒认识自己处于 “否塞期”。特征是：上情不能下达，下情无法上达，好人受气，小人得志。

生存策略：

+ 底层（初六）：个人坚守正道（贞），不与浊流同污，可保内心安宁与人格吉祥。
+ 中层（六二、六三）：警惕成为 阿谀者（包承） 或 献丑者（包羞）。
+ 高层（九四）：等待正确指令（有命），不擅自行动，并团结同道（畴），保存实力。

+ 扭转关键（九五）：需要出现 刚健中正、心怀惕惧（其亡其亡）的领导者，方能暂停否运，并靠 持续的危机感 来巩固根基。
+ 终极规律（上九）：坚信 否极泰来 的规律。最黑暗时，光明也就不远了（先否后喜）。这给予人们 穿越周期的信心。
+ 核心心法：卦辞总纲——“俭德辟难”。收敛锋芒，俭省德行，避免招摇，以避祸端。

否卦与泰卦的承续：泰卦（䷊）与否卦（䷋）是 完全相反的一对，代表了事物发展的 两个极端状态。泰卦讲 “通达”（小往大来），否卦讲 “闭塞”（大往小来）。两者相续，深刻揭示了 物极必反、循环往复 的宇宙规律：泰极否来，否极泰来。从泰到否，是从 巅峰跌入谷底 的必然过程；而从否中，又孕育着新的泰的生机（上九“倾否”）。这两卦共同教导我们：在顺境中要防否（泰卦九三），在逆境中要待泰（否卦上九）。
