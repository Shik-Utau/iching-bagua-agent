# 随卦（兑上震下）

**卦画**：䷐

## 总论：随从的哲学

**核心短词**：“向晦入宴息”

**卦象**：上兑（☱）为泽、为悦，下震（☳）为雷、为动。泽雷随。雷震于泽下，泽水随雷而动；内怀动力（震），外显愉悦（兑），故能使人追随。

**核心卦辞**：“随，元亨利贞，无咎。”

**总纲**：随卦探讨 “追随”与“被追随” 的智慧。如何选择正确的对象去追随，以及如何让他人自愿追随自己。

+ “随”：随从、跟随、随和。
+ “元亨利贞”：具备创始、亨通、有利、贞固这 四种美德，是“随”能成功的根本。
+ “无咎”：如此则没有过错。

**本质**：随卦的核心是 “随时之义” 与 “动而悦”。它强调追随之道必须 顺应时势（随时），同时，真正的追随是 内心愉悦（悦）地跟随正确的行动（动）。其最高境界是 “君子以向晦入宴息”——懂得在黄昏时入室休息，象征 顺应自然规律与生活节律，该动则动，该息则息。

## 卦辞



### 经

**原文**：元亨，利贞，无咎。

**白话**：至为亨通，利于守持正固，没有咎害。

### 彖传

**原文**：随，刚来而下柔，动而说，随。大亨贞无咎，而天下随时。随时之义大矣哉！

**白话**：随卦，是阳刚者前来谦居于阴柔者之下，自身行动而使人愉悦，所以称为随从。大为亨通，持守正道没有灾祸，于是天下万物都随从适宜的时机。随从时机的意义真是重大啊！

### 大象传

**原文**：泽中有雷，随；君子以向晦入宴息。

**白话**：水泽中响动着雷声，象征随从；君子因此随着天色向晚而回家休息。


## 爻辞

### 初九：官有渝，贞吉。出门交有功。


**原文**：官有渝，贞吉。出门交有功。

**白话**：思想观念有改变，守正吉祥。出门与人交往能获成功。

**小象传**
**原文**：“官有渝”，从正吉也。“出门交有功”，不失也。

**白话**：官职虽有变动，只要遵从正道就会吉祥。出门与人交往能够获得成功，是因为没有偏离正道。


**说明**

这是 随从的起点——变通守正。

+ “官有渝”：职责、职位（官）发生变动（渝）。
+ “贞吉”：守持正道 则吉祥。
+ “出门交有功”：走出门去（出门）与人交往（交），会建立功绩。
**相关性**：初九阳刚在下，是 追随行动的发起者。“官有渝”象征 时势变化带来的机遇或挑战。此时，正确的“随”之道是：内心坚守原则（贞），但行动上要灵活变通，主动走出原有的小圈子（出门），去与外界（尤其是九四）广泛交流（交）。如此，才能在新的环境中建立功业。这强调了 “随”不是被动跟从，而是主动适应时变的积极选择。


### 六二：系小子，失丈夫。


**原文**：系小子，失丈夫。

**白话**：系恋于小子（初九），失去丈夫（九五）。

**小象传**
**原文**：“系小子”，弗兼与也。

**白话**：拴住了小人物，就不能同时兼顾其他人了。


**说明**

这是 随从的抉择——舍小从大。

+ “系小子”：系缚、依附于小人（小子）（指初九）。
+ “失丈夫”：就会 失去大人物、君子（丈夫）（指九五）。
+ 爻传“弗兼与也”：因为 不能同时兼顾两者。
**相关性**：六二柔顺中正，本应与九五（丈夫）正应，追随君王。但它距离初九（小子）很近，易受其影响。此爻尖锐指出：在追随的选择上，常常面临“鱼与熊掌不可兼得”的困境。若因眼前便利或私情而依附了错误的对象（小子），就会错失真正值得追随的伟岸人物（丈夫）。这是对 目光短浅、因小失大 的严重警告。


### 六三：系丈夫，失小子。随有求得，利居贞。


**原文**：系丈夫，失小子。随有求得，利居贞。

**白话**：系恋于丈夫（九四），失去小子（初九）。随从于人，有求必得，利于安居守正。

**小象传**
**原文**：“系丈夫”，志舍下也。

**白话**：心系于阳刚的丈夫，是决意舍弃在下位的阴柔小人。


**说明**

这是 随从的正道——从阳守静。

+ “系丈夫”：依附于大人物、君子（丈夫）（指九四）。
+ “失小子”：失去小人（小子）（指初九）。
+ “随有求得”：追随（随）而有所求，必能获得。
+ “利居贞”：利于 安居、守持正道。
**相关性**：六三与六二相反，它选择了向上追随阳刚的九四（丈夫），而疏远了初九（小子）。这是 明智的抉择。因为追随强者（丈夫）和正道，目标容易达成（有求得）。但爻辞同时提醒：在“求得”之后，要 懂得安居，持守正道（利居贞），不可得意忘形，贪求无厌。这体现了 “随”而有节 的智慧。


### 九四：随有获，贞凶。有孚在道，以明，何咎？


**原文**：随有获，贞凶。有孚在道，以明，何咎？

**白话**：随从于人而有所获，守正以防凶险。心怀诚信，合乎正道，行事光明，哪会有咎害？

**小象传**
**原文**：“随有获”，其义凶也。“有孚在道”，明功也。

**白话**：追随别人而有所收获，这意思是凶险的。“心怀诚信而坚守正道”，这是为了彰显功业。


**说明**

这是 随从的险境——功高震主。

+ “随有获”：追随（于九五）而大有所获（指权力、声望）。
+ “贞凶”：即使 动机纯正（贞），也有 凶险。
+ “有孚在道，以明，何咎”：但只要 心怀诚信（有孚），行事合乎正道（在道），光明磊落（以明），又有什么过错呢？
**相关性**：九四是大臣之位，追随君王（九五）而功勋卓著，威望极高（随有获）。这极易引起君王的猜忌，故即使忠心耿耿（贞），也有“功高震主”之凶。化解此凶的唯一方法，就是 极致的“有孚在道，以明”——让忠诚与正道 发自内心且公开透明，毫无私心与隐瞒，使上下都看得明白。如此，方能消除疑虑，转凶为无咎。此爻揭示了 高层追随者（重臣）的独特风险与生存法则。


### 九五：孚于嘉，吉。


**原文**：孚于嘉，吉。

**白话**：诚信施于美善之人，吉祥。

**小象传**
**原文**：“孚于嘉吉”，位正中也。

**白话**：心怀诚信又受到嘉奖而获得吉祥，是因为居位端正而守中道。


**说明**

这是 被追随的核心——诚待善者。

+ “孚于嘉”：以 诚信（孚） 对待 美善、贤能之人（嘉）。
+ “吉”：吉祥。
+ 爻传“位正中也”：因为 居于正中尊位。
**相关性**：九五阳刚中正，居君位，是 众人追随的对象。他如何使天下人诚心追随？关键在于 “孚于嘉”——不是对所有人无差别信任，而是 将诚信特别施予那些品德美善、才能出众的贤者（嘉，指六二）。如此，既能赢得贤者的真心辅佐，也能向天下昭示自己 亲贤臣、远小人的明确态度，从而吸引更多贤者来随。这是 领袖凝聚人心的最高明手腕。


### 上六：拘系之，乃从维之。王用亨于西山。


**原文**：拘系之，乃从维之。王用亨于西山。

**白话**：拘禁强系，又用绳索捆绑。君王（以此诚敬）祭祀于西山。

**小象传**
**原文**：“拘系之”，上穷也。

**白话**：用绳索捆绑拘禁起来，是因为处于上位者已经无路可走了。


**说明**

这是 随从的终极——诚感顽冥。

+ “拘系之，乃从维之”：强行拘禁捆缚（拘系）他，才能（乃）用绳索层层拴住（维）使他跟随。
+ “王用亨于西山”：君王（王）因此在西山举行祭祀（亨）（以示诚心感格上天与先祖）。
+ 爻传“上穷也”：因为 处在上位而穷困无应。
**相关性**：上六处卦之极，穷极无应，象征 极度孤高、冥顽不化、难以追随（或被追随）者。对于这种人，普通的感召（悦）已无效，有时甚至需要 用强制手段（拘系） 先将其纳入正轨。但强制并非目的，君王随后在西山虔诚祭祀，表明其 最终目的仍是以至诚之心去感化。此爻揭示了 “随”道的边界与无奈：对于极少数顽冥者，需 恩威并施，先以力制，再以诚化。


## 总结

**总结**：随卦的现代启示
随卦的 “向晦入宴息” 是关于 个人选择、团队建设与领导力 的深邃智慧。

追随者的智慧：

+ 应变（初九）：主动适应变化（官有渝），积极向外寻求（出门交）。

+ 抉择（六二、六三）：眼光要远，要追随真正的强者与正道（丈夫），而非眼前便利（小子）。追随成功后要 懂得知足守正（利居贞）。

被追随者的法则（九五）：领导者要 以诚信专门对待贤能之士（孚于嘉），以此树立标杆，吸引人才。
特殊情境：

功高者（九四）：必须 极度坦诚、光明正大（有孚在道，以明） 以避祸。
顽固者（上六）：有时需要 先以强力规范，再以诚意感化，恩威并施。

核心心法：大象传总纲——“君子以向晦入宴息”。这意味着要 深刻懂得并顺应时势、规律与节奏。该追随时积极追随（动而悦），该休息时安心休息（入宴息）。“随时之义”是“随”道的灵魂。

随卦与豫卦的承续：豫卦（䷏）讲 “和乐奋动”（顺以动），是 团队和谐、士气高昂的状态；随卦（䷐）则讲 “心悦诚服”（动而悦），是 这种状态下自然产生的追随与归属行为。《序卦传》言：“豫必有随，故受之以随。” 意思是：安乐和悦（豫）的局面，必然会使人心生向往，有人追随（随）。因此，豫是随之因，随是豫之果。一个能带来愉悦和价值的领导者（豫卦九四），自然能吸引追随者（随）。从豫到随，体现了 从“创造价值”到“凝聚人心” 的领导力闭环。
