# 明夷卦（坤上离下）

**卦画**：䷣

## 总论：黑暗时刻的哲学

**核心短词**：“用晦而明”

**卦象**：上坤（☷）为地、为暗，下离（☲）为火、为日、为明。地火明夷。日落地下，明入地中，光明受伤，黑暗降临。

**核心卦辞**：“利艰贞。”

**总纲**：明夷卦象征 “光明殒伤、黑暗时期”，利于在艰难中守持正固。

+ “利艰贞”：利于（利）在艰难（艰）中守持正固（贞）。这是全卦的 生存法则。在黑暗、压抑、小人当道的环境中，君子必须 忍辱负重，坚守正道，等待黎明。

**本质**：明夷卦与晋卦（䷢）互为综卦（颠倒）。晋卦是 日出地上（晋升），明夷卦是 日落地下（衰落）。光明（离）被大地（坤）遮蔽，象征 贤者被伤害，正义被压制，时代昏暗。其**核心精神**是：在至暗时刻，如何 保全自身，坚守内心光明，并智慧地应对，以待天时。

## 卦辞



### 经

**原文**：利艰贞。

**白话**：利于在艰难中守持正固。

### 彖传

**原文**：明入地中，明夷。内文明而外柔顺，以蒙大难，文王以之。利艰贞，晦其明也。内难而能正其志，箕子以之。

**白话**：光明隐入大地之中，这就是明夷卦的象征。内心保持文明美德，外表展现柔顺姿态，以此承受重大磨难，周文王正是这样做的。利于在艰难中坚守正道，因为此时需要暂时掩藏光芒。身处内部困境而能端正心志，箕子正是这样做的。

### 大象传

**原文**：明入地中，明夷；君子以莅众，用晦而明。

**白话**：光明隐入大地之中，这就是明夷卦的意象；君子由此领悟，在治理众人时，要善于收敛自己的明察，看似隐晦，实则能更清明地洞悉事理。


## 爻辞

### 初九：明夷于飞，垂其翼。君子于行，三日不食。有攸往，主人有言。


**原文**：明夷于飞，垂其翼。君子于行，三日不食。有攸往，主人有言。

**白话**：光明殒伤时向外飞翔，低垂着翅膀。君子急于远行，多日顾不上饮食。有所前往，所遇主人会有责言。

**小象传**
**原文**：“君子于行”，义不食也。

**白话**：君子在旅途中奔波，是因为道义而不接受俸禄。


**说明**

这是 黑暗的初临——识微远遁。

+ “明夷于飞，垂其翼”：光明殒伤时（明夷）飞翔（于飞），低垂（垂）翅膀（其翼）。
+ “君子于行，三日不食”：君子（君子）远行（于行），多日（三日）没有吃食（不食）。
+ “有攸往，主人有言”：有所前往（有攸往），主人（主人）会有责言（有言）。
+ 爻传“君子于行，义不食也”：君子远行，是道义（义）使他顾不上吃食（不食）。

**相关性**：初九阳刚处下，是 黑暗初现时最先感知的君子。“飞”象征 迅速离开；“垂其翼”比喻 收敛锋芒，低调潜行。“三日不食”形容 行程仓促艰辛，但为道义（避祸）而甘之如饴。“主人有言”指 出逃可能遭到当权者（主人）的批评或误解。爻传强调这是 “义不食也”——为了道义而做出的选择。此爻描绘了 **智者于乱世初显时的决断：见微知著，不待祸至，毅然隐退。虽受委屈，但保住了根本。


### 六二：明夷，夷于左股，用拯马壮，吉。


**原文**：明夷，夷于左股，用拯马壮，吉。

**白话**：光明殒伤，左腿受伤，用强壮的马来拯救，可获吉祥。

**小象传**
**原文**：六二之吉，顺以则也。

**白话**：六二爻之所以吉祥，是因为它既柔顺又遵循了法则。


**说明**

这是 黑暗的受伤——得助脱险。

+ “明夷，夷于左股”：光明殒伤（明夷），伤（夷）在左大腿（左股）。
+ “用拯马壮，吉”：用（用）强壮（壮）的马来拯救（拯），可获吉祥（吉）。
+ 爻传“六二之吉，顺以则也”：六二的吉祥（吉），是因为柔顺（顺）而遵循法则（以则）。

**相关性**：六二柔顺中正，是 黑暗时期受伤的贤臣。“左股”是 非关键部位，象征 受伤但未危及生命或根本。“拯马”比喻 外部的强力援助（可能是正直的同僚或某种有利条件）。爻辞指出：在受伤时，若能 借助强大的外力（马壮）及时拯救，则可转危为安，获得吉祥。爻传点明原因：得益于其 柔顺而守则（顺以则） 的品德，故能得人相助。此爻强调：**在困境中，自身的柔顺与守正（则）是获救的内在基础，而 善用外援是脱险的关键。


### 九三：明夷于南狩，得其大首，不可疾贞。


**原文**：明夷于南狩，得其大首，不可疾贞。

**白话**：在光明殒伤时往南方征伐，俘获元凶首恶，但不可操之过急，要守持正固。

**小象传**
**原文**：南狩之志，乃大得也。

**白话**：向南方征伐的志向，是为了大展宏图，获得丰硕成果。


**说明**

这是 黑暗的反击——除害有度。

+ “明夷于南狩”：光明殒伤时（明夷）在南方（南）征伐（狩）。
+ “得其大首”：俘获（得）元凶（其大首）。
+ “不可疾贞”：不可操之过急（不可疾），须守持正固（贞）。
+ 爻传“南狩之志，乃大得也”：南方征伐的志向（志），乃有大收获（大得）。

**相关性**：九三阳刚处下卦之极，与上六相应。象征 在黑暗时代，身处下位而刚毅的君子。“南”是 光明方位（离方），“狩”是 除害之举。爻辞描述：君子在黑暗中期盼光明（南），并采取行动清除祸首（得其大首）。但特别告诫：“不可疾贞”——**不可急于求成，行动必须 稳健、有节、合乎正道（贞）。爻传“乃大得也”肯定其 志向与行动的正当性与潜在成果。此爻说明：**在黑暗中反抗邪恶是正义的，但必须 讲究策略，避免因急躁而失败或引发更大混乱。


### 六四：入于左腹，获明夷之心，于出门庭。


**原文**：入于左腹，获明夷之心，于出门庭。

**白话**：进入左方腹地，获悉光明殒伤的内情，于是毅然走出门庭。

**小象传**
**原文**：“入于左腹”，获心意也。

**白话**：进入左腹，是为了探明内心的真实想法。


**说明**

这是 黑暗的核心——知险速离。

+ “入于左腹”：进入（入于）左腹（左腹）。
+ “获明夷之心”：获悉（获）光明殒伤的内情（明夷之心）。
+ “于出门庭”：于是（于）离开（出）门庭（门庭）。
+ 爻传“入于左腹，获心意也”：进入左腹，是获悉了（黑暗的）真实心意。

**相关性**：六四阴柔，已进入上卦坤（黑暗）体，且逼近君位（六五）。象征 处于黑暗权力核心附近的臣子。“左腹”比喻 核心圈的非关键位置，“心”比喻 黑暗的真相与意图。爻辞描述：**此人 得以接近黑暗核心，洞悉了其险恶用心（获明夷之心）。在认清无可救药后，毫不犹豫地抽身离去（于出门庭）。爻传“获心意也”强调 “知” 是“行”的前提。此爻展现了 **另一种智慧：深入虎穴以知真情，知不可为则断然舍离。这是 在污浊环境中保持清白的决绝。


### 六五：箕子之明夷，利贞。


**原文**：箕子之明夷，利贞。

**白话**：像箕子那样处于光明殒伤之时，利于守持正固。

**小象传**
**原文**：箕子之贞，明不可息也。

**白话**：箕子坚守正道，说明光明不会熄灭。


**说明**

这是 黑暗的君侧——佯狂守志。

+ “箕子之明夷”：像箕子（箕子）那样处于光明殒伤时（明夷）。
+ “利贞”：利于守持正固（利贞）。
+ 爻传“箕子之贞，明不可息也”：箕子的守正（贞），说明光明（明）不可熄灭（不可息）。

**相关性**：六五阴柔居尊，是 黑暗时代的君主（商纣） 之位。但爻辞不取君象，而取 箕子（纣王叔父，贤臣）之象。箕子在纣王暴政下，为保全宗庙、延续文明，佯装疯癫，披发为奴，但内心坚守正道。爻辞以箕子为典范，指出：**在至暗的君主身边，最大的智慧就是 “利贞”——以各种方式（包括装疯）守持内心的光明与正道，使之不灭。爻传“明不可息也”是 全卦的点睛之笔，宣告：**外在的黑暗可以压制光明，但 内心的光明（正道、理想）是永远不可熄灭的。此爻是 明夷卦的精神内核，给出了 在绝境中保存希望的最高典范。


### 上六：不明晦，初登于天，后入于地。


**原文**：不明晦，初登于天，后入于地。

**白话**：不发出光明反而带来黑暗，起初升登于天，最终坠落于地。

**小象传**
**原文**：“初登于天”，照四国也。“后入于地”，失则也。

**白话**：开始升到天上，光芒普照四方各国。后来坠入地下，是因为背离了正确的法则。


**说明**

这是 黑暗的终结——自取灭亡。

+ “不明晦”：不光明（不明）反而晦暗（晦）。
+ “初登于天，后入于地”：起初（初）升登于天（登于天），后来（后）坠入地下（入于地）。
+ 爻传“初登于天，照四国也；后入于地，失则也”：起初登天，曾照耀四方；后来入地，是因为丧失法则。

**相关性**：上六阴柔处卦之极，是 黑暗的顶点，象征昏君（如纣王）。“不明晦”直接定义其本质：本身并非光明（不明），而是制造晦暗（晦）的源头。“初登于天”比喻 其曾居高位，拥有权势；“后入于地”预言 其必将败亡，坠入深渊。爻传揭示了原因：**起初能“照四国”，是 依仗其位（而非其德）；最终“失则”，是因为 完全背离了天道法则。此爻是 对黑暗统治者的最终审判，说明 **违背光明、倒行逆施者，无论一时多么显赫，终将 被天道抛弃，彻底覆灭。同时也暗示 黑暗的极点，就是光明的转折点。


## 总结

**总结**：明夷卦的现代启示

明夷卦的 “用晦而明” 是关于 在逆境、挫折、不公或黑暗时代，如何生存、坚守并等待转机的深刻智慧。

黑暗中的六种处境与选择：

+ 见机速退（初九）：垂翼远行，义不食也。
+ 受伤得救（六二）：借马拯伤，顺以则也。
+ 除暴宜缓（九三）：南狩得首，不可疾贞。
+ 知密而遁（六四）：获心出门，知险速离。
+ 守正存明（六五）：箕子之贞，明不可息。
+ 黑暗之极（上六）：登天入地，失则而亡。

核心心法：大象传总纲——“明入地中，明夷；君子以莅众，用晦而明。” 这意味着：

+ “明入地中，明夷”：是 明夷卦之象（光明隐入地下，世道昏暗）。
+ “君子以莅众，用晦而明”：君子效法此象，在治理众人时，外示晦暗，内守光明。

这是 明夷卦精神的灵魂：**“用晦”是 外在的生存策略（韬光养晦，和光同尘）；“而明”是 内在的不可动摇的原则（内心光明，坚守正道）。它教导我们：**在不利环境中，要善于隐藏锋芒（用晦），以保护内心的光明与志向（而明）。这不是懦弱，而是 极高明的韧性生存智慧。

根本精神：彖传 “明入地中，明夷。内文明而外柔顺，以蒙大难，文王以之。利艰贞，晦其明也。内难而能正其志，箕子以之。” 举了两位圣贤为例：

+ “文王以之”：周文王 内怀文明之德，外示柔顺之态，以此度过被纣王囚禁的“大难”。这是 “用晦”的典范。
+ “箕子以之”：箕子 身处朝廷内部患难（内难）中，却能端正心志，守持正道。这是 “而明”的典范。

明夷卦将 “利艰贞” 的哲学，具象化为文王的 “外柔顺” 和箕子的 “内正志”。它告诉我们：**黑暗终将过去（上六“入于地”即是黑暗的终结），关键在于 在黑暗中保存火种，在艰难中砥砺心志。无论个人遭遇不公，还是社会经历动荡，此卦都给予我们 在绝望中寻找希望、在压抑中保持尊严的力量与方法。
