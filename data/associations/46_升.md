# 升卦（坤上巽下）

**卦画**：䷭

## 总论：上升之道的哲学

**核心短词**：“积小以高大”

**卦象**：上坤（☷）为地、为顺，下巽（☴）为风、为木。地风升。地中生木，顺势而升。

**核心卦辞**：“元亨。用见大人，勿恤。南征吉。”

**总纲**：升卦象征 “上升、发展”，至为亨通。宜于出现大德之人，不必忧虑。向南方进发可获吉祥。

+ “元亨”：上升之势，本身就具备至为亨通的基因。
+ “用见大人，勿恤”：宜于（用）出现大德之人（见大人），不必忧虑（勿恤）。在上升的过程中，需要有德才兼备的领导者（大人）来引导方向、凝聚力量，如此则前途光明，无需担忧。
+ “南征吉”：向南方（南）进发（征）可获吉祥（吉）。“南”在八卦中对应 “离”卦，象征光明、文明。这不仅是方位指引，更是 战略方向：上升之道，应朝向光明、文明的方向前进，如此才能获得吉祥。

**本质**：升卦是萃卦的覆卦，描述 “柔以时升” 的状态。下巽木（为入、为顺），上坤地（为顺），树木从大地中生长，柔顺而适时地上升。其**核心精神**是：**探讨 事物如何顺应时势、遵循规律，实现稳健、持续的发展与晋升。它强调 积累（积小）、顺势（巽而顺）、得助（刚中而应）、方向正确（南征）。

## 卦辞


### 经

**原文**：元亨。用见大人，勿恤，南征吉。

**白话**：至为亨通。宜于出现大德之人，不必忧虑，向南方进发吉祥。

### 彖传

**原文**：柔以时升，巽而顺，刚中而应，是以大亨。“用见大人，勿恤”，有庆也。“南征吉”，志行也。

**白话**：阴柔之气依循时势而上升，谦逊而柔顺，阳刚居中并能与之呼应，因此大为亨通。“得以见大人，不必忧虑”，是因为有吉庆。“向南征伐吉祥”，是因为志向得以施行。

### 大象传

**原文**：地中生木，升；君子以顺德，积小以高大。

**白话**：大地中生长出树木，象征上升；君子因此顺应美德，积累微小以至崇高宏大。


## 爻辞

### 初六：允升，大吉。


**原文**：允升，大吉。

**白话**：宜于上升，大为吉祥。

**小象传**
**原文**：“允升大吉”，上合志也。

**白话**：能够上升而大为吉祥，是因为与上方的意志相合。


**说明**

这是 上升的起点——根基稳固，得信而升。

+ “允升”：宜于（允）上升（升）。“允”有 允当、诚信、获得信任 之意。
+ “大吉”：大为吉祥（大吉）。
+ 爻传“允升大吉，上合志也”：宜于上升大为吉祥，是因为（初六）与上方的意志相合。

**相关性**：初六阴柔处下，如 树木之根，是 上升的根基。“允升”意味着 **其上升的意愿与行动，获得了上方（九二、九三乃至坤土）的认可与支持（上合志）。因为 根基稳固（巽木入地），方向正确（顺应坤土），且得到信任，所以 一开始就大为吉祥。此爻强调：**任何上升与发展，必须始于一个稳固、可信且与整体目标一致的基础。


### 九二：孚乃利用禴，无咎。


**原文**：孚乃利用禴，无咎。

**白话**：心怀诚信，即使简单的禴祭也有利，没有咎害。

**小象传**
**原文**：九二之孚，有喜也。

**白话**：九二的诚信，会带来喜庆。


**说明**

这是 上升的进阶——心存诚信，虽简亦利。

+ “孚乃利用禴”：只要心怀诚信（孚），即使微薄的禴祭（乃利用禴）也有利。
+ “无咎”：没有咎害（无咎）。
+ 爻传“九二之孚，有喜也”：九二的诚信，会带来喜庆。

**相关性**：九二阳刚居中，与六五君王正应，是 上升过程中的中坚力量。爻辞与萃卦六二相同，都强调了 “孚乃利用禴”。在升卦语境下，这意味着：**在追求上升、发展的过程中，内心的诚信（孚）远比外在形式或物质贡献的丰厚更重要。只要 诚心诚意，努力进取，即使 起点不高、资源有限（禴祭之薄），也会 得到上方的赏识与提携（与六五应），从而 顺利上升，没有咎害，且终有喜庆。此爻阐述：**上升之路，品德（诚）是比暂时的实力更持久的通行证。


### 九三：升虚邑。


**原文**：升虚邑。

**白话**：上升进入空虚的城邑。

**小象传**
**原文**：“升虚邑”，无所疑也。

**白话**：登上高丘上的城邑，心中没有任何疑虑。


**说明**

这是 上升的加速——前无阻碍，顺势而上。

+ “升虚邑”：上升（升）进入（虚）城邑（邑）。“虚邑”指 空旷、没有设防的城邑。
+ 爻传“升虚邑，无所疑也”：上升进入空虚的城邑，说明无所疑虑。

**相关性**：九三阳刚过甚，处下卦之极，面临上卦坤土（虚邑）。坤为地、为顺、为众，也有 “虚”（空旷）之象。“升虚邑”是 一个极其顺畅的意象：上升者（九三） 面前是 一片空旷的领域（坤土），没有任何障碍与抵抗，可以 毫无疑虑（无所疑也）地长驱直入，尽情发展。此爻描绘了 **上升过程中最理想的阶段：**势如破竹，前方一片坦途，可以放手施展，快速推进。


### 六四：王用亨于岐山，吉，无咎。


**原文**：王用亨于岐山，吉，无咎。

**白话**：君王在岐山举行祭祀，吉祥，没有咎害。

**小象传**
**原文**：“王用亨于岐山”，顺事也。

**白话**：大王在岐山举行祭祀，这是顺应时势的举动。


**说明**

这是 上升的转折——敬顺天道，获神之佑。

+ “王用亨于岐山”：君王（王）在岐山（于岐山）举行祭祀（用亨）。
+ “吉，无咎”：吉祥（吉），没有咎害（无咎）。
+ 爻传“王用亨于岐山，顺事也”：君王在岐山祭祀，是顺从天道之事。

**相关性**：六四阴柔得正，已进入上卦坤顺之地，且靠近君位（六五）。“岐山” 是 周朝发祥之地，象征 事业的根基与起点。“王用亨于岐山”描述的是：在上升至一定高度、面临新阶段时，领袖（王） 回到 根本之地（岐山），举行庄严的祭祀（亨）。这并非迷信，而是 一种象征：“顺事”**——反省初心，感恩所得，敬顺天地祖先的规律与庇佑。通过这种 精神上的回归与巩固，可以 获得吉祥，确保上升之路没有咎害。此爻强调：**在快速发展中，适时地回顾根本、敬畏规律、凝聚精神（顺事），是 持续稳健上升的重要保障。


### 六五：贞吉，升阶。


**原文**：贞吉，升阶。

**白话**：守持正固吉祥，沿着阶梯步步上升。

**小象传**
**原文**：“贞吉升阶”，大得志也。

**白话**：坚守正道可获吉祥，如同步步高升，这是大展宏图、得偿所愿的象征。


**说明**

这是 上升的顶点——以正守成，稳步登高。

+ “贞吉”：守持正固（贞）可获吉祥（吉）。
+ “升阶”：沿着阶梯（阶）步步上升（升）。
+ 爻传“贞吉升阶，大得志也”：守持正固可获吉祥、沿着阶梯上升，说明（六五）心志大为得偿。

**相关性**：六五阴柔居中，居尊位，是 上升的君主与成功者。爻辞描绘了 一种稳健、有序的上升状态：“升阶”——**不是飞跃，而是 一步一个台阶，循序渐进。这要求领导者 自身必须“贞”——持守正道，不偏不倚。如此，则 吉祥，且 其上升的志向（大得志） 能够 稳步实现。此爻是 对成功领导者的描述：**居于高位，**更要以正道为阶梯，**实现 可持续的、得人心的上升与发展。


### 上六：冥升，利于不息之贞。


**原文**：冥升，利于不息之贞。

**白话**：在昏暗中上升，利于永不停止地守持正固。

**小象传**
**原文**：“冥升”在上，消不富也。

**白话**：上升到极高处却还昏昧不明，必然会消退而无法保持富足。


**说明**

这是 上升的终点——过犹不及，贞以自守。

+ “冥升”：昏昧不明（冥）地上升（升）。
+ “利于不息之贞”：宜于（利于）永不停止（不息）地守持正固（之贞）。
+ 爻传“冥升在上，消不富也”：昏昧不明地上升到了极点，说明（上升之势）将消减，不会富盛。

**相关性**：上六阴柔处卦之极，是 上升的尽头。“冥升”形容 **上升到了极点，却仍不知停止，陷入了一种 盲目、失去方向的惯性状态。这是 危险的，因为 物极必反，再往前就是衰落（消不富也）。爻辞给出的唯一出路是 “利于不息之贞”：**在无法继续上升时，**唯一有利的做法是 永不松懈地持守正道（贞）。这并非鼓励继续冒进，而是强调 **以“贞”来 稳固既有的成果，防止因昏昧（冥）而导致的崩溃。此爻是 对“亢龙有悔”的另一种表述，警告：**上升有其极限，**知止是智慧；若不知止，则唯有用 极致的正道 来自我保全。


## 总结

**总结**：升卦的现代启示

升卦的 “积小以高大” 是关于 “成长、进步、晋升”的积极哲学，它描绘了一条 从根基到顶峰的完整发展路径。

践行上升之道的六个阶段：

+ 顺势而升（初六）：允升，大吉。
+ 以诚求升（九二）：孚乃利用禴，无咎有喜。
+ 畅通无阻（九三）：升虚邑，无所疑。
+ 顺事而升（六四）：王用亨于岐山，吉无咎。
+ 尊位以正（六五）：贞吉，升阶，大得志。
+ 升极有悔（上六）：冥升，利于不息之贞。

核心心法：大象传总纲——“地中生木，升；君子以顺德，积小以高大。” 这意味着：

+ “地中生木，升”：是 升卦之象（树木从大地中生长，不断升高）。
+ “君子以顺德，积小以高大”：君子效法此象，遵循顺德（或：顺应美德），积累微小以成就高大。

这是 升卦精神的灵魂：**“升”不是 凭空飞跃，而是像树木生长一样，**一个 持续积累、循序渐进 的过程。君子领悟到，要实现上升与发展，必须 “顺德”——**一是 遵循客观规律（顺），二是 修养自身美德（德）。同时，要 “积小以高大”——**从细微处着手，脚踏实地，日积月累，最终才能 成就宏伟的事业与人格。这是 对“一步登天”幻想的彻底否定，也是对 “持之以恒”美德的最高礼赞。

根本精神：彖传 “柔以时升，巽而顺，刚中而应，是以大亨……南征吉，志行也。” 点明了上升之道的成功要素：

+ “柔以时升”：柔顺者顺应时机而上升。强调 时机的重要性。
+ “巽而顺”：谦逊（巽）而又柔顺（坤）。强调 上升的态度。
+ “刚中而应”：阳刚者守中道而有应合。强调 上升的助力与结构。
+ “南征吉，志行也”：向南方进发吉祥，说明心志得以实行。

升卦告诉我们：**“上升”是 生命与事业的普遍渴望。成功的上升需要 顺应时势（以时）、谦逊务实（巽顺）、内心刚强而有外援（刚中而应）、方向正确（南征）。其最高智慧在于 **大象传的积累哲学：**任何伟大的成就，都源于 无数微小努力的持续叠加（积小以高大）。这便是在 “地中生木” 的生机景象中，所蕴含的 关于成长、奋斗与成功的永恒真理。
