# 乾卦（乾上乾下）

**卦画**：䷀

## 总论：开创的哲学

**核心短词**：“自强不息”

**卦象**：上干（☰）为天、为健，下干（☰）为天、为健。干为天。纯阳至健，天行健，君子以自强不息。

**核心卦辞**：“元，亨，利，贞。”

**总纲**：乾卦象征 “天”的创始、亨通、有利与正固 四种根本德性。具备这四德，则大吉大利。

+ “元”：创始、开始、根源。
+ “亨”：亨通、通达、顺利。
+ “利”：有利、适宜、和谐。
+ “贞”：正固、守正、坚定。

**本质**：乾卦是 纯阳之卦，代表 天道、阳刚、创始、进取、领导力。其**核心精神**是 “健”，即 刚健不息、永不停滞的运动与创造力。卦辞“元亨利贞”被称为 “四德”，是 天道运行、万物创始与发展的完整循环，也是 君子（效法天道者）应具备的四种根本品德。

## 卦辞



### 经

**原文**：元，亨，利，贞。

**白话**：创始、通达、适宜、正固。

### 彖传

**原文**：大哉乾元，万物资始，乃统天。云行雨施，品物流形。大明终始，六位时成，时乘六龙以御天。乾道变化，各正性命，保合太和，乃利贞。首出庶物，万国咸宁。

**白话**：伟大啊乾元，万物依赖它起始，它统领着整个天道。云朵飘行雨水施降，各类事物流动成形。太阳的光辉终而复始地照耀，六个方位随着时节形成，如同按时驾驭六条龙运行于天。乾道的变化，使万物各自端正其本性与命运，保持和谐状态，有利于守持正道。乾元首先创生出众多事物，使天下万方都安宁太平。

### 大象传

**原文**：天行健，君子以自强不息。

**白话**：天的运行刚强劲健，君子因此不停地自我奋发图强。


## 爻辞

### 初九：潜龙勿用。


**原文**：潜龙勿用。

**白话**：龙潜伏在水中，暂不宜有所作为。

**小象传**
**原文**：'潜龙勿用'，阳在下也。

**白话**：龙潜藏不出，是因为阳气还处在最下方。


**说明**

这是 开创的最高境界——群龙共和。

+ “见群龙无首”：出现（见）一群龙（群龙），没有（无）首领（首）。
+ “吉”：吉祥。
+ 爻传“天德不可为首也”：因为 天的德行（天德）是（让万物各得其所）而不自居为首。

**相关性**：“用九”是 乾卦六爻皆阳（皆变）时的总断。“群龙”象征 众多阳刚健动的力量。“无首”并非没有领导，而是 不以首领自居，不逞强好胜，刚而能柔，彼此平等协作，各尽所能。这体现了 天道“生而不有，为而不恃”的最高品德（天德）。在这种状态下，刚健的力量得到最和谐、最有效的发挥，故 大吉。此爻揭示了 **“自强不息”的终极目标：不是个人的独霸，而是 整体的和谐与共创。


### 九二：见龙在田，利见大人。


**原文**：见龙在田，利见大人。

**白话**：龙出现在田野，利于见到大人。

**小象传**
**原文**：'见龙在田'，德施普也。

**白话**：看到龙出现在田野上，说明美德正在广泛地施行。


**说明**

这是 开创的显现——初试锋芒。

+ “见龙在田”：龙出现（见，同“现”）在田野（田）。
+ “利见大人”：利于（利）遇见（见）大人（大人）。
+ 爻传“德施普也”：因为 （龙的）德行（德）开始普遍施与（施普）。

**相关性**：九二阳刚得中，已从“潜”升至“地上”。象征 才能初步显现，开始在社会上活动，建立声誉。“田”是 人类活动的领域。“利见大人”有两层含义：一是利于被有德位者（大人）发现和赏识；二是自身行为应效法“大人”之德。爻传“德施普也”指出：**此时的关键不是炫耀能力，而是 以德行影响周遭，惠及他人。此爻是 从“独善其身”走向“兼济天下”的过渡。


### 九三：君子终日乾乾，夕惕若，厉无咎。


**原文**：君子终日乾乾，夕惕若，厉无咎。

**白话**：君子整天勤奋健进，夜晚仍警惕戒惧，虽有危险，但无灾祸。

**小象传**
**原文**：'终日乾乾'，反复道也。

**白话**：一天到晚勤奋努力，意味着要反复践行正道。


**说明**

这是 开创的奋进——戒慎勤勉。

+ “君子终日干干”：君子（君子）整天（终日）勤奋健行（干干）。
+ “夕惕若”：到了夜晚（夕）依然警惕（惕）反省。
+ “厉无咎”：虽有危险（厉），但无咎害（无咎）。
+ 爻传“反复道也”：因为 （如此）是为了反复践行正道。

**相关性**：九三处下卦之极，上不挨天，下不落地，是 “多凶”的人位。象征 事业进入攻坚阶段，内外压力增大，处境危险（厉）。爻辞描绘了 君子在此阶段的应有状态：白天奋发有为（干干），晚上戒惧反省（惕若）。通过 不懈的努力（不息）和深刻的自省（反复道），才能 化险为夷，避免过错（无咎）。此爻是 “自强不息”精神最艰苦、最核心的体现。


### 九四：或跃在渊，无咎。


**原文**：或跃在渊，无咎。

**白话**：龙有时跃起，有时退处深渊，均无灾祸。

**小象传**
**原文**：'或跃在渊'，进无咎也。

**白话**：有时腾跃上进，有时退处深渊，这是说前进没有灾祸。


**说明**

这是 开创的抉择——进退有据。

+ “或跃在渊”：或者（或）腾跃（跃）上进，或者退处（在）深渊（渊）。
+ “无咎”：没有咎害。
+ 爻传“进无咎也”：因为 （审时度势的）进取（进）没有咎害。

**相关性**：九四已进入上卦，逼近九五君位，但 阳居阴位，位置不正。象征 处于重大转折关头，面临“进（跃）”与“退（在渊）”的抉择。“或”字体现了 试探、犹豫与不确定性。爻辞的智慧在于：无论选择进取还是暂时退守，只要 审时度势，符合道义，都是正确的，都不会有咎害（无咎）。爻传“进无咎也”侧重鼓励：在条件成熟时，勇于进取是应该的。此爻强调：**“自强不息”不是蛮干，而是 智慧与勇气的结合，懂得进退之道。


### 九五：飞龙在天，利见大人。


**原文**：飞龙在天，利见大人。

**白话**：龙飞翔于天空，利于见到大人。

**小象传**
**原文**：'飞龙在天'，大人造也。

**白话**：龙飞在天上，是大人奋起作为的象征。


**说明**

这是 开创的巅峰——居中得位。

+ “飞龙在天”：龙飞腾（飞）于天上（在天）。
+ “利见大人”：利于（利）遇见（见）大人（大人）。
+ 爻传“大人造也”：因为 （这是）大人（大人）有所作为（造）的时候。

**相关性**：九五阳刚中正，居尊位，是 卦中最尊贵、最理想的位置。象征 事业达到顶峰，才能、德行与地位完美结合，可以大展抱负，造福天下。此时的“利见大人”含义更深：一是作为领导者（大人）本身，其作为利于天下；二是需要汇聚更多贤能（大人）共同成就伟业。爻传“大人造也”宣告：**这是 领导者创建功业、实现理想的黄金时期。此爻是 “自强不息”精神的最高成就。


### 上九：亢龙有悔。


**原文**：亢龙有悔。

**白话**：龙飞得过高，将有悔恨。

**小象传**
**原文**：'亢龙有悔'，盈不可久也。

**白话**：龙飞到过高的地方会有悔恨，因为满盈的状态无法长久保持。

### 用九：见群龙无首，吉。

**原文**：见群龙无首，吉。

**白话**：出现一群龙，都不以首领自居，吉祥。

**小象传**
**原文**：'用九'，天德不可为首也。

**白话**：用九这一爻，体现了天的美德，那就是不争强好胜、不居首位。


**说明**

这是 开创的警示——过刚则折。

+ “亢龙”：飞得过高（亢）的龙（龙）。
+ “有悔”：将有悔恨。
+ 爻传“盈不可久也”：因为 盈满（盈）的状态不可能持久。

**相关性**：上九处卦之极，阳气过盛，居高而无位。象征 事业达到顶峰后，如果不知节制，继续一味刚进，就会走向反面。“亢”指 过分、过度、骄傲。这种状态会导致 脱离群众、失去根基、决策失误，最终 产生悔恨（有悔）。爻传“盈不可久也”揭示了 物极必反的自然规律。此爻是 对“自强不息”的重要补充：进取须有度，应懂得谦退与平衡。


## 总结

**总结**：乾卦的现代启示

乾卦的 “自强不息” 是关于 个人成长、事业开创与领导力发展 的完整路线图。

人生的六个阶段（揭示了从潜藏到巅峰再到反思的完整循环）：

+ 潜龙（初九）：沉潜积累，勿用。
+ 见龙（九二）：崭露头角，利见大人。
+ 惕龙（九三）：勤奋戒惧，厉无咎。
+ 跃龙（九四）：审时度势，或跃在渊。
+ 飞龙（九五）：大展宏图，利见大人。
+ 亢龙（上九）：盛极知返，有悔。

核心心法：大象传总纲——“天行健，君子以自强不息。” 这意味着：

+ “天行健”：是 乾卦之象（天道运行，刚强劲健，永不停息）。
+ “君子以自强不息”：君子效法此象，自我奋发图强，永不懈怠。

这是 乾卦精神的灵魂：将外在的、客观的“天道”（健），内化为个人的、主观的“人道”（自强不息）。它鼓励我们：无论处于何种境遇，都应保持积极进取、永不止步的精神状态。

根本精神：彖传 “大哉乾元，万物资始，乃统天” 与 “乾道变化，各正性命，保合太和，乃利贞” 将“乾”道置于宇宙本原的高度。伟大的乾元（创始力），是万物赖以产生的根源，它统率着整个天道。乾道的变化（如六爻），使万物各得其所、各正性命，保持太和（最高和谐），于是达到利与贞（有利与正固）。乾卦告诉我们：个人的“自强不息”与宇宙的“创生不息”是同构的。我们学习乾卦，不仅是学习成功学，更是学习如何 将个人的生命节奏，融入并效法宇宙的宏大韵律，从而实现 “元亨利贞”的圆满人生。
