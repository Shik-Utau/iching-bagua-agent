# 夬卦（兑上乾下）

**卦画**：䷪

## 总论：决断之道的哲学

**核心短词**：“施禄及下，居德则忌”

**卦象**：上兑（☱）为泽、为悦，下乾（☰）为天、为健。泽天夬。泽水蒸发，决于上天。

**核心卦辞**：“扬于王庭，孚号有厉。告自邑，不利即戎，利有攸往。”

**总纲**：夬卦象征 “决断、清除”，（将小人）公布于君王朝廷之上，心怀诚信地疾呼危险。告诫自己封邑内的人，不适宜立即动用武力，利于有所前往。

+ “扬于王庭，孚号有厉”：这是 决断的方式。将问题（小人）公开化、透明化（扬于王庭），并 以诚信之心发出警告，揭示危险（孚号有厉）。强调 决断的公开性与正义性。
+ “告自邑，不利即戎”：这是 决断的策略。先告诫自己人，统一内部思想（告自邑）；不适宜立即诉诸武力（不利即戎），因为武力易生变乱，且可能伤及无辜。
+ “利有攸往”：这是 决断的指向。利于有所前往，即 最终必须采取行动，彻底解决问题。

**本质**：夬卦描述 “刚决柔” 的状态。五阳在下，一阴在上（上六），象征 君子道长，小人道消 的决断时刻。上兑泽水即将被下乾阳气蒸干（决），但 阴爻（小人）居于最高位，仍有影响力。其**核心精神**是：**在优势明显（五阳对一阴）时，如何以最稳妥、最正义、最少副作用的方式，清除最后的障碍或邪恶。决断需要 果敢（健），也需要策略（悦）。

## 卦辞



### 经

**原文**：扬于王庭，孚号有厉。告自邑，不利即戎，利有攸往。

**白话**：在君王的朝廷上公布小人的罪状，心怀诚信地号令众人，但需警惕危险。告诫自己封邑内的人，不利于立即动用武力，利于有所前往（以德决断）。

### 彖传

**原文**：夬，决也，刚决柔也。健而说，决而和。“扬于王庭”，柔乘五刚也。“孚号有厉”，其危乃光也。“告自邑，不利即戎”，所尚乃穷也。“利有攸往”，刚长乃终也。

**白话**：夬卦，是决断的意思，象征阳刚决断阴柔。刚健而能使人悦服，决断而能归于平和。“在王庭上公开宣扬”，是因为阴柔凌驾于众阳刚之上。“真诚呼号有危险”，这种危机意识反而能光大其事。“告诫自己封邑内的人，不宜立即动武”，因为崇尚武力会导致穷途末路。“利于有所前往”，是因为阳刚之气增长，最终能取得好的结果。

### 大象传

**原文**：泽上于天，夬；君子以施禄及下，居德则忌。

**白话**：泽水汇聚于天穹之上，象征决断；君子因此要将福禄施予下属，若是积德自居就会招致忌恨。


## 爻辞

### 初九：壮于前趾，往不胜，为咎。


**原文**：壮于前趾，往不胜，为咎。

**白话**：强盛表现在脚趾前端，前往不能取胜，反致咎害。

**小象传**
**原文**：不胜而往，咎也。

**白话**：不能取胜却还要前往，这是自找灾祸。


**说明**

这是 决断的初始——戒之在躁。

+ “壮于前趾”：强盛（壮）表现在前脚趾（于前趾）上。
+ “往不胜，为咎”：前往（往）不能取胜（不胜），反招致咎害（为咎）。
+ 爻传“不胜而往，咎也”：不能取胜却要前往，就是咎害。

**相关性**：初九阳刚处下，是 决断力量的最底层。“前趾”象征 行动的初始、微末之力。“壮于前趾”比喻 仅有微末的强壮，或仅有冲动的勇气，就自以为强大。在全局（五阳）尚未协调、准备不足时，若 轻率冒进（往），企图单独解决问题，必然 无法取胜（不胜），反而会 打草惊蛇，破坏大局，招致咎害。爻传的批评直接：**明知不胜还要去，就是过错。此爻强调：**决断大事，最忌个人英雄主义的躁动。力量必须凝聚，行动必须协同。


### 九二：惕号，莫夜有戎，勿恤。


**原文**：惕号，莫夜有戎，勿恤。

**白话**：警惕地呼号，即使深夜有战事，也不必忧虑。

**小象传**
**原文**：“有戎勿恤”，得中道也。

**白话**：有兵戎之事也不必忧虑，是因为持守中正之道。


**说明**

这是 决断的准备——戒惧严防。

+ “惕号”：时刻警惕（惕）并呼号（号）。
+ “莫夜有戎”：即使（莫，通“暮”）深夜（夜）有战事（有戎）。
+ “勿恤”：也不必忧虑（勿恤）。
+ 爻传“有戎勿恤，得中道也”：有战事也不必忧虑，是因为（九二）获得中道。

**相关性**：九二阳刚居中，是 决断力量的中坚。爻辞描绘了 高度戒备的状态：“惕号”是 内心的警惕与对外的警示；“莫夜有戎”比喻 最坏的情况、突如其来的袭击。因为 准备充分，警戒森严（得中道，指方法得当），所以 即使突发变故，也能从容应对，不必忧虑。此爻强调：**在决断的关键时期，必须保持最高度的警惕，做好最坏的打算。充分的准备（惕号）是信心（勿恤）的来源。


### 九三：壮于頄，有凶。君子夬夬，独行遇雨，若濡有愠，无咎。


**原文**：壮于頄，有凶。君子夬夬，独行遇雨，若濡有愠，无咎。

**白话**：强盛表现在颧骨上（怒形于色），有凶险。君子刚毅决断，独自前行遇雨，若被淋湿而恼怒，但没有咎害。

**小象传**
**原文**：“君子夬夬”，终无咎也。

**白话**：君子果断作出决定，最终不会有灾祸。


**说明**

这是 决断的考验——隐忍待机。

+ “壮于頄，有凶”：强盛（壮）表现在颧骨上（于頄，指怒形于色），有凶险（有凶）。
+ “君子夬夬，独行遇雨，若濡有愠，无咎”：君子（君子）果敢决断（夬夬），独自前行（独行）遇雨（遇雨），似被淋湿（若濡）而有愠怒（有愠），但没有咎害（无咎）。
+ 爻传“君子夬夬，终无咎也”：君子果敢决断，终究没有咎害。

**相关性**：九三阳刚过甚，处下卦之极，与上六小人相应，是 决断力量中与“小人”有私交或关联者。“壮于頄”形容 将决断的意志过于外露，写在脸上，这容易 激化矛盾，引发对方反扑，故凶。爻辞后半段描述了其复杂心态：君子内心决意清除小人（夬夬），但 因与上六有应，不得不与之周旋（独行遇雨），表面接触（若濡）难免招致同道误解而心生愠怒（有愠）。然而，只要 其决断的意志坚定不移（君子夬夬），这种 必要的、暂时的隐忍与周旋，最终 不会导致过错（终无咎）。此爻揭示了 **决断中的复杂情况：**有时需要 外示妥协，内藏决断，承受暂时的委屈与误解，以达成最终目标。


### 九四：臀无肤，其行次且。牵羊悔亡，闻言不信。


**原文**：臀无肤，其行次且。牵羊悔亡，闻言不信。

**白话**：臀部没有皮肤，行动趑趄不前。若能牵系着羊（柔顺）般的决心，悔恨可消亡，但听到忠言却不相信。

**小象传**
**原文**：“其行次且”，位不当也。“闻言不信”，聪不明也。

**白话**：走路踉跄不稳，是因为所处的位置不恰当。听到劝告却不相信，是因为耳朵听不清事理。


**说明**

这是 决断的彷徨——不决之害。

+ “臀无肤，其行次且”：臀部（臀）没有皮肤（无肤），行动（其行）趑趄不前（次且）。
+ “牵羊悔亡”：若能牵系着羊（牵羊，指柔顺跟随九五）则悔恨消亡（悔亡）。
+ “闻言不信”：但听到（闻言）忠言（指爻辞的告诫）却不相信（不信）。
+ 爻传“其行次且，位不当也；闻言不信，聪不明也”：行动趑趄不前，是因为位置不当；听到忠言却不信，是听觉不分明（判断力差）。

**相关性**：九四阳居阴位，不中不正，是 决断力量中犹豫不决者。“臀无肤，其行次且”是 生动比喻：臀部受伤，坐立不安，想走又走不动，形象地刻画了 进退失据、彷徨不决的窘态。爻辞指出出路：“牵羊”——像牵着羊一样，柔顺地跟随前面的阳刚（九五）行动，即可免悔。但可悲的是，其自身 判断力低下（聪不明），对这条明路 “闻言不信”，依旧迟疑。爻传点明根源：“位不当也”**——因其 自身德才与位置不匹配，缺乏决断的魄力与智慧。此爻是 对优柔寡断者的深刻描绘与警示。


### 九五：苋陆夬夬，中行无咎。


**原文**：苋陆夬夬，中行无咎。

**白话**：像斩除苋陆草一样刚毅决断，持中而行，没有咎害。

**小象传**
**原文**：“中行无咎”，中未光也。

**白话**：行事中正没有过错，但中正之道尚未发扬光大。


**说明**

这是 决断的核心——中正除奸。

+ “苋陆夬夬”：像斩除（夬夬）柔脆的苋陆草（苋陆）一样果敢决断。
+ “中行无咎”：持中而行（中行），没有咎害（无咎）。
+ 爻传“中行无咎，中未光也”：持中而行没有咎害，但中道尚未光大。

**相关性**：九五阳刚中正，居尊位，是 决断之主，清除小人的最终决策者与执行者。“苋陆”是一种 柔脆易折的草，比喻 虽居高位（上六）但本质虚弱的小人。“夬夬”形容 决断的果敢与坚决。爻辞描述：君王 以中正之道（中行），果断清除小人（苋陆夬夬），这样做 没有咎害。但爻传意味深长地补充：“中未光也”**——**虽然中正，但 中道的光明尚未完全彰显。为何？因为 “夬”本身是刚决柔，是斗争，即使正义，也非最和谐的境界；且 上六小人仍在，问题刚解决，中道的教化尚未普及。此爻强调：**最高领导者的决断，必须 既果敢又中正，但也要认识到，决断之后，建设与教化（使中道光大）的任务更加重要。


### 上六：无号，终有凶。


**原文**：无号，终有凶。

**白话**：不必号啕痛哭，最终必有凶险。

**小象传**
**原文**：“无号”之“凶”，终不可长也。

**白话**：“无号”所预示的凶险，终究不会长久持续。


**说明**

这是 决断的对象——小人末路。

+ “无号”：不必呼号（无号，或释为：没有呼号，即沉默）。
+ “终有凶”：终究（终）有凶险（有凶）。
+ 爻传“无号之凶，终不可长也”：不必呼号（或没有呼号）的凶险，说明（小人之势）终究不可长久。

**相关性**：上六阴柔，处卦之极，是 被决断的小人。在五阳的绝对优势下，其 大势已去。“无号”有两解：一是 其罪行已昭告天下（扬于王庭），辩白呼号已无人听信；二是 在众阳决断的洪流前，吓得连呼号都发不出来。无论哪种，都预示其 “终有凶”——覆灭的结局不可避免。爻传“终不可长也”则从天道角度总结：**邪不胜正，小人得势 终究不可长久。此爻作为全卦结尾，明确了 决断的必然结果，也宣告了 正义的最终胜利。


## 总结

**总结**：邪不胜正，小人得势 终究不可长久。此爻作为全卦结尾，明确了 决断的必然结果，也宣告了 正义的最终胜利。

**总结**：夬卦的现代启示
夬卦的 “施禄及下，居德则忌” 是关于 “决裂、清除、裁决”的严肃哲学，它教导我们 如何在优势下，以理性、正义且有效的方式解决根本矛盾。

践行决断之道的六个关键：

+ 戒之在躁（初九）：壮于前趾，往不胜为咎。
+ 常备无患（九二）：惕号莫夜，有戎勿恤。
+ 隐忍待机（九三）：夬夬独行，若濡无咎。
+ 迟疑之害（九四）：臀无肤，闻言不信。
+ 中正除奸（九五）：苋陆夬夬，中行无咎。
+ 势穷必亡（上六）：无号，终有凶。

核心心法：大象传总纲——“泽上于天，夬；君子以施禄及下，居德则忌。” 这意味着：

+ “泽上于天，夬”：是 夬卦之象（泽水蒸发于天，即将决散）。
+ “君子以施禄及下，居德则忌”：君子效法此象，施予恩泽于下民，切忌自己积德不施。

这是 夬卦精神的灵魂：“夬”是 刚决柔，是 阳对阴的清除。但君子领悟到，防止“小人”滋生、避免走到“决断”这一步的根本方法，在于 平时要“施禄及下”——将利益、恩泽广施于民众，赢得人心。反之，如果 自己独占功德与利益（居德），就会 招致怨恨与对立（忌），最终可能酿成需要“夬”的祸患。这体现了 中国政治哲学中“预防优于惩治”的深刻思想。

根本精神：彖传 “夬，决也，刚决柔也。健而说，决而和……利有攸往，刚长乃终也。” 点明了决断之道的精髓：

+ “健而说，决而和”：刚健（乾）而能使人悦服（兑），决断而能导致和谐。这是 决断的理想效果——不是制造分裂，而是通过清除障碍达成新的和谐。
+ “利有攸往，刚长乃终也”：利于有所前往，说明阳刚之气增长直至最终（清除阴柔）。

夬卦告诉我们：“决断”是 不得已而为之的最后手段。它需要 公开公正（扬于王庭）、充分准备（惕号）、内部协同（不利即戎）、领袖果敢（苋陆夬夬），同时要 警惕冒进（壮于前趾）、避免犹豫（其行次且）。其最高智慧在于 **大象传的告诫：** 最好的“决断”，是 通过平时的“施禄及下”来防患于未然，使“决断”没有发生的必要。这便是在 “五阳决一阴” 的强势局面下，所蕴含的 关于斗争、清算与长治久安的深刻辩证思想。
