# 复卦（坤上震下）

**卦画**：䷗

## 总论：复兴的哲学

**核心短词**：“见天地之心”

**卦象**：上坤（☷）为地、为顺，下震（☳）为雷、为动。地雷复。雷在地中，阳气复苏；一阳来复，生机萌动。

**核心卦辞**：“复，亨。出入无疾，朋来无咎。反复其道，七日来复，利有攸往。”

**总纲**：复卦宣告了 在剥落殆尽之后，阳气（正道、生机）重新回复 的喜讯。象征 黑暗过去，光明复来，万物复苏。此时亨通无阻，利于行动。

+ “复”：回复、复兴、回归。
+ “亨”：亨通。
+ “出入无疾，朋来无咎”：出入没有疾病，朋友前来没有过错。形容 内外环境恢复和谐顺畅。
+ “反复其道，七日来复”：循环往复是天道规律，经过七天（一个周期）就会回复。强调 复兴是必然的周期性规律。
+ “利有攸往”：利于有所前往、有所作为。

**本质**：复卦的核心是 “刚反动而以顺行” 与 “复见其天地之心乎”。卦中五阴在上，一阳在下，展示了 阳刚之力（生机/正道）从最底层（初爻）重新发动 的景象。这微弱的阳气（初九）虽力量尚小，但 其运动方向顺应天道（以顺行），且 生机勃勃（动）。这“一阳来复”的景象，让君子看到了 天地化育万物、永不灭绝的仁心与本性（天地之心）。

## 卦辞



### 经

**原文**：亨。出入无疾，朋来无咎。反复其道，七日来复，利有攸往。

**白话**：亨通。阳气生长出入没有疾患，朋友前来没有咎害。返转回复沿着一定的规律，过不了七日必将回复，利于有所前往。

### 彖传

**原文**：复亨，刚反。动而以顺行，是以出入无疾，朋来无咎。反复其道，七日来复，天行也。利有攸往，刚长也。复其见天地之心乎？

**白话**：复卦通达，阳刚之气返回。行动顺乎自然，所以出入没有阻碍，朋友前来没有灾祸。阴阳消长循环往复，经过七天回归重新开始，这是天地运行的规律。利于有所前往，因为阳刚之气在增长。从复卦大概可以看出天地化育万物的本心吧？

### 大象传

**原文**：雷在地中，复；先王以至日闭关，商旅不行，后不省方。

**白话**：雷声隐没在大地之中，象征复归；先代君王因此在冬至日关闭城门，商人旅客停止出行，君主也不巡视四方。


## 爻辞

### 初九：不远复，无祗悔，元吉。


**原文**：不远复，无祗悔，元吉。

**白话**：偏离不远就回复正道，不至于悔恨，至为吉祥。

**小象传**
**原文**：“不远之复”，以修身也。

**白话**：走得不远就返回，这是为了修养自身。


**说明**

这是 复兴的起点——知错速改。

+ “不远复”：走出不远（不远）就回复（复）正道。
+ “无祗悔”：不至于（无）产生悔恨（祗悔）。
+ “元吉”：至为吉祥。
+ 爻传“以修身也”：这是 用以修养自身。

**相关性**：初九是全卦 唯一的阳爻，是 “复”的象征与核心。它处于最下位，象征 复兴从最微小、最初始处发端。“不远复”描述了一种 极高的道德自觉与行动力：过失初萌，立即察觉并回头（复）。因为纠正及时，所以 “无祗悔”，并获致 根本性的吉祥（元吉）。此爻定义了 “复”的最高标准：不贰过，善于自省并即刻改正。这是 个人修养（修身）的根基。


### 六二：休复，吉。


**原文**：休复，吉。

**白话**：美好的回复，吉祥。

**小象传**
**原文**：“休复之吉”，以下仁也。

**白话**：能够美好地回归正道而获得吉祥，是因为能够谦恭地亲近仁德之人。


**说明**

这是 复兴的追随——择善而从。

+ “休复”：美好（休）的回复（复）。
+ “吉”：吉祥。
+ 爻传“以下仁也”：因为 能谦下亲近仁德（初九）。

**相关性**：六二柔顺中正，紧邻初九阳爻。初九是“仁”与“善”的化身（一阳来复）。六二能 以柔顺之德，主动亲近、追随（下）这份刚刚萌发的仁善力量（仁），这种行为本身就是一种 美好的回复（休复）。它不依靠自己的力量回复，而是 通过追随光明、依附正道来实现复兴。这体现了 在复兴潮流中，积极向善、附丽明德 的智慧，故获吉祥。


### 六三：频复，厉无咎。


**原文**：频复，厉无咎。

**白话**：皱着眉头勉强回复，有危险但无咎害。

**小象传**
**原文**：“频复之厉”，义无咎也。

**白话**：愁眉苦脸地回来，虽然危险，但从道理上讲并没有过错。


**说明**

这是 复兴的摇摆——屡失屡复。

+ “频复”：频繁（频）、屡次地回复（复）（又犯错又改正）。
+ “厉无咎”：虽有危险（厉），但最终无过错（无咎）。
+ 爻传“义无咎也”：从 道义上看（义）并无过错。

**相关性**：六三阴柔失位，且处于下卦之极（多忧惧之位）。这象征一个人 意志不坚，德行不稳，在错误与正道之间 反复摇摆（频复）。这种行为本身是 危险的（厉），因为可能一失足成千古恨。但爻辞肯定其 “无咎”，关键在于 他每次偏离后，终究还是选择了“复”（回复正道）。这体现了 天道对悔过之人的宽容：只要最终心向光明，即便过程曲折，仍可免于咎害。此爻鼓励 失足者永不放弃改过自新的机会。


### 六四：中行独复。


**原文**：中行独复。

**白话**：居中行正，独自回复。

**小象传**
**原文**：“中行独复”，以从道也。

**白话**：通过中正之道独自返回，这是为了遵从正道。


**说明**

这是 复兴的自觉——择善固执。

+ “中行独复”：持守中道而行（中行），独自（独）回复（复）正道。
+ 爻传“以从道也”：因为 遵从（从）正道。

**相关性**：六四已进入上卦坤（顺），且处于五阴之中。上下左右皆为阴爻，象征 环境依然晦暗，众人可能尚未觉悟。但六四因与初九相应，内心 笃信正道。他能 不随波逐流，不顾环境压力，独自一人（独）毅然选择回复（复）。这种回复，是基于 对中正之道的坚定信仰（以从道），而非外在影响。此爻歌颂了 在集体迷茫中，能保持清醒、坚守原则的独立精神。


### 六五：敦复，无悔。


**原文**：敦复，无悔。

**白话**：敦厚笃实地回复，没有悔恨。

**小象传**
**原文**：“敦复无悔”，中以自考也。

**白话**：敦厚地复归正道而没有懊悔，是因为内心秉持中道并能自我省察。


**说明**

这是 复兴的笃实——厚德载物。

+ “敦复”：敦厚笃实（敦）地回复（复）。
+ “无悔”：没有悔恨。
+ 爻传“中以自考也”：因为 居守中位并能自我考察（自考）。

**相关性**：六五柔中居尊，是 领导者。她的“复”，不是激烈的改过，而是 一种深厚、沉稳、不间断的自我敦促与反省（敦复）。作为尊者，她能 以中道自我要求，持续考察、修正自身（中以自考），使德行日益厚重。这种 “润物细无声”式的内在复兴，虽无惊人之举，却能 稳固根基，防患未然，故能 “无悔”。此爻阐述了 领导者应有的内省与稳健的复兴之道。


### 上六：迷复，凶，有灾眚。用行师，终有大败；以其国君，凶；至于十年不克征。


**原文**：迷复，凶，有灾眚。用行师，终有大败；以其国君，凶；至于十年不克征。

**白话**：迷误不知回复，凶险，有灾祸。用于行军作战，终将大败；危及国君，凶险；以至于十年之久不能兴兵征战。

**小象传**
**原文**：“迷复之凶”，反君道也。

**白话**：在复归正道时迷失方向会招致凶险，这是因为违背了为君之道。


**说明**

这是 复兴的反面——执迷不返。

+ “迷复”：迷失（迷）了回复（复）之路（不知悔改）。
+ “凶，有灾眚”：凶险，有天灾人祸（灾眚）。
后续描述：形容若将这种“迷复”的状态用于行动（行师），会导致 彻底失败，祸及根本（国君），且长期无法恢复（十年不克征）。
+ 爻传“反君道也”：因为 违背了君主（君子）应行之道。

**相关性**：上六阴柔处卦之极，距离初阳最远，象征 昏昧到了极点，完全丧失了回复的意愿与能力。“迷复”是 复卦的终极反面：在应该回复、可以回复的时候，却 执迷不悟，拒绝反省，一意孤行。这必然导致 最大的凶险与灾祸，不仅个人失败，还会 牵连整体，造成长期难以挽回的颓势。此爻是对 顽固不化、拒绝改过者 的最严厉警告。


## 总结

**总结**：复卦的现代启示

复卦的 “见天地之心” 是关于 希望、反省、改过与新生 的周期性智慧。

复兴的层次：

+ 至善（初九）：“不远复”——过失初萌，立即回头。这是 复德的最高境界。
+ 向善（六二）：“休复”——主动亲近、追随仁善的力量。
+ 摇摆（六三）：“频复”——屡次犯错，但终究知返。天道 宽容悔改者。
+ 独善（六四）：“中行独复”——在黑暗中 独自坚守正道。
+ 笃善（六五）：“敦复”——领导者 敦厚稳健、持续内省 的复兴。
+ 迷途（上六）：“迷复”——执迷不悟，拒绝回复，终至大凶。

核心心法：大象传总纲——“先王以至日闭关，商旅不行，后不省方”。这意味着：

古代君王在 冬至（阳气复生的“至日”） 这天，会 关闭城门，静养休息，商旅停止活动，君王也不巡视四方。

这是 顺应天时：在阳气刚刚萌动、最微弱的时刻，不扰动它，让它静静生长。这是一种 对新生力量的极度呵护与尊重。

应用于人事：在 个人修养、事业或社会复兴的初期，应 创造一个安静、内省、不折腾的环境，让 新生的希望与正气（初九） 得以稳固扎根，自然壮大。切忌 揠苗助长或急于求成。

根本精神：彖传 “复，其见天地之心乎！” 这是《周易》中最富哲学洞见的感叹之一。在万物凋零（剥）的严冬，看到那一点微阳（初九）从地下发动，君子由此领悟到：天地化育万物之心，从未灭绝；正道与生机，是宇宙永恒的本性。复卦给予人类的，不仅是 “利有攸往” 的行动指南，更是 在最黑暗时刻对光明必然回归的坚定信仰。这种信仰，就是 “天地之心” 在人心中的映现。

复卦与剥卦的承续：剥卦（䷖）讲 “剥落凋零”（厚下安宅），是 阴气侵蚀阳气，直至仅存一阳（硕果） 的衰败过程；复卦（䷗）则讲 “一阳来复”（见天地之心），是 阳气从最低点重新萌发、壮大 的新生过程。《序卦传》言：“剥者，剥也。物不可以终尽剥，穷上反下，故受之以复。” 意思是：剥是剥落。事物不可能永远剥落净尽，上面穷尽了就会返回到下面（重新开始），所以继之以复卦。剥极必复，是宇宙的根本规律。从剥到复，构成了一个完整的 “衰极而盛” 的周期，给予人们 在绝望中守望希望 的永恒力量。这也提醒我们，在顺境（贲）时需防“剥”，在逆境（剥）时要信“复”。
