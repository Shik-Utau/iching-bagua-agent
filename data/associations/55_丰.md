# 丰卦（震上离下）

**卦画**：䷶

## 总论：丰大之道的哲学

**核心短词**：“日中则昃，月盈则食”

**卦象**：上震（☳）为雷、为动，下离（☲）为火、为明、为日。雷火丰。雷电交加，光明而盛大。

**核心卦辞**：“亨，王假之，勿忧，宜日中。”

**总纲**：丰卦象征 “丰大、盛大”。亨通，君王可以达到丰大的境界，不必忧虑，宜于保持如日正中。

+ “亨，王假之”：亨通（亨），君王（王）可以达到（假，至）丰大的境界。指明丰大之时本身是 亨通昌盛 的，且 唯有德位兼备的君王 能够 引领和代表 这种盛况。
+ “勿忧，宜日中”：不必忧虑（勿忧），宜于保持如日正中（宜日中）。这是丰卦的 核心诫命与智慧。“日中”是 太阳升至最高点，光明最盛之时，比喻丰大、鼎盛的 最佳状态。“宜日中”是 祈使句，要求在丰大之时，**要努力保持这种 如日中天 的 光明、中正、不偏不倚 的状态。因为一旦 偏离“中”道，盛极必衰的 忧虑（忧） 就会产生。所以“勿忧”的前提是 “宜日中”。

**本质**：丰卦描述 “雷电皆至” 的状态。雷（震） 代表 威动与奋起，火（离） 代表 光明与智慧。雷电交加，象征一种 气势磅礴、光明普照、万物显明 的 盛大景象。其**核心精神**是：**探讨 “丰”的智慧——**如何 创造、达到并维持 丰大昌盛的局面，同时深刻警惕 盛极必衰 的 自然规律。它强调 “明以动”——**以 光明（明） 指导 行动（动），在鼎盛时 持守中道，防止倾覆。

## 卦辞



### 经

**原文**：亨。王假之，勿忧，宜日中。

**白话**：亨通。君王可以达到丰大之境，不必忧虑，适宜保持如日正中。

### 彖传

**原文**：丰，大也。明以动，故丰。“王假之”，尚大也。“勿忧，宜日中”，宜照天下也。日中则昃，月盈则食，天地盈虚，与时消息，而况于人乎？况于鬼神乎？

**白话**：丰，就是盛大的意思。光明而行动，所以能成就盛大。“君王达到这样的境界”，是因为他崇尚宏大的气象。“不必忧虑，适宜保持如日当空的状态”，是说应当让光明普照天下。太阳到了正午就会偏斜，月亮圆满之后就会亏缺，天地万物有盈满有虚缺，都随着时间变化而消长，何况是人呢？何况是鬼神呢？

### 大象传

**原文**：雷电皆至，丰；君子以折狱致刑。

**白话**：雷电交加，象征丰盛；君子因此明察决断讼狱，慎重施行刑罚。


## 爻辞

### 初九：遇其配主，虽旬无咎，往有尚。


**原文**：遇其配主，虽旬无咎，往有尚。

**白话**：遇到相匹配的主人，即使十日（一个周期）内也无咎害，前往会受到尊尚。

**小象传**
**原文**：“虽旬无咎”，过旬灾也。

**白话**：虽然过了十天也没有灾祸，但超过十天就会有灾难了。


**说明**

这是 丰大的开端——明者遇主，携手并进。

+ “遇其配主”：遇到（遇）相匹配的君主（配主）。
+ “虽旬无咎”：尽管两者均等（旬，均等）也无咎害（无咎）。
+ “往有尚”：前往（往）必受尊尚（有尚）。
+ 爻传“虽旬无咎，过旬灾也”：尽管均等无咎，但若想超过均等（过旬）就会有灾祸。

**相关性**：初九阳刚处下，为 离明之始，象征 有才德的贤明之士。“配主”指 与之相匹配的君主，在卦中指 九四（同为阳爻，虽非正应，但同德相求）。初九 明，九四 动，二者 明动相配，是开创丰大局面的 理想搭档。“旬”指 均等、平衡。初九与九四 地位、德能相当，这种 均势 在合作初期 并无咎害，反而能 互相尊重，共赴前程（往有尚）。但爻传 立刻警告：“过旬灾也”。如果一方企图 压倒另一方，打破均势，灾祸 就会降临。此爻阐明：**丰大事业的 起始，贵在 找到志同道合、能力匹配的伙伴，并 保持平等、协作的良性关系。


### 六二：丰其蔀，日中见斗，往得疑疾，有孚发若，吉。


**原文**：丰其蔀，日中见斗，往得疑疾，有孚发若，吉。

**白话**：丰大其障蔽，正午时却见到星斗，前往会得疑嫉之疾，但心怀诚信，发挥明德，可获吉祥。

**小象传**
**原文**：“有孚发若”，信以发志也。

**白话**：心怀诚信而勃发，这是用诚信来激发心志。


**说明**

这是 丰大的遮蔽——光明被掩，诚信通幽。

+ “丰其蔀”：丰大之时却遮蔽（丰其）了光明（蔀，草席，喻遮蔽物）。
+ “日中见斗”：犹如正午（日中）出现星斗（见斗）。
+ “往得疑疾”：前往（往）必遭猜疑（得疑疾）。
+ “有孚发若，吉”：但以诚信（有孚）启发对方（发若），可获吉祥（吉）。
+ 爻传“有孚发若，信以发志也”：以诚信启发对方，说明诚信可以启发他人的心志。

**相关性**：六二阴柔中正，本为 离明之主，是 至明之爻。但 上无应与，且被 九三、九四 等阳爻 重重遮蔽（“丰其蔀”），导致 其光明无法显现。这好比 太阳当空，却被巨大阴影遮盖，以致白昼如夜，可见星斗（日中见斗）。象征 在丰大局面中，中正贤明者反而被 小人或障碍 所 蒙蔽和压制，导致 行动受阻，被人猜忌（往得疑疾）。破解之道在于 “有孚发若”：凭借 至诚的信念与德行（孚），去 感发、照亮（发） 周遭的 昏暗与猜疑（若）。爻传“信以发志也”强调：诚信具有 穿透黑暗、启发人心 的 强大力量。此爻教导：当 身处丰大却昏暗的环境 时，外在行动可能无效甚至有害，唯有 向内坚守诚信，并以之向外感化，才能 拨云见日，获得吉祥。


### 九三：丰其沛，日中见沬，折其右肱，无咎。


**原文**：丰其沛，日中见沬，折其右肱，无咎。

**白话**：丰大其幡幔，正午时却见到小星，折断其右臂，没有咎害。

**小象传**
**原文**：“丰其沛”，不可大事也。“折其右肱”，终不可用也。

**白话**：遮蔽得这么严重，说明不能做大事。折断了右臂，说明终究无法施展才能。


**说明**

这是 丰大的黑暗——光明尽失，断臂求生。

+ “丰其沛”：丰大之时却幔幕遮天（沛，通“旆”，大幡，喻厚重遮蔽）。
+ “日中见沬”：犹如正午（日中）出现无名小星（沬，小星）。
+ “折其右肱”：折断右臂（折其右肱）。
+ “无咎”：但无咎害（无咎）。
+ 爻传“丰其沛，不可大事也；折其右肱，终不可用也”：幔幕遮天，说明不可从事大事；折断右臂，说明终究无法被任用。

**相关性**：九三阳刚过中，处 离明之极，是 光明强盛者。但 上遇九四，同为阳刚，敌而不应，且 陷入上卦震动的重阴之中，遮蔽比六二更甚（“沛”比“蔀”更厚重）。这导致 光明完全被吞噬，正午竟能看到 微末小星（沬），黑暗至极。“折其右肱”是 残酷的比喻：右臂 是 有力的助手、行动的关键。折断右臂 意味着在 至暗时刻，必须 主动放弃重要的力量、权柄或辅助，做出巨大的牺牲。唯有如此，才能 避免更大的灾祸，换来 “无咎”（仅仅是无过，而非有福）。爻传直言 “不可大事”、“终不可用”，宣告了在此境遇下的 彻底无奈：英雄无用武之地，只能 退而自保。此爻揭示了丰大局面中 可能出现的 最极端黑暗，以及 在 无可作为时，“舍” 以 “保身” 的 生存智慧。


### 九四：丰其蔀，日中见斗，遇其夷主，吉。


**原文**：丰其蔀，日中见斗，遇其夷主，吉。

**白话**：丰大其障蔽，正午时却见到星斗，遇到平易之主，吉祥。

**小象传**
**原文**：“丰其蔀”，位不当也。“日中见斗”，幽不明也。“遇其夷主”，吉行也。

**白话**：丰卦中丰大其遮蔽物，是因为所处位置不当。正午出现星斗，是因为天空幽暗不明。遇到与自己平等相称的主人，吉祥而可以前行。


**说明**

这是 丰大的遇合——动者遇明，共济时艰。

+ “丰其蔀，日中见斗”：丰大之时却遮蔽了光明，犹如正午出现星斗。（与六二爻辞前半相同）
+ “遇其夷主”：但遇到（遇）与自己平易相得的主人（夷主）。
+ “吉”：可获吉祥（吉）。
+ 爻传“丰其蔀，位不当也；日中见斗，幽不明也；遇其夷主，吉行也”：遮蔽光明，是因为（九四）位置不当；正午见星斗，是因为幽暗不明；遇到平易之主，说明前行可获吉祥。

**相关性**：九四阳刚失正，已入 上卦震动 之体，是 有行动力但处境不佳者。它也面临 “丰其蔀，日中见斗” 的 昏暗局面（爻传归因于其 “位不当”）。但转机在于 “遇其夷主”。“夷主”指 平易、可亲的君主，在卦中指 初九（与九四同为阳爻，但初九在下为明，九四在上为动，二者 明动相求）。九四虽处昏暗，但能 向下寻求，与 初九之明 相遇结合。动者得明指引，明者得动施行，君臣相得，故能 冲破黑暗，携手前行（吉行），获得 吉祥。此爻与六二形成 对比：同样身处黑暗，六二靠 内在诚信（孚） 感化，九四靠 向外遇合（遇） 突破。它说明：在丰大的困境中，寻找 志同道合、优势互补的伙伴，是 打破僵局的重要途径。


### 六五：来章，有庆誉，吉。


**原文**：来章，有庆誉，吉。

**白话**：招来贤明之士，有福庆和声誉，吉祥。

**小象传**
**原文**：六五之吉，有庆也。

**白话**：六五爻之所以吉祥，是因为有值得庆贺的好事。


**说明**

这是 丰大的核心——柔君纳明，天下归心。

+ “来章”：招来（来）贤明之士（章，文采，喻贤明）。
+ “有庆誉，吉”：必有福庆（有庆）和声誉（誉），吉祥（吉）。
+ 爻传“六五之吉，有庆也”：六五的吉祥，是因为有福庆。

**相关性**：六五阴柔居中，居 尊位，是丰大之世的 君主。其 自身并非强明（阴柔），但 持守中道。其 致丰之道 在于 “来章”——主动 招徕、汇聚（来） 天下的 贤明英才（章）。因为君主 谦柔中正，虚怀若谷，故能 吸引贤者来归。贤者毕至，则 光明普照，德政施行，自然带来 举国的福庆（庆） 和君主的 美誉（誉），故而 吉祥。爻传强调 “有庆也”，指出其 吉祥 是 普惠天下 的 共同福庆，而非 一己之私利。此爻指明了领导者在丰大之世的 根本任务：不在于 自身逞强，而在于 搭建平台，汇聚光明（人才），如此方能 持盈保泰，吉庆有余。


### 上六：丰其屋，蔀其家，窥其户，阒其无人，三岁不觌，凶。


**原文**：丰其屋，蔀其家，窥其户，阒其无人，三岁不觌，凶。

**白话**：丰大其房屋，障蔽其居室，从门缝窥视，寂静无人，三年不见其人，有凶险。

**小象传**
**原文**：“丰其屋”，天际翔也。“窥其户，阒其无人”，自藏也。

**白话**：丰大他的房屋，是像鸟飞在天上一样高远。从门户向里窥视，寂静不见人影，是他自己隐藏起来了。


**说明**

这是 丰大的终结——自我壅蔽，丰极而亡。

+ “丰其屋，蔀其家”：丰大其房屋（丰其屋），遮蔽其居室（蔀其家）。
+ “窥其户，阒其无人”：从门缝窥视（窥其户），寂静空无一人（阒其无人）。
+ “三岁不觌，凶”：三年不见露面（三岁不觌），凶险（凶）。
+ 爻传“丰其屋，天际翔也；窥其户，阒其无人，自藏也”：丰大其房屋，是（得意忘形）飞翔于天际；从门缝窥视空无一人，是自我隐藏。

**相关性**：上六阴柔处卦之极，是丰大之世的 终极迷失者。“丰其屋，蔀其家”描绘了一幅 矛盾而可悲的景象：拼命 扩大、装饰外在的屋宇（丰其屋），却同时用厚厚的帘幕将内部 完全遮蔽起来（蔀其家）。这象征一个人 在丰大富足后， 极度膨胀（天际翔），追求 外在的奢华与排场，却 内心昏暗，自我封闭，与世隔绝。结果就是 “阒其无人”——从外面看 富丽堂皇，里面却 死寂空洞，毫无生机。“三岁不觌”强调这种 自我放逐、与世隔绝 的状态 持续很久，彻底断绝了 与他人的联系与交流。这无疑是 最大的凶险，意味着丰大走到了 孤立、腐朽、灭亡 的尽头。爻传“自藏也”点明：这非外力所致，纯属 自作自受。此爻是对 丰大之弊 的 最深刻警示：若丰大不能带来 光明、开放与共享，反而导致 傲慢、封闭与孤独，那么 “丰” 便是 “凶” 的 前奏。


## 总结

**总结**：丰卦的现代启示

丰卦的 “日中则昃，月盈则食” 是关于 “盛大、成功、巅峰”的深邃智慧与永恒警示。它既描绘了 “明以动” 创造的 辉煌成就，也毫不留情地揭示了 盛极必衰 的 铁律。

实践丰大之道的六个阶段与陷阱：

+ 明动相配（初九）：遇其配主，虽旬无咎，往有尚。
+ 明被遮蔽（六二）：丰其蔀，日中见斗，往得疑疾，有孚发若，吉。
+ 明极被蔽（九三）：丰其沛，日中见沬，折其右肱，无咎。
+ 动而遇明（九四）：丰其蔀，日中见斗，遇其夷主，吉。
+ 柔中招贤（六五）：来章，有庆誉，吉。
+ 自我封闭（上六）：丰其屋，蔀其家，窥其户，阒其无人，三岁不觌，凶。

核心心法：大象传总纲——“雷电皆至，丰；君子以折狱致刑。” 这意味着：

+ “雷电皆至，丰”：是 丰卦之象（雷电交加，声势浩大）。
+ “君子以折狱致刑”：君子效法此象，明察决断狱讼，威严施行刑罚。

这是丰卦精神的 独特应用。君子从雷电的 光明（离）与威动（震） 中，领悟到在 国家丰大、政事繁盛 之时，**更需运用法律的 光明（明察） 与 威严（动刑），来 裁断是非，惩治奸恶，以维持盛世的 公正与秩序。这指出了 丰大局面 得以持久 的 制度保障—— 法治的明与威。

根本精神：彖传 “丰，大也。明以动，故丰。王假之，尚大也。勿忧，宜日中，宜照天下也。日中则昃，月盈则食，天地盈虚，与时消息，而况于人乎？况于鬼神乎？” 揭示了丰大之道的宇宙法则：

+ “丰，大也。明以动，故丰”：丰，就是丰大。光明（离）而行动（震），所以能丰大。解释 卦德 与 卦名。
+ “王假之，尚大也”：君王可以达到丰大，是崇尚宏大的美德。
+ “勿忧，宜日中，宜照天下也”：不必忧虑，宜于保持如日正中，这样才能普照天下。强调 “日中” 的目的是 “照天下”，即将丰大之 光明与恩泽 广施于众。
+ “日中则昃，月盈则食，天地盈虚，与时消息，而况于人乎？况于鬼神乎？”：太阳到了正中就要偏斜，月亮圆满之后就要亏蚀；天地的盈满与虚缺，都随着时间而消长息止，何况是人呢？何况是鬼神呢？ 这是丰卦最震撼人心、最具哲学高度的 论断。它将 “丰”与“衰” 的 辩证关系，上升到 宇宙运行的根本规律（天地盈虚） 和 时间流转的必然过程（与时消息） 的高度。人间的丰大，同样 无法逃脱这一规律。因此，“勿忧” 并非 盲目乐观，而是在 深刻认知规律 后的一种 清醒的坦然 与 积极的持守（宜日中）。

丰卦告诉我们：“丰”是人人都向往的 美好境界，但 通往和维持“丰”的道路，充满了 光明与黑暗的搏斗（蔀、沛）、合作与孤立的抉择（配主、夷主）、开放与封闭的考验（来章、自藏）。其 最高智慧 在于 彖传的 最后一句——深刻领悟 “天地盈虚，与时消息” 的 大道，从而在 最丰盛的时刻，**保持如日居中的 清醒、中正与普照之心，延缓“昃”与“食”的到来，并坦然面对 必然的周期。这便是在 “雷电皆至” 的 盛大交响 中，所蕴含的关于 成功、巅峰、规律与持守 的 永恒天机。
