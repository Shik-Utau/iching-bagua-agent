# 涣卦（巽上坎下）

**卦画**：䷺

## 总论：离散与凝聚的辩证智慧

**核心短词**：“风行水上”

**卦象**：上巽（☴）为风、为木，下坎（☵）为水。风水涣。风行水上，涣散流动。

**核心卦辞**：“亨，王假有庙，利涉大川，利贞。”

**总纲**：涣卦象征 “涣散、离散”。亨通，君王以至诚感格神灵而保有宗庙，利于涉越大河巨流，利于守持正固。

+ “亨”：亨通（亨）。离散本身看似 危机，但卦辞却首言 “亨”。这揭示了 涣卦的 核心奥义：离散是 危机，也是 转机。旧的秩序与结构 瓦解，为新的整合与创造提供了 空间。关键在于如何 应对。
+ “王假有庙”：君王以至诚感格神灵而保有宗庙（王假有庙）。这是应对涣散的首要 与 根本 策略。“庙” 是 宗庙，象征精神信仰、文化传统、人心所系的 核心。在天下涣散 之时，君王不是急于用强力去 收拢，而是首先回到最根本的精神与文化 原点（有庙），以至诚之心 （假） 去感召神灵与 祖先，重新凝聚人心的认同感与 归属感。这是 “聚心”。
+ “利涉大川”：利于涉越大河巨流（利涉大川）。“大川” 象征巨大的 艰难险阻。当人心重新 凝聚，精神有了 依托，涣散的力量就能被转化为克服险阻、开创新局的 动力。这是 “聚力”。
+ “利贞”：利于守持正固（利贞）。在涣散与凝聚的 过程中，必须坚守 正道。无论是 凝聚人心，还是 克服险阻，都不能偏离中正 的原则，否则可能形成新的、更危险的结党或 专制。

**本质**：涣卦描述 “风行水上，涣” 的状态。风在水上吹拂，水面泛起 涟漪，水波 扩散，象征一种 离散、扩散、流动、变化 的 态势。其**核心精神**是：探讨 “散”与“聚”的辩证关系——如何在涣散的危机中看到 生机，如何通过凝聚人心与精神来克服 涣散，并将涣散的能量引导向积极的 方向（如 涉川）。它强调 “王乃在中也”——君王的中正与至诚是凝聚涣散的 核心枢纽。

## 卦辞

### 经

**原文**：亨。王假有庙，利涉大川，利贞。

**白话**：亨通。君王以至诚感格神灵，保有宗庙，利于涉越大河巨川，利于守持正固。

### 彖传

**原文**：涣，亨。刚来而不穷，柔得位乎外而上同。“王假有庙”，王乃在中也。“利涉大川”，乘木有功也。

**白话**：涣卦，通达。阳刚者来到而不会穷困，阴柔者在外面取得位置而与上位者同心。“君王来到宗庙”，是说君王处于中位。“适宜渡过大河”，是说乘着木舟而能建功立业。

### 大象传

**原文**：风行水上，涣；先王以享于帝立庙。

**白话**：风在水面上吹拂，象征涣散；先代君王因此祭祀天帝，建立宗庙。


## 爻辞

### 初六：用拯马壮，吉。


**原文**：用拯马壮，吉。

**白话**：借助健壮的马匹来拯救，吉祥。

**小象传**
**原文**：初六之吉，顺也。

**白话**：初六爻之所以吉祥，是因为能够顺从。


**说明**

这是 涣散的初始——力量微弱，需借外力。

+ “用拯马壮”：借助（用）健壮的（壮）良马（马）来拯救（拯）。
+ “吉”：吉祥（吉）。
+ 爻传“初六之吉，顺也”：初六的吉祥，是因为（其）顺承（九二）。

**相关性**：初六阴柔处下，是涣散的 开始，自身力量极其 微弱，如同陷入坎险的 底部。爻辞没有让其独自 挣扎，而是指示其 “用拯马壮”。“马” 象征阳刚的 力量，在此指九二 阳爻。初六明智地选择顺承 （顺也） 并借助上方九二的 强大力量（马壮）来拯救自己脱离 险境。这体现了在涣散初起、自身力弱时 的 生存智慧：不 逞强，不 孤立，主动依附或寻求强有力的 援助，方能 转危为安，得 “吉”。此爻确立了应对涣散 的 基本策略之一： 团结互助，借力脱险。


### 九二：涣奔其机，悔亡。


**原文**：涣奔其机，悔亡。

**白话**：涣散之时奔向可供凭依的几案，悔恨消亡。

**小象传**
**原文**：“涣奔其机”，得愿也。

**白话**：洪水冲散了人群，大家奔向几案般的高地，得以实现安定下来的愿望。


**说明**

这是 涣散的中坚——找到依托，安定心神。

+ “涣奔其机”：涣散之时（涣）奔向（奔）几案（机，安身之所）。
+ “悔亡”：悔恨消亡（悔亡）。
+ 爻传“涣奔其机，得愿也”：涣散之时奔向几案，是得遂所愿。

**相关性**：九二阳刚居中，是下卦 坎险 中的 中流砥柱。“机” 通 “几”，是古人席地而坐时倚靠的 矮桌，象征安稳、可以凭依的 处所。在天下涣散、人心浮动 之际，九二没有盲目 奔走，而是迅速找到一个可以安身立命、稳定心神的 “据点”（奔其机）。这个 “机”，对内是自身的中正品德与 定力，对外是可以信赖的组织或 环境。因为找到了这个 “安身之所”，所以原先可能因涣散而产生的焦虑与悔恨便 自然 消亡（悔亡）。爻传称其 “得愿也”，说明这正是在涣散中最渴望得到 的 东西——安定与 凭依。此爻指明了在涣散局面中 的 关键行动：迅速确立一个稳固的 立足点，以此为基础，方能进可图 凝聚，退可保 自身。


### 六三：涣其躬，无悔。


**原文**：涣其躬，无悔。

**白话**：涣散自身（私欲），没有悔恨。

**小象传**
**原文**：“涣其躬”，志在外也。

**白话**：涣散自身，是因为志向在向外发展。


**说明**

这是 涣散的深化——消散私念，融入大局。

+ “涣其躬”：涣散自身（躬，指自身私心、小我）。
+ “无悔”：无所悔恨（无悔）。
+ 爻传：无直接对应，但结合上下文，其意自明。

**相关性**：六三阴柔不中不正，处下卦坎险之 上，上无 应爻。其处境 尴尬，容易固守一己之 私。爻辞却给出了一个看似 矛盾 的 指令：“涣其躬”。在需要凝聚的 时候，为何要“涣散 自身”？此处的 “躬”，并非指肉体的 消散，而是指内心 的 “小我”—— 私心、成见、固执 的 自我意识。“涣其躬” 意味着主动地破除这些狭隘的自我 壁垒，让自己的心意与 精神 “涣散” 开来，去顺应时代的 大潮，融入集体的 需要。这是一种更高境界 的 “凝聚”——通过消散 “小我”，来成就 “大我”。如此，虽然可能失去一些个人的 东西，但因为符合大道与 时势，故 “无悔”。此爻揭示了应对涣散的一种深刻 的 心法： 有时，真正的 出路 不在于 “聚拢” 什么，而在于 “散掉” 什么——散掉 私心，方能与公义 相合。


### 六四：涣其群，元吉。涣有丘，匪夷所思。


**原文**：涣其群，元吉。涣有丘，匪夷所思。

**白话**：涣散其朋党，至为吉祥。涣散小群，聚成山丘般的大群，不是平常思虑所能及。

**小象传**
**原文**：“涣其群，元吉”，光大也。

**白话**：众人离散，大吉大利，这是品德光明正大的表现。


**说明**

这是 涣散的升华——打破小圈子，实现大团结。

+ “涣其群，元吉”：涣散其朋党（群），至为吉祥（元吉）。
+ “涣有丘，匪夷所思”：涣散（小群）而聚成山丘（大群），不是平常思虑所能及（匪夷所思）。
+ 爻传“涣其群，元吉，光大也”：涣散其朋党，至为吉祥，是因为（其）德行光明正大。

**相关性**：六四阴柔得正，居上卦巽顺之 始，下无 应爻，上 承 九五 君王。“群” 指私下的朋党、小团体。在涣散的 时代，人们容易 抱团取暖，形成各种利益 小圈子，这看似是一种 “凝聚”，实则是更大范围涣散的原因和 表现，会阻碍真正的天下 大同。六四作为 近君大臣，其伟大之处 在于 “涣其群”——不是去建立或巩固自己的 小圈子，而是主动去涣散、拆解这些不利于整体团结的 朋党。爻传盛赞此为 “光大也”，因为这体现了光明正大、大公无私的 品德。其结果是 “元吉”（至为吉祥）。更 奇妙的是，“涣有丘”：当这些狭隘的小团体 被 “涣散” 后，其成员不是变成 一盘散沙，而是以更高的原则 （如对君王的忠诚、对道义的追求） 重新 凝聚，形成像山丘一样稳固而崇高的 大团体（丘）。这种 “散小聚大” 的转化 效果，超出寻常的 思虑，故称 “匪夷所思”。此爻是涣卦思想的 巅峰，揭示了政治与组织 管理的 至高艺术：通过破除私下的、局部的 结盟（涣其群），来实现整体的、基于正道 的 大团结（涣有丘）。


### 九五：涣汗其大号，涣王居，无咎。


**原文**：涣汗其大号，涣王居，无咎。

**白话**：像发汗般发布盛大号令，涣散君王积聚的财富（以济民），没有咎害。

**小象传**
**原文**：“王居无咎”，正位也。

**白话**：君王居此没有灾祸，是因为处在正当的位置上。


**说明**

这是 涣散的枢纽——君王至诚，号令畅通，散财济众。

+ “涣汗其大号”：像发散汗水（汗）一样发布（其）盛大号令（大号）。
+ “涣王居”：涣散（积聚）君王（王）的居所（居，指财富、库藏）。
+ “无咎”：没有咎害（无咎）。
+ 爻传“王居无咎，正位也”：君王涣散其积聚而无咎害，是因为（其）居于正位（行为正当）。

**相关性**：九五阳刚中正，居 尊位，是凝聚涣散 的 核心—— 君王。“涣汗” 是一个绝妙 的 比喻：汗水从体内 发出，遍布 全身，不可 收回。以此比喻君王 发布的 盛大号令（大号），也应该像出汗 一样，发自内心的 至诚，畅通无阻地传达到每一个 角落，深入人心，不可更改或 收回。这是 “聚心” 的 关键 举措。“涣王居” 则是 “聚力” 的具体 行动：“王居” 指君王积聚的财富与 资源。在涣散危难 之时，君王不是紧守 财库，而是 主动 “涣散” 它们，散发出去赈济 百姓，拯救 危难。这看似是 “散财”，实则是最有效的 “聚民”。爻传解释其所以 “无咎”，是因为 九五 “正位也”——既指其居于君王 的正位，更指其行为符合君王应有的 正道（散财济民）。此爻指明了领导者在危机中的核心责任 与 行动：以至诚号令统一 思想，以散财济众来凝聚 力量。


### 上九：涣其血，去逖出，无咎。


**原文**：涣其血，去逖出，无咎。

**白话**：涣散其血灾（伤害），远离而脱出，没有咎害。

**小象传**
**原文**：“涣其血”，远害也。

**白话**：洪水冲散了血灾，远离了祸害。


**说明**

这是 涣散的终结——伤害消散，远避自安。

+ “涣其血去逖出”：涣散（其）伤害（血）使之离去（去），远走（逖）避害而出（出）。
+ “无咎”：没有咎害（无咎）。
+ 爻传“涣其血，远害也”：涣散其伤害，是为了远离祸害。

**相关性**：上九阳刚处卦之极，是涣散过程的 终点。“血” 象征伤害、流血 冲突。“逖” 是 远。上九身处极高 之位，目睹或经历了整个涣散 过程。在一切即将尘埃落定或转化完成 之际，其最后的智慧 是 “涣其血”——让那些残留的伤害与怨气 也 彻底 “涣散” 掉，随风 而逝。同时，“去逖出”：自身也主动远离是非 之地，保持 距离，以免被残余的祸患所 波及。爻传直言其目的是 “远害也”。这并非消极 逃避，而是一种明哲保身的清醒与 通达。当大的涣散危机已经 度过，新的秩序正在 建立，个人最重要的就是避免成为旧矛盾的 牺牲品，为新的开始保存 力量。故 “无咎”。此爻为涣卦画上了一个理性而冷静 的 句号：涣散的最终目的，是消除 伤害，远离 祸患，获得 平安。


## 总结

**总结**：涣卦的现代启示

涣卦的 “风行水上” 是关于 “危机管理、组织变革、人心凝聚”的深刻哲学。它系统阐述了从离散的危机中看到 生机，并通过一系列由内而外、由近及远的 策略，最终实现更高层次凝聚的 完整过程。

应对涣散危机的六个步骤与境界：

+ 借力拯济（初六）：用拯马壮，吉。
+ 得其所安（九二）：涣奔其机，悔亡。
+ 破除私我（六三）：涣其躬，无悔。
+ 破除朋党（六四）：涣其群，元吉；涣有丘，匪夷所思。
+ 君王发令（九五）：涣汗其大号，涣王居，无咎。
+ 远害自保（上九）：涣其血去逖出，无咎。

核心心法：大象传总纲——“风行水上，涣；先王以享于帝立庙。” 这意味着：

+ “风行水上，涣”：是 涣卦之象（风行水上，推波散澜）。
+ “先王以享于帝立庙”：先王观此象，通过祭祀天帝、建立宗庙（来凝聚人心）。
这是涣卦应对策略的根本与 起点。先王从风行水上的涣散 之象中，领悟到在物质与组织层面涣散 时，最首要、最根本的工作是在精神与文化 层面 进行 “凝聚”。“享于帝” 是沟通超越性的 信仰 与 价值（天）；“立庙” 是巩固历史性的传统与 认同（祖）。通过 这两者，为涣散的人群重新找到共同的精神家园与意义 归属。这指出了应对任何重大危机或变革 的 首要原则：重建或强化共同的价值观与文化 认同。

根本精神：彖传 “涣，亨。刚来而不穷，柔得位乎外而上同。‘王假有庙’，王乃在中也。‘利涉大川’，乘木有功也。” 揭示了涣散转化的内在机理与力量源泉：

+ “涣，亨。刚来而不穷，柔得位乎外而上同”：涣散，亨通。（九二）阳刚下来（处险中）而不会穷困，（六四）阴柔得位在外而向上与（九五）协同。解释卦辞 “亨” 的 原因，从卦爻结构上说明为何涣散 能 亨通：因为有九二的阳刚力量 （刚来） 在险中作为支柱而 不穷竭，有六四的柔顺力量 （柔得位） 在外配合君王而协同 一致。这是涣中有聚的内在结构 保证。
+ “‘王假有庙’，王乃在中也”：“君王以至诚感格神灵而保有宗庙”，是因为君王居于中正之位。强调 “王假有庙” 这一核心举措之所以 有效，根本在于君王自身的中正品德 与 地位（在中）。心正则感格 神灵，位中则凝聚 万民。
+ “‘利涉大川’，乘木有功也”：“利于涉越大河巨流”，是因为乘坐木舟（喻巽木）而获成功。解释 “利涉大川” 的 原因。上卦巽 为木、为舟，下卦坎 为水、为川。卦象本身就是 “乘木舟以涉川”。这意味着，当人心通过 “王假有庙” 凝聚 起来后，这种凝聚力本身就如同一艘 坚固的 大船（巽木），足以承载众人渡过涣散的 险难 之水（坎水），开创 新局，建立 功业（有功）。

涣卦告诉我们：“散” 与 “聚” 是 一体两面。旧的 “聚”（僵化结构） 的 “散”，正是新的、更有活力的 “聚” 的 开始。应对 “涣” 的 最高智慧，不是恐惧与 压制，而是首先在精神层面建立强大的 向心力（享帝立庙），然后 以此 为核心，破除私心 与 朋党（涣躬、涣群），畅通号令与 救济（涣汗、涣居），最终将涣散的能量引导向克服困难、开创未来的共同行动 中（涉大川）。这便是在 “风行水上” 的 扩散流动 中，所蕴含的关于 危机转化、人心凝聚与组织重生 的 深刻智慧。
