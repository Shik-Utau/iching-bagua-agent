# 节卦（坎上兑下）

**卦画**：䷻

## 总论：节制之道的哲学

**核心短词**：“制数度，议德行”

**卦象**：上坎（☵）为水、为险，下兑（☴）为泽、为悦。水泽节。泽上有水，以堤防节制水流。

**核心卦辞**：“亨，苦节不可贞。”

**总纲**：节卦象征 “节制、节度”。亨通，但过分节制以致苦涩则不可守持正固。

+ “亨”：亨通（亨）。适当的节制能防止过度，避免祸患，使事物 有序发展，故本身是亨通的。
+ “苦节不可贞”：过分节制以致苦涩（苦节）则不可守持正固（不可贞）。这是节卦的 核心辩证思想。节制是 美德，但一旦 过度，变成 “苦节”——令人痛苦、难以忍受的 节制，就走向了 反面，不再是 正道，故 “不可贞”（不可固守）。卦辞开篇就 划定了 “节” 的 边界：适度为 亨，过度为 苦。

**本质**：节卦描述 “泽上有水” 的状态。泽（兑） 的容量 有限，需要堤坝来调节、容纳上方的 水（坎），防止 泛滥。象征一种以制度、规范、自律来调节欲望、行为、资源的 管理智慧。其**核心精神**是：探讨 “节”的智慧——如何建立并遵守适当的 尺度与规范，以达到 亨通，同时警惕过度节制带来的 僵化与痛苦。它强调 “当位以节，中正以通”——节制要 得当、适中，方能畅通。

## 卦辞



### 经

**原文**：亨。苦节不可贞。

**白话**：亨通。但过分节制以致痛苦，则不可守持正固。

### 彖传

**原文**：节，亨，刚柔分而刚得中。“苦节不可贞”，其道穷也。说以行险，当位以节，中正以通。天地节而四时成，节以制度，不伤财，不害民。

**白话**：节制之道，亨通顺利，因为刚强与柔顺相互区分，而刚强居于中正之位。“过度节制不可持久”，是因为那样会导致道路穷尽。以愉悦的心态面对险阻，居于适当的位置进行节制，保持中正就能通达顺利。天地有节制才形成四季更替，用制度来规范节制，就能不浪费财物，不伤害百姓。

### 大象传

**原文**：泽上有水，节；君子以制数度，议德行。

**白话**：水泽之上有水，象征节制；君子因此制定礼数法度，评议道德行为。


## 爻辞

### 初九：不出户庭，无咎。


**原文**：不出户庭，无咎。

**白话**：不走出门户庭院，没有咎害。

**小象传**
**原文**：“不出户庭”，知通塞也。

**白话**：待在家里不外出，是因为明白道路通畅还是阻塞的道理。


**说明**

这是 节制的开端——谨言慎行，知止不出。

+ “不出户庭”：不走出（不出）门户庭院（户庭）。
+ “无咎”：没有咎害（无咎）。
+ 爻传“不出户庭，知通塞也”：不走出门户庭院，是懂得畅通与阻塞的时机。

**相关性**：初九阳刚处下，是节制的 初始。“户庭” 是最内层、最私密的 空间。爻辞劝诫：在事情开始或地位卑微 时，最重要的节制 是 “不出”——不轻易向外行动、不随意发表 言论。因为此时力量 薄弱，情况 不明，贸然外出容易犯错或 招祸。爻传点明其智慧 在于 “知通塞也”：懂得何时该畅通（出），何时该阻塞（不出）。这种对时机的敏感与 自律，是节制的 第一课，故 “无咎”。


### 九二：不出门庭，凶。


**原文**：不出门庭，凶。

**白话**：不走出家门庭院，有凶险。

**小象传**
**原文**：“不出门庭，凶”，失时极也。

**白话**：待在家里不出去，会有凶险，这是因为他完全错过了时机。


**说明**

这是 节制的错位——该进不进，坐失良机。

+ “不出门庭”：不走出（不出）家门庭院（门庭）。
+ “凶”：有凶险（凶）。
+ 爻传“不出门庭凶，失时极也”：不走出家门庭院而有凶险，是因为极度错失时机。

**相关性**：九二阳刚居中，地位和能力比初九有所提升。“门庭” 比 “户庭” 更 靠外，是家庭与社会的 交界。九二本应在适当的时机走出 家门，有所作为，服务 社会。但其却依然固守 “不出” 的 教条，不敢越雷池 一步。这就是节制 过度，变成了保守与 退缩。爻传严厉批评 其 “失时极也”——极度地错失了行动的 时机。该节制时 节制，该行动时 行动，方为 中道。九二的错误在于不知 变通，当出而 不出，故招致 “凶”。此爻与初九形成 对比，强调 “节” 必须因时、因位而 异。


### 六三：不节若，则嗟若，无咎。


**原文**：不节若，则嗟若，无咎。

**白话**：不能节制，就会嗟叹悲伤，（但能嗟叹自省则）没有咎害。

**小象传**
**原文**：“不节之嗟”，又谁咎也？

**白话**：不能节制而带来的叹息，又能责怪谁呢？


**说明**

这是 节制的反面——放纵而悔，悔则免咎。

+ “不节若，则嗟若”：不能节制（不节若），于是嗟叹悲伤（则嗟若）。
+ “无咎”：（但知悔则）无咎害（无咎）。
+ 爻传“不节之嗟，又谁咎也”：不能节制而嗟叹，又能归咎于谁呢？

**相关性**：六三阴柔不中不正，处下卦兑悦之 极，象征 贪图 享乐，缺乏 自制力。“不节若” 描述其放纵 自己，不知节制的 状态。结果自然是带来麻烦与 损失，故 “嗟若”（叹息后悔）。爻传 反问 “又谁咎也？”：这能怪 谁呢？ 咎由自取。然而，爻辞却 给出了 “无咎” 的 出路：虽然犯了 错，但因为能产生嗟叹（即悔恨 之心），认识到 错误，就有了改正的 可能。知错能改，善莫大焉，故最终可 “无咎”。此爻揭示了节制修养的一个 重要 过程：从 “不节” 到 “知嗟”（悔），再到可能的 “无咎”（改）。


### 六四：安节，亨。


**原文**：安节，亨。

**白话**：安然施行节制，亨通。

**小象传**
**原文**：“安节之亨”，承上道也。

**白话**：安心节制所以亨通，是因为顺承了上面的正道。


**说明**

这是 节制的得宜——顺承正道，心安理得。

+ “安节”：安然奉行节制（安节）。
+ “亨”：亨通（亨）。
+ 爻传“安节之亨，承上道也”：安然奉行节制而亨通，是因为顺承上位（九五）的正道。

**相关性**：六四阴柔得正，上承九五中正 之 君。其 “节” 不是 被迫的，也不是 痛苦的，而是 “安” 的——安然、心安理得、自然而然地遵守 规范。因为其所遵守的规范 （节），是来自上位的正道 （上道），本身就是合理的。顺承 此道，既是尽 本分，也是保 平安，故能获“亨”通。此爻描绘了在良好制度下，个体自觉守节的 理想 状态：制度 合理，个人 安心，社会 亨通。


### 九五：甘节，吉，往有尚。


**原文**：甘节，吉，往有尚。

**白话**：甘美愉快的节制，吉祥，前往会受到尊尚。

**小象传**
**原文**：“甘节之吉”，居位中也。

**白话**：甘美适中的节制之所以吉祥，是因为九五爻居于上卦中位，能持守中道。


**说明**

这是 节制的核心——君王设节，悦民服之。

+ “甘节”：甘美愉快的节制（甘节）。
+ “吉，往有尚”：吉祥（吉），前往必受尊尚（往有尚）。
+ 爻传“甘节之吉，居位中也”：甘美愉快的节制而吉祥，是因为（九五）居于中正之位。

**相关性**：九五阳刚中正，居 尊位，是节卦的 卦主，代表制定并推行节制之道的 君主。其 “节” 的境界 是 “甘”——甘美、令人 愉悦。这与卦辞 警告 的 “苦节” 截然相反。“甘节” 意味着君主所设立的制度与 规范，是适中的、合理的、符合民情 的，既能起到调节约束 作用，又不让人感到痛苦 压抑，反而能带来秩序与和谐的美好 感受。因为其 “居位中也”（持守中正 之道），所以能制定出 “甘节”。如此，不仅自身 吉祥，其政策 推行 下去（往），也必受到民众的推崇与 尊尚（有尚）。此爻指明了领导者在制度建设上的 最高 标准：让节制本身成为一种 “甘美” 的 体验，而非 “苦涩” 的 负担。


### 上六：苦节，贞凶，悔亡。


**原文**：苦节，贞凶，悔亡。

**白话**：过分节制以致痛苦，守持正固以防凶险，悔恨消亡。

**小象传**
**原文**：“苦节贞凶”，其道穷也。

**白话**：过分节制而坚守不变会有凶险，是因为这条路已经走到了尽头。


**说明**

这是 节制的极端——过度为苦，悔则转机。

+ “苦节”：过分节制以致苦涩（苦节）。
+ “贞凶”：守持此道（贞）有凶险（凶）。
+ “悔亡”：但知悔则凶险消亡（悔亡）。
+ 爻传“苦节贞凶，其道穷也”：过分节制而固守有凶险，是因为（其）道路穷困不通。

**相关性**：上六阴柔处卦之极，是节制之道的终点与 极端。它将 “节” 推向了 反面，成为卦辞所 警告 的 “苦节”。“苦节” 是令人痛苦、难以忍受的苛酷 节制，比如过度的节俭变成 吝啬，严格的律法变成 严刑峻法。爻传 指出 “其道穷也”：这条路已经走到了 尽头，行不通了。如果还固执地 守持 此道（贞），必然招致反抗与 崩溃，故 “凶”。然而，爻辞再次给出了 一线 生机：“悔亡”。如果能意识到这是 “苦节”，产生悔悟 之心，并加以 调整，那么 “凶” 的后果就可能避免或 消除（悔亡）。此爻作为卦的 终结，与 卦辞 “苦节不可贞” 首尾呼应，并与六三爻 “不节若则嗟若” 形成 另一组 对比：六三是 “不节” 而 悔，上六 是 “过节”（苦节） 而 悔。两者都因 “悔” 而得 “无咎” 或 “悔亡”。这再次强调了 “节” 的中道智慧与 “悔” 的修正 价值。


## 总结

**总结**：节卦的现代启示

节卦的 “制数度，议德行” 是关于 “尺度、规范、自律”的平衡智慧。它深刻阐述了 “节” 的 双重性：适度则 亨，过度则 苦。

实践节制之道的六个层次与教训：

+ 慎始知节（初九）：不出户庭，无咎。
+ 当出不出（九二）：不出门庭，凶。
+ 失节知悔（六三）：不节若，则嗟若，无咎。
+ 安然有节（六四）：安节，亨。
+ 中正以节（九五）：甘节，吉，往有尚。
+ 节极则苦（上六）：苦节，贞凶，悔亡。

核心心法：大象传总纲——“泽上有水，节；君子以制数度，议德行。”这意味着：

+ “泽上有水，节”：是节卦之象（水在泽上，需堤防调节）。
+ “君子以制数度，议德行”：君子效法此象，制定礼数法度，评议道德行为。

这是节卦精神的社会应用。君子从水需堤防以成泽的 现象中，领悟到治理社会也需要 “制” 与 “议”。“制数度”是建立外在的、客观的制度、标准、规范（数度）；“议德行”是培养内在的、主观的道德评议与 自觉（德行）。二者 结合，方能实现从外在约束到内在自律的完整节制 体系。

根本精神：彖传“节，亨。刚柔分而刚得中。‘苦节不可贞’，其道穷也。说以行险，当位以节，中正以通。天地节而四时成；节以制度，不伤财，不害民。”揭示了节制之道的宇宙法则与社会价值：

+ “节，亨。刚柔分而刚得中”：节卦，亨通。因为（卦中）阳刚与阴柔分明，且（九五、九二）阳刚获得中位。从卦体结构解释“亨”的原因。
+ “‘苦节不可贞’，其道穷也”：重申卦辞警告，并指出原因。
+ “说以行险，当位以节，中正以通”：（下卦兑）欣悦而（上卦坎）行于险难，（诸爻）居位适当以行节制，（九五）持中守正而可畅通。从卦德、爻位综合解释如何实现“亨”。
+ “天地节而四时成；节以制度，不伤财，不害民”：天地有所节制而形成四季；用制度来推行节制，就能不浪费财物，不伤害百姓。这是节卦思想的最高升华。它将“节”的原理上升到 宇宙规律（天地节），并落实到 治国根本（节以制度）。指出 “节” 的 终极目的，是 为了 “不伤财，不害民”——保护 资源，爱护 人民。这使得 “节” 从个人 修养，扩展为一项关乎自然规律与社会福祉的根本 原则。

节卦告诉我们：“节”是一种关乎生存与发展的根本 智慧。无论是个人的欲望与 行为，还是组织的资源与 制度，抑或国家的财政与 政策，都需要 “节”。其艺术在于 把握 “度”：从 “不出户庭” 的 谨慎，到 “甘节” 的 愉悦，避免陷入 “不出门庭” 的僵化与 “苦节” 的 苛酷。其最高境界是九五爻 的 “甘节”——让节制本身成为一种符合中道、令人心悦诚服的美好 秩序。这便是在 “泽上有水” 的调节意象中，所蕴含的关于 分寸、制度、和谐与可持续性 的永恒法则。
