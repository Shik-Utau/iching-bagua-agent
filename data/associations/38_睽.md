# 睽卦（离上兑下）

**卦画**：䷥

## 总论：对立与统一的哲学

**核心短词**：“以同而异”

**卦象**：上离（☲）为火、为中女，下兑（☱）为泽、为少女。火泽睽。火炎上，泽润下，二女同居，其志不同行。

**核心卦辞**：“小事吉。”

**总纲**：睽卦象征 “乖离、对立、矛盾”，做小事吉祥。

+ “小事吉”：做小事（小事）吉祥（吉）。在意见不合、人心离散（睽）的时候，不宜谋划大事、推动大变革，而应 从具体、细小、务实的事情做起，逐步建立信任，化解分歧。

**本质**：睽卦描述 “差异与对立” 的状态。上离火向上燃烧，下兑泽向下渗透，运动方向相反；离为中女，兑为少女，虽同居一室（同），但志向不同（异）。其**核心精神**是：**承认并正视差异与矛盾（睽）的客观存在，并智慧地 在“异”中寻求“同”，在“分”中促成“合”，最终实现 “睽”的积极效用（时用大矣哉）。

## 卦辞

### 经

**原文**：小事吉。

**白话**：做小事吉祥。

### 彖传

**原文**：睽，火动而上，泽动而下；二女同居，其志不同行。说而丽乎明，柔进而上行，得中而应乎刚，是以小事吉。天地睽而其事同也，男女睽而其志通也，万物睽而其事类也。睽之时用大矣哉！

**白话**：睽卦的卦象，就像火焰燃烧向上，泽水流动向下；又如同两个女子同居一室，心思却各奔东西。下卦兑为悦，依附于上卦离的光明，柔顺者前进向上，居中正之位又与阳刚者相应，因此做小事吉祥。天地上下分隔却共同化育万物，男女阴阳有别却能心意相通，万物形态各异却遵循相似的规律。睽卦所体现的差异与配合的道理，其作用真是大啊！

### 大象传

**原文**：上火下泽，睽；君子以同而异。

**白话**：上面是火下面是泽，象征乖离；君子因此求同存异。


## 爻辞

### 初九：悔亡。丧马勿逐，自复。见恶人，无咎。


**原文**：悔亡。丧马勿逐，自复。见恶人，无咎。

**白话**：悔恨消亡。丢失马匹不必追寻，它会自己回来。遇见恶人，没有咎害。

**小象传**
**原文**：“见恶人”，以辟咎也。

**白话**：见到恶人，是为了避免灾祸。


**说明**

这是 乖离的初态——不拒不合。

+ “悔亡”：悔恨消亡（悔亡）。
+ “丧马，勿逐，自复”：丢失（丧）马匹（马），不必追寻（勿逐），自己会回来（自复）。
+ “见恶人，无咎”：见到（见）恶人（恶人），并无咎害（无咎）。
+ 爻传“见恶人，以辟咎也”：见到恶人，是为了避免咎害。

**相关性**：初九阳刚处下，与九四敌应，是 “睽”的开始。“丧马”比喻 失去同道或有利条件。爻辞的智慧在于：**在乖离之初，不必强求挽回（勿逐），应 顺其自然，静待转机（自复）。对于与自己对立的人（恶人），也不必刻意回避或敌视（见），保持接触，了解其意，反而可以避免因误解而激化矛盾（辟咎）。这种 不拒绝、不迎合、坦然面对 的态度，能使可能的悔恨消亡（悔亡）。此爻教导：**处理分歧的第一步是 保持开放与耐心，不激化对立。


### 九二：遇主于巷，无咎。


**原文**：遇主于巷，无咎。

**白话**：在巷道中遇见主人，没有咎害。

**小象传**
**原文**：“遇主于巷”，未失道也。

**白话**：在小巷中遇到主人，说明没有迷失道路。


**说明**

这是 乖离的寻求——迁就相遇。

+ “遇主于巷”：遇见（遇）主人（主）于巷道（巷）。
+ “无咎”：无咎害（无咎）。
+ 爻传“遇主于巷，未失道也”：在巷道中遇见主人，并未丧失正道。

**相关性**：九二阳刚居中，与六五相应，但处于“睽”时，且前有九四阻碍。象征 虽有正应，但道路不通，无法在正堂大路相见。“巷”是 偏僻、非正式的小路。爻辞描述：**为了与主人（六五）相遇，不惜 迁回曲折，在巷道中相见。这种行为看似不够堂堂正正，但在乖离的时势下，是 务实、变通的做法，目的是为了 保持联系，不使关系彻底断绝。爻传肯定其 “未失道”——根本目标（求合）与内心正道并未丧失。此爻说明：**在矛盾中求合作，有时需要 放下身段，灵活变通，以非正式的方式保持沟通渠道。


### 六三：见舆曳，其牛掣，其人天且劓，无初有终。


**原文**：见舆曳，其牛掣，其人天且劓，无初有终。

**白话**：看见大车被拖曳，牛被牵制，驾车人遭受额上刺字和割鼻的刑罚，起初不利但终有好结果。

**小象传**
**原文**：“见舆曳”，位不当也。“无初有终”，遇刚也。

**白话**：车子被拖住，是因为位置没摆对。开头不顺最终有好结果，是因为遇到了刚强者。


**说明**

这是 乖离的挣扎——历难终通。

+ “见舆曳，其牛掣”：看见（见）车（舆）被拖曳（曳），牛（其牛）被牵制（掣）。
+ “其人天且劓”：其人（其人）遭受额刺（天）和削鼻（劓）的刑罚。
+ “无初有终”：起初（无初）不利，但终有善果（有终）。
+ 爻传“见舆曳，位不当也；无初有终，遇刚也”：车被拖曳，是因为位置不当；起初不利终有善果，是因为遇到阳刚（上九）。

**相关性**：六三阴柔失正，处上下卦之间，上承九四，上应上九，处境复杂。象征 在乖离局面中，自身力量弱，又受多方牵制（舆曳牛掣），甚至遭受打击与伤害（天且劓），故 起初艰难（无初）。但其 与上九终有正应，只要 坚持到底，最终能得到阳刚（上九）的接纳与帮助，从而 化解矛盾，获得善终（有终）。爻传指出：**其困境源于 “位不当”（自身条件不足），转机在于 “遇刚”（得到强者援手）。此爻揭示：**在矛盾中，弱小者可能经历磨难，但只要目标正确、坚持到底，仍有遇合的可能。


### 九四：睽孤，遇元夫，交孚，厉无咎。


**原文**：睽孤，遇元夫，交孚，厉无咎。

**白话**：乖离孤独之时，遇见阳刚的大丈夫，以诚信相交，虽有危险但无咎害。

**小象传**
**原文**：“交孚无咎”，志行也。

**白话**：因为交往诚信而没有过错，所以志向能够实现。


**说明**

这是 乖离的共鸣——诚心相感。

+ “睽孤”：乖离（睽）而孤独（孤）。
+ “遇元夫”：遇到（遇）大丈夫（元夫，指初九）。
+ “交孚”：以诚信相交（交孚）。
+ “厉无咎”：虽有危险（厉）但无咎害（无咎）。
+ 爻传“交孚无咎，志行也”：以诚信相交而无咎害，是因为心志得以实行。

**相关性**：九四阳居阴位，与初九敌应，在“睽”时亦感孤独（睽孤）。但它与初九 同为阳爻，处境相似（同是“睽孤”）。两者 在孤独中相遇（遇元夫），因同病相怜而 摒弃成见，以赤诚之心（交孚）相待。这种 基于共同处境和真诚的结交，虽然看起来不合常规（有厉），却能 打破乖离，实现心志（志行），故 无咎。此爻说明：**在普遍对立的局面下，超越固有关系（如正应），以最本真的诚意（孚）去连接处境相似者，可以开辟新的合作通路。


### 六五：悔亡，厥宗噬肤，往何咎？


**原文**：悔亡，厥宗噬肤，往何咎？

**白话**：悔恨消亡，其同宗者（九二）正在噬咬柔肤（六三），前往会合有什么咎害呢？

**小象传**
**原文**：“厥宗噬肤”，往有庆也。

**白话**：同宗的人像咬软肉一样和合，前往会有喜庆。


**说明**

这是 乖离的化解——亲睦易合。

+ “悔亡”：悔恨消亡（悔亡）。
+ “厥宗噬肤”：与其宗亲（厥宗）如咬噬柔肤（噬肤）般和合。
+ “往何咎”：前往（往）有何咎害（何咎）？
+ 爻传“厥宗噬肤，往有庆也”：与其宗亲如咬噬柔肤般和合，前往必有福庆。

**相关性**：六五柔中居尊，与九二相应，是 乖离局面中寻求和解的君主。“厥宗”指 同宗亲属（九二）。“噬肤”比喻 解决问题像咬噬柔软的皮肤一样容易、深入。爻辞描述：**君主 以柔中之道，主动与对立方（九二）的核心力量和解，过程顺利，关系亲密。如此，以往的悔恨自然消亡，此时 积极行动（往），不仅无咎，还会 带来福庆（有庆）。此爻展现了 **领导者在矛盾中 以柔克刚、主动亲和、化解对立 的高明艺术，是 “小事吉”积累后，实现大事和合的典范。


### 上九：睽孤，见豕负涂，载鬼一车，先张之弧，后说之弧。匪寇婚媾，往遇雨则吉。


**原文**：睽孤，见豕负涂，载鬼一车，先张之弧，后说之弧。匪寇婚媾，往遇雨则吉。

**白话**：乖离孤独，看见猪满身污泥，又有一车鬼怪，先拉开弓欲射，后又放下弓。原来不是盗寇，而是求婚配者，前往遇雨（阴阳和合）则吉祥。

**小象传**
**原文**：“遇雨之吉”，群疑亡也。

**白话**：遇到雨而获得吉祥，是因为所有的疑虑都消失了。


**说明**

这是 乖离的幻灭——疑去喜来。

+ “睽孤”：乖离（睽）而孤独（孤）。
+ “见豕负涂，载鬼一车”：看见（见）猪（豕）满身污泥（负涂），装载（载）一车鬼怪（鬼一车）。
+ “先张之弧，后说之弧”：先张弓（先张之弧）欲射，后放下（后说之弧）弓矢。
+ “匪寇婚媾”：原来不是（匪）盗寇（寇）而是求婚者（婚媾）。
+ “往遇雨则吉”：前往（往）遇雨（遇雨）则吉祥（则吉）。
+ 爻传“遇雨之吉，群疑亡也”：遇雨的吉祥，是因为所有的疑虑都消亡了。

**相关性**：上九阳刚处卦之极，是 乖离的顶点，也是孤独多疑的极点。因长期对立，内心充满猜忌，将事物都看成丑陋邪恶的（豕负涂、鬼一车），甚至准备攻击（张之弧）。但最终 发现真相（匪寇婚媾），放下敌意（说之弧）。“雨”象征 阴阳和合、疑虑洗刷、心结解开。当 所有的误会与猜疑都如雨水冲刷般消散（群疑亡也），乖离便转化为和合，前往自然吉祥。此爻以戏剧化的场景，揭示了 **“睽”的根源往往在于 猜疑与误解，而化解之道在于 沟通、澄清与放下成见。这是 睽极必合、疑释生喜 的生动写照。


## 总结

**总结**：睽卦的现代启示

睽卦的 “以同而异” 是关于 处理分歧、矛盾、对立，并从中创造性地实现更高层次统一的智慧。

处理对立的六种情境与智慧：

+ 初态静待（初九）：勿逐自复，见恶无咎。
+ 迁就求通（九二）：遇主于巷，未失其道。
+ 历难终合（六三）：受制遇刚，无初有终。
+ 诚心相感（九四）：睽孤交孚，志行无咎。
+ 柔中化解（六五）：宗亲噬肤，往有庆也。
+ 疑释而合（上九）：群疑亡也，遇雨则吉。

核心心法：大象传总纲——“上火下泽，睽；君子以同而异。” 这意味着：

+ “上火下泽，睽”：是 睽卦之象（火向上，泽向下，性质相背）。
+ “君子以同而异”：君子效法此象，谋求大同而保留小异。
这是 睽卦精神的灵魂：“同” 是 追求根本目标、核心利益或基本原则的一致；“异”** 是 允许方法、路径、次要问题上的差异存在。它教导我们：**不要强求完全一致（那是“同而不和”的小人），而要在 尊重差异（异）的基础上寻求合作（同）。这正是 “和而不同” 的君子境界。

根本精神：彖传 “天地睽而其事同也，男女睽而其志通也，万物睽而其事类也。睽之时用大矣哉！” 将“睽”的价值提升到宇宙高度：

天地上下悬隔（睽），但化育万物的事功相同。

男女体质性情不同（睽），但结成夫妇的心志相通。

万物形态千差万别（睽），但生生不息的事理相类。

“睽”的时宜效用太伟大了！

睽卦告诉我们：**差异、对立（睽）不是坏事，而是 世界多样性与创造力的源泉。关键在于我们如何 运用智慧，使“睽”发挥积极的“时用”——在差异中见统一，在对立中求合作，在矛盾中创生机。无论是人际矛盾、团队分歧、商业竞争还是国际关系，此卦都提供了 超越对立、实现共赢的深邃哲理。
