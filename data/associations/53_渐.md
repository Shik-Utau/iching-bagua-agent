# 渐卦（巽上艮下）

**卦画**：䷴

## 总论：渐进之道的哲学

**核心短词**：“进得位，往有功”

**卦象**：上巽（☴）为木、为入，下艮（☶）为山、为止。风山渐。山上有木，树木在山上逐渐生长。

**核心卦辞**：“女归吉，利贞。”

**总纲**：渐卦象征 “渐进”。女子出嫁吉祥，利于守持正固。

+ “女归吉”：以 女子出嫁（女归） 这一 过程 比喻 “渐进”。出嫁需 经过纳采、问名、纳吉、纳征、请期、亲迎 等 循序渐进 的礼仪，不可 骤然而行，故得 吉祥。这象征任何事物的发展，只有 遵循次序，稳步推进，才能 获得成功与吉祥。
+ “利贞”：利于守持正固。强调在渐进的过程中，必须 持守正道，心志坚定，不可 急于求成或偏离方向。

**本质**：渐卦描述 “山上有木” 的状态。树木（巽） 在 高山（艮） 上 缓慢而坚定地生长，象征一种 有序、缓慢、持续 的 前进过程。其**核心精神**是：探讨 “渐”的智慧——如何通过 不疾不徐、循序渐进 的方式，克服障碍（山），实现成长与上升（木）。它强调过程的 正当性、次序性 与结果的 稳固性。

## 卦辞

### 经

**原文**：女归吉，利贞。

**白话**：女子出嫁吉祥，利于守持正固。

### 彖传

**原文**：渐之进也，女归吉也。进得位，往有功也。进以正，可以正邦也。其位刚得中也。止而巽，动不穷也。

**白话**：渐卦讲的是渐进，女子出嫁循礼渐进可获吉祥。渐进能获得适当的位置，前往必有功绩。遵循正道渐进，可以端正邦国。卦中阳刚居于中位。静止而谦逊，行动就不会困穷。

### 大象传

**原文**：山上有木，渐；君子以居贤德善俗。

**白话**：山上有树木生长，象征渐进；君子因此积累贤德，改善风俗。


## 爻辞

### 初六：鸿渐于干，小子厉，有言，无咎。


**原文**：鸿渐于干，小子厉，有言，无咎。

**白话**：大雁渐进于水岸，年轻人有危险，虽有言语责难，但无咎害。

**小象传**
**原文**：“小子之厉”，义无咎也。

**白话**：小孩遇到危险，但从道理上讲没有灾祸。


**说明**

这是 渐进的初始——初出茅庐，临水而惧。

+ “鸿渐于干”：大雁（鸿）渐进于（渐于）水涯（干）。
+ “小子厉，有言”：幼童（小子）有危险（厉），遭人指责（有言）。
+ “无咎”：但最终无咎害（无咎）。
+ 爻传“小子之厉，义无咎也”：幼童的危险，从道理上看并无咎害。

**相关性**：初六阴柔处下，如 幼雁或幼童，刚刚 开始渐进之旅。“干”是 水边，安全与危险的交界。大雁初临水涯，小心翼翼，象征起步阶段的 审慎与不安。“小子厉”比喻 初进者经验不足，面临风险；“有言”指会遭到旁人的 非议或责难（如质疑其能力）。但爻辞断定“无咎”，爻传更说“义无咎也”——从 渐进之道的义理 来看，这种 初期的谨慎、面临的批评，是 正常且无害的，因为 它促使进者更加小心。此爻阐明：渐进之初， 遭遇困难和非议是常态，只要 心存戒惧，稳步前行，便可 化险为夷。


### 六二：鸿渐于磐，饮食衎衎，吉。


**原文**：鸿渐于磐，饮食衎衎，吉。

**白话**：大雁渐进于磐石之上，安享饮食，和乐欢畅，吉祥。

**小象传**
**原文**：“饮食衎衎”，不素饱也。

**白话**：一边吃喝一边欢乐，不是白吃白喝。


**说明**

这是 渐进的稳固——得中得正，安然享福。

+ “鸿渐于磐”：大雁渐进于（渐于）磐石（磐）。
+ “饮食衎衎”：安享饮食和乐（饮食衎衎）。
+ “吉”：吉祥（吉）。
+ 爻传“饮食衎衎，不素饱也”：安享饮食和乐，说明（六二）不是白吃饭的（而是有德才）。

**相关性**：六二阴柔中正，上应九五，是渐进过程中 找到稳固立足点者。“磐”是 大而平的石头，坚固安稳。大雁从水涯登上磐石，象征 地位得到巩固，处境变得安全。“饮食衎衎”描绘了一种 从容、和乐、满足 的生活状态。爻传“不素饱也”是关键：它 并非不劳而获，而是凭借自身的 中正德行与才干，理应享受这份安稳与福泽。此爻描绘了渐进之道的 一个美好阶段：通过 踏实前进，取得稳固地位，从而 心安理得地享受成果。


### 九三：鸿渐于陆，夫征不复，妇孕不育，凶；利御寇。


**原文**：鸿渐于陆，夫征不复，妇孕不育，凶；利御寇。

**白话**：大雁渐进于高平之地，丈夫出征不返，妻子怀孕却无法生育，有凶险；利于防御敌寇。

**小象传**
**原文**：“夫征不复”，离群丑也。“妇孕不育”，失其道也。“利用御寇”，顺相保也。

**白话**：丈夫出征没有回来，是因为离开了同伴。妇女怀孕却不生育，是因为失去了正道。利于抵御敌寇，是因为和顺可以互相保护。


**说明**

这是 渐进的偏离——刚亢冒进，失其伦常。

+ “鸿渐于陆”：大雁渐进于（渐于）高平之地（陆）。
+ “夫征不复，妇孕不育，凶”：丈夫出征不返（夫征不复），妻子怀孕却不能养育（妇孕不育），凶险（凶）。
+ “利御寇”：但利于抵御强寇（利御寇）。
+ 爻传“夫征不复，离群丑也；妇孕不育，失其道也；利用御寇，顺相保也”：丈夫出征不返，是离开了同类；妻子怀孕不育，是失去了夫妇之道；利于抵御强寇，是（上下）和顺互相保护。

**相关性**：九三阳刚过中，处下卦之极，与上九无应，是渐进中 急躁冒进、脱离群体者。“陆”是 高而平的旱地，对大雁（水鸟）而言 并非宜居之所，象征前进方向 偏离了本性或适宜的环境。“夫征不复”比喻 一味向前，不知回头，失去了与家园（原点）的联系；“妇孕不育”比喻事情 有了开端（孕），却无法完成和收获（不育），因为 失去了必要的配合与滋养（失道）。故总体 凶险。但爻辞留下一线转机：“利御寇”。因为 九三毕竟阳刚，在 群体面临外敌（寇）时，其 刚健之力 可用于 防御和保护，此时 上下能团结一致（顺相保）。此爻警示：**渐进 不可脱离根本、失去配合、盲目冒进，否则 事虽成而道已失，终归凶险。


### 六四：鸿渐于木，或得其桷，无咎。


**原文**：鸿渐于木，或得其桷，无咎。

**白话**：大雁渐进于树木之上，或许能寻得平柯栖息，没有咎害。

**小象传**
**原文**：“或得其桷”，顺以巽也。

**白话**：或者得到平直的树枝，这是顺应而谦逊的表现。


**说明**

这是 渐进的适应——以柔济刚，寻得依托。

+ “鸿渐于木”：大雁渐进于（渐于）树木（木）。
+ “或得其桷”：或许能寻得（或得其）平柯（桷）栖息。
+ “无咎”：没有咎害（无咎）。
+ 爻传“或得其桷，顺以巽也”：或许能寻得平柯栖息，是因为（六四）柔顺而驯服。

**相关性**：六四阴柔得正，已进入上卦巽（木），但 大雁（鸿）足蹼，本不适宜栖息于树木的枝桠。这象征 进入了一个 看似不适合自己 的新环境或阶段。“或得其桷”是 关键转机：“桷”是房屋的椽子，这里指 平整的树枝。这意味着通过 细心寻找、灵活适应，能在新环境中 找到适合自己的、安稳的立足点。爻传“顺以巽也”点明成功原因：凭借柔顺（坤德）而又能 深入（巽德） 的品性，顺应环境，灵活调整，故得 安稳无咎。此爻教导：在渐进过程中，当 进入陌生或不利环境时，不应强求或抱怨，而应 发挥柔韧的智慧，主动寻找和创造适合自己的条件。


### 九五：鸿渐于陵，妇三岁不孕，终莫之胜，吉。


**原文**：鸿渐于陵，妇三岁不孕，终莫之胜，吉。

**白话**：大雁渐进于山陵，妻子三年不怀孕，但外物终究不能取胜，吉祥。

**小象传**
**原文**：“终莫之胜，吉”，得所愿也。

**白话**：最终没人能胜过他，吉祥，是因为实现了心中的愿望。


**说明**

这是 渐进的高峰——坚守中正，迟来而胜。

+ “鸿渐于陵”：大雁渐进于（渐于）山陵（陵）。
+ “妇三岁不孕”：妻子三年不怀孕（妇三岁不孕）。
+ “终莫之胜，吉”：但外物最终不能取胜（终莫之胜），吉祥（吉）。
+ 爻传“终莫之胜，吉，得所愿也”：外物最终不能取胜而获吉祥，是因为（九五）得偿所愿。

**相关性**：九五阳刚中正，居尊位，是 渐进之道的 领导者和成功典范。“陵”是 高耸的山冈，象征 事业或地位的 高峰。“妇三岁不孕”是一个 意味深长的比喻：“怀孕” 象征 “结果、成就”。三年不孕 表示达到高位后，成果 并非立即可见，需要长时间的 积累、等待和孕育。这期间可能有 阻碍、怀疑（外物） 试图 干扰或取代。但爻辞坚定地说：“终莫之胜，吉”。因为九五 持守中正之道，根基稳固，任何外力最终都无法 战胜或动摇 它。经过 耐心的等待（三岁），愿望终将实现（得所愿），故得 吉祥。此爻揭示了渐进成功的 深层法则：真正的、稳固的成就，往往 来得缓慢，需要在高位上 耐心守持，静待瓜熟蒂落。


### 上九：鸿渐于陆，其羽可用为仪，吉。


**原文**：鸿渐于陆，其羽可用为仪，吉。

**白话**：大雁渐进于高山之陆（云天），其羽毛可用作典礼的仪饰，吉祥。

**小象传**
**原文**：“其羽可用为仪，吉”，不可乱也。

**白话**：羽毛可以用来作为仪饰，吉祥，这说明人的心志不能纷乱。


**说明**

这是 渐进的超越——功成身退，德泽流芳。

+ “鸿渐于陆”：大雁渐进于（渐于）高山四顾之陆（陆，此处指云天之上的高平之地）。
+ “其羽可用为仪”：其羽毛（其羽）可用作（可用为）仪饰（仪）。
+ “吉”：吉祥（吉）。
+ 爻传“其羽可用为仪，吉，不可乱也”：其羽毛可用作仪饰而获吉祥，说明（上九的）志节不可扰乱。

**相关性**：上九阳刚处卦之极，是渐进过程的 完成者与超越者。此“陆”与九三之“陆”不同，指 高山之巅、云天之上的空旷之地，象征 超越于世俗进取之外 的 崇高境界。大雁飞至此地，其 轻盈洁白的羽毛（其羽） 不再仅仅用于 飞翔（工具），而可作为 高雅美丽的仪饰（仪），供人 瞻仰、效法。这比喻：当一个人 依循渐进之道，完成人生功业后，其 人格、品德、风范（羽） 便 升华 为一种 可资效仿的楷模（仪），流泽后世。爻传“不可乱也”强调：这种 崇高的志节与风范，是 纯净、有序、不可淆乱 的。此爻是对渐进修养 最高境界的礼赞：其 最终价值，不在于 到达了某个位置，而在于其 过程所淬炼出的精神与风骨，能 成为世人的典范与指引。


## 总结

**总结**：渐卦的现代启示

渐卦的 “进得位，往有功” 是关于 “循序渐进、稳步成长”的完整成功学。它反对 投机取巧和揠苗助长，崇尚 一步一个脚印的扎实积累。

实践渐进之道的六个阶段：

+ 初进临险（初六）：鸿渐于干，小子厉，有言，无咎。
+ 得位而安（六二）：鸿渐于磐，饮食衎衎，吉。
+ 过刚失配（九三）：鸿渐于陆，夫征不复，妇孕不育，凶；利御寇。
+ 柔顺得所（六四）：鸿渐于木，或得其桷，无咎。
+ 尊位守中（九五）：鸿渐于陵，妇三岁不孕，终莫之胜，吉。
+ 超然于进（上九）：鸿渐于陆，其羽可用为仪，吉。

核心心法：大象传总纲——“山上有木，渐；君子以居贤德善俗。” 这意味着：

+ “山上有木，渐”：是 渐卦之象（树木在山上逐渐长高）。
+ “君子以居贤德善俗”：君子效法此象，积蓄贤德，改善风俗。

这是 渐卦精神的灵魂。君子看到 树木的缓慢生长，领悟到 德行的培养（居贤德） 和 社会风气的改善（善俗），也 如同树木生长一样，是一个 缓慢、持久、潜移默化 的 渐进过程。不能 急于求成，而需 持之以恒，以身作则，春风化雨。这指出了渐进之道的 终极社会价值——**用于 个人修身 和 教化天下。

根本精神：彖传 “渐之进也，女归吉也。进得位，往有功也。进以正，可以正邦也。其位，刚得中也。止而巽，动不穷也。” 揭示了渐进之道的成功逻辑：

+ “渐之进也，女归吉也”：渐卦所说的进，是像女子出嫁那样循序渐进的进，所以吉祥。重申 以“女归”喻“渐” 的核心意象。
+ “进得位，往有功也”：前进而获得适当的位置，前往必能建立功业。这是渐卦的 核心承诺——**只要 依序渐进，每一步都站稳脚跟（得位），那么 整个前进过程（往） 就 必然能积累功绩（有功）。
+ “进以正，可以正邦也”：沿着正道前进，就可以端正邦国。将 渐进之道 从 个人成功 提升到 治国平天下 的高度。
+ “其位，刚得中也”：（九五）的位置，是阳刚得中。点明渐进成功的 核心力量 在于领导者的 刚健与中道。
+ “止而巽，动不穷也”：（下卦艮）静止而（上卦巽）驯顺，这样行动就不会困穷。从 卦德 解释 渐进的动力机制：**内心知道 何时该止（艮止），行动又能 柔顺深入（巽入），如此 动静结合，前进的 力量就永不枯竭。

渐卦告诉我们：“渐”是 自然与人事的普遍法则。无论是 个人学习、职业发展、德行修养，还是 家庭建立、事业开拓、社会治理，遵循 渐进之道—— 有次序（女归）、守正道（利贞）、得位置（磐、陵）、持耐心（三岁不孕）——终将 “往有功”，并可能 “其羽可用为仪”，达到生命与事业的 圆满与崇高。这便是在 “山上有木” 的生动图景中，所昭示的关于 耐心、次序、积累与成功 的 不朽真理。
