# 井卦（坎上巽下）

**卦画**：䷯

## 总论：井养之道的哲学

**核心短词**：“劳民劝相”

**卦象**：上坎（☵）为水、为险，下巽（☴）为风、为木。水风井。木上有水，汲水养人。

**核心卦辞**：“改邑不改井，无丧无得。往来井井。汔至，亦未繘井，羸其瓶，凶。”

**总纲**：井卦象征 “水井、养民”。村邑可以迁移，水井不可改移，（汲水）无所丧失也无所获得。往来者都依井为用。汲水时，水瓶将至井口尚未出井，却倾覆了水瓶，有凶险。

+ “改邑不改井，无丧无得”：这是 井的恒常与无私。村邑（邑）可以改变（改），水井（井）却不可改移（不改）。人们从井中 汲水，看似有所得，但井水并未减少（无丧）；看似无所获，但井水也未增多（无得）。井 恒常稳定，滋养万物而不自居其功。
+ “往来井井”：往来者（往来）都依井（井井）为用。井 公开、平等地为所有人服务，是 公共利益的象征。
+ “汔至，亦未繘井，羸其瓶，凶”：这是 用井的告诫。汲水时，水瓶（汔）将至井口（至），绳索（繘）尚未完全提出井（亦未繘井），却倾覆了（羸）水瓶（其瓶），有凶险（凶）。比喻 事情在即将成功的关键时刻，因疏忽或器具不善而失败，功亏一篑。

**本质**：井卦描述 “巽乎水而上水” 的状态。下巽木（为入、为绳），上坎水，以木制器具（桶）深入水中，将水提上来。其**核心精神**是：**以 “井” 为喻，探讨 如何建立并维护一个 稳定、持久、公平、滋养众人 的体系（如制度、道德、公共事业）。它强调 恒德（不改）、奉献（无丧无得）、公共性（往来井井），并警告 维护与使用过程中的风险（羸其瓶）。

## 卦辞



### 经

**原文**：改邑不改井，无丧无得。往来井井。汔至亦未繘井，羸其瓶，凶。

**白话**：城邑可以改迁，但水井不会改变，没有丧失也没有获得。人们往来汲水，井水依然洁净。汲水时，快到井口却未出井，碰坏了汲水瓶，有凶险。

### 彖传

**原文**：巽乎水而上水，井。井养而不穷也。“改邑不改井”，乃以刚中也。“汔至亦未繘井”，未有功也。“羸其瓶”，是以凶也。

**白话**：风在水下吹动而水向上涌出，这就是井的卦象。井水滋养万物而不会枯竭。“村落可以迁移但水井不会改变”，这是因为刚健中正的品格始终如一。“汲水时快到井口却还没提出井沿”，说明努力尚未成功。“打水的罐子倾覆破损”，所以会有凶险。

### 大象传

**原文**：木上有水，井；君子以劳民劝相。

**白话**：树木之上有水，象征水井；君子因此鼓励民众勤劳互助。


## 爻辞

### 初六：井泥不食，旧井无禽。


**原文**：井泥不食，旧井无禽。

**白话**：井底有淤泥，水不能食用，旧井边没有鸟兽光顾。

**小象传**
**原文**：“井泥不食”，下也。“旧井无禽”，时舍也。

**白话**：井底有污泥，所以井水不能饮用，这是因为位置处在最下方。废弃的老井连鸟雀都不来，是因为它已被时代舍弃。


**说明**

这是 井的初始——淤塞失修，为人所弃。

+ “井泥不食”：井底有污泥（井泥），无法食用（不食）。
+ “旧井无禽”：旧井（旧井）边连鸟兽（无禽）也不来。
+ 爻传“井泥不食，下也；旧井无禽，时舍也”：井底有污泥无法食用，是因为（初六）地位卑下；旧井边无鸟兽，是因为时势已将其舍弃。

**相关性**：初六阴柔处下，如 井之最底部。爻辞描绘了一幅 井道废弛的衰败景象：井水 被污泥污染，失去饮用价值；连 鸟兽（禽） 都 不来光顾，说明 其滋养功能已完全丧失。爻传点明原因：“下也”——自身地位卑下，能力微薄；“时舍也”——被时代所抛弃。此爻象征 **一个体系或一个人，**如果长期不自我更新、不修养德行（不清淤），就会 彻底失去价值，被人遗忘。


### 九二：井谷射鲋，瓮敝漏。


**原文**：井谷射鲋，瓮敝漏。

**白话**：井底积水处有小鱼，汲水的瓦瓮破旧漏水。

**小象传**
**原文**：“井谷射鲋”，无与也。

**白话**：井底的小鱼被射中，说明无人应和援助。


**说明**

这是 井的进阶——虽有微用，器具有瑕。

+ “井谷射鲋”：井底穴窍（井谷）有水，只可射得（射）小鱼（鲋）。
+ “瓮敝漏”：汲水的瓦瓮（瓮）破旧（敝）漏水（漏）。
+ 爻传“井谷射鲋，无与也”：井底穴窍射得小鱼，是因为无人应援（无与）。

**相关性**：九二阳刚居中，但上无应援（与六五不应），是 井中有才但未被充分使用者。“井谷射鲋”比喻 其才德（井水） 如同 井底的缝隙之水，只能 滋养小鱼小虾（鲋），无法上达，惠及大众。“瓮敝漏”进一步比喻：**即使有人来汲水（使用其才），也因为 汲水器具（比喻任用者或制度）破旧不堪，导致 水漏无法盛载，才德依旧无法被有效汲取和利用。爻传“无与也”指出根本：**缺乏 上方的赏识与提携（无应）。此爻描绘了 怀才不遇的典型困境：**自身虽有可用之才，但 或因渠道不畅，或因领导者不善用（瓮敝漏），导致才能被埋没。


### 九三：井渫不食，为我心恻。可用汲，王明，并受其福。


**原文**：井渫不食，为我心恻。可用汲，王明，并受其福。

**白话**：井水已淘去污浊却无人食用，使我心中悲伤。这井水可以汲用了，若君王圣明，众人将共享福泽。

**小象传**
**原文**：“井渫不食”，行恻也。求“王明”，受福也。

**白话**：井水已经清洁却无人饮用，这是让人感到惋惜的行为。祈求君王英明，是为了让天下人都能承受福泽。


**说明**

这是 井的转机——才德已修，待明君用。

+ “井渫不食”：井水已淘去污泥洁净（井渫）却无人食用（不食）。
+ “为我心恻”：使我（为我）心中恻痛（心恻）。
+ “可用汲，王明，并受其福”：可以（可用）汲用了（汲）！若君王贤明（王明），众人将（并）共享福泽（受其福）。
+ 爻传“井渫不食，行恻也；求王明，受福也”：井水洁净却无人食用，是因为（九三）行为令人恻惜；祈求君王贤明，是为了承受福泽。

**相关性**：九三阳刚过甚，处下卦之极，临近上卦坎水，是 井德已修、亟待任用者。“井渫”指 井已清淤，水已洁净，比喻 才德已备，可供使用。然而 “不食”，即 仍未被任用，这令有识之士 为之痛心（行恻）。爻辞发出强烈的呼声：“可用汲！”并指出关键：“王明”——**需要 贤明的领导者（君王） 来 发现并任用（汲） 此才。如此，则 “并受其福”——不仅个人得展其才，天下人也将共享其带来的福泽。此爻表达了 才德之士对明君的渴望，以及 贤才得用则天下受益的道理。


### 六四：井甃，无咎。


**原文**：井甃，无咎。

**白话**：用砖石修砌井壁，没有咎害。

**小象传**
**原文**：“井甃无咎”，修井也。

**白话**：井壁修好没有灾祸，这是说水井已经修好了。


**说明**

这是 井的巩固——自我完善，防患未然。

+ “井甃”：以砖石修砌（甃）井壁。
+ “无咎”：没有咎害（无咎）。
+ 爻传“井甃无咎，修井也”：以砖石修砌井壁没有咎害，这是在修治水井。

**相关性**：六四阴柔得正，已进入上卦坎水，是 井的维护者。“井甃”是 一项重要的维护工程：用砖石加固井壁，防止坍塌，保持清洁。这比喻 **体系或个人，**在已有一定基础（井有水）后，**仍需 持续地进行自我建设、自我完善（修井），以 巩固根本，防范风险。这样做 虽然看似平常，没有立竿见影的功绩，但能 确保长久稳定，故没有咎害。此爻强调：**成就的维持，**离不开 日常不懈的修缮与保养。


### 九五：井冽，寒泉食。


**原文**：井冽，寒泉食。

**白话**：井水清澈甘冽，如寒泉般可供食用。

**小象传**
**原文**：“寒泉之食”，中正也。

**白话**：寒泉的泉水可以饮用，是因为它居中守正。


**说明**

这是 井的鼎盛——至善至美，普惠众生。

+ “井冽”：井水清澈甘冽（井冽）。
+ “寒泉食”：如寒泉（寒泉）般可供食用（食）。
+ 爻传“寒泉之食，中正也”：如寒泉般可供食用，是因为（九五）居中守正。

**相关性**：九五阳刚中正，居尊位，是 井德的完美体现者。“井冽，寒泉食”描绘了 最理想的水井状态：水质至清至纯（冽），如天然寒泉，清凉甘美，滋养众人。这比喻 一个 德行完美、才能卓越的领袖或一套 至善的制度，能够 最纯粹、最有效地惠及天下。爻传点明根源：“中正也”——**一切源于 **其 中正无私的品德与作为。此爻是 对最高境界的“井养之德”的礼赞。


### 上六：井收勿幕，有孚元吉。


**原文**：井收勿幕，有孚元吉。

**白话**：井水汲取完毕，不要盖上井盖，心怀诚信，至为吉祥。

**小象传**
**原文**：“元吉”在上，大成也。

**白话**：高居上位而能获得至为吉祥，是因为功业已全面成就。


**说明**

这是 井的终点——功成不居，开放共享。

+ “井收勿幕”：井功已成（井收），不必（勿）覆盖井口（幕）。
+ “有孚元吉”：心怀诚信（有孚），至为吉祥（元吉）。
+ 爻传“元吉在上，大成也”：至为吉祥在于上位（上六），是因为大功告成。

**相关性**：上六阴柔处卦之极，是 井道的完成者。“井收”意味着 修井、浚井、维护的整个过程已经圆满完成。“勿幕”是 画龙点睛之笔：不要盖上井盖。这象征着 井德的最大公无私——**功成之后，**不独占其利，不设限封闭，而是 永远向众人开放，任人取用。“有孚”强调 这种开放是出于至诚之心，而非沽名钓誉。如此，则 至为吉祥（元吉），标志着 “井养之道”的大功告成（大成）。此爻揭示了 **奉献的最高境界：**成就伟大功业后，以完全开放、毫无保留的姿态，服务于世。


## 总结

**总结**：井卦的现代启示

井卦的 “劳民劝相” 是关于 “奉献、服务、公共福祉”的崇高哲学，它以 “井” 为完美喻体，阐述了一套 从衰败到复兴、从私用到公益的完整体系构建与维护之道。

践行井养之道的六个步骤：

+ 井德废弃（初六）：井泥不食，旧井无禽。
+ 才弱未用（九二）：井谷射鲋，瓮敝漏。
+ 修德待时（九三）：井渫不食，为我心恻，可用汲，王明。
+ 自修以备（六四）：井甃，无咎。
+ 中正养人（九五）：井冽，寒泉食。
+ 大成无私（上六）：井收勿幕，有孚元吉。

核心心法：大象传总纲——“木上有水，井；君子以劳民劝相。” 这意味着：

+ “木上有水，井”：是 井卦之象（以木器汲水而上）。
+ “君子以劳民劝相”：君子效法此象，为民操劳，劝勉百姓互助。

这是 井卦精神的灵魂。君子从“井”的意象中领悟到的，不仅是 自身的修养与奉献（如井之养人），更是 一种社会治理与教化的责任。“劳民”不是役使百姓，而是 为百姓事务辛勤操劳，如同 维护水井使其不竭；“劝相”是 劝导百姓相互帮助、和睦共处，如同 众人有序共用一井。这体现了 儒家“修己以安人”的思想：**领导者自身要具备井德（稳定、奉献），同时要 组织社会、教化民众，形成互助共享的良性生态。

根本精神：彖传 “巽乎水而上水，井；井养而不穷也。改邑不改井，乃以刚中也。” 点明了井道的永恒价值：

+ “井养而不穷也”：水井滋养万物而没有穷尽。这是 井德的根本特性——生生不息，利他无穷。
+ “改邑不改井，乃以刚中也”：村邑可改而水井不可改，是因为（井有）刚中之德。

井卦告诉我们：**“井”是 文明与秩序的基石。一个社会、一种文化、一种精神，若能像“井”一样，具备 恒常稳定（不改）、公正无私（往来井井）、滋养众生（养而不穷） 的品德，那么它将 超越时空，成为永恒的财富。其最高智慧在于 **大象传的推广与教化：个人的井德固然可贵，但 更伟大的，是将这种“井养精神”推而广之，“劳民劝相”，使之成为 整个社会的共同信念与行动准则。这便是在 “木上有水” 的汲引景象中，所蕴含的 关于奉献、公益与社会建设的永恒理想。
