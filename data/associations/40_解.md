# 解卦（震上坎下）

**卦画**：䷧

## 总论：解除困境的哲学

**核心短词**：“赦过宥罪”

**卦象**：上震（☳）为雷、为动，下坎（☵）为水、为险。雷水解。雷雨大作，雷雨作，而百果草木皆甲坼。

**核心卦辞**：“利西南。无所往，其来复吉。有攸往，夙吉。”

**总纲**：解卦象征 “缓解、解除、解脱”，利于走向西南（坤方，平地）。没有前往的目标，返回安居可获吉祥；有所前往，及早行动可获吉祥。

+ “利西南”：延续蹇卦的策略，利于 走向平易之地（西南坤方），象征 解除险难宜用平易柔和之道。
+ “无所往，其来复吉”：如果 没有明确要去的地方或目标，那么 返回原处、安居休整 就是吉祥的。这是 险难初解后的休养生息。
+ “有攸往，夙吉”：如果 有明确要去的地方或目标，那么 及早（夙）行动 可获吉祥。这是 抓住解脱后的时机，积极作为。

**本质**：解卦描述 “动而免乎险” 的状态。上震雷动，下坎险陷，在险境中采取行动（动），从而脱离险境（免乎险）。雷雨交加，冲刷万物，象征 一场大动荡、大变革后，束缚解除，生机勃发。其**核心精神**是：**当险难缓解、束缚解除时，要 把握时机，或静养恢复（来复），或迅疾行动（夙往），并秉持 宽大、舒缓（赦过宥罪） 的原则来处理遗留问题，以巩固解难的成果。

## 卦辞



### 经

**原文**：利西南。无所往，其来复吉。有攸往，夙吉。

**白话**：利于走向西南（平地）。没有必须前往的目标，返回安居可获吉祥。若有所前往，及早行动吉祥。

### 彖传

**原文**：解，险以动，动而免乎险，解。解利西南，往得众也。其来复吉，乃得中也。有攸往夙吉，往有功也。天地解而雷雨作，雷雨作而百果草木皆甲坼。解之时大矣哉！

**白话**：解卦，意味着在险境中行动，通过行动来脱离危险，这就是解。解卦利于向西南方向行动，因为前往那里会得到众人的支持。返回原处也是吉祥的，因为能够保持中正之道。有所前往并及早行动会带来吉祥，因为前进会建立功业。天地间的郁结消散时，雷雨就会兴起，雷雨发作，百果草木都破壳萌发。解卦所蕴含的时机意义真是伟大啊！

### 大象传

**原文**：雷雨作，解；君子以赦过宥罪。

**白话**：雷雨交加，象征解脱；君子因此赦免过错，宽恕罪责。


## 爻辞

### 初六：无咎。


**原文**：无咎。

**白话**：没有咎害。

**小象传**
**原文**：刚柔之际，义无咎也。

**白话**：在刚强与柔和交接的时刻，把握分寸就不会有过错。


**说明**

这是 解脱的初始——平静无过。

+ “无咎”：没有咎害（无咎）。
+ 爻传“刚柔之际，义无咎也”：（初六）处于刚柔交接之际，从道理上讲没有咎害。

**相关性**：初六阴柔处下，与九四相应，上承九二。象征 险难（坎）刚刚开始解除，处于解脱的边缘。爻辞极其简洁，仅“无咎”二字。这是因为：**在解脱之初，自身力量尚弱，但上有应援（九四），近有扶助（九二），且 时势已转向缓和（刚柔之际），只要 不妄动，顺其自然，便不会有过错。爻传指出，这是 时势使然（义无咎也）。此爻描绘了 险难解除后，最平和、安稳的初始状态：无需作为，静享平安即是福。


### 九二：田获三狐，得黄矢，贞吉。


**原文**：田获三狐，得黄矢，贞吉。

**白话**：田猎获得多只狐狸，得到黄色的箭矢，守持正固吉祥。

**小象传**
**原文**：九二贞吉，得中道也。

**白话**：九二爻守持正固可获吉祥，是因为它能够遵循中正不偏的道理。


**说明**

这是 解脱的行动——清除隐患。

+ “田获三狐”：田猎（田）获得（获）多只狐狸（三狐）。
+ “得黄矢”：得到（得）黄色的箭矢（黄矢）。
+ “贞吉”：守持正固（贞）可获吉祥（吉）。
+ 爻传“九二贞吉，得中道也”：九二守正吉祥，是因为获得中道。

**相关性**：九二阳刚居中，是 解除险难的核心执行者。“田猎”象征 主动出击，解决问题。“狐狸”比喻 隐藏的奸邪、小人或遗留的隐患。“三狐”表示 数量多，问题复杂。“黄矢”中，黄色代表中道，矢代表正直，合起来象征 因秉持中正之道而获得的奖赏、认可或权威。爻辞描述：**在解脱时期，果断行动，清除那些造成或加剧险难的隐患（获狐）。由于 行动本身是正义、中道的（贞，得中道），故能 成功并获得应得的荣誉与资源（得黄矢），整个过程吉祥。此爻强调：**解脱不仅是摆脱束缚，更要 主动清理废墟，根除后患，且行动必须 公正、适中。


### 六三：负且乘，致寇至，贞吝。


**原文**：负且乘，致寇至，贞吝。

**白话**：背负财物而乘坐大车，招致盗寇来抢夺，守持正固也难免憾惜。

**小象传**
**原文**：“负且乘”，亦可丑也。自我致戎，又谁咎也？

**白话**：背着东西却坐在车上，这行为也太难看了。自己招来了贼寇，又能怪谁呢？


**说明**

这是 解脱的过失——德不配位。

+ “负且乘”：背负（负）财物且乘坐（且乘）车辆。
+ “致寇至”：招致（致）盗寇（寇）来抢（至）。
+ “贞吝”：即使意图正固（贞）也难免憾惜（吝）。
+ 爻传“负且乘，亦可丑也；自我致戎，又谁咎也”：背负财物坐在车上，也是可耻的；自己招来兵戎之祸，又能怪谁呢？

**相关性**：六三阴柔失正，处下卦坎险之极，象征 在解脱后，小人得志或德才不称者占据高位。“负”是 小人的劳作，“乘”是 君子的车驾。“负且乘”形容 才德卑下（负）却窃居高位（乘），行为与身份严重不符。这种 “德不配位” 的丑态，自然会 引人嫉恨，招致攻击（致寇至）。爻辞指出，即使其主观上想做好（贞），但由于 根本性的错位，也难免遭遇憾惜（吝）。爻传的批评更严厉：**这是 自取其辱（亦可丑也），自我招祸（自我致戎），怪不得别人（又谁咎也）。此爻是 深刻的警示：**险难解除后，若让不当之人占据要位，或自身行为失当，将会引发新的、更严重的危机。


### 九四：解而拇，朋至斯孚。


**原文**：解而拇，朋至斯孚。

**白话**：解开你脚拇指的束缚，朋友就会前来，以诚信相待。

**小象传**
**原文**：“解而拇”，未当位也。

**白话**：解开你脚拇指的束缚，是因为所处的位置不恰当。


**说明**

这是 解脱的扩展——由近及远。

+ “解而拇”：解开（解）你（而）大脚趾（拇）的束缚。
+ “朋至斯孚”：朋友（朋）就会前来（至），并以诚信（斯孚）相待。
+ 爻传“解而拇，未当位也”：解开大脚趾的束缚，是因为（九四）位置不当。

**相关性**：九四阳居阴位，与初六相应，是 解脱局面中，位置不甚妥当但拥有资源的阳刚者。“拇”是大脚趾，象征 细微的、最初的束缚或隔阂。“解而拇”指 从自身做起，解除那些最微小、最亲近的误解或束缚（如与初六的关系）。爻辞揭示了一个连锁反应：当你 主动解开自己身边的小疙瘩，展现出诚意与开放姿态，更广泛的朋友（朋）就会 感知到你的诚信（斯孚），从而前来汇聚、相助。爻传“未当位也”暗示：**正因为其位置不够稳固，才更需要 从修复身边关系做起，以诚信赢得支持，弥补位不当的缺陷。此爻说明：**解脱的效应需要 从局部、从身边开始扩散，诚信是吸引盟友、扩大成果的磁石。


### 六五：君子维有解，吉。有孚于小人。


**原文**：君子维有解，吉。有孚于小人。

**白话**：君子能够纾解险难，吉祥。甚至能用诚信感化小人。

**小象传**
**原文**：君子有解，小人退也。

**白话**：君子能够解除险难，小人便会自行退避。


**说明**

这是 解脱的高度——德服众人。

+ “君子维有解，吉”：君子（君子）能够（维）纾解险难（有解），吉祥（吉）。
+ “有孚于小人”：能用诚信（有孚）感化小人（于小人）。
+ 爻传“君子有解，小人退也”：君子能够纾解险难，小人就会退去。

**相关性**：六五柔中居尊，是 解脱时期的君主或领导者。爻辞首先肯定：君子（指六五） 具备 纾解险难的能力与责任（维有解），这本身就是吉祥的。更进一步，其 **吉祥不仅在于解决问题，更在于 能以最大的诚信（有孚）去感化、包容甚至转化那些曾经制造麻烦的“小人”。这不是姑息养奸，而是 以德服人，从根本上消除对立，实现更高层次的和谐。爻传“小人退也”描述了结果：**在君子诚信德行的感召下，小人要么被感化而改过，要么因失去市场而退却。此爻展现了 **解脱的最高境界：不仅是事功的解决，更是人心的归服与社会的净化。


### 上六：公用射隼于高墉之上，获之，无不利。


**原文**：公用射隼于高墉之上，获之，无不利。

**白话**：王公射落高墙上的恶隼，一举擒获，无所不利。

**小象传**
**原文**：“公用射隼”，以解悖也。

**白话**：王公射落恶隼，是为了解除悖乱的祸患。


**说明**

这是 解脱的终结——铲除元凶。

+ “公用射隼于高墉之上”：王公（公）用箭射（用射）高墙（高墉）之上的恶隼（隼）。
+ “获之”：擒获（获）它。
+ “无不利”：无所不利（无不利）。
+ 爻传“公用射隼，以解悖也”：王公射杀恶隼，是为了解除悖乱。

**相关性**：上六处卦之极，是 解脱的最后阶段。“公”指 位高权重者；“隼”是 凶猛的恶鸟，比喻 盘踞在高位、顽固不化的元凶巨恶；“高墉”象征 其占据的险要位置。爻辞描绘了一幅 终极决战的画面：在解脱的尾声，必须 动用强力（射），精准打击（于高墉之上），彻底清除 那些造成一切险难的罪魁祸首（隼）。一旦成功（获之），则 所有隐患尽除，万事通达（无不利）。爻传点明目的：“以解悖也”**——**为了 从根本上解除悖逆与祸乱。此爻强调：**解脱事业要取得彻底胜利，有时必须 对首恶进行果断、彻底的清算，如此方能奠定长久太平的基础。


## 总结

**总结**：解卦的现代启示

解卦的 “赦过宥罪” 是关于 危机缓解、问题解决、束缚解除后，如何巩固成果、修复关系、开创新局的全面指导。

解除困境的六个步骤与心法：

+ 初解静享（初六）：刚柔之际，无咎为宜。
+ 主动除患（九二）：田获三狐，得中贞吉。
+ 警示错位（六三）：负且乘，自我致戎。
+ 诚信聚友（九四）：解拇朋至，斯孚为要。
+ 德服化人（六五）：君子有解，孚及小人。
+ 铲除元凶（上六）：射隼高墉，以解悖乱。

核心心法：大象传总纲——“雷雨作，解；君子以赦过宥罪。” 这意味着：

+ “雷雨作，解”：是 解卦之象（雷雨兴起，险难消散）。
+ “君子以赦过宥罪”：君子效法此象，赦免过错，宽宥罪责。
这是 解卦精神的灵魂：雷雨荡涤污垢后，天地清新。君子在险难解除后，也应 以宽宏、舒缓的心态来处理遗留问题。“赦过”** 是对 一般性错误 的宽恕；“宥罪” 是对 更严重罪责 的酌情宽减。这并非无原则的纵容，而是 **为了 缓和矛盾，促进和解，让社会尽快从创伤中恢复生机。这是一种 政治智慧与人道关怀 的结合。

根本精神：彖传 “解，险以动，动而免乎险，解。解利西南，往得众也。其来复吉，乃得中也。有攸往夙吉，往有功也。天地解而雷雨作，雷雨作而百果草木皆甲坼。解之时大矣哉！” 生动阐释了“解”的伟大：

+ “险以动，动而免乎险”：在险境中行动，通过行动脱离险境，这就是“解”。
+ “其来复吉，乃得中也”：返回安居吉祥，是因为符合中道（休养生息）。
+ “有攸往夙吉，往有功也”：有所前往及早吉祥，是因为前往可以建功（积极作为）。
+ “天地解而雷雨作……百果草木皆甲坼”：天地舒解于是雷雨兴起……各种果实草木都破壳萌芽。这是 对“解”后生机勃发景象的诗意描绘。
+ “解之时大矣哉！”：“解”的时义太伟大了！

解卦告诉我们：**“解”是一个 充满希望与生机的时刻。它既需要 雷雨般的果断行动（射隼），也需要 雨露般的宽和胸怀（赦宥）；既需要 静养恢复（来复），也需要 趁势进取（夙往）。关键在于 准确把握“解”的时机（时），灵活运用 “动”与“静”、“宽”与“严” 的策略，最终实现 “百果草木皆甲坼” 的繁荣新局面。无论是个人走出低谷、企业渡过危机，还是社会结束动荡，此卦都提供了 一套从解除困境到开创新局的完整心法。
