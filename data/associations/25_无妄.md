# 无妄卦（乾上震下）

**卦画**：䷘

## 总论：无妄的哲学

**核心短词**：“茂对时育”

**卦象**：上干（☰）为天、为健，下震（☳）为雷、为动。天雷无妄。天下雷行，万物肃然；动以天行，真实不虚。

**核心卦辞**：“无妄，元亨利贞。其匪正有眚，不利有攸往。”

**总纲**：无妄卦倡导 “真实无伪、循理而动” 的至高境界。遵循此道则大亨通，背离此道则生灾祸。

+ “无妄”：不虚妄、不妄为、至诚真实。
+ “元亨利贞”：具备创始、亨通、有利、贞固这四种天德。这是对“无妄”之道的最高赞美。
+ “其匪正有眚”：如果动机不纯、行为不正（匪正），就会有灾祸（眚）。
+ “不利有攸往”：不利于有所前往（指若心怀妄念，则任何行动都不利）。

**本质**：无妄卦的核心是 “动而健，刚中而应” 与 “天命不佑，行矣哉”。卦象下震（动）上干（健），意味着 行动（震）遵循天道（干）的刚健法则。九五阳刚中正，与六二相应，象征 领导者（九五）以中正之德应合天下。整个卦强调：行动必须本于至诚，合乎正理（动而健）。一旦动机不纯（匪正），便是违背“无妄”的天命，上天都不会保佑，行动必然招灾。

## 卦辞



### 经

**原文**：元亨，利贞。其匪正有眚，不利有攸往。

**白话**：至为亨通，利于守持正固。若不守正道则有灾祸，不利于有所前往。

### 彖传

**原文**：无妄，刚自外来而为主于内，动而健，刚中而应，大亨以正，天之命也。其匪正有眚，不利有攸往，无妄之往，何之矣？天命不佑，行矣哉！

**白话**：无妄卦，阳刚之气从外部来而成为内部的主宰，行动刚健有力，阳刚居中而上下应和，大为亨通且持守正道，这是上天的旨意。如果不守正道就会有灾祸，不利于有所前往。在无妄之时还要前往，能去哪里呢？上天不保佑，还能行动吗？

### 大象传

**原文**：天下雷行，物与无妄；先王以茂对时，育万物。

**白话**：天下雷声震动，万物都真实不虚；先代君王因此勉力配合天时，养育万物。


## 爻辞

### 初九：无妄，往吉。


**原文**：无妄，往吉。

**白话**：不妄为，前往吉祥。

**小象传**
**原文**：“无妄之往”，得志也。

**白话**：没有虚妄的前往，就能实现志愿。


**说明**

这是 无妄的起点——心诚则吉。

+ “无妄”：秉持无妄（真实无伪）之心。
+ “往吉”：前往（行动）则吉祥。
+ 爻传“得志也”：心志得以实现。

**相关性**：初九阳刚处下，是 震卦（动）的主爻，也是 “无妄”之动力的源泉。它象征行动之初，动机纯粹，心无杂念，完全遵循正理。以这样的初心去行动（往），必然顺利吉祥，因为其 心志（得志）与天道（无妄）相合。此爻定义了 “无妄”行动的根本：动机至诚。


### 六二：不耕获，不菑畬，则利有攸往。


**原文**：不耕获，不菑畬，则利有攸往。

**白话**：不期望刚耕种就有收获，不期望刚开垦的田就能变成熟田，这样就利于有所前往。

**小象传**
**原文**：“不耕获”，未富也。

**白话**：不耕种却想收获，这是不可能致富的。


**说明**

这是 无妄的精髓——为所当为。

+ “不耕获”：不为了（不）耕种（耕）就期望收获（获）。
+ “不菑畲”：不为了开垦荒地（菑）就期望得到熟田（畲）。
+ “则利有攸往”：这样就利于有所前往。
+ 爻传“未富也”：因为 心思不在于求富。

**相关性**：六二柔顺中正，与九五相应，是 “无妄”之德的完美体现者。“耕”与“菑”是 当下的努力，“获”与“畲”是 未来的结果。爻辞的核心是：只问耕耘，不问收获；只专注于当下应做的正事，而不对结果抱有非分的期望与执着。这种 毫无功利算计、纯粹循理而为的心态，才是真正的“无妄”。正因为心无挂碍（未富也），所以行动（攸往）最为有利。此爻揭示了 “无妄”的深层心态：消除对结果的妄念。


### 六三：无妄之灾：或系之牛，行人之得，邑人之灾。


**原文**：无妄之灾：或系之牛，行人之得，邑人之灾。

**白话**：不妄为却遭灾：有人拴着一头牛，被过路人牵走，村里人却遭了灾（被怀疑）。

**小象传**
**原文**：行人得牛，邑人灾也。

**白话**：路人捡到牛，是村里人的灾祸。


**说明**

这是 无妄的考验——横来之祸。

+ “无妄之灾”：无缘无故（无妄）的灾祸。
场景：有人拴着的牛，被过路的行人牵走了，失主却怪罪同村的人，使他们无辜受灾。
+ 爻传“邑人灾也”：这是村里人的灾祸。

**相关性**：六三阴柔失正，且处震动之极（多凶），象征 自身虽无过错，却因环境、他人或意外因素而遭受无端牵连与灾祸。这就是 “无妄之灾”——并非因自己“妄为”招致，而是命运中无法预料的意外打击。此爻承认，即便恪守“无妄”，人生仍可能遭遇不公与不幸。它提醒我们 世事复杂，福祸无常，但即便如此，也不应改变自己“无妄”的本心。


### 九四：可贞，无咎。


**原文**：可贞，无咎。

**白话**：可以守持正固，没有咎害。

**小象传**
**原文**：“可贞无咎”，固有之也。

**白话**：能够坚守正道而没有灾祸，是因为本来就具备这样的美德。


**说明**

这是 无妄的坚守——固守其正。

+ “可贞”：可以（能够）守持正道（贞）。
+ “无咎”：没有过错。
+ 爻传“固有之也”：因为 （正道）是本身固有的。

**相关性**：九四阳爻居阴位，且逼近九五君位，处境 多惧多疑。在复杂的环境与高位诱惑下，他需要做的不是积极进取，而是 牢牢守住“无妄”的正道（可贞）。爻传“固有之也”强调：“无妄”之道并非外求，而是人心中固有的天理与良知。只要 持守这本有的正念，就能在纷扰中免于咎害。此爻适用于 身处复杂局面，需以“守正”来自保的情形。


### 九五：无妄之疾，勿药有喜。


**原文**：无妄之疾，勿药有喜。

**白话**：不妄为却得了病，不用服药，会有自愈之喜。

**小象传**
**原文**：“无妄之药”，不可试也。

**白话**：没有虚妄却生病时所用的药，不可以轻易尝试。


**说明**

这是 无妄的治国——不治之治。

+ “无妄之疾”：无缘无故（无妄）的疾病（比喻国家意外的、小的弊病）。
+ “勿药有喜”：不必用药（勿药），自有痊愈之喜。
+ 爻传“不可试也”：（药）不可轻易尝试。

**相关性**：九五阳刚中正，居君位，是 “无妄”之德的施行者。国家偶尔出现小问题（无妄之疾），就像人偶尔染上小恙。高明的君主（九五）懂得，只要国家整体运行在“无妄”（至诚、公正）的正道上，这些小问题会像身体有自愈能力一样，自然消解。如果 妄动干戈，滥用“药石”（严刑峻法或激进改革）去干预，反而可能扰乱系统，加重病情（不可试也）。此爻阐述了 “无为而治”的高级形态：以“无妄”之德为根本，信任系统的自我调节能力。


### 上九：无妄，行有眚，无攸利。


**原文**：无妄，行有眚，无攸利。

**白话**：虽不妄为，但行动将有灾祸，无所利益。

**小象传**
**原文**：“无妄之行”，穷之灾也。

**白话**：没有虚妄的行为却遭遇困顿，这是时运穷尽导致的灾祸。


**说明**

这是 无妄的极限——时穷难行。

+ “无妄”：（动机）没有虚妄。
+ “行有眚”：但行动（行）却招致灾祸（眚）。
+ “无攸利”：没有任何利益。
+ 爻传“穷之灾也”：这是 处于穷极之位（上九）所带来的灾祸。

**相关性**：上九阳刚处卦之极，象征 “无妄”之道已发展到尽头，时势已穷。此时，即便个人动机纯正（无妄），但 客观形势已极度不利，任何行动都可能与环境产生剧烈冲突，导致失败与灾祸（行有眚）。这并非“无妄”之道的失败，而是 时运不济。此爻告诫：“无妄”并非万能护身符。在时势穷极、大势已去的情况下，即便心正，也需懂得“止”，不宜强行“有攸往”。这体现了 “识时”的智慧。


## 总结

**总结**：无妄卦的现代启示

无妄卦的 “茂对时育” 是关于 真诚、务实、遵循规律 的行动哲学。

无妄的层次：

+ 初心（初九）：动机至诚，动则吉祥。
+ 心态（六二）：不问收获，只问耕耘，消除对结果的妄念。
+ 意外（六三）：承认 “无妄之灾” 的存在，坦然面对意外。
+ 守成（九四）：在复杂环境中，固守本心正道 以自保。
+ 治国（九五）：以 “无妄”之德为根本，信任系统自愈，不妄加干预。
+ 识时（上九）：懂得 时势穷极则宜止，非心不正，乃时不利。

核心心法：大象传总纲——“天下雷行，物与无妄；先王以茂对时，育万物。” 这意味着：

+ “天下雷行，物与无妄”：天雷震动，遍行天下，万物无不 惊肃、真实地依时生长（不敢虚妄）。
+ “先王以茂对时，育万物”：先王效法此象，勉力（茂）配合天时（对时），养育万物。

其核心是 “对时”：人的行动（育万物）必须与天道运行的时节、规律（时）相配合、相适应。不超前，不滞后，不妄为。这就是 “动而健” 的真谛——行动（动）要遵循（而）天道的刚健法则（健），即自然与社会发展的客观规律。

根本精神：卦辞 “其匪正有眚” 与彖传 “天命不佑，行矣哉” 构成了最严厉的警告。它宣告：“无妄”是“天命”。任何 动机不纯、行为不正（匪正）的“妄为”，都是 对天命的背离，必然招致灾祸（有眚），因为 “天命不佑”。这从宇宙法则的高度，确立了 “至诚务实” 为唯一正确的生存与发展之道。

无妄卦与复卦的承续：复卦（䷗）讲 “一阳来复”（见天地之心），是 正气（阳气）在衰败后重新萌生、回归；无妄卦（䷘）则讲 “动以天行”（茂对时育），是 在正气回归之后，如何秉持这至诚纯正之心去行动、去创造。《序卦传》言：“复则不妄矣，故受之以无妄。” 意思是：回复到正道就不会虚妄了，所以继之以无妄卦。“复”是状态的回归（心正），“无妄”是行动的准则（行正）。从复到无妄，构成了 “心正”而后“行正” 的完整逻辑，是 个人修养与事业发展的连贯过程。
